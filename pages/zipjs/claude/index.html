zip.js 핵심 기능 둘러보기

zip.js는 브라우저에서 ZIP 파일을 만들고 읽는 데 특화된 라이브러리입니다. Reader/Writer 조합으로 데이터 흐름을 다루는 스트림 기반 API가 특징이며, AES 암호화·진행률 콜백처럼 단순 압축 라이브러리에는 잘 없는 기능도 지원합니다.
  • ZipWriter + TextReader로 만드는 다중 파일 ZIP 생성 + 다운로드
  • ZipReader로 하는 ZIP 파일 목록·내용 읽기
  • password 옵션으로 하는 암호화된 ZIP 생성/해제
  • onprogress 콜백으로 보는 압축 진행률
※ 아래 위판 서류 내용은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·기록과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 다중 파일 ZIP 생성 + 다운로드

BlobWriter에 쓰는 ZipWriter를 만들고, add(파일명, Reader)를 여러 번 호출해서 파일을 하나씩 담습니다. 경로에 /가 들어가면 그대로 폴더 구조가 됩니다.
소스 코드 보기 
const zipWriter = new zip.ZipWriter(new zip.BlobWriter());
await zipWriter.add('위판일지/1월.txt', new zip.TextReader('1월 위판 기록...'));
await zipWriter.add('위판일지/2월.txt', new zip.TextReader('2월 위판 기록...'));
await zipWriter.add('조합원명단.txt', new zip.TextReader('홍길동, 김철수, 이영희'));

const zipBlob = await zipWriter.close();   // ZIP 내용이 담긴 Blob
const url = URL.createObjectURL(zipBlob);
// 다운로드

2. ZIP 파일 목록·내용 읽기

바로 위에서 만든 ZIP을 ZipReader로 열어 getEntries()로 항목 목록을 가져오고, 각 항목의 getData(Writer)로 내용을 꺼냅니다.
    소스 코드 보기 
    const zipReader = new zip.ZipReader(new zip.BlobReader(zipBlob));
const entries = await zipReader.getEntries();
// entries[i].filename, entries[i].uncompressedSize, entries[i].directory 등

for (const entry of entries) {
  if (!entry.directory) {
    const text = await entry.getData(new zip.TextWriter());
    console.log(entry.filename, text);
  }
}
await zipReader.close();

    3. 비밀번호로 암호화된 ZIP

    ZipWriter의 password 옵션을 주면 AES로 암호화된 ZIP을 만들 수 있습니다. 읽을 때도 같은 옵션이 필요하며, 비밀번호가 틀리면 getData()가 에러를 던집니다.
    소스 코드 보기 
    const zipWriter = new zip.ZipWriter(new zip.BlobWriter(), { password: 'secret123' });
await zipWriter.add('비밀문서.txt', new zip.TextReader('암호화된 내용입니다'));
const zipBlob = await zipWriter.close();

const zipReader = new zip.ZipReader(new zip.BlobReader(zipBlob));
const entries = await zipReader.getEntries();
try {
  // password는 getData()에 넘겨야 함 (ZipReader 생성자가 아니라)
  const text = await entries[0].getData(new zip.TextWriter(), { password: '틀린비밀번호' });
} catch (e) {
  console.log(e.message); // "Invalid password"
}

    4. 압축 진행률 표시

    큰 파일을 담을 때는 add() 호출의 옵션에 onprogress를 넘기면 진행 상황을 알 수 있습니다. ZipWriter 생성자에 주는 것이 아니라 각 add() 호출마다 따로 지정해야 한다는 점에 유의해야 합니다.
    소스 코드 보기 
    const zipWriter = new zip.ZipWriter(new zip.BlobWriter());

// onprogress는 add()의 옵션 인자로 전달한다 (ZipWriter 생성자 옵션이 아님!)
await zipWriter.add('대용량파일.txt', new zip.TextReader(bigText), {
  onprogress: (progress, total) => {
    console.log(Math.round(100 * progress / total) + '%');
  }
});
await zipWriter.close();
