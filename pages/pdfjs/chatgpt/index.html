이 페이지는 브라우저에서 파일을 읽는다. 단, URL로 불러온 문서는 해당 서버의 CORS 정책을 따르며, 민감한 문서는 승인되지 않은 외부 URL에 올리지 않아야 한다.
PDF.js Feature Lab 사용 안내

이 페이지는 PDF.js의 표시 계층을 직접 사용하는 단일 HTML 예제다. 기본 샘플 PDF는 HTML 내부에 Base64로 내장되어 있으며, 텍스트, 내부/외부 링크, 북마크, 벡터 도형, AcroForm 양식이 포함되어 있다.

문서 로드파일 입력, 드래그앤드롭, URL 로드, 진행률, 암호 입력 처리
렌더링HiDPI canvas, 확대/축소, 회전, 연속/한 쪽 보기, PNG 내보내기
정보 추출메타데이터, 페이지 라벨, 텍스트, 목차, 레이어, 첨부 파일
상호작용텍스트 선택, 검색, 링크 목적지, 기본 AcroForm 위젯, 로컬 책갈피

단일 HTML 구성: 기본 테스트 PDF는 이 파일 안에 내장되어 있다. 다만 PDF.js 라이브러리는 CDN에서 불러온다. 폐쇄망에서 완전 오프라인으로 쓰려면 PDF.js generic build 파일을 별도로 배치하거나 빌드 단계에서 라이브러리까지 인라인해야 한다.

키보드: ←/→ 페이지 이동, Ctrl/Cmd + F 검색 입력, +/− 확대/축소, R 회전, B 현재 페이지 저장.
