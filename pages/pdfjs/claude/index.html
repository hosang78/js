PDF.js 핵심 기능 둘러보기

PDF.js는 Mozilla가 만든 순수 JavaScript PDF 렌더링 엔진입니다. 브라우저 플러그인 없이 PDF를 Canvas에 직접 그리고, 원문 텍스트를 그대로 선택·검색할 수 있는 투명한 텍스트 레이어까지 함께 제공합니다.
  • PDF 페이지를 Canvas에 렌더링, 페이지 이동 지원
  • scale · rotation 옵션으로 확대/축소와 회전
  • 공식 TextLayer 클래스로 만드는 마우스로 드래그 선택 가능한 텍스트
  • 페이지 텍스트를 색인화해 찾은 뒤 좌표를 계산해 그리는 검색어 하이라이트
※ 아래에서 여는 "2026년 상반기 수산물 위판 실적 보고서" PDF는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·조직·절차와 무관합니다. PDF.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 렌더링 + 페이지 이동

getDocument()로 PDF를 불러와 page.render()로 Canvas에 그립니다. 이 보고서는 총 4페이지이며, 버튼으로 페이지를 이동할 수 있습니다.
- / -
코드 보기 
const doc = await pdfjsLib.getDocument({ url: './sample-catch-report.pdf' }).promise;
const page = await doc.getPage(pageNum);          // 1부터 시작
const viewport = page.getViewport({ scale: 1.3 });
canvas.width = viewport.width;
canvas.height = viewport.height;
await page.render({ canvasContext: ctx, viewport, canvas }).promise;

2. 확대/축소 + 회전

getViewport({ scale, rotation })에 넘기는 값만 바꾸면 페이지를 다시 계산해서 그릴 수 있습니다. 회전은 90도 단위로 적용됩니다.
130%
코드 보기 
const viewport = page.getViewport({ scale, rotation });   // rotation: 0, 90, 180, 270
canvas.width = viewport.width;
canvas.height = viewport.height;
await page.render({ canvasContext: ctx, viewport, canvas }).promise;

3. 선택 가능한 텍스트 레이어

Canvas에 그려진 글자는 이미지일 뿐이라 마우스로 선택할 수 없습니다. 공식 pdfjsLib.TextLayer가 투명한 <span>들을 글자 위에 정확히 겹쳐서, 실제로 드래그해 문장을 선택할 수 있게 해줍니다. 아래에서 직접 드래그해보세요.
텍스트 레이어 생성 중...
코드 보기 
const textLayer = new pdfjsLib.TextLayer({
  textContentSource: page.streamTextContent(),
  container: textLayerDiv,
  viewport,
});
await textLayer.render();

// 주의: TextLayer 내부 CSS가 --total-scale-factor 변수로 레이어 크기를 계산하므로
// 렌더링에 쓴 scale과 반드시 똑같이 맞춰줘야 캔버스 글자와 위치가 어긋나지 않는다.
pageWrapEl.style.setProperty('--total-scale-factor', scale);

4. 텍스트 검색 + 하이라이트

검색어를 입력하면 4페이지 전체에서 찾아 노란색으로 표시합니다. 한글은 PDF 안에서 한 글자씩 개별 항목으로 쪼개져 있는 경우가 많아, 페이지 전체 글자를 하나의 문자열로 이어붙인 뒤 그 안에서 찾고 해당 구간을 포함하는 항목들의 위치를 모아 하이라이트 박스를 그립니다.
- / -
코드 보기 
// 페이지의 모든 텍스트 항목을 하나의 문자열로 이어붙이면서, 각 항목이 차지하는
// 문자 구간 [start, end)을 함께 기록해둔다 (한글이 한 글자씩 쪼개져 있어도 안전)
function buildIndex(items) {
  let fullText = '';
  const itemRanges = [];
  items.forEach((item) => {
    const start = fullText.length;
    fullText += item.str;
    itemRanges.push({ start, end: fullText.length, item });
  });
  return { fullText, itemRanges };
}
