LiteGraph.js 핵심 기능 둘러보기

LiteGraph.js는 Rete.js나 Drawflow처럼 노드 기반 흐름을 만드는 라이브러리지만, HTML5 Canvas 위에 자체 렌더러와 실행 엔진을 모두 내장하고 있다는 점이 다릅니다. DOM 요소를 직접 그리지 않고 캔버스에 노드·소켓·연결선·위젯까지 전부 그려줍니다.
  • Canvas 기반 내장 렌더러 — 노드 생성부터 드래그 연결, 캔버스 확대/축소·이동까지 기본 제공
  • graph.start()로 그래프를 매 프레임(기본 60fps)마다 실행하는 실시간 실행 루프 — Rete.js의 "요청 시 계산"과 달리 계속 돌아가는 라이브 시뮬레이션에 가까움
  • 노드 안에 슬라이더·숫자·버튼 같은 위젯을 내장 지원, 데이터 연결과 이벤트(EVENT/ACTION) 연결을 점선/실선으로 구분해서 그려줌
  • 그래프 전체를 JSON으로 직렬화(serialize)하고 복원(configure)
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·절차와 무관합니다. LiteGraph.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 그래프 에디터 (Canvas 내장 렌더러)

"위판장" 노드의 출력 소켓(오른쪽 점)을 "경매장" 노드의 입력 소켓(왼쪽 점)으로 드래그해 연결해보세요. 캔버스 빈 곳을 드래그하면 화면이 이동하고, 마우스 휠로 확대/축소됩니다 — 전부 LiteGraph.js가 기본으로 제공하는 기능입니다.
아직 "위판장" → "경매장" 연결이 없습니다.
코드 보기 
const graph = new LGraph();
const canvas = new LGraphCanvas(canvasEl, graph);  // 렌더러 + 인터랙션이 내장되어 있음

function MarketNode() {
  this.addInput('in', 'number');
  this.addOutput('out', 'number');
}
MarketNode.title = '위판장';
LiteGraph.registerNodeType('custom/market', MarketNode);

const market = LiteGraph.createNode('custom/market');
market.pos = [250, 90];
graph.add(market);

// 소켓을 마우스로 드래그하면 ConnectionPlugin 없이도 바로 연결된다
market.connect(0, auction, 0);   // 코드로 직접 연결할 수도 있음

2. 내장 위젯 + 실시간 실행 루프

슬라이더를 움직여보세요. graph.start()가 매 프레임 그래프 전체를 다시 실행하기 때문에, 별도의 재계산 트리거 없이도 "합계" 노드가 값을 즉시 반영합니다. 합계 노드는 onDrawForeground로 결과 숫자를 캔버스에 직접 그립니다 — Canvas 기반이라 노드 안에 원하는 그래픽을 자유롭게 그릴 수 있습니다.
총 위판량: -
코드 보기 
function BoatNode(title) {
  this.addOutput('catch', 'number');
  this.addWidget('slider', 'kg', 120, (v) => { this.properties.value = v; },
    { min: 0, max: 500, precision: 0 });
  this.properties = { value: 120 };
}
BoatNode.prototype.onExecute = function() {
  this.setOutputData(0, this.properties.value);   // 매 프레임 호출됨
};

function SumNode() {
  this.addInput('a', 'number');
  this.addInput('b', 'number');
  this.addOutput('sum', 'number');
}
SumNode.prototype.onExecute = function() {
  const total = Math.round((this.getInputData(0) || 0) + (this.getInputData(1) || 0));
  this.setOutputData(0, total);
  this._total = total;
};
SumNode.prototype.onDrawForeground = function(ctx) {
  ctx.fillStyle = '#0b6b3a';
  ctx.fillText(this._total + ' kg', 10, this.size[1] - 10);
};

graph.start();  // requestAnimationFrame 루프로 매 프레임 onExecute 호출

3. 이벤트 / 액션 트리거 노드

데이터가 아니라 "신호"를 전달하는 연결입니다. "경매 시작" 버튼을 눌러보세요. 데이터 연결(위 섹션의 실선)과 달리 이벤트 연결은 점선으로 그려지고, 버튼을 누를 때만 신호가 흐릅니다.
아직 경매가 시작되지 않았습니다.
코드 보기 
function AuctionStartNode() {
  this.addOutput('start', LiteGraph.EVENT);         // 이벤트 출력
  this.addWidget('button', '경매 시작', null, () => {
    this.triggerSlot(0);                            // 버튼 클릭 시 신호 발생
  });
}

function AuctionLogNode() {
  this.addInput('trigger', LiteGraph.ACTION);        // 액션 입력
  this.count = 0;
}
AuctionLogNode.prototype.onAction = function(action, param) {
  this.count++;                                      // 신호가 도착할 때만 실행됨
  this.setDirtyCanvas(true);
};

start.connect(0, log, 0);  // EVENT → ACTION 연결은 캔버스에 점선으로 표시된다

4. 직렬화 (serialize / configure)

현재 그래프를 JSON으로 내보낸 뒤, 완전히 새로운 그래프에 그대로 불러와 복원합니다.
원본 그래프
복원된 그래프
아직 내보내지 않았습니다.
코드 보기 
const json = graphA.serialize();          // 그래프 → 직렬화 가능한 객체
localStorage.setItem('flow', JSON.stringify(json));

const restored = JSON.parse(localStorage.getItem('flow'));
graphB.configure(restored);               // 새 그래프에 그대로 복원
