지원 형식과 상태

공식 저장소는 현재 유지보수 모드임을 명시한다. 버전을 고정하고 실제 대상 기기·바코드로 충분히 시험하는 것이 안전하다.

    if (result) console.log(result.getText(), result.getBarcodeFormat());

이 페이지의 구현 범위와 제한

처리 위치
이미지·영상 픽셀과 판독 결과를 서버로 전송하지 않고 현재 브라우저에서 처리
카메라 요구사항
HTTPS 또는 localhost 권장. 모바일 브라우저의 권한 정책과 카메라 구현에 따라 torch·zoom 지원 차이
이미지 URL
외부 서버가 CORS를 허용하지 않으면 Canvas 보안 정책으로 URL 판독 실패 가능
물리 스캐너
USB/HID 바코드 스캐너 제어 기능은 제공하지 않으며, 키보드 입력형 장치는 일반 입력 이벤트로 별도 처리
Micro QR·MaxiCode·RSS
형식별 구현 및 안정성 차이가 있으므로 실제 샘플 검증 필수
오프라인 사용
현재 파일은 CDN에서 라이브러리를 불러옴. 완전 오프라인 환경에서는 JS 파일을 내부 서버나 동일 폴더에 배치하도록 경로 수정 필요
