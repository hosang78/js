ZXing JS 핵심 기능 둘러보기

ZXing JS는 QR 코드·바코드를 이미지나 웹캠 영상에서 읽어내는(디코딩하는) 라이브러리입니다. 유명한 Java용 ZXing 라이브러리를 자바스크립트로 옮긴 것입니다.
  • 이미지 파일이나 <img>/<canvas> 요소에서 코드를 읽어 텍스트로 반환
  • QR 코드 외에도 Data Matrix, Aztec 같은 여러 2차원 코드 포맷을 자동으로 구분해서 인식
  • 인식 결과에는 코드의 위치(모서리 좌표)도 함께 담겨 있어 화면에 표시 가능
  • 웹캠 영상을 계속 읽어서 코드가 나타나는 순간 자동으로 인식(연속 스캔)
※ 아래 QR/바코드 예시는 ZXing JS 학습용으로 만든 가상의 위판 등록번호이며, 실제 수협중앙회의 코드 체계가 아닙니다. 이 페이지는 핵심 라이브러리 @zxing/library(CDN)와 브라우저 전용 API를 제공하는 공식 애드온 @zxing/browser(CDN)를 함께 사용합니다. 다른 외부 API는 사용하지 않습니다.

1. 이미지에서 QR 코드 디코딩

아래는 이 페이지가 직접 만든 예시 QR 코드입니다. "디코딩하기"를 누르면 이미지 안의 텍스트를 읽어옵니다. 직접 이미지를 올려서 시도해볼 수도 있습니다.
아직 디코딩 안 함
내 이미지로 시도:
파일을 선택해보세요.
코드 보기 
const reader = new ZXingBrowser.BrowserQRCodeReader();
const result = await reader.decodeFromImageElement(imgEl);
result.getText(); // 디코딩된 문자열

// 사용자가 올린 파일의 경우
const url = URL.createObjectURL(file);
const result2 = await reader.decodeFromImageUrl(url);

2. 여러 2D 바코드 포맷 자동 인식

같은 등록번호를 QR / Data Matrix / Aztec 세 가지 포맷으로 각각 만들었습니다. 포맷을 지정하지 않아도 BrowserMultiFormatReader가 알아서 어떤 포맷인지 구분해 읽습니다.
QR_CODE
DATA_MATRIX
AZTEC
코드 보기 
const reader = new ZXingBrowser.BrowserMultiFormatReader();
// 포맷을 지정하지 않으면 QR/DataMatrix/Aztec/PDF417 등을 모두 시도해봄
const result = await reader.decodeFromImageElement(someImgEl);
ZXing.BarcodeFormat[result.getBarcodeFormat()]; // 'QR_CODE' | 'DATA_MATRIX' | 'AZTEC' ...

3. 인식 결과의 모서리 좌표 표시

디코딩 결과에는 코드의 위치를 나타내는 좌표들(resultPoints)이 들어 있습니다. QR 코드는 보통 특징점(파인더 패턴) 3곳의 좌표가 담깁니다. "위치 표시하기"를 누르면 이미지 위에 그 위치를 점으로 찍어줍니다.
아직 인식 안 함
코드 보기 
const result = await reader.decodeFromImageElement(imgEl);
const points = result.getResultPoints(); // QR은 보통 3개(파인더 패턴), 포맷에 따라 개수가 다름

points.forEach((p) => {
  ctx.beginPath();
  ctx.arc(p.getX(), p.getY(), 5, 0, Math.PI * 2);
  ctx.fillStyle = 'red';
  ctx.fill();
});

4. 웹캠으로 실시간 스캔

카메라로 QR/바코드를 비추면 실시간으로 인식합니다. 브라우저가 카메라 접근 권한을 요청합니다 (카메라가 없거나 거부하면 안내 메시지가 표시됩니다).
카메라를 시작해보세요.
코드 보기 
const reader = new ZXingBrowser.BrowserMultiFormatReader();

const controls = await reader.decodeFromVideoDevice(
  undefined, // 첫 번째로 찾은 카메라 사용
  videoEl,
  (result, error) => {
    if (result) console.log('인식됨:', result.getText());
    // error는 프레임마다 코드가 안 보일 때도 계속 발생하므로 보통 무시
  },
);

// 스캔 중지
controls.stop();
