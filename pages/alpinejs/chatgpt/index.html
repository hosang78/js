x-ignore 영역
Alpine이 이 하위 트리를 건드리지 않습니다. 외부 에디터·지도 위젯 등에 유용합니다.

            
CSP 환경
일반 빌드는 HTML 속성의 JavaScript 표현식을 처리하기 위해 Function 생성이 필요하다. 엄격한 CSP 환경에서는 공식 @alpinejs/csp 빌드와 외부 함수 추출 방식을 검토해야 합니다.

            
운영 체크
CDN 버전 고정, SRI·내부 배포 검토, x-html 입력 정화, 플러그인 선행 로드, x-cloak CSS 설정이 필요합니다.
