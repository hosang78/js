Alpine.js 핵심 기능 둘러보기

Alpine.js는 HTML 태그의 속성(x-*)만으로 반응형 상태와 상호작용을 붙일 수 있는 가벼운 라이브러리입니다. React/Vue처럼 별도 빌드 과정 없이, 스크립트 태그 하나로 바로 씁니다.
  • x-data로 정의한 상태가 바뀌면 그 상태를 쓰는 화면이 자동으로 다시 그려짐
  • x-model(양방향 바인딩), x-text/x-bind(값 표시)
  • x-show+x-transition으로 조건부 표시와 애니메이션
  • x-for로 배열을 반복 렌더링, Alpine.store로 컴포넌트 간 상태 공유
※ 아래 위판 신청/목록 데이터는 Alpine.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 절차가 아닙니다. 이 페이지는 Alpine.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 반응형 상태 (x-data · x-model · x-text)

어종과 수량을 바꾸면, 별도 이벤트 코드 없이 예상 금액이 즉시 다시 계산됩니다.
어종 수량(kg)
kg × 원 = 원
코드 보기 
<div x-data="{ species: '고등어', prices: {고등어: 3200, ...}, qty: 10 }">
  <select x-model="species">...</select>
  <input type="number" x-model.number="qty" />

  <!-- species나 qty가 바뀌면 아래 값도 자동으로 갱신됨 -->
  <span x-text="(prices[species] * qty).toLocaleString()"></span>원
</div>

2. 조건부 렌더링 + 트랜지션 (x-show · x-transition)

버튼을 누르면 상세 정보 패널이 부드럽게 나타나고 사라집니다.
부산공동어시장
오늘 위판량: 480kg · 참여 조합원: 62명 · 개장 시각: 05:00
코드 보기 
<div x-data="{ open: false }">
  <button x-on:click="open = !open">상세정보</button>

  <div x-show="open" x-transition.duration.300ms>
    ...상세 내용...
  </div>
</div>

3. 목록 렌더링 (x-for)

배열에 항목을 추가·삭제하면 x-for가 화면을 자동으로 다시 그립니다.
위판장이 없습니다.
코드 보기 
<template x-for="market in markets" :key="market.id">
  <div class="list-item">
    <span x-text="market.name + ' · ' + market.volume + 'kg'"></span>
    <button x-on:click="removeMarket(market.id)">삭제</button>
  </div>
</template>

4. 전역 상태 공유 (Alpine.store)

아래 두 패널은 서로 다른 x-data 블록이지만, 같은 Alpine.store를 바라보기 때문에 한쪽에서 즐겨찾기를 누르면 다른 쪽 개수도 함께 바뀝니다.

패널 A — 어종 고르기

패널 B — 즐겨찾기 현황

즐겨찾기 개수: 개
코드 보기 
Alpine.store('favorites', {
  list: [],
  toggle(name) {
    this.list = this.list.includes(name)
      ? this.list.filter((n) => n !== name)
      : [...this.list, name];
  },
});

<!-- 서로 다른 x-data 블록에서도 $store.favorites로 같은 상태를 공유 -->
<span x-on:click="$store.favorites.toggle('고등어')">...</span>
<span x-text="$store.favorites.list.length"></span>
