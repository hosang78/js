Marked 핵심 기능 둘러보기

Marked는 마크다운 문법으로 쓴 글을 HTML로 변환하는 아주 빠른 파서입니다. 깃허브 이슈, 게시판, 메모 앱처럼 "간단한 문법으로 서식 있는 글쓰기"가 필요한 곳에 널리 쓰입니다.
  • marked.parse(text) 한 줄로 마크다운 문자열을 HTML로 변환
  • GitHub에서 쓰는 확장 문법(GFM) — 표, 취소선, 체크리스트 등을 기본 지원
  • marked.use()로 렌더링 규칙(링크, 제목 등)을 원하는 대로 커스터마이즈 가능
  • 주의: Marked는 결과 HTML을 정화(sanitize)하지 않으므로, 사용자 입력을 다룰 땐 별도로 안전 처리가 필요함
※ 아래 위판장 게시글 예시는 Marked 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 게시판이 아닙니다. 이 페이지는 기본적으로 Marked(CDN)를 사용하고, 4번 섹션에서만 DOMPurify(CDN)를 함께 사용해 안전한 렌더링 방법을 보여줍니다.

1. 기본 마크다운 → HTML 변환

왼쪽에 마크다운을 입력하면 오른쪽에 실시간으로 변환됩니다.
렌더링 결과
코드 보기 
const html = marked.parse(markdownText);
previewBox.innerHTML = html;

2. GFM 기능 (표 · 체크리스트 · 취소선)

GitHub에서 쓰는 확장 문법입니다. Marked는 기본적으로 GFM이 켜져 있습니다.
렌더링 결과
코드 보기 
marked.parse(text, { gfm: true }); // gfm은 기본값이 true

3. 커스텀 렌더러

기본은 평범한 <a>/<h2>를 만들지만, 커스텀 렌더러를 등록하면 모든 링크에 target="_blank"를 붙이고, 제목마다 앵커용 id를 자동으로 넣을 수 있습니다.
기본 렌더러
커스텀 렌더러 (링크 target=_blank, 제목에 id)
코드 보기 
const customMarked = new marked.Marked().use({
  renderer: {
    link({ href, title, tokens }) {
      const text = this.parser.parseInline(tokens);
      return `<a href="${href}" target="_blank" rel="noopener noreferrer">${text}</a>`;
    },
    heading({ tokens, depth }) {
      const text = this.parser.parseInline(tokens);
      const id = text.toLowerCase().replace(/\s+/g, '-');
      return `<h${depth} id="${id}">${text}</h${depth}>`;
    },
  },
});

4. 실용 예시 — 안전한 렌더링 (Marked + DOMPurify)

※ 이 섹션은 Marked 외에 DOMPurify도 함께 사용합니다.
마크다운 안에는 순수 HTML도 그대로 쓸 수 있는데, Marked는 이를 정화하지 않고 그대로 통과시킵니다. 사용자가 올린 글을 게시판에 보여줄 땐 DOMPurify로 한번 더 정화한 뒤 렌더링해야 안전합니다. 아래는 일부러 위험한 코드를 섞은 예시입니다.
Marked 변환 직후 HTML (정화 전 · 텍스트로만 표시, 실행 안 됨)
DOMPurify로 정화 후 실제 렌더링
코드 보기 
const rawHtml = marked.parse(markdownText);   // Marked: 위험한 태그도 그대로 통과됨
const safeHtml = DOMPurify.sanitize(rawHtml); // DOMPurify: script/onerror 등 제거
postBox.innerHTML = safeHtml; // 정화된 결과만 렌더링
