Leaflet 핵심 기능 둘러보기

Leaflet은 웹에서 가장 널리 쓰이는 경량 지도 라이브러리입니다. 가볍고 플러그인 생태계가 풍부해 OpenStreetMap 기반 서비스는 물론, 실내 지도·게임 맵 같은 비(非)지리 좌표 지도에도 자주 쓰입니다.
  • L.map(el)으로 지도를 만들고 L.marker().bindPopup()로 마커+팝업 추가
  • L.circle/rectangle/polygon으로 벡터 도형을 그리고 색상·굵기 등 스타일 지정
  • L.geoJSON(data)로 GeoJSON을 바로 레이어로 변환, onEachFeature로 개별 상호작용 추가
  • L.control.layers()로 레이어를 켜고 끄는 UI, map.on('zoomend', ...)로 지도 이벤트 감지
※ 이 샌드박스 환경에서는 실제 지도 타일 서버(OpenStreetMap 등)로 네트워크 접근이 막혀 있어, 대신 가상 위판장 배치도 이미지를 L.CRS.Simple + L.imageOverlay로 띄워 같은 지도 API를 그대로 확인합니다. 실제 서비스라면 이 자리에 L.tileLayer('https://.../{z}/{x}/{y}.png')로 진짜 지도 타일을 넣으면 됩니다 — 마커·도형·GeoJSON·이벤트 코드는 완전히 동일하게 동작합니다. 배치도는 가상의 예시이며 실제 수협중앙회의 시설이 아닙니다.

1. 마커 + 팝업

배치도 위 각 구역에 마커를 찍었습니다. 마커를 클릭하면 팝업이 뜹니다.
코드 보기 
const map = L.map('map1', { crs: L.CRS.Simple, minZoom: -2 });
L.imageOverlay('floorplan.png', bounds).addTo(map);
L.marker(toLatLng(190, 140)).addTo(map).bindPopup('1구역 - 활어 보관');

2. 벡터 도형 (원·사각형·다각형)

주차장 구역 위에 원·사각형·다각형으로 임시 구역을 표시했습니다.
코드 보기 
L.circle(toLatLng(200, 560), { radius: 50, color: '#e0524a', fillOpacity: 0.3 }).addTo(map);
L.rectangle([toLatLng(650, 620), toLatLng(850, 540)], { color: '#4f7dff' }).addTo(map);
L.polygon([toLatLng(900,550), toLatLng(970,550), toLatLng(970,700), toLatLng(900,700)]).addTo(map);

3. GeoJSON 레이어 + 마우스오버 스타일

GeoJSON으로 정의한 가상 조업구역 위에 마우스를 올리면 채우기 투명도가 진해집니다.
코드 보기 
L.geoJSON(geoData, {
  style: { color: '#22c07a', fillOpacity: 0.2 },
  onEachFeature: (feature, layer) => {
    layer.bindTooltip(feature.properties.name);
    layer.on('mouseover', () => layer.setStyle({ fillOpacity: 0.6 }));
    layer.on('mouseout', () => layer.setStyle({ fillOpacity: 0.2 }));
  },
}).addTo(map);

4. 레이어 컨트롤 + 줌 이벤트

오른쪽 위 레이어 아이콘으로 구역 표시를 켜고 끌 수 있습니다. 확대/축소할 때마다 실제 줌 레벨이 아래에 표시됩니다.
줌 레벨: -
코드 보기 
L.control.layers(null, { '조업구역 A': geoLayer, '보관 구역': zoneLayer }).addTo(map);
map.on('zoomend', () => {
  document.getElementById('output4').textContent = '줌 레벨: ' + map.getZoom();
});
