IMask 핵심 기능 둘러보기

IMask는 별도 의존성이 없는 순수 자바스크립트 입력 마스킹(input mask) 라이브러리입니다. 사용자가 입력창에 타이핑하는 즉시 지정한 형식(전화번호, 통화, 날짜 등)에 맞춰 값을 자동으로 정리해줍니다.
  • 고정된 패턴 마스크(예: 000-00-00000)
  • 천단위 콤마·최소/최대값이 있는 숫자 마스크
  • 입력값에 따라 여러 패턴 중 알맞은 것을 자동으로 고르는 동적(dynamic) 마스크
  • 달력 유효성까지 검사하는 날짜 마스크
  • value/unmaskedValue/typedValue 세 가지 값 형태를 실시간으로 비교
※ 아래 사업자등록번호·단가·전화번호·등록일은 이 페이지를 위해 만든 가상의 예시 입력값이며, 실제 수협중앙회 조합원 정보와 무관합니다. IMask(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 패턴 마스크

가상 위판장 사업자등록번호 형식(000-00-00000)입니다. 숫자만 입력해도 하이픈이 자동으로 채워집니다.
코드 보기 
IMask(document.getElementById("i1"), {
  mask: "000-00-00000"
});

2. 숫자 마스크 (천단위 콤마)

가상 위판 단가(원/kg)입니다. 천 단위마다 콤마가 자동으로 붙고, 0~1,000,000 범위를 벗어나는 값은 입력되지 않습니다.
코드 보기 
IMask(document.getElementById("i2"), {
  mask: Number,
  thousandsSeparator: ",",
  scale: 0,
  signed: false,
  min: 0,
  max: 1000000
});

3. 동적 마스크 — 전화번호 자동 판별

숫자만 입력하면 앞자리에 따라 휴대전화(010-0000-0000), 서울 지역전화(02-000-0000), 그 외 지역전화(000-000-0000) 형식 중 알맞은 것을 자동으로 골라줍니다.
코드 보기 
IMask(document.getElementById("i3"), {
  mask: [
    { mask: "000-0000-0000", startsWith: "01" },
    { mask: "00-000-0000", startsWith: "02" },
    { mask: "000-000-0000" }
  ],
  dispatch: (appended, dynamicMasked) => {
    const num = (dynamicMasked.value + appended).replace(/\D/g, "");
    if (num.indexOf("02") === 0) return dynamicMasked.compiledMasks[1];
    if (num.indexOf("01") === 0) return dynamicMasked.compiledMasks[0];
    return dynamicMasked.compiledMasks[2];
  }
});

4. 날짜 마스크

가상 조합원 등록일입니다(2015-01-01 ~ 2035-12-31). 실제로 없는 날짜(예: 13월, 32일)는 입력되지 않습니다.
코드 보기 
IMask(document.getElementById("i4"), {
  mask: Date,
  min: new Date(2015, 0, 1),
  max: new Date(2035, 11, 31)
});
// 참고: blocks/pattern을 직접 지정해 Y·m·d를 커스텀 MaskedRange로
// 재정의하면(예: blocks:{Y:{...},m:{...},d:{...}}) 완전한 날짜를
// 입력해도 마지막 한 글자가 씹히는 현상을 실제로 확인했습니다(IMask
// 7.6.1). min/max만 지정하고 기본 blocks를 그대로 쓰면 정상 동작합니다.

5. value / unmaskedValue / typedValue 비교

같은 입력값이라도 세 가지 형태로 읽을 수 있습니다: 화면에 보이는 value, 구분자를 뺀 순수 숫자 unmaskedValue, 실제 자바스크립트 타입(숫자)인 typedValue. 완성 여부도 함께 표시합니다.
코드 보기 
const mask5 = IMask(document.getElementById("i5"), {
  mask: Number,
  thousandsSeparator: ",",
  scale: 0,
  min: 0,
  max: 9999
});

mask5.on("accept", () => {
  console.log(mask5.value);          // "1,234" (화면 표시용 문자열)
  console.log(mask5.unmaskedValue);  // "1234"  (구분자 제거)
  console.log(mask5.typedValue);     // 1234    (실제 number 타입)
  console.log(mask5.masked.isComplete); // 4자리를 다 채웠는지 여부
});
