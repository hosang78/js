IMask 7.6.1 · Vanilla JavaScript

입력 마스크의
거의 모든 기능을 한 화면에서

Pattern, RegExp, Function, Number, Date, Range, Enum, Dynamic, 반복 블록, 보안 입력, 이벤트, Pipe, Model API까지 직접 입력하고 값을 비교할 수 있는 단일 HTML 데모다.

모든 입력은 type="text" 마스킹값·원본값·타입값 동시 표시 검색·분류·다크모드 공식 CDN + 대체 CDN
IMask 라이브러리를 불러오지 못했다. 인터넷 연결 또는 CDN 접근 허용 여부를 확인해줘.

FUNCTION06

함수형 검증 마스크

예: 013579 가능 · 12321 불가

value-
unmasked-
typed-
코드 보기

  value.split('').every((ch, i) =>
    !value[i - 1] || value[i - 1] < ch
  )
