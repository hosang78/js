Prism.js 핵심 기능 둘러보기

Prism.js는 CodeMirror·Monaco 같은 편집 가능한 에디터와 달리, 이미 있는 코드를 읽기 전용으로 예쁘게 색칠해 보여주는 가벼운 문법 강조기입니다. 블로그 글이나 문서 안의 코드 블록에 흔히 쓰입니다.
  • <pre><code class="language-xxx"> 구조에 Prism.highlightAll() 한 번이면 페이지의 모든 코드 블록이 강조됨
  • 핵심(core)에는 JavaScript/CSS/HTML만 내장되어 있고, 나머지 언어는 autoloader 플러그인이 필요할 때마다 CDN에서 자동으로 내려받음
  • line-numbers 플러그인으로 줄 번호, line-highlight 플러그인으로 특정 줄 강조
  • toolbar + copy-to-clipboard 플러그인으로 코드 블록에 복사 버튼 추가 (코드 블록에 마우스를 올리면 우측 상단에 나타남)
※ 이 페이지의 코드 예시(어획 보고, 위판 시세 조회 등)는 모두 가상의 예시이며 실제 수협중앙회의 시스템 코드가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 문법 강조 + 언어 전환 (autoloader)

JavaScript/CSS는 core에 내장되어 있지만, SQL은 core에 없어서 autoloader가 처음 클릭 시 CDN에서 문법 파일을 내려받습니다(느리게 뜨는 것이 정상입니다).
function catchReport(species, weight) {
  return `${species}: ${weight}kg 위판(가상)`;
}
코드 보기 
// 코어에 없는 언어는 autoloader 플러그인이 자동으로 불러옴
<script src="prism.js"></script>
<script src="plugins/autoloader/prism-autoloader.js"></script>

codeEl.className = 'language-sql';
codeEl.textContent = 'SELECT * FROM records;';
Prism.highlightElement(codeEl); // 필요하면 prism-sql.js를 자동으로 fetch

2. 줄 번호 (line-numbers)

<pre class="line-numbers">만 추가하면 자동으로 줄 번호가 붙습니다.
const records = [
  { species: '고등어', weight: 320 },
  { species: '갈치', weight: 180 },
];
const total = records.reduce((sum, r) => sum + r.weight, 0);
코드 보기 
<pre class="line-numbers"><code class="language-javascript">
...
</code></pre>

3. 특정 줄 강조 (line-highlight)

data-line 속성에 강조할 줄 번호를 지정합니다.
function auctionPrice(species) {
  if (species === '고등어') return 4200; // 이 줄 강조
  if (species === '갈치') return 3100;
  // 4~5번째 줄도 강조됨
  return null;
}
코드 보기 
<pre data-line="2,4-5"><code class="language-javascript">
...
</code></pre>

4. 툴바 + 복사 버튼

코드 블록에 마우스를 올리면 우측 상단에 "Copy" 버튼이 나타납니다.
console.log('위판 공지(가상): 05시 개장');
코드 보기 
<script src="plugins/toolbar/prism-toolbar.js"></script>
<script src="plugins/copy-to-clipboard/prism-copy-to-clipboard.js"></script>
// 별도 설정 없이 자동으로 모든 코드 블록에 복사 버튼이 추가됨
