2. 시트 탐색 및 셀 검사

셀을 클릭하면 SheetJS Cell Object의 핵심 속성을 확인하고 값·수식·표시 형식을 바꿀 수 있습니다.

선택된 셀 없음
시트의 셀을 클릭하세요.
수식은 앞의 = 없이 입력합니다. SheetJS는 수식 저장을 담당하며, 계산은 Excel 등 스프레드시트 앱에서 수행됩니다.

3. 시트 및 워크북 조작

`book_append_sheet`, 시트 객체 메타데이터, 복사와 재명명 흐름을 실습합니다.

숨김 시트는 파일 안에는 유지됩니다. 이 페이지에서는 확인을 위해 숨김 시트도 탭으로 표시합니다.

4. 시트 기능 적용

현재 선택 시트에 병합, 필터, 링크, 주석, 열 폭, 보호 속성을 적용합니다.

보호 비밀번호는 Excel 호환 XOR 난독화 수준이며, 민감한 데이터 보호 수단으로 사용하면 안 됩니다.

6. 데이터 추출 및 내보내기

파일 형식별 다운로드와 브라우저 Blob 기반 저장을 확인합니다.

중요: SheetJS CE는 데이터와 숫자 표시 형식 중심입니다. CSS 기반의 셀 스타일, 차트, 피벗테이블 등 Excel 고급 시각 기능은 Community Edition 범위 밖이거나 원본 파일 보존 수준으로 제한될 수 있습니다.
브라우저 환경에서 파일 선택은 File API를 이용하며, `readFile`은 브라우저 보안 제약으로 일반적으로 사용할 수 없습니다.

7. 워크북·시트 메타데이터

문서 속성, 정의된 이름, 선택 시트 속성을 확인합니다.

8. JSON 미리보기 및 실행 로그

`sheet_to_json` 및 `sheet_to_formulae` 결과와 실행 이력을 확인합니다.
