SheetJS CE 핵심 기능 둘러보기

SheetJS CE(Community Edition, 예전 이름 "xlsx")는 브라우저에서 서버 없이 엑셀 파일을 읽고 쓸 수 있게 해주는 라이브러리입니다. 표 형태 데이터를 다루는 거의 모든 화면(다운로드/업로드, 일괄 등록 등)에 쓰입니다.
  • 엑셀(.xlsx) 파일을 선택하면 내용을 파싱해서 JS 배열/JSON으로 바로 사용 가능
  • JS 배열(JSON)을 엑셀 파일로 만들어 바로 다운로드 가능
  • 워크북 하나에 여러 시트(sheet)를 담아 내보낼 수 있음
  • CSV 텍스트 ↔ 표 데이터 상호 변환 가능
※ 아래 위판 실적 데이터는 SheetJS 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 통계가 아닙니다. 이 페이지는 SheetJS CE(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다. 업로드한 파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다.

1. 엑셀 파일 읽기

.xlsx 파일을 선택하면 첫 번째 시트 내용을 파싱해서 아래에 표로 보여줍니다.
파일을 선택해보세요.
코드 보기 
const buf = await file.arrayBuffer();
const workbook = XLSX.read(buf);
const firstSheet = workbook.Sheets[workbook.SheetNames[0]];
const rows = XLSX.utils.sheet_to_json(firstSheet); // [{컬럼명: 값, ...}, ...]

2. 표 데이터 → 엑셀 다운로드

아래 가상의 "위판 실적" 표를 엑셀 파일로 내보냅니다.
코드 보기 
const sheet = XLSX.utils.json_to_sheet(rows); // JSON 배열 -> 시트
const workbook = XLSX.utils.book_new();
XLSX.utils.book_append_sheet(workbook, sheet, '위판실적');
XLSX.writeFile(workbook, '위판실적.xlsx');

3. 여러 시트로 내보내기

같은 데이터를 위판장별로 나눠서, 워크북 하나에 시트 여러 개로 담아 내보냅니다.
버튼을 누르면 위판장 수만큼 시트가 담긴 엑셀 파일이 만들어집니다.
코드 보기 
const workbook = XLSX.utils.book_new();
for (const market of markets) {
  const marketRows = rows.filter((r) => r.위판장 === market);
  const sheet = XLSX.utils.json_to_sheet(marketRows);
  XLSX.utils.book_append_sheet(workbook, sheet, market.slice(0, 31)); // 시트명 31자 제한
}
XLSX.writeFile(workbook, '위판장별_실적.xlsx');

4. CSV 붙여넣기 → 표 변환

CSV 텍스트를 붙여넣고 "변환"을 누르면 표로 보여주고, 엑셀로도 저장할 수 있습니다.
코드 보기 
const workbook = XLSX.read(csvText, { type: 'string' });
const sheet = workbook.Sheets[workbook.SheetNames[0]];
const rows = XLSX.utils.sheet_to_json(sheet);
