Split.js 핵심 기능 둘러보기

Split.js는 화면을 드래그 가능한 여러 영역으로 나눠주는 아주 가벼운(약 2KB) 라이브러리입니다. 프레임워크 의존성이 없고, 순수 CSS(flex)와 소량의 JS로 리사이즈 가능한 분할 레이아웃을 만듭니다.
  • 기본 Split([...]) 호출로 만드는 수평 분할(좌우)
  • direction: 'vertical'로 만드는 수직 분할(상하)
  • 수평·수직 분할을 겹쳐 쓰는 중첩 분할(IDE 스타일 레이아웃)
  • setSizes() / getSizes() / collapse()로 하는 크기 제어
※ 아래 패널 이름과 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면·통계와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 수평 분할

가운데 회색 막대(gutter)를 드래그해서 좌우 패널의 너비 비율을 바꿔보세요. minSize로 최소 너비를 지정해 패널이 너무 좁아지지 않게 막습니다.

위판장 목록

A위판장부산
B위판장포항
C위판장여수
D위판장속초

상세 정보

왼쪽 목록에서 위판장을 고르면 이 영역에 최근 위판 현황, 참여 조합원 수 같은 상세 정보가 표시된다고 가정한 자리입니다. (가상 예시)

코드 보기 
Split(['#split1-a', '#split1-b'], {
  sizes: [38, 62],
  minSize: 120,
  gutterSize: 8,
});

2. 수직 분할

direction: 'vertical'을 주면 좌우 대신 위아래로 나뉘고, gutter도 상하 드래그(row-resize) 커서로 바뀝니다.

3. 중첩 분할 — IDE 스타일 레이아웃

수평 분할 안에 수직 분할을 한 번 더 넣어, 코드 에디터 같은 "사이드바 + 메인/로그" 레이아웃을 만들 수 있습니다. 세 영역 모두 독립적으로 드래그해서 크기를 조절해보세요.

사이드바

위판 현황
시세 조회
조합원 명부

메인 영역

오늘 위판량: 4,820kg · 평균가 4,200원/kg (가상 예시)

로그

10:02위판 등록 완료
10:15정산 처리 완료
코드 보기 
// 바깥쪽: 사이드바 | 메인래퍼 (수평)
Split(['#split3-side', '#split3-main-wrap'], {
  sizes: [25, 75],
  minSize: [80, 240],
  gutterSize: 8,
});

// 안쪽: 메인래퍼 내부를 다시 상/하로 (수직)
Split(['#split3-top', '#split3-bottom'], {
  direction: 'vertical',
  sizes: [65, 35],
  minSize: 50,
  gutterSize: 8,
});

4. setSizes / getSizes / collapse로 하는 크기 제어

버튼으로 직접 비율을 지정하거나 왼쪽 패널을 완전히 접을 수 있습니다. 드래그를 멈출 때마다 onDragEnd 콜백으로 현재 비율을 읽어와 아래 상태 박스에 표시합니다.

유통 현황

가상의 유통 물량 데이터가 표시되는 자리입니다.

정산 현황

가상의 정산 내역이 표시되는 자리입니다.

현재 비율: 50% / 50%
코드 보기 
const split4 = Split(['#split4-a', '#split4-b'], {
  sizes: [50, 50],
  minSize: 0,          // collapse()로 0까지 줄이려면 minSize를 0으로 둔다
  gutterSize: 8,
  onDragEnd: (sizes) => updateStat(sizes),
});

s4_5050.addEventListener('click', () => { split4.setSizes([50, 50]); updateStat(split4.getSizes()); });
s4_2080.addEventListener('click', () => { split4.setSizes([20, 80]); updateStat(split4.getSizes()); });
s4_collapse.addEventListener('click', () => { split4.collapse(0); updateStat(split4.getSizes()); });
