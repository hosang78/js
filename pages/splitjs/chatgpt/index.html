10. 핵심 코드

가장 일반적인 초기화 구조입니다.

const split = Split(['#left', '#right'], { sizes: [30, 70], minSize: [120, 180], gutterSize: 10, gutterAlign: 'center', snapOffset: 30, dragInterval: 1, direction: 'horizontal', onDragStart(sizes) { console.log('start', sizes); }, onDrag(sizes) { console.log('drag', sizes); }, onDragEnd(sizes) { console.log('end', sizes); } }); split.setSizes([40, 60]); console.log(split.getSizes()); split.collapse(0); split.destroy();
브라우저에서 파일을 열면 바로 실행됩니다. 최초 실행에는 CDN 연결이 필요합니다.
