i18next 핵심 기능 둘러보기

i18next는 웹페이지의 문구를 여러 언어로 관리하고, 상황에 맞게 실시간으로 전환해 보여주는 국제화(i18n) 라이브러리입니다.
  • 언어별 번역 리소스를 init()에 등록하고, t('key')로 해당 언어 문구를 조회
  • {{변수}} 문법으로 번역문 안에 값을 끼워넣는 보간(interpolation)
  • count 값에 따라 key_one / key_other를 자동으로 골라주는 복수형 처리
  • changeLanguage() 한 번으로 페이지 전체의 언어를 즉시 전환
※ 이 페이지의 한국어·영어·일본어 번역 문구는 모두 가상의 예시이며, 실제 수협중앙회의 다국어 공지·번역 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.
언어 전환: — 아래 모든 섹션이 함께 바뀝니다 (changeLanguage 데모, 4번 참고)

1. 기본 초기화 + 번역 (t 함수)

t('notice')로 현재 언어에 맞는 문구를 가져옵니다.
코드 보기 
await i18next.init({
  lng: 'ko',
  fallbackLng: 'en',
  resources: {
    ko: { translation: { notice: '금일 위판 공지' } },
    en: { translation: { notice: "Today's Auction Notice" } },
    ja: { translation: { notice: '本日の入札公告' } },
  },
});

i18next.t('notice');

2. 보간(interpolation)

이름을 입력하면 {{name}} 자리에 그대로 끼워져 번역문이 완성됩니다.
코드 보기 
// resources: { greeting: '안녕하세요, {{name}}님' }
i18next.t('greeting', { name: '수협' });
// => "안녕하세요, 수협님"

3. 복수형(pluralization)

물품 개수를 바꿔보면, 값에 따라 itemCount_one / itemCount_other 중 알맞은 번역이 자동으로 선택됩니다.
코드 보기 
// resources: {
//   itemCount_one: '위판 물품이 {{count}}건 있습니다',
//   itemCount_other: '위판 물품이 {{count}}건 있습니다',
// }
i18next.t('itemCount', { count: 1 }); // count 값으로 _one/_other 자동 선택

4. changeLanguage()로 런타임 언어 전환

상단의 언어 버튼을 누르면 changeLanguage()가 호출되어 이 페이지의 1~3번 섹션이 모두 즉시 갱신됩니다.
현재 언어: ko
코드 보기 
await i18next.changeLanguage('en');
i18next.language; // 'en'
i18next.t('notice'); // 이후 t() 호출은 모두 새 언어로 반환됨
