proj4js 핵심 기능 둘러보기

proj4js는 지도를 그리지 않고, 서로 다른 좌표계 사이에서 좌표값 자체를 순수하게 변환해주는 라이브러리입니다. OpenLayers·CesiumJS 같은 지도 라이브러리가 내부적으로 쓰는 것과 같은 종류의 변환 계산을 직접 다룰 수 있습니다.
  • proj4(fromEPSG, toEPSG, [x, y]) 한 줄로 두 좌표계 사이를 즉시 변환
  • proj4.defs()로 라이브러리에 기본 내장되지 않은 좌표계를 직접 정의(국가별 측량 좌표계 등)
  • .forward() / .inverse()로 정변환·역변환, 원래 좌표로 돌아오는지 검증 가능
  • 변환기(converter) 객체를 한 번 만들어두고 여러 점에 재사용 — 매번 좌표계 문자열을 다시 넘길 필요 없음
※ 좌표계는 EPSG:5179(Korea 2000 / Unified CS, 국토지리정보원이 실제 사용하는 국내 좌표계 정의)를 사용했습니다 — 좌표계 정의 자체는 실제 표준이지만, 입력하는 위경도 값은 모두 가상의 예시이며 실제 위판장 위치가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 좌표 변환 (WGS84 → Web Mercator)

위경도(EPSG:4326)를 웹 지도에서 흔히 쓰는 Web Mercator(EPSG:3857)로 변환합니다.
아직 변환 안 함
코드 보기 
proj4('EPSG:4326', 'EPSG:3857', [129.0756, 35.0951]);
// => [14368630.07, 4176812.38]

2. 커스텀 좌표계 정의 (EPSG:5179)

proj4js에 기본 내장되지 않은 국내 좌표계를 proj4.defs()로 직접 정의한 뒤 변환합니다.
아직 변환 안 함
코드 보기 
proj4.defs(
  'EPSG:5179',
  '+proj=tmerc +lat_0=38 +lon_0=127.5 +k=0.9996 +x_0=1000000 +y_0=2000000 +ellps=GRS80 +units=m +no_defs'
);
proj4('EPSG:4326', 'EPSG:5179', [129.0756, 35.0951]);

3. 역변환(inverse) — 라운드트립 확인

2번에서 변환한 EPSG:5179 좌표를 다시 위경도로 되돌려, 원래 값과 일치하는지 확인합니다.
먼저 2번에서 변환을 실행해주세요
코드 보기 
const converter = proj4('EPSG:4326', 'EPSG:5179');
const forward = converter.forward([129.0756, 35.0951]);
const back = converter.inverse(forward);
// back은 원래 [129.0756, 35.0951]과 (부동소수점 오차 범위 내에서) 동일

4. 변환기 재사용 — 여러 점 일괄 변환

변환기 객체를 한 번만 만들어두고, 위판장 3곳의 좌표를 한 번에 변환합니다.
지점(가상)경도위도Web Mercator XWeb Mercator Y
코드 보기 
const converter = proj4('EPSG:4326', 'EPSG:3857'); // 한 번만 생성
const results = points.map((p) => converter.forward(p)); // 여러 점에 재사용
