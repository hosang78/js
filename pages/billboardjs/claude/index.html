Billboard.js 핵심 기능 둘러보기

Billboard.js는 D3.js 위에서 동작하는 재사용 가능한 차트 라이브러리로(네이버 제작, C3.js의 후속작), 하나의 옵션 객체로 다양한 차트 타입을 조합하고 확대/축소·구간 강조·실시간 갱신 같은 기능을 켤 수 있습니다.
  • data.types로 계열마다 다르게 지정하는 차트 타입 결합(막대+라인)
  • 드래그 확대/축소(zoom) + 하단 서브차트 내비게이터(subchart)
  • regions로 그리는 특정 구간 강조
  • chart.load()로 만드는 실시간 스트리밍 슬라이딩 윈도우
※ 아래 위판량 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Billboard.js(CDN, D3 포함 번들) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 차트 타입 결합 (막대 + 라인)

같은 y축을 공유하는 일별 위판량(막대)과 7일 이동평균(라인)을 한 차트에 그렸습니다. data.types에 계열별로 타입을 다르게 지정하면 됩니다.
코드 보기 
bb.generate({
  bindto: '#chart1',
  data: {
    x: 'x',
    columns: [
      ['x', ...dates],
      ['위판량', ...values],
      ['7일 이동평균', ...movingAvg],
    ],
    types: { 위판량: 'bar', '7일 이동평균': 'line' },
    colors: { 위판량: '#2a78d6', '7일 이동평균': '#eda100' },
  },
  axis: { x: { type: 'timeseries', tick: { format: '%m/%d' } } },
});

2. 드래그 확대/축소 + 서브차트 내비게이터

메인 차트를 드래그하면 그 구간으로 확대됩니다. 하단의 작은 서브차트에서 양 끝 손잡이를 움직이면 메인 차트가 그 구간에 맞춰 다시 그려집니다.
코드 보기 
bb.generate({
  bindto: '#chart2',
  data: { x: 'x', columns: [ ['x', ...dates], ['A위판장', ...a], ['B위판장', ...b], ['C위판장', ...c] ] },
  zoom: { enabled: true, type: 'drag' },
  subchart: { show: true, size: { height: 40 } },
  axis: { x: { type: 'timeseries', tick: { format: '%m/%d' } } },
});

3. 구간 강조(Regions)

성수기로 지정한 기간을 regions로 옅게 칠해 표시했습니다. 특정 기간을 한눈에 강조하고 싶을 때 유용합니다.
코드 보기 
bb.generate({
  bindto: '#chart3',
  data: { x: 'x', columns: [ ['x', ...dates], ['위판량', ...values] ], types: { 위판량: 'area-spline' } },
  regions: [
    { axis: 'x', start: peakStart, end: peakEnd, class: 'peak-season',
      label: { text: '성수기', center: 'xy' } },
  ],
  axis: { x: { type: 'timeseries', tick: { format: '%m/%d' } } },
});

4. 실시간 스트리밍 갱신

1초마다 새 값 하나를 추가하고 가장 오래된 값은 버려서, 항상 최근 20일 창을 유지합니다.
스트리밍 대기 중...
코드 보기 
// 새 값 하나를 뒤에 붙이고 가장 오래된 값 하나를 버린 "20일 창" 배열을 만들어
// 매번 통째로 load() 한다.
//
// billboard.js는 데이터 일부만 이어붙이는 chart.flow()도 제공하지만, 이 버전(4.0.3)의
// 팩키지드(all-in-one) 빌드에서는 timeseries 축 + flow()를 함께 쓰면 내부 날짜 파서가
// 간헐적으로 실패해 화면이 갱신되지 않는 문제가 있어(콘솔에도 "Failed to parse x" 경고가
// 남음), 매번 전체 윈도우를 다시 넘기는 load() 방식으로 우회했다.
dates = [...dates.slice(1), nextDateStr];
values = [...values.slice(1), nextValue];
chart.load({ columns: [['x', ...dates], ['위판량', ...values]] });
