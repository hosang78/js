매출은 막대, 가입자는 라인, 전환율은 y2 축 영역 차트로 표시합니다. 드래그 줌, 하단 서브차트, 특정 구간 강조, x/y 그리드, 툴팁 포맷을 함께 적용했습니다.

-가입자 합계
-평균 전환율
-최고 매출 월

날짜 컬럼을 x축으로 사용하고, 라인/스플라인/영역을 섞어 추세를 표현합니다.

11. 핵심 코드 패턴

Billboard.js는 bb.generate()로 차트를 생성하고, 생성된 chart 객체의 API로 데이터를 로드·숨김·전환·줌 처리합니다.

const chart = bb.generate({
  bindto: '#chart',
  data: {
    columns: [['매출', 30, 120, 90], ['가입자', 50, 80, 140]],
    types: { '매출': 'bar', '가입자': 'line' },
    axes: { '가입자': 'y2' }
  },
  axis: { y2: { show: true } },
  zoom: { enabled: true },
  subchart: { show: true }
});

chart.load({ columns: [['신규', 20, 40, 70]] });
chart.unload({ ids: ['신규'] });
chart.transform('area-spline', '가입자');
chart.hide(['매출']);
chart.show(['매출']);

참고: 이 샘플은 CDN을 사용하므로 인터넷이 연결된 환경에서 바로 실행됩니다. 내부망/폐쇄망에서는 billboard.js CSS/JS 파일을 내려받아 같은 폴더에 두고 링크 경로만 로컬 파일명으로 바꾸면 됩니다.
