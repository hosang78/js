PixiJS 핵심 기능 둘러보기

PixiJS는 WebGL을 활용하는 빠른 2D 렌더링 라이브러리입니다. Canvas 2D API보다 훨씬 많은 오브젝트를 부드럽게 다룰 수 있어 게임·인터랙티브 그래픽에 널리 쓰입니다.
  • await app.init({...})로 초기화(v8부터 비동기) 후 app.stage에 오브젝트 추가
  • new Graphics().rect(...).fill(색상) 같은 체이닝 방식으로 도형을 그림
  • app.ticker.add(fn)으로 매 프레임 호출되는 애니메이션 등록
  • obj.eventMode = 'static'로 지정하면 클릭·호버 같은 포인터 이벤트 사용 가능
  • obj.filters = [new BlurFilter(), ...]로 내장 필터 효과 적용
※ 이 페이지의 위판 구역 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 도형(Graphics) + Ticker 애니메이션

사각형·원·다각형을 그려 각자 다른 속도로 회전시킵니다.
코드 보기 
const box = new PIXI.Graphics().rect(-40, -40, 80, 80).fill(0x4f7dff);
app.stage.addChild(box);
app.ticker.add(() => { box.rotation += 0.01; });

2. 텍스트 렌더링

굵기·색상·그림자 등 스타일이 다른 텍스트 세 종류를 렌더링합니다.
코드 보기 
const title = new PIXI.Text({
  text: '가상 위판장 현황판',
  style: { fill: 0xffffff, fontSize: 28, fontWeight: 'bold' },
});

3. 인터랙션 (클릭 · 호버)

아래 위판 구역 카드를 클릭해보세요. 클릭할 때마다 색이 바뀌고 카운트가 올라갑니다.
아직 클릭 안 함
코드 보기 
zone.eventMode = 'static';
zone.cursor = 'pointer';
zone.on('pointerdown', () => { zone.tint = 0xe0524a; clickCount++; });
zone.on('pointerover', () => { zone.scale.set(1.05); });
zone.on('pointerout', () => { zone.scale.set(1); });

4. 내장 필터 효과 비교

버튼으로 Blur(흐림)와 ColorMatrix(흑백) 필터를 켜고 끄며 같은 도형에 어떻게 적용되는지 비교합니다.
코드 보기 
const blur = new PIXI.BlurFilter({ strength: 8 });
const gray = new PIXI.ColorMatrixFilter();
gray.grayscale(1);
shape.filters = [blur, gray]; // 배열이라 여러 필터를 동시에 적용 가능

5. Container로 그룹 묶기

여러 도형을 하나의 Container에 넣으면, 각 도형이 자전하는 동시에 컨테이너 전체가 공전합니다.
코드 보기 
const group = new PIXI.Container();
group.addChild(shape1, shape2, shape3); // 자식들은 그룹 기준 상대 좌표
app.stage.addChild(group);
app.ticker.add(() => {
  group.rotation += 0.005;      // 그룹 전체 공전
  shape1.rotation += 0.03;      // 개별 자전
});
