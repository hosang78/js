LeaderLine 핵심 기능 둘러보기

LeaderLine은 화면 위 두 지점(또는 두 DOM 엘리먼트)을 화살표가 달린 안내선(leader line)으로 이어주는 라이브러리입니다. 노드 에디터처럼 그래프를 "구성"하는 게 아니라, 이미 화면에 있는 UI 요소들 사이의 관계를 시각적으로 짚어서 보여주는 용도입니다.
  • straight/arc/fluid/magnet/grid 등 다양한 경로(path) 스타일
  • 시작/중간/끝 라벨, 점선 애니메이션, 그림자, 아웃라인 같은 시각 효과
  • 요소 전체가 아니라 특정 좌표(pointAnchor)나 영역(areaAnchor)을 정확히 가리킬 수 있음
  • 마우스를 올렸을 때만 나타나는 안내선(mouseHoverAnchor), 요소가 움직이면 line.position()으로 선도 따라 움직임
※ 아래 위판 시세·데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·시세와 무관합니다. LeaderLine(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 연결선 + 경로(path) 종류

버튼을 눌러 같은 두 카드를 잇는 선의 경로 스타일을 바꿔보세요.
위판장 입고
경매장
코드 보기 
const line = new LeaderLine(elA, elB, { path: 'fluid', color: '#2a78d6', size: 4 });

btnGroup.forEach((btn) => {
  btn.addEventListener('click', () => {
    line.path = btn.dataset.path;   // 속성만 바꿔주면 즉시 다시 그려짐
  });
});

2. 라벨 + 시각 효과

시작·중간·끝 라벨과 점선 애니메이션, 그림자, 아웃라인 효과입니다. 버튼으로 켜고 꺼보세요.
조합원 어선
위판 접수
코드 보기 
const line = new LeaderLine(elA, elB, {
  color: '#eda100', size: 4,
  startLabel: '입고', middleLabel: '검수', endLabel: '완료',
});

dashBtn.addEventListener('click', () => {
  line.dash = line.dash ? false : { animation: true };
});
shadowBtn.addEventListener('click', () => {
  line.dropShadow = !line.dropShadow;
});
outlineBtn.addEventListener('click', () => {
  line.outline = !line.outline;
  line.outlineColor = '#1c5cab';
});

3. 특정 좌표 / 영역 가리키기

pointAnchor는 표 안의 특정 셀처럼 요소의 한 점을, areaAnchor는 카드 안의 특정 영역을 정확히 가리킵니다.
오늘 최고가
어종단가(원/kg)
고등어4,200
갈치18,500
오징어9,800
품질 특이사항
갈치 · 냉동 위판 로트
품질 B등급 구간
코드 보기 
// 표 안의 특정 셀(중앙 지점)을 가리킴
new LeaderLine(callout, LeaderLine.pointAnchor(cellEl, { x: '50%', y: '50%' }),
  { color: '#eda100' });

// 카드 안의 특정 하위 영역(테두리 강조)을 가리킴
new LeaderLine(callout2, LeaderLine.areaAnchor(subRegionEl, {
  color: 'rgba(27,175,122,0.25)'
}), { color: '#1baf7a' });

4. 마우스 오버 표시 + 드래그 시 자동 재계산

노란 카드에 마우스를 올리면 연결선이 나타납니다. 파란 카드(제목 부분)를 드래그해서 옮겨보면 line.position()이 호출되어 선이 즉시 따라옵니다.
마우스를 올리면 안내선 표시
위판장 (드래그 가능)
코드 보기 
new LeaderLine(
  LeaderLine.mouseHoverAnchor(hoverEl, 'draw'),  // 마우스 오버 시 그려지는 효과로 표시
  targetEl,
  { color: '#eda100' }
);

// 드래그로 카드를 옮길 때마다 좌표를 갱신하고 선을 다시 계산
targetEl.addEventListener('pointermove', (e) => {
  targetEl.style.left = ...;
  targetEl.style.top = ...;
  line.position();       // 선의 시작/끝점을 다시 계산해서 그려줌
});
