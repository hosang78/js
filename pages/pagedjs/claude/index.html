Paged.js 핵심 기능 둘러보기

Paged.js는 일반 HTML/CSS 문서를 브라우저 위에서 인쇄용 페이지 단위로 잘라 보여주는 페이지네이션 엔진(polyfill)입니다. CSS Paged Media / GCPM 스펙(@page, 각주, 실행 헤더 등)을 표준 브라우저가 지원하지 않는 부분까지 미리 구현해서, PDF 인쇄물 레이아웃을 브라우저에서 바로 미리보기할 수 있게 해줍니다.
  • @page { size; margin; }로 정의하는 여러 페이지 인쇄물 레이아웃
  • counter(page) · string-set으로 넣는 페이지 번호와 실행 헤더
  • float: footnote로 자동 배치되는 각주
  • @page :first로 지정하는 표지 페이지 스타일 + 강제 페이지 나눔
※ 아래 위판 안내문·보고서 내용은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·공지·절차와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.
※ Paged.js는 각 미리보기의 페이지 스타일을 문서 전체에 전역으로 주입하기 때문에(인스턴스별로 구분되지 않음), 두 미리보기를 동시에 열어두면 나중 스타일이 먼저 만든 미리보기에도 새어 들어갈 수 있습니다. 그래서 이 데모는 버튼을 누르면 다른 섹션의 미리보기를 자동으로 정리하고 항상 하나만 유지합니다.

1. 여러 페이지 인쇄물 레이아웃

@page 규칙으로 페이지 크기(size)와 여백(margin)을 정하면, 내용이 길어질 때 자동으로 다음 페이지로 넘어갑니다. Paged.Previewer().preview()가 지정한 요소 안에 실제 페이지 박스들을 그려 넣습니다.

위판 안내문

이 문서는 Paged.js 페이지네이션 데모를 위한 가상의 안내문입니다. 오늘 위판은 오전 6시부터 시작됩니다. 참여를 원하는 조합원은 사전 등록이 필요하며, 등록은 각 위판장 사무실에서 접수합니다. 신분증과 조합원증을 반드시 지참해야 하며, 등록 마감은 위판 시작 30분 전입니다.

위판 순서는 등록 순서대로 배정되며, 순서 배정표는 위판장 게시판에 게시됩니다. 순서를 놓친 조합원은 해당 회차 종료 후 남은 물량에 한해 참여할 수 있습니다. 기상 악화 등으로 위판이 지연되거나 취소될 수 있으니 당일 공지를 꼭 확인해 주시기 바랍니다.

낙찰가는 실시간으로 집계되며, 품목별 평균가는 위판 종료 직후 게시판에 공개됩니다. 정산은 익일 오전에 각 위판장을 통해 이루어지며, 계좌 이체를 원하는 경우 사전에 계좌 정보를 등록해야 합니다. 현금 정산을 원하는 조합원은 정산 창구에서 신분 확인 후 수령할 수 있습니다.

위판장 내에서는 안전을 위해 지정된 통로로만 이동해 주시기 바라며, 개인 운반 장비를 반입할 경우 사전 신고가 필요합니다. 미신고 장비는 반입이 제한될 수 있습니다. 그 밖의 문의 사항은 각 위판장 사무실 또는 본소 운영팀으로 연락해 주시기 바랍니다.

소스 코드 보기 
const css = `
  @page {
    size: 4in 5.6in;
    margin: 0.35in;
  }
  body { font-size: 10px; font-family: sans-serif; line-height: 1.5; }
`;
const previewer = new Paged.Previewer();
const flow = await previewer.preview(
  sourceEl.cloneNode(true),   // 원본 DOM 조각
  [{ 'inline': css }],        // 문자열 CSS를 객체로 바로 전달 가능 (네트워크 요청 없음)
  viewportEl                  // 페이지들을 그려 넣을 컨테이너
);
console.log(flow.total);      // 생성된 페이지 수

2. 페이지 번호 + 실행 헤더

각 h2 제목을 string-set으로 저장해두면, 같은 값을 @top-center { content: string(...); }로 페이지 상단에 반복 출력할 수 있습니다. 페이지 번호는 counter(page)로 하단에 자동 표시됩니다.

수수료 및 정산 안내

위판 수수료는 거래 금액의 3%로 책정되며, 정산 시 자동으로 차감되어 별도로 납부할 필요가 없습니다. 조합원 등급에 따라 일부 할인이 적용될 수 있으며, 등급별 할인율은 매년 초 총회에서 결정됩니다. 수수료 관련 이의가 있는 경우 정산 익일까지 정산팀에 접수해야 합니다.

정산 대금은 익일 오전 각 위판장을 통해 지급되며, 계좌 이체 신청자는 신청일로부터 2영업일 이내에 입금됩니다. 정산 명세서는 위판장 키오스크 또는 온라인 조합원 페이지에서 확인할 수 있습니다. 명세서 오류 발견 시 즉시 정산팀으로 문의해 주시기 바랍니다.

휴무 및 특별 공지

매월 둘째·넷째 주 월요일은 정기 휴무일이며, 명절 전후로는 별도 공지된 일정에 따라 운영됩니다. 휴무일 위판 일정은 최소 3일 전에 게시판과 문자 알림으로 공지됩니다.

본 안내문의 내용은 사정에 따라 변경될 수 있으며, 변경 사항은 각 위판장 게시판을 통해 공지됩니다. 이상으로 수수료 및 정산 안내를 마칩니다.

소스 코드 보기 
const css = `
  @page {
    size: 4in 5.6in;
    margin: 0.45in 0.35in 0.55in;
    @bottom-center { content: counter(page); font-size: 9px; }
    @top-center { content: string(doctitle); font-size: 8px; color: #888; }
  }
  h2 { string-set: doctitle content(); }   /* 이 제목이 나올 때마다 값을 갱신 */
`;

3. 각주 (float: footnote)

본문 안의 <span>에 float: footnote를 주면, 해당 텍스트가 페이지 하단 각주 영역으로 자동으로 옮겨지고 번호가 매겨집니다. 각주가 있는 페이지가 바뀌면 각주도 그 페이지를 따라갑니다.

어획물 위판 참여 조합원은 매년 정기 총회정기 총회는 매년 2월 마지막 주에 개최되며, 참석은 조합원 본인 또는 위임장을 지참한 대리인만 가능합니다.에 참석하여 그 해의 위판 운영 방침에 대한 의결권을 행사할 수 있습니다. 총회에서는 수수료율, 휴무일 지정, 시설 투자 계획 등 주요 안건이 다뤄집니다.

신규 조합원 가입은 상시 접수하며, 가입 심사는 조합원 자격 요건 확인 후 이루어집니다. 가입비 및 출자금출자금은 탈퇴 시 정관에 정한 절차에 따라 환급받을 수 있습니다.은 가입 신청 시 본소 회원관리팀에 안내받을 수 있습니다. 심사는 통상 2주 이내에 완료됩니다.

소스 코드 보기 
<p>정기 총회<span class="fn">총회는 매년 2월에 개최됩니다.</span>에 참석...</p>

const css = `
  .fn { float: footnote; }
  ::footnote-marker { content: counter(footnote) ") "; font-weight: bold; }
  ::footnote-call   { content: counter(footnote); vertical-align: super; font-size: 7px; }
`;

4. 표지 페이지 스타일 + 강제 페이지 나눔

@page :first는 첫 페이지에만 다른 배경·스타일을 적용할 때 씁니다 (표지 디자인 등). 특정 위치에서 무조건 다음 페이지로 넘기고 싶을 때는 break-before: page를 씁니다.
⚠ 주의: break-before: page는 실제 테스트 결과 요소의 인라인 style 속성으로 줘서는 적용되지 않았고, 스타일시트 안에서 클래스 선택자(예: .newpage { break-before: page; })로 지정해야 정상적으로 페이지가 나뉘었습니다. Paged.js가 페이지 나눔 지점을 계산할 때 CSS 파서가 해석한 스타일시트 규칙만 보고, 엘리먼트의 인라인 스타일은 참고하지 않기 때문으로 보입니다.

수협중앙회 가상 위판 실적 보고서 표지입니다. 이 보고서는 Paged.js 데모를 위해 작성된 가상의 문서이며, 실제 통계가 아닙니다.

본문 페이지입니다. 표지와 달리 배경색 없이 일반 페이지 스타일이 적용됩니다. @page :first는 오직 첫 페이지에만 적용되고, 두 번째 페이지부터는 기본 @page 스타일로 돌아옵니다.

소스 코드 보기 
<p>표지 문단...</p>
<p class="newpage">본문 페이지...</p>   <!-- 클래스로 강제 나눔 지정 -->

const css = `
  @page { size: 4in 5.6in; margin: 0.35in; }
  @page :first { background: #4f7dff; color: #fff; }
  .newpage { break-before: page; }   /* 인라인 style로는 동작하지 않음 */
`;
