Quill 핵심 기능 둘러보기

Quill은 웹페이지에 서식 있는 글쓰기(굵게, 목록, 링크 등)를 넣을 수 있게 해주는 리치 텍스트 에디터입니다. 게시판 글쓰기 화면, 메모 앱 등에 흔히 쓰입니다.
  • 문서 내용과 서식을 { insert, attributes } 형태의 Delta라는 자체 JSON으로 표현 (HTML을 직접 다루지 않음)
  • theme: 'snow'(항상 보이는 툴바) / theme: 'bubble'(텍스트를 드래그해야 뜨는 인라인 툴바) 두 가지 기본 테마 제공
  • text-change 이벤트로 내용이 바뀔 때마다 실시간 감지
  • history 모듈이 기본 내장되어 있어 실행 취소/다시 실행이 바로 동작
※ 이 페이지의 위판 공지·시세 문구는 모두 가상의 예시이며 실제 수협중앙회의 공지·자료가 아닙니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 에디터(Snow 테마) + 실시간 읽기

항상 보이는 툴바로 서식을 적용할 수 있습니다. 글을 수정하면 text-change 이벤트가 실시간으로 감지되어 아래 텍스트/HTML이 갱신됩니다.
아직 입력 없음
코드 보기 
const quill = new Quill('#editor1', { theme: 'snow' });

quill.on('text-change', () => {
  const text = quill.getText();          // 순수 텍스트
  const html = quill.getSemanticHTML();   // 서식이 반영된 HTML
});

2. Delta 형식으로 콘텐츠 다루기

버튼을 누르면 굵게·색상 서식이 섞인 공지를 Delta(JSON) 형태로 직접 만들어 삽입합니다. 아래에서 실제 Delta 구조를 확인할 수 있습니다.
아직 삽입 안 함
코드 보기 
const Delta = Quill.import('delta');

quill.setContents(new Delta()
  .insert('금일 위판 시세: ')
  .insert('고등어 4500원/kg', { bold: true, color: '#c0392b' })
  .insert(' (전일 대비 인상)\n'));

console.log(quill.getContents()); // { ops: [ {insert, attributes}, ... ] }

3. Bubble 테마 (인라인 툴바)

Snow와 달리 툴바가 평소엔 숨어 있다가, 텍스트를 드래그해서 선택하면 그 자리에 작은 툴바가 떠오릅니다. 아래 글을 드래그해보세요.
코드 보기 
const quill = new Quill('#editor3', { theme: 'bubble' });

4. 읽기 전용 모드 토글

disable() / enable()로 편집 가능 여부를 바로 전환합니다. 공지가 확정된 뒤 더 이상 수정 못 하게 잠그는 용도 등에 씁니다.
코드 보기 
quill.disable();       // 편집 불가
quill.enable();        // 다시 편집 가능
quill.isEnabled();     // 현재 상태 확인

5. 실행 취소 / 다시 실행

아래 에디터에 한 문장을 이어서 입력해보고, "실행 취소"를 눌러보세요. 짧은 시간(기본 1초) 안에 이어친 입력은 한 번에 묶여서 취소됩니다.
코드 보기 
const quill = new Quill('#editor5', { theme: 'snow' });
// history 모듈은 기본 내장 — 1초 안의 연속 입력을 한 단위로 묶어서 취소

quill.history.undo();
quill.history.redo();
