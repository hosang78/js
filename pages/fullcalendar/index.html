FullCalendar 핵심 기능 둘러보기

FullCalendar는 월간·주간·일간·목록 형태의 달력 UI를 통째로 제공하는 라이브러리입니다. 일정 표시뿐 아니라 날짜 클릭, 이벤트 드래그 같은 상호작용도 기본 내장돼 있습니다.
  • new FullCalendar.Calendar(el, options) 한 번으로 완성된 달력 UI 생성
  • headerToolbar 버튼으로 월간(dayGridMonth)/주간(timeGridWeek)/목록(listWeek) 뷰 전환
  • locale: 'ko'로 요일·버튼 문구를 한국어로 표시
  • editable: true면 이벤트를 마우스로 끌어 다른 날짜로 옮길 수 있음
※ 아래 위판 일정 데이터는 FullCalendar 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 일정이 아닙니다. 이 페이지는 FullCalendar(CDN, Standard Bundle) 하나만 사용하고 (한국어 로케일 파일도 같은 라이브러리의 일부입니다) 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 캘린더 + 한국어 로케일

이번 달 위판 일정을 월간 달력으로 보여줍니다. locale: 'ko'로 요일과 버튼 문구가 한국어로 표시됩니다.
코드 보기 
const calendar = new FullCalendar.Calendar(document.getElementById('calendar1'), {
  initialView: 'dayGridMonth',
  locale: 'ko',
  events: [
    { title: '고등어 위판', start: '2026-07-13' },
    { title: '정기 조합원 총회', start: '2026-07-17' },
  ],
});
calendar.render();

2. 뷰 전환 (월간 · 주간 · 목록)

오른쪽 위 버튼으로 월간/주간/목록 보기를 전환할 수 있습니다.
코드 보기 
new FullCalendar.Calendar(el, {
  initialView: 'dayGridMonth',
  headerToolbar: {
    left: 'prev,next today',
    center: 'title',
    right: 'dayGridMonth,timeGridWeek,listWeek', // 월간/주간/목록 버튼
  },
  events: [...],
}).render();

3. 날짜 클릭으로 일정 추가 · 이벤트 클릭으로 삭제

빈 날짜를 클릭하면 그 날짜에 새 위판 일정이 추가됩니다. 이미 있는 일정을 클릭하면 바로 삭제됩니다.
날짜나 일정을 클릭해보세요.
코드 보기 
let count = 1;
new FullCalendar.Calendar(el, {
  dateClick(info) {
    calendar.addEvent({ title: `새 위판 일정 ${count++}`, start: info.dateStr });
  },
  eventClick(info) {
    info.event.remove(); // 클릭한 이벤트를 바로 삭제
  },
}).render();

4. 드래그로 일정 이동 (editable)

일정을 마우스로 끌어서 다른 날짜에 놓아보세요. eventDrop이 이동 전/후 날짜를 알려줍니다.
일정을 끌어서 옮겨보세요.
코드 보기 
new FullCalendar.Calendar(el, {
  editable: true, // 드래그로 이동 가능하게
  eventDrop(info) {
    const oldDate = info.oldEvent.startStr;
    const newDate = info.event.startStr;
    status.textContent = `"${info.event.title}" 일정을 ${oldDate} → ${newDate} 로 옮겼습니다.`;
  },
}).render();
