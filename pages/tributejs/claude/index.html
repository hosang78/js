Tribute.js 핵심 기능 둘러보기

Tribute.js는 슬랙·깃허브 댓글창처럼 @를 입력하면 사람 이름이 자동완성되는 "멘션" 기능을 textarea· contentEditable 요소에 붙여주는 라이브러리입니다.
  • @ 입력으로 뜨는 기본 멘션 자동완성
  • collection으로 여러 트리거 문자 동시 사용(@조합원, #위판장)
  • values를 함수로 넘겨 흉내낸 비동기 검색
  • contentEditable에 붙여 만드는 스타일 있는 멘션 삽입
※ 아래 조합원·위판장 이름은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 명부·조직과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 멘션 자동완성

아래 댓글창에 @를 입력해보세요. 조합원 이름 목록이 뜨고, 화살표 키로 고른 뒤 Enter나 Tab을 누르면 선택한 이름이 삽입됩니다.
코드 보기 
new Tribute({
  trigger: '@',
  values: MEMBERS, // [{ key: '김민수', value: '김민수', region: '부산' }, ...]
  selectTemplate: (item) => `@${item.original.value}`, // 뒤 공백은 replaceTextSuffix가 자동으로 붙여준다
  menuItemTemplate: (item) =>
    `<span class="name">${item.original.value}</span><span class="meta">${item.original.region}</span>`,
}).attach(document.getElementById('ta1'));

2. 여러 트리거 문자 동시 사용

한 입력창에서 @는 조합원을, #는 위판장을 서로 다른 목록으로 자동완성합니다. collection 옵션에 트리거별 설정을 배열로 넘기면 됩니다.
코드 보기 
new Tribute({
  collection: [
    { trigger: '@', values: MEMBERS, selectTemplate: (item) => `@${item.original.value}` },
    { trigger: '#', values: PORTS, selectTemplate: (item) => `#${item.original.value}` },
  ],
}).attach(document.getElementById('ta2'));

3. 비동기 검색

values에 배열 대신 함수를 넘기면 타이핑할 때마다 그 함수가 호출됩니다. 실제 서버 조회를 흉내내기 위해 일부러 400ms 지연을 넣었습니다.
아직 검색한 적이 없습니다.
코드 보기 
new Tribute({
  trigger: '@',
  values: (text, cb) => {
    stat.textContent = '검색 중...';
    setTimeout(() => {
      const results = MEMBERS.filter((m) => m.value.includes(text));
      stat.innerHTML = `${results.length}명 검색됨`;
      cb(results); // 실제로는 fetch() 결과를 여기서 넘겨준다
    }, 400);
  },
}).attach(document.getElementById('ta3'));

4. contentEditable + 스타일 있는 멘션 삽입

일반 텍스트 입력창은 서식이 있는 텍스트를 넣을 수 없어서, 색이 들어간 멘션 칩을 넣으려면 contentEditable 요소에 붙여야 합니다. selectTemplate이 HTML을 그대로 반환합니다.
코드 보기 
new Tribute({
  trigger: '@',
  values: MEMBERS,
  // contentEditable에서는 replaceTextSuffix 기본값이 알아서 nbsp를 붙여주므로 여기서는 안 넣는다
  selectTemplate: (item) =>
    `<span class="mention-chip" contenteditable="false">@${item.original.value}</span>`,
}).attach(document.getElementById('ce4'));
