noUiSlider 핵심 기능 둘러보기

noUiSlider는 의존성 없는 가벼운 range slider(범위 슬라이더) 라이브러리입니다. 단일 값 선택뿐 아니라 여러 개의 핸들로 구간을 나누는 슬라이더도 만들 수 있고, 터치·키보드 조작도 기본 지원합니다.
  • 단일 핸들 슬라이더 + 값 표시 툴팁
  • 듀얼 핸들로 최솟값·최댓값 범위 선택, 숫자 입력창과 양방향 연동
  • 눈금(pips) 표시 + 구간마다 스텝 간격이 다른 비선형(non-linear) 슬라이더
  • 여러 핸들 + 구간별 색상(connect)을 가진 수직 슬라이더
※ 아래 중량·단가·온도 수치는 이 페이지를 위해 만든 가상의 예시 데이터이며, 실제 수협중앙회의 위판 실적·통계와 무관합니다. noUiSlider(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 슬라이더 + 툴팁

가상 위판 중량 필터입니다(0~500kg, 10kg 단위). 핸들을 드래그하면 위에 값이 표시됩니다.
코드 보기 
noUiSlider.create(document.getElementById("slider1"), {
  start: [200],
  connect: [true, false],
  range: { min: 0, max: 500 },
  step: 10,
  tooltips: true,
  format: {
    to: (v) => Math.round(v) + "kg",
    from: (v) => Number(v.replace("kg", ""))
  }
});

2. 듀얼 핸들 범위 슬라이더 + 입력창 연동

가상 위판 단가 범위(원/kg)를 지정합니다. 슬라이더를 움직이면 입력창이, 입력창을 바꾸면 슬라이더가 함께 갱신됩니다.
최소 원 ~ 최대 원
코드 보기 
const slider2 = document.getElementById("slider2");
noUiSlider.create(slider2, {
  start: [2000, 8000],
  connect: true,
  range: { min: 0, max: 10000 },
  step: 100
});

const inputMin = document.getElementById("input2min");
const inputMax = document.getElementById("input2max");

slider2.noUiSlider.on("update", (values, handle) => {
  [inputMin, inputMax][handle].value = Math.round(values[handle]);
});

inputMin.addEventListener("change", () => slider2.noUiSlider.set([inputMin.value, null]));
inputMax.addEventListener("change", () => slider2.noUiSlider.set([null, inputMax.value]));

3. 눈금(pips) + 비선형 구간 스텝

가상 위판 단가 구간입니다. 저가 구간(0~1,000원)은 100원 단위로 촘촘하게, 고가 구간(1,000~10,000원)은 500원 단위로 성기게 움직이도록 range에 중간 지점을 추가했습니다. 아래 눈금 라벨도 함께 보세요.
코드 보기 
noUiSlider.create(document.getElementById("slider3"), {
  start: [3000],
  connect: [true, false],
  range: {
    min: [0, 100],        // 0~20% 구간은 100 단위 스텝
    "20%": [1000, 500],   // 20~100% 구간은 500 단위 스텝
    max: [10000]
  },
  pips: {
    mode: "positions",
    values: [0, 20, 50, 80, 100],
    density: 4
  }
});

4. 수직 다중 핸들 + 구간별 색상

냉동 보관동의 가상 구역별 온도 구간을 핸들 3개로 나눠봅니다. 구간마다 다른 색을 입혀 "냉동 / 저온 / 냉장 / 상온"처럼 구간을 구분해서 보여줄 수 있습니다.
냉동 구역(가상)
저온 구역(가상)
냉장 구역(가상)
상온 구역(가상)
코드 보기 
const slider4 = document.getElementById("slider4");
noUiSlider.create(slider4, {
  start: [-15, 0, 10],
  connect: [true, true, true, true],
  orientation: "vertical",
  range: { min: -20, max: 20 },
  step: 1,
  tooltips: true,
  format: {
    to: (v) => Math.round(v) + "°C",
    from: (v) => Number(v.replace("°C", ""))
  }
});
