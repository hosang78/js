성능 시험

현재 문서를 복제해 가상 문서 집합을 만든 뒤 인덱스 생성 시간과 반복 검색 시간을 측정한다. 브라우저 성능에 따라 결과가 달라진다.

검색 문법 및 기능 지도

기능예시설명
기본 OR 검색search browser기본적으로 하나 이상의 용어가 일치하면 결과 후보가 된다.
필수 용어+search +index두 용어가 모두 포함된 문서만 검색.
제외 용어search -serverserver가 포함된 결과 제외.
필드 제한title:search지정 필드만 검색.
검색 시 부스트search^10 browsersearch 일치 점수의 중요도 증가.
와일드카드brows*, *ware, b*er앞·뒤·중간 문자 패턴 검색.
퍼지 검색serch~1편집 거리 1 이내의 유사 단어 검색.
필드 부스트this.field('title',{boost:10})제목 일치가 본문 일치보다 높은 점수를 받도록 설정.
문서 부스트this.add(doc,{boost:3})특정 문서 전체의 랭킹 가중치 증가.
Query APIquery.term(...)presence, wildcard, editDistance, boost, fields를 객체 옵션으로 제어.
메타데이터metadataWhitelistposition을 저장해 하이라이트·문맥 표시 등에 활용.
직렬화JSON.stringify(idx)미리 만든 인덱스를 저장하고 lunr.Index.load로 복원.
파이프라인trimmer → stopWordFilter → stemmer토큰 전처리 과정을 제거·추가·사용자 정의 가능.
불변 인덱스변경 시 rebuild2.x에서는 생성된 인덱스에 문서를 직접 추가·수정·삭제할 수 없음.
이 파일은 Lunr.js를 CDN에서 불러온다. 완전한 폐쇄망 사용 시 lunr.min.js를 내려받아 HTML과 같은 폴더에 두고 script src를 로컬 경로로 변경해야 한다.
