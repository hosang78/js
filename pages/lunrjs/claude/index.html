Lunr.js 핵심 기능 둘러보기

Lunr.js는 Elasticsearch 같은 질의 문자열(query string) 문법을 브라우저에서 그대로 쓸 수 있는 전문(full-text) 검색 라이브러리입니다. FlexSearch·MiniSearch와 달리 검색어 자체에 field:단어, 단어~2, 단어^3 같은 문법을 섞어 쓸 수 있습니다.
  • field:단어로 하는 필드 지정 검색
  • 단어* 와일드카드, 단어~N 오타 허용(편집 거리)
  • 단어^N 부스트, +필수 -제외 검색
  • JSON.stringify(idx) + lunr.Index.load()로 하는 인덱스 직렬화
※ 아래 위판 물품 목록은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 물품·통계와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.
⚠ 실제로 겪은 문제: Lunr.js의 기본 파이프라인에는 lunr.trimmer가 들어있는데, 이 함수는 \W (영문 기준 "단어가 아닌 문자") 정규식으로 토큰 앞뒤를 잘라냅니다. 한글은 이 기준으로 전부 "단어가 아닌 문자"라서, 토큰 전체가 통째로 사라져 한글 검색이 아예 안 됩니다 ('고등어'.replace(/^\W+/,'').replace(/\W+$/,'')를 콘솔에 찍어보면 빈 문자열이 나옵니다). 이 페이지의 모든 예시는 this.pipeline.remove(lunr.trimmer)로 이 문제를 우회한 상태입니다. (라이브러리 소스 코드에도 "이 구현은 비라틴 문자에는 맞지 않을 수 있다"는 주석이 있습니다.)

1. 필드 지정 검색 (field:단어)

검색어 앞에 필드명을 붙이면 그 필드에서만 찾습니다. 아무 접두어 없이 검색하면 색인된 모든 필드에서 찾습니다.
    소스 코드 보기 
    const idx = lunr(function () {
  this.ref('id');
  this.field('name');
  this.field('description');
  this.pipeline.remove(lunr.trimmer);       // 한글이 지워지는 문제 우회
  this.searchPipeline.remove(lunr.trimmer);
  products.forEach((p) => this.add(p));
});

idx.search('name:고등어');   // name 필드에서만 검색

    2. 와일드카드 · 오타 허용(편집 거리)

    *는 와일드카드, ~N은 N까지의 편집 거리를 허용하는 오타 검색입니다.
      소스 코드 보기 
      idx.search('고등*');     // 와일드카드: '고등'으로 시작하는 단어
idx.search('고둥어~1');  // 오타 허용: 편집 거리 1까지 ('고둥어' → '고등어' 매칭)

      3. 부스트 · 필수/제외 검색

      단어^N은 그 단어의 가중치를 N배로 높입니다. +단어는 반드시 포함, -단어는 반드시 제외합니다.
        소스 코드 보기 
        idx.search('name:갈치^5 description:갈치');  // name에서 찾으면 5배 가중치
idx.search('+위판장 -전복');                  // '위판장'은 필수, '전복'은 제외

        4. 인덱스 직렬화 (저장 · 다시 불러오기)

        한 번 만든 인덱스를 JSON.stringify()로 저장해두면, 나중에 문서를 다시 추가하지 않고도 lunr.Index.load()로 바로 검색할 수 있습니다. (정적 사이트 검색에 자주 쓰는 방식입니다.)
          소스 코드 보기 
          const json = JSON.stringify(idx);     // 인덱스를 문자열로 저장 (파일이나 localStorage 등에)
// ...나중에, 문서를 다시 추가하지 않고...
const loadedIdx = lunr.Index.load(JSON.parse(json));
loadedIdx.search('갈치');             // 바로 검색 가능
