Zod 핵심 기능 둘러보기

Zod는 TypeScript 친화적인 스키마 검증 라이브러리입니다. 스키마를 한 번 정의하면 런타임 검증과 타입 추론을 동시에 얻을 수 있어, ajv(JSON 스키마 기반)보다 JS/TS 코드 안에서 직접 스키마를 짜는 스타일을 선호할 때 널리 쓰입니다.
  • z.object({...}).safeParse(data)로 예외 없이 {success, data|error} 결과 받기
  • 스키마 정의 시 { error: '메시지' }로 필드별 커스텀 에러 메시지 지정
  • z.treeifyError() / z.prettifyError()로 에러를 사람이 읽기 좋은 구조로 변환
  • .transform()으로 타입 변환, .refine()으로 커스텀 비즈니스 규칙 검증
※ 이 페이지의 위판 신고서 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. Zod는 브라우저용 번들을 따로 배포하지 않아(ESM 전용) jsdelivr의 ESM 변환 엔드포인트(/+esm)로 불러옵니다. 검증 중 실제로 확인한 점: v3에서 쓰이던 required_error/invalid_type_error 옵션과 .format()/ .flatten() 메서드는 v4에서 사라지고, 통합된 error 옵션과 z.treeifyError()/z.prettifyError() 함수로 대체되었습니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 스키마 + safeParse

위판 신고서 스키마(항구명, 어종, 무게>0)를 만들고 아래 값으로 검증합니다.
아직 검증 안 함
코드 보기 
const ReportSchema = z.object({
  port: z.string(),
  species: z.string(),
  weightKg: z.number().positive(),
});
const result = ReportSchema.safeParse({ port, species, weightKg: Number(weight) });
// result.success === true면 result.data, false면 result.error

2. 커스텀 에러 메시지 + treeifyError / prettifyError

이름을 비워두거나 나이에 숫자가 아닌 값을 넣고 검증해보세요. 필드별 한국어 에러 메시지가 두 가지 형태로 표시됩니다.
아직 검증 안 함
코드 보기 
const NamedSchema = z.object({
  name: z.string({ error: '이름은 문자열이어야 합니다' }).min(1, { error: '이름을 입력해주세요' }),
  age: z.number({ error: '나이는 숫자여야 합니다' }).min(0),
});
const r = NamedSchema.safeParse({ name, age: Number(age) });
if (!r.success) {
  z.treeifyError(r.error);   // 필드별 트리 구조
  z.prettifyError(r.error);  // 사람이 읽기 좋은 텍스트
}

3. transform + refine — 자동 변환 + 비즈니스 규칙

문자열로 입력받은 무게를 숫자로 자동 변환(transform)하고, 0보다 커야 한다는 규칙을 refine으로 검증합니다.
아직 검증 안 함
코드 보기 
const Schema = z.object({
  weightText: z.string().transform((v) => Number(v)),
}).refine((data) => data.weightText > 0, { error: '무게는 0보다 커야 합니다', path: ['weightText'] });
const r = Schema.safeParse({ weightText: '85.5' });
// r.data.weightText는 숫자 85.5 (문자열이 아님)

5. discriminatedUnion — 결제 방식별 다른 필수 필드

결제 방식을 바꿔보세요. '계좌이체'를 고르면 은행명이 필수가 되고, '현금'은 필요 없습니다.
아직 검증 안 함
코드 보기 
const PaymentSchema = z.discriminatedUnion('method', [
  z.object({ method: z.literal('cash'), amount: z.number() }),
  z.object({ method: z.literal('transfer'), amount: z.number(), bank: z.string() }),
]);
// method가 'transfer'인데 bank가 없으면 실패
