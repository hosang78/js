05 · BACKUP, RESTORE & API CHEAT SHEET

JSON 백업 · 복원 · DB 삭제

이 페이지는 별도 애드온 없이 테이블 배열을 직렬화한 간단한 백업 예시입니다.

전체 데이터 JSON 내보내기각 테이블 toArray() → Blob 다운로드
JSON 복원 (현재 데이터 대체)파일 검증 → clear() → bulkAdd()
브라우저 DB 완전 초기화db.delete() 후 DB 인스턴스 재생성

첨부 Blob은 JSON으로 안전하게 직렬화할 수 없으므로 이 단순 백업 예시에서는 파일 메타데이터만 포함됩니다. Blob까지 이식하려면 Dexie의 dexie-export-import 애드온 등 Blob 지원 백업 방식을 사용해야 합니다.
