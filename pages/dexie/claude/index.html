Dexie.js 핵심 기능 둘러보기

Dexie.js는 브라우저 내장 데이터베이스인 IndexedDB를 다루기 쉽게 감싸주는 라이브러리입니다. 서버 없이 브라우저 안에 데이터를 저장하고, 새로고침해도 남아있습니다.
  • 테이블을 정의하고 add/toArray/delete로 CRUD 수행 — 데이터는 IndexedDB에 영구 저장됨
  • where()/orderBy()로 조건 검색·정렬 가능
  • liveQuery로 데이터가 바뀌면 화면이 자동으로 다시 그려지는 반응형 조회 가능
  • transaction으로 여러 테이블에 걸친 작업을 원자적으로 처리(하나 실패하면 전체 취소) 가능
※ 아래 위판 접수/재고 데이터는 Dexie.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 시스템/재고와는 무관합니다. 데이터는 이 브라우저(기기)에만 저장되고 서버로 전송되지 않습니다. 이 페이지는 Dexie.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 저장 · 조회 · 삭제 (영속성)

아래에서 등록한 내용은 IndexedDB에 저장되어, 이 페이지를 새로고침해도 사라지지 않습니다. 한번 등록해보고 새로고침해서 확인해보세요.

const db = new Dexie('WipanDexieDemo');
db.version(1).stores({ entries: '++id, fish, qty, market, createdAt' });

await db.entries.add({ fish: '고등어', qty: 50, market: '부산공동어시장', createdAt: Date.now() });
const all = await db.entries.toArray();
await db.entries.delete(id);

2. 쿼리 · 정렬

어종으로 필터링하고, 등록순/수량순으로 정렬해서 조회합니다.
코드 보기 
// 어종으로 필터
const filtered = await db.entries.where('fish').equals('고등어').toArray();

// 수량 많은 순 정렬
const sorted = await db.entries.orderBy('qty').reverse().toArray();

3. liveQuery — 실시간 반응형 조회

아래 "총 건수"와 "최근 등록 5건"은 liveQuery로 구독하고 있어서, 1번 섹션에서 데이터를 추가/삭제하거나 아래 버튼으로 테스트 데이터를 추가하면 새로고침 없이 자동으로 갱신됩니다.
총 0건
코드 보기 
Dexie.liveQuery(() => db.entries.count())
  .subscribe((count) => { countBadge.textContent = `총 ${count}건`; });

Dexie.liveQuery(() => db.entries.orderBy('createdAt').reverse().limit(5).toArray())
  .subscribe((rows) => { renderTable(rows); }); // 다른 곳에서 데이터가 바뀌어도 자동 재실행됨

4. 트랜잭션 — 원자적 처리 · 롤백

"위판 접수"를 하면 접수 기록 추가와 재고 차감이 하나의 트랜잭션으로 묶여서 실행됩니다. 재고보다 많은 수량을 접수하려 하면 중간에 실패하고, 둘 다 취소(롤백)됩니다.
위판 접수를 시도해보세요.
코드 보기 
await db.transaction('rw', db.entries, db.stock, async () => {
  const current = await db.stock.get(fish);
  if (!current || current.qty < qty) {
    throw new Error('재고 부족'); // 이 에러가 나면 아래 두 작업 모두 취소됨
  }
  await db.stock.update(fish, { qty: current.qty - qty });
  await db.entries.add({ fish, qty, market: '위판접수', createdAt: Date.now() });
});
