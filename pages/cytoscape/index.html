Cytoscape.js 핵심 기능 둘러보기

Cytoscape.js는 노드(점)와 엣지(선)로 이루어진 네트워크(그래프)를 그리고 분석하는 라이브러리입니다. maxGraph처럼 다이어그램을 그리는 것도 되지만, 최단경로·연결관계 분석 같은 그래프 이론 계산 기능이 강점입니다.
  • 노드/엣지 데이터만 주면 여러 자동 배치 알고리즘(레이아웃)으로 그려줌
  • CSS와 비슷한 셀렉터 문법으로 데이터 속성에 따라 스타일을 다르게 지정 가능
  • 클릭·호버 등 이벤트를 노드/엣지 단위로 처리 가능
  • 다익스트라(dijkstra) 등 최단경로 알고리즘이 내장돼 있어 바로 사용 가능
※ 아래 위판장 운송망은 Cytoscape.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 물류/운송 체계와는 무관합니다. 이 페이지는 Cytoscape.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 그래프 · 레이아웃 전환

같은 네트워크를 여러 배치 알고리즘(레이아웃)으로 다시 그려봅니다. 노드를 드래그로 옮길 수도 있습니다.
코드 보기 
const cy = cytoscape({
  container: document.getElementById('cy1'),
  elements: [
    { data: { id: 'hub', label: '중앙물류센터' } },
    { data: { id: 'busan', label: '부산공동어시장' } },
    { data: { id: 'e1', source: 'busan', target: 'hub', weight: 50 } },
  ],
});

cy.layout({ name: 'cose' }).run();  // cose / circle / grid / breadthfirst 등

2. 속성별 스타일링

type 데이터 값에 따라 노드 모양·색을 다르게 주고, 엣지 굵기는 weight(거리) 값에 비례하게 매핑했습니다.
중앙물류센터 위판장
코드 보기 
cy.style([
  { selector: 'node[type = "hub"]', style: { shape: 'round-rectangle', 'background-color': '#2c3e91' } },
  { selector: 'node[type = "market"]', style: { shape: 'ellipse', 'background-color': '#4f7dff' } },
  { selector: 'edge', style: { width: 'mapData(weight, 30, 100, 1, 8)' } },
]);

3. 클릭 · 호버 인터랙션

노드에 마우스를 올리면 연결된 경로가 강조되고, 클릭하면 상세 정보가 아래에 표시됩니다.
노드에 마우스를 올리거나 클릭해보세요.
코드 보기 
cy.on('mouseover', 'node', (evt) => {
  evt.target.connectedEdges().addClass('highlighted');
});
cy.on('mouseout', 'node', (evt) => {
  evt.target.connectedEdges().removeClass('highlighted');
});
cy.on('tap', 'node', (evt) => {
  const n = evt.target;
  console.log(n.data('label'), n.degree()); // degree = 연결된 엣지 수
});

4. 최단경로 (Dijkstra)

출발/도착 위판장을 고르면 dijkstra로 거리(가상 km) 기준 최단 경로를 찾아 강조합니다.
출발/도착을 고르고 버튼을 눌러보세요.
코드 보기 
const dijkstra = cy.elements().dijkstra({
  root: '#busan',
  weight: (edge) => edge.data('weight'),
});

const path = dijkstra.pathTo(cy.$id('mokpo'));   // 경로에 포함된 노드+엣지 컬렉션
const dist = dijkstra.distanceTo(cy.$id('mokpo')); // 총 거리
path.addClass('highlighted');
