Golden Layout 핵심 기능 둘러보기

Golden Layout은 VS Code나 여러 IDE에서 보던 것처럼, 패널을 행·열·탭으로 자유롭게 배치하고 마우스로 드래그해서 재배치할 수 있는 다중 패널 레이아웃 매니저입니다.
  • row/column/stack으로 구성하는 다중 패널 레이아웃
  • 탭이나 패널 제목을 드래그해서 재배치(다른 자리로 옮기거나 탭으로 합치기)
  • addComponent()로 하는 패널 동적 추가
  • saveLayout() + loadLayout()으로 하는 레이아웃 저장·복원
※ 아래 패널 이름과 내용은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면과 무관합니다. Golden Layout은 npm 패키지 자체에 브라우저용 번들이 없어(번들러 사용을 전제로 배포됨), CDN에서 jsDelivr의 자동 번들링 기능 (+esm)으로 불러왔습니다. 그 외 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 행/열/탭으로 구성하는 다중 패널 레이아웃

왼쪽은 위아래로 쌓인 두 패널(열), 오른쪽은 탭 두 개가 묶인 패널(스택)입니다. 헤더를 드래그해서 직접 배치를 바꿔보세요.
코드 보기 
const layout = new GoldenLayout(document.getElementById('gl1'));
layout.registerComponentFactoryFunction('panel', (container, state) => {
  container.element.innerHTML = `<div class="gl-panel-content">${state.text}</div>`;
});
layout.loadLayout({
  root: {
    type: 'row',
    content: [
      { type: 'column', content: [
        { type: 'component', componentType: 'panel', title: '위판 현황', componentState: { text: '...' } },
        { type: 'component', componentType: 'panel', title: '시세 차트', componentState: { text: '...' } },
      ]},
      { type: 'stack', content: [
        { type: 'component', componentType: 'panel', title: '조업 일지', componentState: { text: '...' } },
        { type: 'component', componentType: 'panel', title: '공지사항', componentState: { text: '...' } },
      ]},
    ],
  },
});

2. 드래그로 패널 재배치

탭이나 패널 제목을 마우스로 눌러 다른 자리로 옮기거나 다른 패널 위에 놓아 탭으로 합쳐보세요. 배치가 바뀔 때마다 stateChanged 이벤트가 발생하는 것을 아래 상태 박스에서 확인할 수 있습니다.
아직 배치가 바뀌지 않았습니다.
코드 보기 
let changeCount = 0;
layout.on('stateChanged', () => {
  changeCount++;
  statEl.innerHTML = `배치가 ${changeCount}번 바뀌었습니다.`;
});

3. 패널 동적 추가

버튼을 누르면 addComponent()로 새 패널이 레이아웃에 즉시 추가됩니다. 추가된 패널도 다른 패널과 마찬가지로 드래그해서 옮길 수 있습니다.
코드 보기 
let count = 0;
addBtn.addEventListener('click', () => {
  count++;
  layout.addComponent('panel', { text: `추가된 위판장 ${count}` }, `위판장 ${count}`);
});

4. 레이아웃 저장 · 복원

패널을 자유롭게 드래그해서 배치를 바꾼 뒤 "저장"을 누르면 현재 배치가 JSON으로 저장됩니다. 다시 뒤섞은 뒤 "복원"을 누르면 저장했던 배치로 돌아옵니다.
아직 저장된 배치가 없습니다.
코드 보기 
let savedConfig = null;
saveBtn.addEventListener('click', () => {
  savedConfig = layout.saveLayout();   // 현재 배치를 JSON으로 직렬화 (ResolvedLayoutConfig)
});
restoreBtn.addEventListener('click', () => {
  if (!savedConfig) return;
  // saveLayout()의 결과를 loadLayout()에 그대로 넣으면 에러가 난다.
  // LayoutConfig.fromResolved()로 변환해야 한다.
  layout.loadLayout(LayoutConfig.fromResolved(savedConfig));
});
