Choices.js 핵심 기능 둘러보기

Choices.js는 평범한 <select>나 <input>을 검색·다중선택·태그 입력이 되는 세련된 선택 UI로 바꿔주는 라이브러리입니다.
  • 기존 <select> 요소 하나에 new Choices(el)만 하면 검색 가능한 드롭다운으로 변신
  • 다중 선택 시 태그 형태로 표시되고, 각 태그에 제거 버튼을 붙일 수 있음
  • 선택지를 그룹(optgroup)으로 묶어서 보여줄 수 있음
  • 미리 정해진 목록 없이, 사용자가 직접 입력해서 태그를 추가하는 것도 가능
※ 아래 위판장/어종 목록은 Choices.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 조직/분류 체계와는 무관합니다. 이 페이지는 Choices.js(CDN) 하나만 사용하고 (내부적으로 Fuse.js를 검색에 사용하지만 별도로 불러오지 않아도 되는 번들에 포함되어 있습니다) 다른 외부 API는 사용하지 않습니다.

1. 검색 가능한 단일 선택

위판장을 하나 고릅니다. 입력창에 타이핑하면 목록이 검색됩니다.
위판장을 선택해보세요.
코드 보기 
const choices1 = new Choices('#select1', { searchEnabled: true });

document.getElementById('select1').addEventListener('addItem', (e) => {
  console.log('선택됨:', e.detail.label);
});

2. 다중 선택 + 제거 버튼

취급하는 어종을 여러 개 고를 수 있습니다. 각 태그의 × 버튼으로 하나씩 제거할 수 있습니다.
선택된 어종: 없음
코드 보기 
const choices2 = new Choices('#select2', {
  removeItemButton: true,
  placeholderValue: '어종을 선택하세요',
});

3. 그룹으로 묶은 선택지

위판장을 지역별로 그룹지어 보여줍니다.
위판장을 선택해보세요.
코드 보기 
new Choices('#select3', {
  choices: [
    { label: '경상권', choices: [
      { value: 'busan', label: '부산공동어시장' },
      { value: 'tongyeong', label: '통영수산시장' },
      { value: 'pohang', label: '포항죽도시장' },
    ]},
    { label: '전라권', choices: [
      { value: 'mokpo', label: '목포수산시장' },
      { value: 'yeosu', label: '여수수산시장' },
    ]},
  ],
});

4. 자유 태그 입력

미리 정해진 목록 없이, 직접 입력하고 Enter를 눌러 관심 키워드 태그를 추가합니다.
키워드 태그: 없음
코드 보기 
new Choices('#input4', {
  removeItemButton: true,
  addItems: true,
  duplicateItemsAllowed: false,
  placeholderValue: '키워드를 입력하고 Enter',
});
