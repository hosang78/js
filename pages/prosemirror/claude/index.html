ProseMirror 핵심 기능 둘러보기

ProseMirror는 Quill·Editor.js보다 훨씬 낮은 수준의 API를 제공하는 리치 텍스트 에디터 툴킷입니다. 완제품 에디터가 아니라, 문서 구조를 엄격하게 정의하고 상태 변화를 직접 제어하고 싶은 개발자를 위한 빌딩 블록에 가깝습니다.
  • Schema가 어떤 노드/마크가 어디에 올 수 있는지 강제 — 스키마에 안 맞는 구조를 만들면 즉시 에러 발생
  • 모든 변경은 Transaction을 통해서만 이루어짐 — state.apply(tr)로 새 상태를 만드는 불변(immutable) 방식
  • 굵게·인용 같은 서식 적용도 상태를 직접 바꾸는 대신, toggleMark(state, dispatch) 같은 순수 함수형 Command로 실행
  • 기능이 prosemirror-state, prosemirror-view, prosemirror-model 등 여러 개의 작은 패키지로 쪼개져 있어 필요한 것만 골라 조합
※ ProseMirror는 CodeMirror 6와 마찬가지로 npm 패키지 자체에 브라우저용 번들이 없습니다 (ESM 전용, prosemirror-state + prosemirror-view + prosemirror-model + prosemirror-example-setup 등 10여 개 패키지로 분산). CDN에서 각각 따로 불러오면 CodeMirror 때와 같은 이유로 여러 인스턴스 충돌 문제가 생길 수 있어, 이 페이지는 필요한 패키지들을 한 번에 올바르게 묶어 만든 번들 파일(prosemirror-bundle.esm.js, 같은 CDN 배포 버전으로 직접 빌드)을 함께 담아 사용합니다. 이 페이지의 위판 공지 내용은 모두 가상의 예시이며 실제 수협중앙회의 공지·자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 에디터 (exampleSetup)

exampleSetup() 플러그인 하나로 메뉴바·키맵·실행취소가 갖춰진 에디터가 즉시 완성됩니다. 자유롭게 입력해보세요.
코드 보기 
const mySchema = new Schema({
  nodes: addListNodes(basicSchema.spec.nodes, 'paragraph block*', 'block'),
  marks: basicSchema.spec.marks,
});

const view = new EditorView(el, {
  state: EditorState.create({
    schema: mySchema,
    plugins: exampleSetup({ schema: mySchema, menuBar: true }),
  }),
});

2. Schema가 문서 구조를 강제

ProseMirror에서는 doc 노드 바로 아래에 텍스트를 직접 넣을 수 없습니다(문단 같은 블록 노드로 감싸야 함). 버튼을 눌러 스키마 위반 시 실제로 에러가 나는 것을 확인하세요.
아직 시도 안 함
코드 보기 
try {
  // doc 바로 아래에 text를 넣음 (허용되지 않는 구조)
  schema.nodes.doc.createChecked(null, [schema.text('직접 텍스트를 doc에 넣으면 안됨')]);
} catch (e) {
  console.log(e.message); // "Invalid content for node doc: ..."
}

3. Transaction 기반 상태 관리

모든 변경은 트랜잭션으로 전달됩니다. dispatchTransaction을 가로채서 트랜잭션이 몇 번 발생했는지, 현재 문서가 어떤 JSON 구조인지 실시간으로 보여줍니다. 아래 에디터에 입력해보세요.
트랜잭션: 0회

    

      코드 보기
      
let txCount = 0;
const view = new EditorView(el, {
  state,
  dispatchTransaction(tr) {
    txCount++;
    const newState = view.state.apply(tr); // 불변 상태 갱신
    view.updateState(newState);
    console.log(newState.doc.toJSON());
  },
});

    

  


  

    
4. Command로 서식 적용 + 실행 취소/다시 실행

    
아래 문장을 드래그해서 선택한 뒤 "굵게" 버튼을 눌러보세요. toggleMark는 상태를 직접 바꾸지 않고, 트랜잭션을 만들어 dispatch로 전달하는 순수 함수(Command)입니다.

    

    

      
      
      
    

    

      코드 보기
      
const view = new EditorView(el, {
  state: EditorState.create({
    schema: basicSchema,
    plugins: [history(), keymap({ 'Mod-z': undo, 'Mod-y': redo }), keymap(baseKeymap)],
  }),
});

toggleMark(schema.marks.strong)(view.state, view.dispatch); // 선택 영역에 굵게 토글
undo(view.state, view.dispatch);
redo(view.state, view.dispatch);
