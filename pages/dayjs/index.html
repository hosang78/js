Day.js 핵심 기능 둘러보기

Day.js는 날짜와 시간을 다루는 아주 가벼운(2KB) 라이브러리입니다. Moment.js와 거의 똑같은 문법을 쓰면서도 훨씬 가볍고, 필요한 기능만 플러그인으로 추가해서 씁니다.
  • format()으로 날짜를 원하는 형식의 문자열로 표현
  • add/subtract/diff로 날짜 계산
  • 기본 기능은 최소화하고, relativeTime("3일 전") 같은 기능은 플러그인으로 추가
  • 로케일(언어) 파일을 불러오면 요일·월 이름이 그 언어로 표시됨
※ 아래 위판 일정/이력 데이터는 Day.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 일정이 아닙니다. 이 페이지는 Day.js(CDN) 하나만 사용하고 (플러그인·로케일 파일도 같은 라이브러리의 일부입니다) 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 포맷팅 · 파싱

지금 이 순간을 여러 형식으로 표현하고, 문자열을 날짜로 파싱해봅니다.
코드 보기 
dayjs().format('YYYY-MM-DD');           // 2026-07-12
dayjs().format('YYYY년 MM월 DD일 dddd'); // 2026년 07월 12일 Sunday
dayjs('2026-07-15').isValid();          // true

2. 날짜 연산 (add · subtract · diff)

위판 예정일을 계산해봅니다.
오늘부터 일 후는?
시작일 종료일
두 날짜를 고르고 버튼을 눌러보세요.
코드 보기 
dayjs().add(7, 'day').format('YYYY-MM-DD (dddd)');
dayjs('2026-08-01').diff(dayjs('2026-07-12'), 'day'); // 일 단위 차이

3. 상대 시간 (relativeTime 플러그인)

위판 등록 이력을 "n일 전" 같은 상대 시간으로 표시합니다. (지금 보는 시점 기준으로 계산됩니다)
코드 보기 
dayjs.extend(dayjs_plugin_relativeTime); // 플러그인 등록

dayjs().subtract(3, 'day').fromNow(); // "3일 전"
dayjs().add(2, 'hour').fromNow();     // "2시간 후"

4. 한국어 로케일

같은 날짜를 영어 로케일과 한국어 로케일로 각각 표시해서 비교합니다.
