10. 실무 코드 조각

COPY & USE

ESM 설정 예시

번들러·프레임워크 프로젝트에서의 기본 방식

import dayjs from 'dayjs';
import utc from 'dayjs/plugin/utc';
import timezone from 'dayjs/plugin/timezone';
import customParseFormat from 'dayjs/plugin/customParseFormat';

dayjs.extend(utc);
dayjs.extend(timezone);
dayjs.extend(customParseFormat);

const value = dayjs.tz('2026-07-01 09:00',
  'YYYY-MM-DD HH:mm', 'Asia/Seoul');
console.log(value.utc().format());

브라우저 CDN 설정 예시

npm 없이 script 태그로 플러그인 확장

<script src=".../dayjs.min.js"></script>
<script src=".../plugin/relativeTime.js"></script>
<script>
  dayjs.extend(window.dayjs_plugin_relativeTime);
  console.log(dayjs().subtract(3, 'hour').fromNow());
</script>
오프라인 사용: 같은 폴더의 download_dayjs_assets.bat 또는 .ps1을 인터넷 연결 상태에서 1회 실행하면, assets/의 로컬 파일을 우선 사용한다.
