Hangul.js 핵심 기능 둘러보기

Hangul.js는 한글 문장의 자음/모음을 분리·조합하고, 이를 이용해 검색이나 문법 처리(조사 선택 등)를 할 수 있게 해주는 라이브러리입니다.
  • 한글을 자모(초성/중성/종성) 단위로 쪼개거나(disassemble) 다시 합칠 수 있음(assemble)
  • 자모 단위로 비교하기 때문에, 글자를 다 입력하지 않아도(IME 조합 중이어도) 검색이 가능함
  • 문장 안에서 검색어가 있는 위치를 찾아 하이라이트할 수 있음(rangeSearch)
  • 받침 유무를 판별해 은/는, 이/가 같은 조사를 자동으로 고를 수 있음
※ 아래 예시의 위판장/어종 목록은 Hangul.js 학습용으로 만든 샘플 데이터이며, 수협중앙회의 실제 현황과는 무관합니다. 이 페이지는 Hangul.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 자모 분리 · 조합

글자를 입력하면 초성/중성/종성으로 쪼갠 뒤, 다시 합쳐서 원래 글자가 나오는지 보여줍니다.
-
-
코드 보기 
Hangul.disassemble('고등어');
// -> ['ㄱ','ㅗ','ㄷ','ㅡ','ㅇ','ㅇ','ㅓ']

Hangul.assemble(['ㄱ','ㅗ','ㄷ','ㅡ','ㅇ','ㅇ','ㅓ']);
// -> '고등어'

2. 미완성 입력도 되는 검색

자모 단위로 비교하기 때문에 고ㄷ처럼 글자를 끝까지 입력하지 않아도 고등어가 결과에 나옵니다. 일반 문자열 검색(indexOf)으로는 안 되는 것입니다.
코드 보기 
const fish = ['고등어', '갈치', '오징어', '새우', '꽃게', '전복'];
const searcher = new Hangul.Searcher('고ㄷ');

fish.filter((name) => searcher.search(name) >= 0);
// -> ['고등어']

3. 문장 내 검색어 하이라이트

rangeSearch로 문장 안에서 검색어의 위치를 모두 찾아 강조합니다.
부산위판장과 목포위판장은 전국 위판장 중에서도 거래량이 많은 위판장으로 꼽힌다.
코드 보기 
Hangul.rangeSearch(sentence, '위판장');
// -> [[2,4], [9,11], [17,19], [33,35]] 같은 [시작,끝] 인덱스 배열

4. 은/는 조사 자동 선택

단어가 받침으로 끝나는지(endsWithConsonant) 판별해서 "은/는"을 자동으로 붙입니다. 한국어 문장을 자동 생성할 때 자주 쓰는 패턴입니다.
코드 보기 
function withEunNeun(word) {
  return word + (Hangul.endsWithConsonant(word) ? '은' : '는');
}

withEunNeun('전복'); // '전복은' (받침 ㄱ 있음)
withEunNeun('고등어'); // '고등어는' (받침 없음)
