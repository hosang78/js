샘플 사용법

  1. 카드 상단 머리글을 잡아 원하는 위치로 이동
  2. 카드 가장자리·모서리를 끌어 크기 조절
  3. 왼쪽 팔레트의 카드를 메인 또는 보관 그리드로 드롭
  4. 메인과 보관 그리드 사이로 기존 위젯 이동
  5. 위젯을 클릭한 뒤 검사기에서 좌표·크기·잠금 속성 변경
  6. 열 수를 직접 바꾸거나 자동 반응형을 켜 창 너비에 따른 재배치 확인
  7. JSON을 수정한 뒤 적용하여 저장·복원 구조 확인
  8. 위젯을 다른 위젯 중앙에 완전히 겹쳐 동적 중첩 기능 실험
  9. 이 데모의 HTML 렌더링은 내부 샘플만 대상으로 하며, 실제 서비스의 사용자 입력 HTML은 별도 정화 필요
