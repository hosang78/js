GridStack.js 핵심 기능 둘러보기

GridStack.js는 카드(위젯)를 격자 위에 배치하고, 마우스로 끌어서 옮기거나 모서리를 끌어서 크기를 바꿀 수 있게 해주는 대시보드용 그리드 레이아웃 라이브러리입니다. jQuery 같은 별도 의존성 없이 동작합니다.
  • GridStack.init() 한 번으로 .grid-stack-item 카드들이 드래그·리사이즈 가능해짐
  • addWidget()/removeWidget()으로 위젯을 코드에서 추가·삭제 가능
  • compact()로 위젯 사이 빈 칸을 자동으로 채워 정렬
  • save()/load()로 현재 배치를 JSON으로 뽑아내고 그대로 복원 가능
※ 아래 위판량·시세·조합원 수 등은 GridStack.js 학습용으로 만든 가상의 샘플 데이터이며, 실제 수협중앙회의 통계가 아닙니다. 이 페이지는 GridStack.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 그리드 + 드래그 · 리사이즈

카드를 마우스로 끌면 위치가 바뀌고, 카드 오른쪽 아래 모서리를 끌면 크기가 바뀝니다. 직접 옮기거나 크기를 바꿔보세요 — 아래 상태창에 마지막 변경 내용이 표시됩니다.
아직 변경 없음
코드 보기 
const grid1 = GridStack.init({ column: 12, cellHeight: 70, margin: 8 }, '#grid1');

grid1.on('change', (event, items) => {
  const item = items[0];
  status1.textContent = `위젯이 (x:${item.x}, y:${item.y}, w:${item.w}, h:${item.h}) 로 바뀜`;
});

2. 위젯 추가 · 삭제

버튼을 누르면 어종 시세 카드가 랜덤하게 추가됩니다. 각 카드의 × 버튼으로 개별 삭제할 수 있습니다.
코드 보기 
// v9+는 XSS 방지를 위해 content를 기본적으로 textContent로 넣는다.
// 우리가 직접 만든 HTML을 그대로 렌더링하려면 renderCB를 innerHTML로 바꿔줘야 한다.
GridStack.renderCB = (el, w) => { if (el && w?.content) el.innerHTML = w.content; };

const grid2 = GridStack.init({ column: 12, cellHeight: 70, margin: 8 }, '#grid2');

grid2.addWidget({
  w: 3, h: 2,
  content: `<div class="widget-card">
    <button class="close-btn">×</button>
    <div class="title">고등어 시세</div>
    <div class="value">3,200원/kg</div>
  </div>`,
});

// × 버튼 클릭 시 해당 위젯 제거
gridEl.addEventListener('click', (e) => {
  if (e.target.classList.contains('close-btn')) {
    grid2.removeWidget(e.target.closest('.grid-stack-item'));
  }
});

3. 빈 공간 자동 정렬 (compact)

아래 위젯들은 일부러 빈 칸을 남기고 배치했습니다. "정렬" 버튼을 누르면 compact()가 빈 칸을 채우며 위젯들을 위로 밀어 올립니다.
코드 보기 
const grid3 = GridStack.init({ column: 12, cellHeight: 70, margin: 8 }, '#grid3');
// 위젯들이 gs-y 값에 일부러 빈틈을 두고 배치되어 있음

document.getElementById('compactBtn').addEventListener('click', () => {
  grid3.compact(); // 빈 칸을 자동으로 채워 위로 정렬
});

4. 레이아웃 저장 · 불러오기 (save / load)

위젯을 자유롭게 옮기거나 크기를 바꾼 뒤 "레이아웃 저장"을 누르면 현재 배치가 JSON으로 추출됩니다. 배치를 흐트러뜨린 다음 "저장한 레이아웃 불러오기"를 누르면 그대로 복원됩니다.
저장된 레이아웃 없음
코드 보기 
const grid4 = GridStack.init({ column: 12, cellHeight: 70, margin: 8 }, '#grid4');

let savedLayout = null;
document.getElementById('saveLayoutBtn').addEventListener('click', () => {
  savedLayout = grid4.save(); // 현재 x/y/w/h/내용을 배열로 추출
});
document.getElementById('loadLayoutBtn').addEventListener('click', () => {
  if (savedLayout) grid4.load(savedLayout); // 저장해둔 배치로 복원
});
