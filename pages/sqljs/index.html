sql.js 핵심 기능 둘러보기

sql.js는 SQLite 데이터베이스 엔진을 WebAssembly로 컴파일해서, 서버 없이 브라우저 안에서 진짜 SQL 쿼리를 실행할 수 있게 해주는 라이브러리입니다.
  • new SQL.Database()로 메모리 안에 SQLite 데이터베이스 생성
  • db.exec(sql)로 SQL을 그대로 실행하고 결과를 컬럼/행 배열로 받음
  • db.prepare(sql) + bind()로 값을 안전하게 끼워넣는 파라미터 바인딩 지원
  • db.export()로 현재 데이터베이스를 진짜 .sqlite 파일(바이너리)로 추출 가능
※ 아래 위판 기록 데이터는 sql.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 데이터베이스가 아닙니다. 이 페이지는 sql.js(CDN, WebAssembly) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다. 모든 데이터는 이 브라우저 탭 안에만 존재하며 새로고침하면 사라집니다.

1. 기본 쿼리 실행

위판 기록 테이블을 만들고 데이터를 넣은 뒤, SELECT로 조회한 결과를 표로 보여줍니다.
코드 보기 
db.run(`
  CREATE TABLE markets (id INTEGER PRIMARY KEY, name TEXT, region TEXT);
  CREATE TABLE records (id INTEGER PRIMARY KEY, market_id INTEGER, species TEXT, weight REAL, price INTEGER);
  INSERT INTO markets VALUES (1, '부산공동어시장', '경상권'), (2, '목포수산시장', '전라권');
  INSERT INTO records (market_id, species, weight, price) VALUES
    (1, '고등어', 320, 3200), (1, '갈치', 180, 8500), (2, '오징어', 95, 6100);
`);

const res = db.exec('SELECT * FROM records');
res[0].columns; // ['id', 'market_id', 'species', 'weight', 'price']
res[0].values;  // [[1, 1, '고등어', 320, 3200], ...]

2. 파라미터 바인딩 — SQL 인젝션 방지

어종 이름으로 검색합니다. 검색어에 x' OR '1'='1 같은 값을 넣고 두 방식을 비교해보세요. 문자열을 그대로 이어붙이면 뚫리고, 파라미터 바인딩을 쓰면 안전합니다.
검색어를 입력하고 버튼을 눌러보세요.
코드 보기 
// 위험: 사용자 입력을 SQL 문자열에 직접 끼워넣음
db.exec(`SELECT * FROM records WHERE species = '${userInput}'`);
// userInput이 "x' OR '1'='1" 이면 -> WHERE species = 'x' OR '1'='1' 가 되어 전체 행이 나옴

// 안전: 값은 별도로 바인딩, SQL 구조와 절대 섞이지 않음
const stmt = db.prepare('SELECT * FROM records WHERE species = :s');
stmt.bind({ ':s': userInput });
while (stmt.step()) rows.push(stmt.getAsObject());
stmt.free();

3. JOIN · GROUP BY 집계

위판장(markets)과 위판 기록(records) 두 테이블을 JOIN하고, 위판장별 합계를 GROUP BY로 구합니다.
코드 보기 
const res = db.exec(`
  SELECT m.name AS market, SUM(r.weight) AS total_weight, COUNT(*) AS records
  FROM records r
  JOIN markets m ON r.market_id = m.id
  GROUP BY m.name
  ORDER BY total_weight DESC
`);

4. 데이터베이스 내보내기 · 가져오기

지금 이 브라우저 안 데이터베이스를 실제 .sqlite 파일로 다운로드하고, 그 파일을 다시 올려서 불러올 수 있습니다.
불러오기:
아직 내보내기/가져오기 안 함
코드 보기 
// 내보내기
const bytes = db.export(); // Uint8Array (진짜 SQLite 파일 바이너리)
const blob = new Blob([bytes], { type: 'application/x-sqlite3' });
const a = document.createElement('a');
a.href = URL.createObjectURL(blob);
a.download = 'wipan-records.sqlite'; // 한글 파일명은 브라우저에서 깨질 수 있어 영문으로 지정
a.click();

// 가져오기
const buffer = await file.arrayBuffer();
const loadedDb = new SQL.Database(new Uint8Array(buffer));
loadedDb.exec('SELECT COUNT(*) FROM records');
