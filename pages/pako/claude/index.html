pako 핵심 기능 둘러보기

pako는 zlib을 자바스크립트로 이식한 압축 라이브러리입니다. 브라우저에는 마땅한 내장 압축 API가 없어서, JSON 데이터를 localStorage나 URL 쿼리스트링에 압축해서 담을 때 널리 쓰입니다.
  • pako.gzip(문자열) / pako.ungzip(바이트, {toText:true})로 압축·해제
  • { level: 1~9 }로 압축 강도(속도 vs 압축률 트레이드오프) 조절
  • new pako.Deflate() + push()로 데이터를 청크 단위 스트리밍 압축
  • 압축 결과는 바이너리(Uint8Array)라 텍스트 저장소에 넣으려면 Base64 인코딩이 필요
※ 이 페이지의 위판 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다. 검증 중 실제로 확인한 점: 예전 버전에서 쓰이던 {to:'string'} 옵션은 pako 3.x에서 {toText:true}로 이름이 바뀌었고, 옛 옵션명을 쓰면 에러 없이 조용히 Uint8Array를 반환해버려 실수를 알아채기 어려웠습니다.

1. 텍스트 압축/해제 (gzip)

아래 텍스트를 gzip으로 압축한 뒤 다시 압축을 풀어 원본과 정확히 일치하는지 실제로 비교합니다.
아직 압축 안 함
코드 보기 
const compressed = pako.gzip(text);          // Uint8Array
const restored = pako.ungzip(compressed, { toText: true }); // 문자열로 복원
console.log(restored === text); // true

2. 압축 레벨 비교

같은 텍스트를 압축 레벨 1(빠름·낮은 압축률)부터 9(느림·높은 압축률)까지 비교합니다.
코드 보기 
pako.deflate(text, { level: 1 }); // 빠르지만 덜 압축됨
pako.deflate(text, { level: 9 }); // 느리지만 더 압축됨

3. 스트리밍 압축 (Deflate 청크 단위 push)

긴 텍스트를 500자씩 잘라 Deflate 인스턴스에 순서대로 밀어넣습니다. 한 번에 압축한 결과와 바이트 단위까지 동일한지 확인합니다.
아직 실행 안 함
코드 보기 
const deflator = new pako.Deflate({ level: 6 });
chunks.forEach((chunk, i) => {
  deflator.push(chunk, i === chunks.length - 1); // 마지막 청크만 true(Z_FINISH)
});
console.log(deflator.result); // 전체 압축 결과

4. gzip + Base64로 localStorage에 저장

가상 위판 기록 50건을 JSON으로 만들어 압축 후 Base64로 인코딩해 실제 localStorage에 저장하고, 다시 읽어와 압축을 풀어 원본과 비교합니다.
아직 저장 안 함
코드 보기 
const gz = pako.gzip(JSON.stringify(data));
const b64 = btoa(String.fromCharCode(...gz));   // 바이너리 → Base64 문자열
localStorage.setItem('key', b64);

const restored = atob(localStorage.getItem('key'));
const bytes = Uint8Array.from(restored, c => c.charCodeAt(0));
const data2 = JSON.parse(pako.ungzip(bytes, { toText: true }));
