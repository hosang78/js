Automerge 핵심 기능 둘러보기

Automerge는 Yjs와 같은 목적(여러 사람이 동시에 편집해도 자동으로 합쳐지는 CRDT)을 갖지만, API 스타일이 전혀 다릅니다. 공유 객체를 직접 변형하는 대신, 일반 JS 객체처럼 다루면서 수정할 때마다 새로운 불변(immutable) 스냅샷을 돌려받는 함수형 방식입니다.
  • Automerge.from(data)로 문서 생성, Automerge.change(doc, fn)으로 수정 — 항상 새 객체를 반환
  • Automerge.clone(doc)으로 독립된 사본을 만들어 각자 수정 후 Automerge.merge()로 자동 병합
  • Automerge.getHistory(doc)로 지금까지의 모든 변경을 시간순 스냅샷으로 조회
  • Automerge.save(doc) / Automerge.load(bytes)로 문서 전체를 바이너리로 저장·복원
※ Automerge 코어는 Rust로 작성되어 WebAssembly(WASM)로 컴파일됩니다. 공식 문서는 브라우저에서 쓰려면 번들러가 필요하다고 안내하지만, 이 패키지는 WASM을 base64 문자열로 아예 JS 안에 내장한 fullfat_base64 진입점을 함께 제공해서 번들러 없이 <script type="module">만으로도 바로 동작하는 것을 실제로 확인했습니다. 이 페이지의 위판 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 문서 생성 + 불변 함수형 수정

버튼을 누르면 change()가 항상 새 객체를 반환하는 것을 확인할 수 있습니다(기존 문서는 그대로 유지됨).

    

    

      코드 보기
      
let doc = Automerge.from({ items: [{ species: '고등어', price: 4200 }] });

const before = doc;
doc = Automerge.change(doc, (d) => {
  d.items.push({ species: '갈치', price: 3100 });
});
doc !== before; // true — 새 객체가 반환됨 (기존 doc은 변하지 않음)

    

  


  

    
2. clone → 독립 수정 → merge로 자동 병합

    
문서 A, B는 clone()으로 나뉜 독립 사본입니다. 각자 다른 필드를 수정한 뒤 "동기화" 버튼을 눌러 자동으로 합쳐지는 것을 확인하세요.

문서 B

        

        

      

    

    

    
아직 동기화 안 함 — 두 문서가 다른 상태입니다

    

      코드 보기
      
let docA = Automerge.from({ notice: '위판 시세: 고등어 4200원' });
let docB = Automerge.clone(docA);

docA = Automerge.change(docA, (d) => { d.notice += ' (인상)'; });
docB = Automerge.change(docB, (d) => { d.marker = '[속보]'; });

docA = Automerge.merge(docA, docB);
docB = Automerge.merge(docB, docA);
// 이제 docA, docB 모두 { notice: '... (인상)', marker: '[속보]' }

    

  


  

    
3. 변경 이력(History) 조회

    
getHistory()는 지금까지의 모든 변경을 각 시점의 문서 스냅샷과 함께 시간순으로 돌려줍니다.

    

    
아직 조회 안 함

    

      코드 보기
      
const history = Automerge.getHistory(doc);
history.forEach((h, i) => {
  console.log(`변경 ${i}:`, h.snapshot); // 그 시점의 문서 전체 스냅샷
});

    

  


  

    
4. save() / load() — 바이너리 직렬화 라운드트립

    
문서 전체를 바이너리로 저장했다가 다시 불러와도 완전히 동일한 내용임을 확인합니다.

    

    
아직 시도 안 함

    

      코드 보기
      
const bytes = Automerge.save(doc);   // Uint8Array
const restored = Automerge.load(bytes);
JSON.stringify(restored) === JSON.stringify(doc); // true
