Cleave.js 핵심 기능 둘러보기

Cleave.js는 타이핑하는 동안 입력값을 실시간으로 원하는 형식에 맞춰 재배열해주는 라이브러리입니다. 카드 번호에 4자리마다 공백을 넣거나, 숫자에 천 단위 콤마를 붙이거나, 날짜·전화 번호를 자동으로 구분해주는 식입니다.
  • creditCard: true로 하는 카드번호 자동 포맷 + 카드사 인식
  • numeral: true로 하는 통화 포맷
  • date: true로 하는 날짜 포맷
  • phone: true + 지역 애드온으로 하는 한국 전화번호 포맷
※ 아래 카드번호·금액·연락처는 이 페이지를 위해 만든 가상의 예시 입력값이며, 실제 결제·개인정보와 무관합니다. 실제 카드번호를 입력하지 마세요. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 카드번호 자동 포맷 + 카드사 인식

숫자를 입력하면 4자리마다 자동으로 띄어 쓰고, 앞자리 패턴으로 Visa · Mastercard 같은 카드사를 실시간으로 인식합니다. (테스트용 예시 번호만 입력해보세요)
카드번호를 입력해보세요.
코드 보기 
new Cleave('#c1', {
  creditCard: true,
  onCreditCardTypeChanged: (type) => {
    stat.textContent = `인식된 카드사: ${type}`;
  },
});

2. 통화 포맷

숫자를 입력하면 천 단위마다 콤마가 붙고 앞에 "₩ "가 붙습니다. 화면 표시와 별개로 getRawValue()로 순수 숫자만 뽑아낼 수 있습니다.
아직 입력된 금액이 없습니다.
코드 보기 
new Cleave('#c2', {
  numeral: true,
  numeralThousandsGroupStyle: 'thousand',
  numeralDecimalScale: 0,
  prefix: '₩ ',
  // prefix를 쓰면 getRawValue()가 기본적으로 접두어까지 포함해서 돌려준다.
  // 순수 숫자만 받으려면 rawValueTrimPrefix를 명시해야 한다.
  rawValueTrimPrefix: true,
});

3. 날짜 포맷

숫자만 입력해도 YYYY-MM-DD 형식으로 하이픈이 자동으로 붙습니다.
아직 입력된 날짜가 없습니다.
코드 보기 
new Cleave('#c3', {
  date: true,
  datePattern: ['Y', 'm', 'd'],
  delimiter: '-',
});

4. 한국 전화번호 포맷

지역 애드온(cleave-phone.kr.js)을 함께 불러오면 한국 번호 체계에 맞춰 지역번호·휴대폰·대표번호 패턴을 구분해서 하이픈을 붙여줍니다.
아직 입력된 번호가 없습니다.
코드 보기 
new Cleave('#c4', {
  phone: true,
  phoneRegionCode: 'KR',
});
