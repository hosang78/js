전국 위판장 현황

해양수산부가 공공데이터포털(data.go.kr)에 공개한 실제 API 2종을 연동한 페이지입니다. 이 저장소의 다른 라이브러리 데모들과 달리, 여기 나오는 위판장·위판 실적 데이터는 가상의 예시가 아니라 실제 정부 공공데이터입니다.

  • 위판장 정보 (select0020List) — 산지조합명, 위판장명, 주소, 전화번호
  • 위판장별 위탁 판매 현황 (select0040List) — 위판일자별 수산물 품목·수량·중량·단가·금액
  • 위판장 목록에서 항목을 클릭하면 그 위판장명으로 바로 위판 현황을 연계 조회합니다
  • 브라우저가 data.go.kr을 직접 호출합니다 (서버 프록시 없음)
⚠️ 개인 테스트 목적으로 발급받은 일반 인증키를 이 페이지 코드에 그대로 사용합니다(요청하신 대로 소스에 노출). data.go.kr 응답은 위·경도 좌표를 제공하지 않아 지도 대신 표로 표시합니다. 브라우저 환경에 따라 직접 호출이 막히면 각 섹션의 "응답 붙여넣기"를 펼쳐서 요청 URL을 새 탭에서 열어 나온 결과를 붙여넣으면 동일하게 표시됩니다. 아래 "원본 응답 보기"에서 실제로 어떤 응답이 왔는지 항상 확인할 수 있습니다.
