UTIF.js 핵심 기능 둘러보기

UTIF.js는 브라우저가 기본적으로 표시하지 못하는 TIFF 이미지를 디코딩해서 캔버스에 그리거나, 반대로 인코딩해서 TIFF 파일을 만드는 라이브러리입니다. 스캐너·팩스·문서 보관용으로 아직도 TIFF가 많이 쓰입니다.
  • UTIF.decode + toRGBA8로 하는 여러 압축 방식(LZW·PackBits)의 TIFF 디코딩
  • 멀티페이지 TIFF 페이지 넘겨보기
  • UTIF.encodeImage로 하는 TIFF 인코딩 + 다운로드
  • UTIF.replaceIMG()로 <img>에 TIFF 직접 표시
※ 아래 TIFF 샘플 파일은 실제 libtiff 도구로 만든 진짜 TIFF 파일이며, 내용은 이 페이지를 위한 가상의 위판 문서 이미지입니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 압축 방식별 TIFF 디코딩 (LZW / PackBits)

TIFF는 압축 방식이 여러 가지입니다. 같은 이미지를 LZW와 PackBits로 각각 압축한 파일을 디코딩해서 파일 크기를 비교합니다.
소스 코드 보기 
const buf = await fetch('sample.tif').then(r => r.arrayBuffer());
const ifds = UTIF.decode(buf);       // 파일 안의 이미지(페이지) 목록
UTIF.decodeImage(buf, ifds[0]);      // 첫 번째 이미지의 픽셀 데이터를 디코딩
const rgba = UTIF.toRGBA8(ifds[0]);  // Uint8Array, canvas putImageData에 바로 사용 가능

const imgData = new ImageData(new Uint8ClampedArray(rgba), ifds[0].width, ifds[0].height);
ctx.putImageData(imgData, 0, 0);

2. 멀티페이지 TIFF 넘겨보기

TIFF 한 파일 안에 여러 페이지가 들어있을 수 있습니다. UTIF.decode()가 반환하는 배열의 길이가 곧 페이지 수입니다.
소스 코드 보기 
const ifds = UTIF.decode(buf);
console.log(ifds.length); // 페이지 수

UTIF.decodeImage(buf, ifds[pageIndex]);
const rgba = UTIF.toRGBA8(ifds[pageIndex]); // 원하는 페이지만 디코딩

3. TIFF 인코딩 + 다운로드

캔버스에 그린 이미지를 UTIF.encodeImage(rgba, width, height)로 TIFF 바이너리로 인코딩합니다.
소스 코드 보기 
const imgData = ctx.getImageData(0, 0, canvas.width, canvas.height);
const tiffBuf = UTIF.encodeImage(imgData.data.buffer, canvas.width, canvas.height);
const blob = new Blob([tiffBuf], { type: 'image/tiff' });
// 다운로드

4. <img>에 TIFF 직접 표시 (replaceIMG)

브라우저는 원래 <img src="파일.tif">를 표시하지 못합니다(깨진 이미지 아이콘만 나옴). UTIF.replaceIMG()를 한 번 호출하면 페이지 안의 모든 TIFF <img> 태그를 찾아서 PNG로 변환해 자동으로 표시해줍니다.
소스 코드 보기 
<img src="photo.tif" />

<script>
  UTIF.replaceIMG(); // 페이지 안의 .tif 이미지를 모두 찾아서 표시 가능한 형태로 바꿔줌
</script>
