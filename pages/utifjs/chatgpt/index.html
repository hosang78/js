처리 로그

UTIF.js 처리 흐름

1. UTIF.decode(buffer)로 IFD 목록 파싱
2. UTIF.decodeImage(buffer, ifd)로 픽셀 데이터 해제
3. UTIF.toRGBA8(ifd)로 8비트 RGBA 변환
4. Canvas 표시 또는 UTIF.encodeImage()로 TIFF 생성

현재 페이지의 RGBA 데이터를 256개 밝기 구간으로 집계한다. 큰 이미지는 최대 약 25만 픽셀만 샘플링한다.
