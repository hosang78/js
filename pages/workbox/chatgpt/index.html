⚙️ Workbox 기능 갤러리 · 단일 HTML 버전

Workbox의 주요 기능을 한 페이지에서 눌러보고 이해하는 샘플

이 파일은 별도 빌드·npm 없이 열 수 있는 단일 HTML이다. 브라우저 보안상 실제 서비스워커는 보통 별도 sw.js가 필요하므로, 이 페이지는 Workbox의 동작 원리를 시뮬레이션하고, 실제 적용 가능한 sw.js 코드도 함께 제공한다.

Workbox는 서비스워커를 쉽게 작성하도록 돕는 라이브러리다. 프리캐시, 라우팅, 캐싱 전략, 만료 정책, 백그라운드 동기화, 캐시 업데이트 알림 같은 기능을 모듈화해서 제공한다.

workbox-sw

서비스워커 안에서 Workbox 모듈을 CDN 또는 로컬 파일로 불러오는 진입점.

importScriptssetConfig

workbox-routing

요청 URL, HTTP 메서드, 목적지에 따라 전략을 연결하는 라우터.

registerRouteNavigationRoute

workbox-strategies

NetworkFirst, CacheFirst, StaleWhileRevalidate 등 대표 캐싱 전략 제공.

NetworkFirstCacheFirst

workbox-precaching

빌드 시점 또는 수동 목록 기반으로 핵심 파일을 미리 캐시.

precacheAndRoutecleanupOutdatedCaches

workbox-expiration

캐시 항목 수와 보관 기간을 제한해 저장공간을 관리.

maxEntriesmaxAgeSeconds

workbox-background-sync

오프라인 상태에서 실패한 POST 요청을 큐에 넣고 온라인 복구 후 재전송.

QueueBackgroundSyncPlugin

Navigation Preload

서비스워커가 부팅되는 동안 브라우저가 네트워크 요청을 미리 시작해 응답 지연을 줄이는 기능이다.

Background Sync

오프라인에서 실패한 POST 요청을 큐에 보관했다가 온라인 복구 시 재시도한다.

Broadcast Update

캐시된 응답이 백그라운드에서 새 버전으로 바뀌었을 때 페이지에 업데이트 알림을 보낸다.
