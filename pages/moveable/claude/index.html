Moveable 핵심 기능 둘러보기

Moveable은 화면 위의 요소를 드래그·리사이즈·회전·워프 등 다양한 방식으로 자유롭게 조작할 수 있게 해주는 라이브러리입니다. 하나의 Moveable 인스턴스가 대상 요소 주위에 조작용 컨트롤(핸들)을 그려주고, 사용자가 그 핸들을 움직이면 이벤트로 변화량을 알려줍니다.
  • 모서리 핸들로 하는 드래그 + 리사이즈
  • 모서리 밖 회전 핸들로 하는 회전(rotatable)
  • target에 배열을 넘겨 여러 요소를 한 번에 다루는 그룹 이동·회전
  • 다른 요소·경계에 자동으로 달라붙는 스냅 가이드라인(snappable)
※ 아래 카드 이름과 배치는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 드래그 + 리사이즈

카드 안쪽을 눌러 드래그하면 이동하고, 모서리·변의 핸들을 드래그하면 크기가 바뀝니다. 어느 모서리로 리사이즈해도 반대쪽 모서리는 그 자리에 고정됩니다.
A위판장
오늘 위판량 820kg
코드 보기 
const moveable = new Moveable(stage1, {
  target: card1,
  draggable: true,
  resizable: true,
});

moveable.on('drag', ({ target, left, top }) => {
  target.style.left = `${left}px`;
  target.style.top = `${top}px`;
});
moveable.on('resize', ({ target, width, height, drag }) => {
  // drag.left/top: 리사이즈 기준점이 반대쪽에 고정되도록 보정된 좌표
  target.style.width = `${width}px`;
  target.style.height = `${height}px`;
  target.style.left = `${drag.left}px`;
  target.style.top = `${drag.top}px`;
});

2. 회전

카드 위쪽에 떨어져 있는 동그란 회전 핸들을 드래그하면 카드가 중심을 기준으로 회전합니다.
특가 알림
고등어 한정 특가
코드 보기 
const moveable = new Moveable(stage2, {
  target: card2,
  rotatable: true,
});

moveable.on('rotate', ({ target, transform }) => {
  target.style.transform = transform;
});

3. 그룹 이동 · 회전

target에 여러 요소를 배열로 넘기면 하나의 그룹으로 묶여 동시에 이동·회전합니다. 카드 하나를 드래그하면 세 카드가 함께 움직입니다.

C위판장
D위판장
코드 보기 
const groupMoveable = new Moveable(stage3, {
  target: [g1, g2, g3],
  draggable: true,
  rotatable: true,
});

groupMoveable.on('dragGroup', ({ events }) => {
  events.forEach((ev) => {
    ev.target.style.left = `${ev.left}px`;
    ev.target.style.top = `${ev.top}px`;
  });
});
groupMoveable.on('rotateGroup', ({ events }) => {
  events.forEach((ev) => {
    ev.target.style.transform = ev.transform;
  });
});

4. 스냅 가이드라인

회색 카드 두 개는 elementGuidelines로 등록된 기준 요소입니다. 보라색 카드를 회색 카드 가장자리나 스테이지 중앙 가까이로 옮겨보면 자동으로 달라붙고 초록 점선 가이드라인이 나타납니다.

const snapMoveable = new Moveable(stage4, {
  target: snapCard,

  snapDirections: { top: true, left: true, bottom: true, right: true, center: true, middle: true },

});

  target.style.left = `${left}px`;
  target.style.top = `${top}px`;
});
