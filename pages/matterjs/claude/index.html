Matter.js 핵심 기능 둘러보기

Matter.js는 중력·충돌·마찰·반발력 같은 실제 물리 법칙을 시뮬레이션하는 2D 리지드바디 엔진입니다. 게임이나 인터랙티브 UI에서 "진짜처럼 움직이는" 오브젝트를 만들 때 쓰입니다.
  • Engine.create()로 물리 세계를 만들고 Bodies.rectangle/circle()로 물체 생성
  • Runner.run(runner, engine)로 시뮬레이션을 매 프레임 진행
  • Matter.Render는 내장 캔버스 렌더러 — 직접 그리기 코드를 짤 필요 없음
  • Events.on(engine, 'collisionStart', ...)로 충돌 순간 감지
  • MouseConstraint로 마우스 드래그, Constraint로 로프·스프링 연결
※ 렌더링은 Matter.js에 내장된 Matter.Render(캔버스 2D 렌더러)를 그대로 사용했습니다. 다른 외부 API는 사용하지 않습니다.

1. 중력 낙하 + 반발(restitution)

반발계수가 다른 도형들을 떨어뜨립니다. 값이 높을수록(공처럼) 더 많이 튕기고, 낮으면(상자처럼) 거의 안 튕깁니다.
코드 보기 
const bouncyBall = Bodies.circle(x, y, 20, { restitution: 0.9 }); // 잘 튕김
const dullBox = Bodies.rectangle(x, y, 40, 40, { restitution: 0.05 }); // 거의 안 튕김

2. 충돌 감지 (collisionStart)

공이 떨어지다가 다른 물체와 부딪히는 순간 색이 바뀝니다. 실제 충돌 이벤트를 감지해서 처리합니다.
충돌 횟수: 0
코드 보기 
Events.on(engine, 'collisionStart', (event) => {
  event.pairs.forEach((pair) => {
    pair.bodyA.render.fillStyle = '#e0524a';
    pair.bodyB.render.fillStyle = '#e0524a';
  });
});

3. 마우스로 드래그 (MouseConstraint)

도형을 마우스로 직접 잡아서 끌었다 놓아보세요. 놓는 순간의 속도가 그대로 관성으로 이어집니다.
코드 보기 
const mouse = Mouse.create(canvas);
const mouseConstraint = MouseConstraint.create(engine, { mouse });
Composite.add(world, mouseConstraint); // 이것만 추가하면 모든 물체가 드래그 가능해짐

4. Constraint로 만든 진자

고정점과 물체를 Constraint로 연결하면 진자가 됩니다. 클릭해서 밀어보세요.
코드 보기 
const constraint = Constraint.create({
  pointA: { x: 250, y: 30 },  // 고정된 지지점
  bodyB: pendulumBob,
  length: 120,
  stiffness: 0.9,
});

5. 마찰(friction) 비교

경사면 위에 마찰이 낮은 상자(파란색)와 높은 상자(주황색)를 올려두면, 마찰이 낮은 쪽이 훨씬 더 멀리 미끄러집니다.
아직 측정 안 함
코드 보기 
Bodies.rectangle(x, y, 30, 30, { friction: 0.001 }); // 미끄러운 표면
Bodies.rectangle(x, y, 30, 30, { friction: 0.9 });   // 거친 표면
