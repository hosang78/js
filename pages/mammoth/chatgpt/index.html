API 및 실무 적용 포인트

현재 화면은 브라우저 입력 방식인 { arrayBuffer }를 사용합니다. 외부 파일 참조 접근은 기본적으로 비활성화된 상태를 유지합니다. transformDocument는 공식 문서상 안정 API로 보장되지 않으므로 실제 도입 시 버전 고정 및 회귀 검증이 필요합니다.
