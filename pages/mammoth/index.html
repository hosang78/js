Mammoth.js 핵심 기능 둘러보기

Mammoth.js는 워드(.docx) 문서를 브라우저에서 서버 없이 깔끔한 HTML로 변환해주는 라이브러리입니다. 워드로 작성한 보고서를 웹 게시판에 올리거나 미리보기로 보여줄 때 유용합니다.
  • .docx 파일을 그대로 넣으면 제목/문단/굵게 등 의미 있는 서식만 뽑아 HTML로 변환
  • 워드 스타일(예: "제목 1")을 원하는 HTML 태그·클래스로 매핑(styleMap) 가능
  • 변환 중 지원되지 않는 서식을 만나면 경고 메시지로 알려줌
  • 서식 없이 순수 텍스트만 뽑아내는 것도 가능(extractRawText)
※ 아래는 Mammoth.js 학습용 데모이며, 업로드한 .docx 파일은 브라우저 안에서만 처리되고 서버로 전송되지 않습니다. 예시로 사용한 "위판 실적 보고서" 내용은 가상이며 실제 수협중앙회의 자료가 아닙니다. 이 페이지는 Mammoth.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 docx → HTML 변환

.docx 파일을 선택하면 HTML로 변환해서 미리보기로 보여줍니다. 여기서 선택한 파일을 아래 2~4번 섹션에서도 함께 사용합니다.
.docx 파일을 선택해보세요.
코드 보기 
const arrayBuffer = await file.arrayBuffer();
const result = await mammoth.convertToHtml({ arrayBuffer });
previewBox.innerHTML = result.value; // 변환된 HTML

2. 스타일 매핑 (styleMap)

기본적으로 워드의 "제목 1(Heading 1)"은 <h1>로 변환됩니다. styleMap으로 이 매핑 규칙을 바꿔볼 수 있습니다.
1번에서 파일을 선택한 뒤 눌러보세요.
코드 보기 
mammoth.convertToHtml({ arrayBuffer }, {
  styleMap: ["p[style-name='Heading 1'] => h2.custom-heading:fresh"],
});

3. 변환 경고 메시지 (messages)

워드 문서에 Mammoth가 인식하지 못하는 스타일이나 요소가 있으면, 변환은 계속 진행되면서 어떤 부분이 문제인지 경고 메시지로 알려줍니다.
1번에서 파일을 선택한 뒤 눌러보세요.
코드 보기 
const result = await mammoth.convertToHtml({ arrayBuffer });
result.messages.forEach((m) => console.log(m.type, m.message));
// 예: "Unrecognised paragraph style: ..." 같은 경고

4. 원본 텍스트만 추출 (extractRawText)

서식을 다 무시하고 순수 텍스트만 뽑아냅니다. 검색 인덱싱이나 요약에 유용합니다.
코드 보기 
const result = await mammoth.extractRawText({ arrayBuffer });
console.log(result.value); // 서식 없는 순수 텍스트
