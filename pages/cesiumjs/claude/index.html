CesiumJS 핵심 기능 둘러보기

CesiumJS는 지금까지 살펴본 MapLibre·OpenLayers·deck.gl과 달리, 평면 지도가 아니라 실제 지구 곡률을 가진 회전하는 3D 지구본을 다루는 라이브러리입니다. 항공·해양·위성 같은 3D 공간 시각화에 특화되어 있습니다.
  • Cesium.Viewer로 3D 지구본 생성, camera.flyTo()로 부드러운 카메라 이동 애니메이션
  • viewer.entities.add()로 지구본 위 어느 위치에나 포인트·라벨·모델 등을 3D로 배치
  • 폴리곤·폴리라인 엔티티로 3D 공간에 영역·경로 표시
  • scene.morphTo2D() / morphTo3D()로 3D 지구본과 평면 지도(2D), 그 중간 형태(Columbus View) 사이를 애니메이션과 함께 전환
※ CesiumJS는 기본 설정으로 쓰면 지형·베이스 이미지에 Cesium ion API 키가 필요합니다. 이 페이지는 API 키 없이도 쓸 수 있는 OpenStreetMapImageryProvider(이미지)와 EllipsoidTerrainProvider(고도 없는 매끈한 타원체 지형)로 구성해 별도 키 없이 동작합니다. 또한 검증 중 폴리곤을 지형에 딱 붙이면(clamp) 외곽선이 자동으로 꺼지는 것을 실제로 확인했고, 3번 섹션에서 height: 0을 지정해 이를 우회했습니다. 위판장 위치는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다.

1. 기본 3D 지구본 + 카메라 이동

마우스로 드래그해 지구본을 돌려보세요. 버튼을 누르면 부산 인근(가상 좌표)으로 카메라가 부드럽게 이동합니다.
코드 보기 
const viewer = new Cesium.Viewer('map1', {
  imageryProvider: new Cesium.OpenStreetMapImageryProvider({ url: 'https://tile.openstreetmap.org/' }),
  terrainProvider: new Cesium.EllipsoidTerrainProvider(),
});

viewer.camera.flyTo({
  destination: Cesium.Cartesian3.fromDegrees(129.0756, 35.0951, 15000),
  duration: 2,
});

2. Entity API — 3D 포인트/라벨 마커

지구본 위 특정 좌표에 점과 라벨을 3D 공간 좌표로 배치합니다.
코드 보기 
viewer.entities.add({
  position: Cesium.Cartesian3.fromDegrees(129.0756, 35.0951),
  point: { pixelSize: 12, color: Cesium.Color.fromCssColorString('#4f7dff') },
  label: { text: '부산공동어시장(가상)', pixelOffset: new Cesium.Cartesian2(0, -20) },
});

3. 폴리곤 엔티티 — 조업 구역 표시

여러 좌표를 이어 3D 공간에 영역을 그립니다.
코드 보기 
viewer.entities.add({
  polygon: {
    hierarchy: Cesium.Cartesian3.fromDegreesArray([129.05, 35.08, 129.10, 35.08, 129.10, 35.12, 129.05, 35.12]),
    material: Cesium.Color.fromCssColorString('#1baf7a').withAlpha(0.4),
    outline: true,
    outlineColor: Cesium.Color.fromCssColorString('#1baf7a'),
    height: 0, // 지형에 클램핑하면 외곽선이 자동으로 꺼지므로 명시적으로 고도 지정
  },
});

4. Scene Mode 전환 (3D ↔ 2D ↔ Columbus View)

같은 지구본을 3D, 평면(2D), 그 중간 형태(Columbus View)로 애니메이션과 함께 전환합니다.
코드 보기 
viewer.scene.morphTo3D(1.0);
viewer.scene.morphTo2D(1.0);
viewer.scene.morphToColumbusView(1.0);
