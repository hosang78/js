Rete.js 핵심 기능 둘러보기

Rete.js는 노드 기반 비주얼 에디터를 직접 만들기 위한 프레임워크입니다. Drawflow처럼 완성된 에디터를 바로 주는 것이 아니라, "노드를 어떻게 그릴지"는 개발자가 정하고 Rete.js는 노드/연결의 데이터 구조와 상호작용(드래그 연결, 확대/축소 등)을 담당합니다.
  • Scope 기반 플러그인 구조 — NodeEditor · AreaPlugin(캔버스) · ConnectionPlugin(드래그 연결)이 부모-자식으로 연결됨
  • 공식 렌더러는 React/Vue/Angular/Svelte용만 있고 순수 JS(vanilla)용은 없어서, 이 페이지는 노드·소켓·연결선을 직접 그리는 최소 렌더러를 만들어 사용
  • rete-engine의 DataflowEngine — 단순히 그려주기만 하는 게 아니라 노드 그래프를 실제로 "실행"해서 값을 계산
  • rete-auto-arrange-plugin으로 노드 자동 배치
※ 아래 어선·위판장 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 조직·통계와 무관합니다. Rete.js 코어 외에 소켓 좌표 추적용 rete-render-utils, 계산 실행용 rete-engine, 자동 배치용 rete-auto-arrange-plugin(내부적으로 ELK.js 사용)을 함께 씁니다. 노드/연결선 자체의 시각적 렌더링은 이 페이지에서 직접 작성한 코드입니다.

1. 기본 노드 에디터 (직접 만든 vanilla 렌더러)

"위판장 입고" 노드의 출력 소켓(오른쪽 점)을 "유통센터" 노드의 입력 소켓(왼쪽 점)으로 마우스 드래그해 새 연결을 만들어보세요. 노드 제목을 드래그하면 위치도 옮길 수 있습니다.
아직 "경매" → "유통센터" 연결이 없습니다.
코드 보기 
// Rete.js는 렌더러가 없으므로 area.addPipe로 'render' 시그널을 가로채
// 노드/소켓/연결선을 직접 DOM에 그린다.
class VanillaRenderPlugin extends Rete.Scope {
  constructor() { super('vanilla-render'); }
}
const render = new VanillaRenderPlugin();
area.use(render);                                  // area의 자식 Scope로 등록해야
const socketPosition = ReteRenderUtils.getDOMSocketPosition();
socketPosition.attach(render);                      // .attach()가 정상 동작한다

render.addPipe((context) => {
  if (context.type === 'render') {
    const { element, type, payload } = context.data;
    if (type === 'node') renderNode(element, payload);
    else if (type === 'connection') renderConnection(element, payload);
  }
  return context;
});

// 소켓 DOM을 만든 뒤, ConnectionPlugin이 찾을 수 있도록 'render'를,
// 좌표 추적을 위해 'rendered'를 area에 순서대로 emit 해줘야 한다.
const data = { element: socketEl, type: 'socket', side, key, nodeId, payload: socket };
area.emit({ type: 'render', data }).then(() => area.emit({ type: 'rendered', data }));

2. 데이터플로우 엔진 — 실시간 재계산

숫자 입력칸은 노드 안에 실제로 내장된 컨트롤(ClassicPreset.InputControl)입니다. 값을 바꾸면 rete-engine의 DataflowEngine이 "합계" 노드부터 "결과" 노드까지 그래프를 따라가며 실제로 다시 계산합니다.
총 위판량: -
코드 보기 
class BoatNode extends ClassicPreset.Node {
  constructor(label, initial) {
    super(label);
    this.addOutput('value', new ClassicPreset.Output(numSocket, '어획량(kg)'));
    this.addControl('value', new ClassicPreset.InputControl('number', {
      initial, change: () => recompute(),   // 값 바뀌면 재계산 트리거
    }));
  }
  data() { return { value: Number(this.controls.value.value) || 0 }; }
}

class SumNode extends ClassicPreset.Node {
  constructor() {
    super('합계');
    this.addInput('a', new ClassicPreset.Input(numSocket, 'A'));
    this.addInput('b', new ClassicPreset.Input(numSocket, 'B'));
    this.addOutput('value', new ClassicPreset.Output(numSocket, '합계'));
  }
  // inputs는 연결된 소스 노드들의 data() 반환값을 rete-engine이 재귀적으로 모아준 것
  data(inputs) {
    const a = inputs.a ? inputs.a[0] : 0;
    const b = inputs.b ? inputs.b[0] : 0;
    return { value: a + b };
  }
}

const engine = new ReteEngine.DataflowEngine();
editor.use(engine);   // editor에 등록해야 nodecreated 시그널을 자동으로 받는다

async function recompute() {
  engine.reset();                                  // 캐시 초기화
  const { value } = await engine.fetch(resultNode.id); // 결과 노드까지 재귀적으로 계산
  resultBox.textContent = `총 위판량: ${value} kg`;
}

3. 다단계 데이터플로우 (재귀 계산)

어선 4척 → 위판장별 합계 2개 → 총 합계, 3단계로 이어진 그래프입니다. 아무 입력값이나 바꿔보면 DataflowEngine.fetch()가 "총 합계" 노드에서 시작해 앞 단계 노드들의 data()를 재귀적으로 호출하며 전체를 다시 계산하는 것을 볼 수 있습니다.
총 위판량: -
코드 보기 
// 어선 1호,2호 → A위판장 합계
await editor.addConnection(new ClassicPreset.Connection(boat1, 'value', sumA, 'a'));
await editor.addConnection(new ClassicPreset.Connection(boat2, 'value', sumA, 'b'));
// 어선 3호,4호 → B위판장 합계
await editor.addConnection(new ClassicPreset.Connection(boat3, 'value', sumB, 'a'));
await editor.addConnection(new ClassicPreset.Connection(boat4, 'value', sumB, 'b'));
// A위판장 합계, B위판장 합계 → 총 합계
await editor.addConnection(new ClassicPreset.Connection(sumA, 'value', total, 'a'));
await editor.addConnection(new ClassicPreset.Connection(sumB, 'value', total, 'b'));

// fetch(total)을 호출하면 total → sumA/sumB → boat1~4 순으로
// 필요한 만큼만 재귀적으로 data()를 호출해 계산한다.
const { value } = await engine.fetch(total.id);

4. 자동 배치 (rete-auto-arrange-plugin + ELK.js)

노드들이 무작위 위치에 흩어져 있습니다. "자동 정렬" 버튼을 누르면 rete-auto-arrange-plugin이 (내부적으로 ELK.js의 레이어드 알고리즘을 사용해) 흐름 방향에 맞춰 노드 위치를 계산하고, 연결선은 실시간으로 따라 움직입니다.
코드 보기 
const arrange = new ReteAutoArrangePlugin.AutoArrangePlugin();
area.use(arrange);
arrange.addPreset(ReteAutoArrangePlugin.Presets.classic.setup());

// 자동 배치 계산에는 노드의 width/height가 필요하다 (직접 지정)
node.width = 150;
node.height = 40 + Math.max(inputCount, outputCount) * 22 + 10;

btnArrange.addEventListener('click', () => arrange.layout());
