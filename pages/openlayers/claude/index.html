OpenLayers 핵심 기능 둘러보기

OpenLayers는 오래되고 검증된 오픈소스 지도 라이브러리로, 다양한 좌표계와 데이터 포맷을 폭넓게 다루는 전통적인 지도 툴킷입니다.
  • ol.Map + ol.View + 타일 source로 기본 지도 구성
  • 벡터 레이어에 Feature를 올리고, ol.Overlay로 지도 위에 HTML 팝업 배치
  • ol.interaction.Draw로 사용자가 지도 위에 직접 점·선·면을 그릴 수 있는 편집 기능 — MapLibre 데모에서는 다루지 않은 부분
  • 내부적으로 지도 좌표는 Web Mercator(EPSG:3857)를 쓰기 때문에, 위경도(EPSG:4326)와 서로 변환하는 fromLonLat/toLonLat이 필수적으로 쓰임
※ 이 페이지의 "부산공동어시장" 등 위치·명칭은 실제 좌표와 다를 수 있는 가상의 예시이며 실제 수협중앙회의 위치 정보가 아닙니다. 타일은 OpenStreetMap을 별도 API 키 없이 사용합니다.

1. 기본 지도 생성

OSM 타일 위에 확대/축소 컨트롤이 기본으로 포함된 지도입니다.
코드 보기 
const map = new ol.Map({
  target: 'map1',
  layers: [new ol.layer.Tile({ source: new ol.source.OSM() })],
  view: new ol.View({
    center: ol.proj.fromLonLat([129.0756, 35.0951]), // 위경도 → Web Mercator
    zoom: 13,
  }),
});

2. 마커(벡터 레이어) + Overlay 팝업

지도 위 파란 점을 클릭하면 ol.Overlay로 만든 HTML 팝업이 뜹니다.
코드 보기 
const marker = new ol.Feature({ geometry: new ol.geom.Point(coord) });
map.addLayer(new ol.layer.Vector({ source: new ol.source.Vector({ features: [marker] }) }));

const overlay = new ol.Overlay({ element: popupEl });
map.addOverlay(overlay);

map.on('click', (evt) => {
  const hit = map.hasFeatureAtPixel(evt.pixel);
  if (hit) overlay.setPosition(evt.coordinate);
});

3. Draw 인터랙션 — 직접 그리기

도형 종류를 고르고 지도를 클릭해서 그려보세요. 면(Polygon)은 더블클릭으로 완료합니다.
그려진 도형: 0개
코드 보기 
const source = new ol.source.Vector();
map.addLayer(new ol.layer.Vector({ source }));

const draw = new ol.interaction.Draw({ source, type: 'Polygon' }); // 'Point' | 'LineString' | 'Polygon'
map.addInteraction(draw);
draw.on('drawend', () => console.log('도형 추가됨'));

4. 좌표계 변환

지도를 클릭하면 내부 좌표(Web Mercator)를 toLonLat()로 위경도로 변환해 보여줍니다.
지도를 클릭해보세요
코드 보기 
map.on('click', (evt) => {
  const [lon, lat] = ol.proj.toLonLat(evt.coordinate);
  console.log(lon.toFixed(4), lat.toFixed(4));
});
