옵션 토글

일부 옵션은 Plyr 인스턴스 생성 시점에 적용됩니다. 런타임에서 완전히 바꾸려면 destroy 후 재생성하는 방식이 안전합니다.

const options = {
  controls: [
    'play-large', 'restart', 'rewind', 'play',
    'fast-forward', 'progress', 'current-time',
    'duration', 'mute', 'volume', 'captions',
    'settings', 'pip', 'airplay', 'fullscreen'
  ],
  settings: ['captions', 'quality', 'speed', 'loop'],
  captions: { active: true, language: 'en', update: true },
  quality: { default: 720, options: [1080, 720, 576] },
  speed: { selected: 1, options: [0.5, .75, 1, 1.25, 1.5, 2] },
  keyboard: { focused: true, global: false },
  tooltips: { controls: true, seek: true },
  fullscreen: { enabled: true, fallback: true, iosNative: false }
};

실무 적용 시 체크할 점

1. 내부망 환경이면 CDN 파일을 다운로드해 로컬 경로로 교체
2. 자막 파일은 .vtt 형식으로 제공
3. iOS/Android 자동재생은 muted, playsinline 여부와 브라우저 정책 확인
4. YouTube/Vimeo는 외부 서비스 접속이 필요하므로 폐쇄망에서는 HTML5 파일 기반 권장
5. DRM·권한 미디어는 서버의 CORS, Range Request, 인증 처리 필요
6. 장시간 영상은 HLS/DASH가 필요할 수 있으며, Plyr 단독이 아니라 hls.js 등과 연동 검토
이 샘플은 Plyr 기능 확인용입니다. CDN 접속이 차단된 내부망에서는 plyr.css, plyr.polyfilled.js, 미디어 파일을 로컬에 내려받아 경로를 바꿔야 합니다.
