Plyr 핵심 기능 둘러보기

Plyr는 브라우저마다 제각각인 기본 video/audio 컨트롤 UI를, 어느 브라우저에서나 똑같이 보이는 깔끔한 커스텀 UI로 감싸주는 미디어 플레이어 라이브러리입니다.
  • new Plyr(selector) 한 줄로 기존 <video>/<audio>를 커스텀 UI로 감쌈
  • <track kind="captions">(VTT 자막 파일)을 자동으로 인식해 자막 켜기/끄기 버튼 제공
  • player.play()/pause()/currentTime 같은 JS API로 프로그램에서 직접 제어, player.on('timeupdate', ...)로 이벤트 구독
  • <audio> 요소를 감싸면 영상용과는 다른 오디오 전용 UI 스킨이 자동으로 적용됨
※ 아래 영상은 실제 위판 홍보 자료가 아니라, ffmpeg로 직접 생성한 컬러바 테스트 패턴 영상 (440Hz 사인파 톤 포함)이며 자막 문구도 가상의 예시입니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 비디오 플레이어

기본 <video> 태그를 Plyr로 감싸면 재생/음량/설정/전체화면 버튼이 갖춰진 커스텀 UI가 자동으로 생성됩니다.
코드 보기 
<video id="player1" controls poster="poster.jpg">
  <source src="sample.mp4" type="video/mp4" />
</video>

new Plyr('#player1');

2. 자막(캡션) 지원

우측 하단 자막(CC) 버튼으로 VTT 자막 트랙을 켜고 끌 수 있습니다.
코드 보기 
<video id="player2" controls>
  <source src="sample.mp4" type="video/mp4" />
  <track kind="captions" label="한국어" src="captions-ko.vtt" srclang="ko" default />
</video>

new Plyr('#player2', { captions: { active: true, language: 'ko' } });

3. JS API로 재생 제어 + 이벤트 구독

아래 버튼으로 플레이어를 직접 제어하고, 재생 진행 상황을 실시간으로 확인합니다.
이벤트 대기 중...
코드 보기 
const player = new Plyr('#player3');

player.on('play', () => console.log('재생 시작'));
player.on('timeupdate', () => console.log(player.currentTime));

playBtn.addEventListener('click', () => player.play());
seekBtn.addEventListener('click', () => { player.currentTime = 5; });

4. 오디오 플레이어 (다른 UI 스킨)

같은 라이브러리로 <audio> 요소를 감싸면 영상용과는 다른, 오디오에 맞춘 컴팩트한 UI가 적용됩니다.
코드 보기 
<audio id="player4" controls>
  <source src="sample-audio.mp3" type="audio/mpeg" />
</audio>

new Plyr('#player4'); // video와 동일한 API, UI만 오디오용으로 자동 전환
