Apache ECharts 핵심 기능 둘러보기

Apache ECharts는 막대·선·파이·지도·게이지 등 매우 다양한 차트 타입을 지원하는 오픈소스 데이터 시각화 라이브러리입니다. 캔버스(또는 SVG)로 그려서 빠르고, 툴팁·확대축소 같은 인터랙션이 기본 내장돼 있습니다.
  • 옵션 객체(option) 하나로 차트 종류·데이터·스타일을 모두 선언적으로 설정
  • 마우스를 올리면 값이 뜨는 툴팁이 기본 제공됨
  • 2개 이상 계열은 범례(legend)로 껐다 켤 수 있음
  • dataZoom으로 긴 시계열 데이터를 드래그/스크롤로 확대해서 볼 수 있음
※ 아래 위판 실적 수치는 ECharts 학습용으로 만든 가상의 샘플 데이터이며, 실제 수협중앙회의 통계가 아닙니다. 이 페이지는 Apache ECharts(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 막대 차트

위판장별 위판량(가상)을 큰 순서로 비교합니다. 막대 끝에 값을 표시했습니다.
코드 보기 
echarts.init(document.getElementById('chart1')).setOption({
  xAxis: { type: 'value' },
  yAxis: { type: 'category', data: ['노량진', '통영', '여수', '목포', '포항', '부산'] },
  series: [{
    type: 'bar',
    data: [130, 150, 190, 210, 260, 480],
    itemStyle: { color: '#2a78d6', borderRadius: [0, 4, 4, 0] },
    barMaxWidth: 24,
    label: { show: true, position: 'right' },
  }],
});

2. 다중 계열 선 차트 + 툴팁

어종별 월별 위판량(가상) 추이입니다. 범례를 클릭하면 계열을 껐다 켤 수 있고, 마우스를 올리면 값이 뜹니다.
코드 보기 
echarts.init(document.getElementById('chart2')).setOption({
  tooltip: { trigger: 'axis' },
  legend: { data: ['고등어', '갈치', '오징어'] },
  xAxis: { type: 'category', data: ['2월', '3월', '4월', '5월', '6월', '7월'] },
  yAxis: { type: 'value' },
  series: [
    { name: '고등어', type: 'line', data: [120, 150, 170, 210, 260, 300], color: '#2a78d6', endLabel: { show: true } },
    { name: '갈치',   type: 'line', data: [90, 100, 95, 110, 130, 140],  color: '#1baf7a', endLabel: { show: true } },
    { name: '오징어', type: 'line', data: [60, 70, 85, 100, 90, 95],    color: '#eda100', endLabel: { show: true } },
  ],
});

3. 도넛 차트

어종별 위판 비중(가상)입니다. 범례와 조각 위 라벨을 함께 표시했습니다.
코드 보기 
echarts.init(document.getElementById('chart3')).setOption({
  tooltip: { trigger: 'item' },
  legend: { bottom: 0 },
  color: ['#2a78d6', '#1baf7a', '#eda100', '#008300', '#4a3aa7'],
  series: [{
    type: 'pie',
    radius: ['45%', '70%'], // 안쪽 반지름을 주면 도넛 모양이 됨
    data: [
      { name: '고등어', value: 420 },
      { name: '갈치', value: 260 },
      { name: '오징어', value: 190 },
      { name: '새우', value: 140 },
      { name: '기타', value: 90 },
    ],
    label: { formatter: '{b}\n{d}%' },
  }],
});

4. dataZoom — 긴 시계열 확대/축소

최근 60일 일별 위판량(가상)입니다. 아래 슬라이더를 드래그하거나, 그래프 위에서 마우스 휠/드래그로 원하는 구간만 확대해서 볼 수 있습니다.
코드 보기 
echarts.init(document.getElementById('chart4')).setOption({
  tooltip: { trigger: 'axis' },
  xAxis: { type: 'category', data: dates },
  yAxis: { type: 'value' },
  dataZoom: [
    { type: 'inside' },       // 그래프 위에서 휠/드래그로 확대
    { type: 'slider' },       // 아래쪽 슬라이더로 구간 선택
  ],
  series: [{
    type: 'line',
    data: values,
    color: '#2a78d6',
    areaStyle: { opacity: 0.1 },
    showSymbol: false,
  }],
});
