epub.js 핵심 기능 둘러보기

epub.js는 EPUB(전자책) 파일을 브라우저에서 바로 렌더링하는 라이브러리입니다. EPUB은 실제로는 HTML/CSS 파일들을 정해진 규칙으로 묶은 ZIP 파일이라, 압축 해제를 위해 JSZip이 함께 필요합니다.
  • EPUB 파일 렌더링 + 페이지 넘기기
  • 목차(TOC) 표시와 챕터 이동
  • 책 전체에 대한 텍스트 검색
  • 폰트 크기 · 테마 변경
※ 아래 EPUB 샘플("가상 위판장 이야기", 3장)은 이 페이지를 위해 지어낸 가상의 짧은 소설이며, 실제 인물·사건과 무관합니다. 공식 검증 도구인 epubcheck로 오류 0건을 확인한 표준 EPUB3 파일입니다.

1. EPUB 렌더링 + 페이지 넘기기

ePub(file)로 책을 열고 book.renderTo(엘리먼트)로 지정한 영역에 그립니다. 아래 읽기 영역은 이 페이지의 모든 섹션이 공유합니다.
소스 코드 보기 
const book = ePub(arrayBufferOrUrl);
const rendition = book.renderTo('reader-area', { width: '100%', height: 320 });
await rendition.display();

rendition.next(); // 다음 섹션/페이지
rendition.prev(); // 이전 섹션/페이지

2. 목차(TOC)로 이동

book.loaded.navigation에서 목차 구조를 받아, 원하는 항목을 클릭하면 바로 그 챕터로 이동합니다. (먼저 위에서 EPUB을 열어야 합니다.)
    소스 코드 보기 
    const nav = await book.loaded.navigation;
nav.toc.forEach((item) => {
  console.log(item.label, item.href);
  // rendition.display(item.href) 로 해당 챕터로 이동
});

    3. 책 전체 텍스트 검색

    각 챕터(section)를 임시로 불러와 section.find(검색어)로 찾은 뒤 section.unload()로 메모리를 정리합니다. 결과를 클릭하면 해당 위치로 이동합니다.
      소스 코드 보기 
      const results = await Promise.all(
  book.spine.spineItems.map((section) =>
    section.load(book.load.bind(book)).then(() => {
      const found = section.find('검색어'); // [{ cfi, excerpt }, ...]
      section.unload();
      return found;
    })
  )
);
const flat = [].concat(...results);
rendition.display(flat[0].cfi); // 검색 결과 위치로 바로 이동(CFI)

      4. 폰트 크기 · 테마 변경

      rendition.themes로 글자 크기를 조절하거나, CSS 규칙을 테마로 등록해서 즉시 바꿔 적용할 수 있습니다.
      소스 코드 보기 
      rendition.themes.fontSize('130%');

rendition.themes.register('dark', {
  body: { background: '#222', color: '#eee' },
});
rendition.themes.select('dark');
