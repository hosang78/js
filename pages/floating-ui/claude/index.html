Floating UI 핵심 기능 둘러보기

Floating UI는 툴팁·드롭다운·팝오버 같은 "떠 있는" 요소를 기준 요소 옆에 정확하게 배치해주는 포지셔닝 라이브러리입니다(Popper.js의 후속). 화면 경계를 벗어나면 자동으로 반대편에 배치하거나, 화살표가 항상 기준 요소를 정확히 가리키게 하는 등 세밀한 위치 계산을 대신 해줍니다.
  • offset 미들웨어로 하는 기본 위치 지정 툴팁
  • flip + shift로 화면 밖을 벗어나지 않는 자동 반전 드롭다운
  • arrow 미들웨어로 대상을 정확히 가리키는 화살표 팝업
  • autoUpdate로 스크롤·리사이즈에 맞춰 계속 따라다니는 실시간 추적 팝오버
※ 아래 카드 이름과 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면·통계와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 위치 지정 툴팁

카드에 마우스를 올리면 computePosition()이 카드 바로 위, 8px 떨어진 위치에 툴팁을 배치합니다.
A위판장
오늘 위판량 820kg · 고등어
코드 보기 
const { computePosition, offset } = FloatingUIDOM;

computePosition(ref1, tip1, {
  placement: 'top',
  middleware: [offset(8)],
}).then(({ x, y }) => {
  Object.assign(tip1.style, { left: `${x}px`, top: `${y}px` });
});

2. flip + shift로 화면 밖을 벗어나지 않는 드롭다운

아래 스크롤 영역 맨 밑에 버튼이 있습니다. 버튼을 누르면 원래는 아래로 펼쳐져야 할 메뉴가 화면(스크롤 영역) 밖으로 나가려는 순간 flip()이 자동으로 위쪽으로 뒤집고, shift()가 좌우로 밀려나지 않게 잡아줍니다.

아래로 스크롤해서 버튼을 찾아보세요 ↓

코드 보기 
const { computePosition, offset, flip, shift } = FloatingUIDOM;

// boundary를 스크롤 영역으로 제한해 그 영역 기준으로 flip이 동작하게 한다.
computePosition(menuBtn2, menu2, {
  placement: 'bottom-start',
  middleware: [
    offset(6),
    flip({ boundary: scrollBox2 }),
    shift({ boundary: scrollBox2, padding: 8 }),
  ],
}).then(({ x, y }) => {
  Object.assign(menu2.style, { left: `${x}px`, top: `${y}px` });
});

3. 화살표로 대상을 정확히 가리키는 팝업

정보 아이콘을 누르면 설명 팝업이 뜨는데, 삼각형(화살표)이 항상 아이콘 중심을 정확히 가리키도록 arrow 미들웨어가 위치를 계산합니다.
위판 수수료율 ?
위판 금액의 3%가 수수료로 부과되는 가상의 예시입니다.
코드 보기 
const { computePosition, offset, flip, shift, arrow } = FloatingUIDOM;

computePosition(ref3, tip3, {
  placement: 'top',
  middleware: [offset(10), flip(), shift({ padding: 5 }), arrow({ element: arrow3 })],
}).then(({ x, y, placement, middlewareData }) => {
  Object.assign(tip3.style, { left: `${x}px`, top: `${y}px` });

  const { x: arrowX, y: arrowY } = middlewareData.arrow;
  const staticSide = { top: 'bottom', right: 'left', bottom: 'top', left: 'right' }[placement.split('-')[0]];
  Object.assign(arrow3.style, {
    left: arrowX != null ? `${arrowX}px` : '',
    top: arrowY != null ? `${arrowY}px` : '',
    [staticSide]: '-4px',
  });
});

4. 스크롤을 따라다니는 실시간 추적 팝오버

팝오버를 연 상태로 아래 영역을 스크롤하거나 창 크기를 바꿔보세요. autoUpdate()가 기준 버튼 위치를 계속 감시해서 팝오버가 버튼을 놓치지 않고 따라다닙니다.

코드 보기 
const { computePosition, offset, autoUpdate } = FloatingUIDOM;
let stopAutoUpdate = null;

function show() {
  stopAutoUpdate = autoUpdate(ref4, tip4, update);
  tip4.classList.add('show');
}
function update() {
  computePosition(ref4, tip4, { placement: 'right', middleware: [offset(8)] })
    .then(({ x, y }) => Object.assign(tip4.style, { left: `${x}px`, top: `${y}px` }));
}
function hide() {
  stopAutoUpdate && stopAutoUpdate();
  tip4.classList.remove('show');
}
