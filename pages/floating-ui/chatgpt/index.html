x: 0, y: 0

텍스트 선택 도구막대 · inline()

아래 문장을 드래그해 선택하면 여러 줄에 걸친 Range의 클라이언트 사각형을 기준으로 도구막대를 배치한다.

Floating UI는 툴팁과 팝오버처럼 기준 요소 주변에 떠 있는 인터페이스의 위치를 계산한다. 긴 문장을 여러 줄에 걸쳐 선택해도 inline 미들웨어를 이용하면 선택된 텍스트의 실제 사각형 집합을 기준으로 자연스럽게 도구막대를 표시할 수 있다.

6. 포함 기능 요약

샘플에서 실제로 호출되는 주요 DOM API
API역할샘플 위치
computePosition()기준 요소와 floating 요소의 x/y 좌표 계산전체
autoUpdate()스크롤·리사이즈·레이아웃 이동·요소 크기 변경 자동 추적툴팁, 팝오버, 스크롤, 동적 콘텐츠
offset()기준 요소와의 간격 조정전체 및 실험실
flip()공간 부족 시 반대편 또는 대체 방향으로 전환툴팁, 팝오버, 실험실
shift()화면 경계를 벗어나지 않도록 같은 축에서 이동전체
arrow()화살표 좌표 계산툴팁, 배치 선택, 실험실
size()가용 폭·높이에 따라 스타일 적용크기 동기화 드롭다운
hide()기준 요소가 가려지거나 벗어난 상태 감지실험실, hide 감지
inline()여러 ClientRect를 가진 인라인·선택 영역 처리텍스트 선택 도구막대
autoPlacement()가장 넓은 공간을 자동 선택자동 최적 배치
VirtualElement포인터 좌표나 Range를 가상의 기준 요소로 사용컨텍스트 메뉴, 커서 추적, 선택 영역
Custom middleware좌표 및 사용자 데이터 확장미들웨어 실험실
