Flatpickr 핵심 기능 둘러보기

Flatpickr는 의존성 없이 동작하는 가볍고 빠른 날짜·시간 선택기 라이브러리입니다. 일반 텍스트 입력창을 달력·시간 선택 UI로 바로 바꿔주고, 범위 선택·다국어·비활성 날짜 지정 같은 기능을 옵션 몇 줄로 설정할 수 있습니다.
  • locale: 'ko'로 하는 한국어 기본 날짜 선택
  • mode: 'range'로 하는 기간 선택
  • enableTime으로 하는 날짜 + 시간 선택
  • inline + disable로 하는 인라인 캘린더 · 요일별 비활성화
※ 아래 일정·위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면·절차와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 날짜 선택 (한국어)

입력창을 클릭하면 한국어 요일·월 이름으로 표시되는 달력이 뜹니다. 실제 저장 형식은 Y-m-d이지만 화면에는 altInput으로 보기 편한 형식을 따로 보여줍니다.
아직 선택된 날짜가 없습니다.
코드 보기 
flatpickr('#dp1', {
  locale: 'ko',
  dateFormat: 'Y-m-d',
  altInput: true,
  altFormat: 'Y년 m월 d일 (D요일)',
  onChange: (selectedDates, dateStr) => {
    stat.textContent = `선택한 날짜: ${dateStr}`;
  },
});

2. 기간(범위) 선택

시작일을 먼저 클릭하고 종료일을 클릭하면 그 사이 날짜가 모두 선택 범위로 표시됩니다. 위판 실적을 조회할 기간을 고를 때 흔히 쓰는 방식입니다.
아직 선택된 기간이 없습니다.
코드 보기 
flatpickr('#dp2', {
  mode: 'range',
  locale: 'ko',
  dateFormat: 'Y-m-d',
  minDate: '2026-01-01',
  maxDate: '2026-12-31',
  onChange: (selectedDates) => {
    if (selectedDates.length === 2) {
      const days = Math.round((selectedDates[1] - selectedDates[0]) / 86400000) + 1;
      stat.textContent = `총 ${days}일 조회`;
    }
  },
});

3. 날짜 + 시간 선택

enableTime을 켜면 달력 아래에 시:분 스크롤이 함께 나타납니다. minuteIncrement로 분 단위 간격을 30분으로 제한했습니다.
아직 선택된 시각이 없습니다.
코드 보기 
flatpickr('#dp3', {
  locale: 'ko',
  enableTime: true,
  time_24hr: true,
  minuteIncrement: 30,
  dateFormat: 'Y-m-d H:i',
  onChange: (selectedDates, dateStr) => {
    stat.textContent = `예약된 시작 시각: ${dateStr}`;
  },
});

4. 인라인 캘린더 + 요일별 비활성화

inline: true로 캘린더를 항상 펼쳐진 채로 보여주고, disable에 함수를 넘겨 일요일(위판장 휴무일)을 선택할 수 없게 막았습니다.
휴무일(일요일)은 회색으로 표시되며 선택할 수 없습니다.
코드 보기 
flatpickr('#dp4', {
  inline: true,
  locale: 'ko',
  dateFormat: 'Y-m-d',
  disable: [
    (date) => date.getDay() === 0, // 일요일 = 휴무일
  ],
  onChange: (selectedDates, dateStr) => {
    stat.textContent = `선택한 조업일: ${dateStr}`;
  },
});
