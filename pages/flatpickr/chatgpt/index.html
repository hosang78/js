샘플 사용 안내
  1. 각 입력창을 눌러 선택 동작을 비교합니다.
  2. API·이벤트 섹션에서 버튼을 눌러 인스턴스 메서드와 훅을 확인합니다.
  3. 설정 실험실에서 옵션 조합 후 새 인스턴스를 즉시 생성합니다.
  4. 테마 변경 버튼은 Flatpickr의 내장 테마 CSS를 순환합니다.
