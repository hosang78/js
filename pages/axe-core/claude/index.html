axe-core 핵심 기능 둘러보기

axe-core는 웹페이지를 실제 스캔해서 WCAG 접근성 위반사항을 자동으로 찾아주는 감사(audit) 엔진입니다. 브라우저 확장 프로그램 Axe DevTools, Lighthouse, 여러 E2E 테스트 도구(Playwright, Cypress 등)가 내부적으로 이 엔진을 사용합니다.
  • axe.run(선택자 또는 DOM 요소)로 특정 영역을 검사, results.violations에 실제 문제 목록이 담김
  • 각 위반사항은 규칙 ID(id), 심각도(impact), 설명(help), 영향받은 요소의 CSS 선택자(target)를 포함
  • runOnly: { type: 'tag', values: [...] }로 WCAG 레벨(A/AA 등) 기준만 골라서 검사 가능
※ 아래 "문제 있는 예제" 영역은 실제 서비스 화면이 아니라, 접근성 문제를 일부러 심어둔 가상의 예시 마크업입니다. 검증 중 color-contrast(명암비) 규칙은 WCAG AA 레벨에서만 잡히고, A 레벨만 검사하면 놓친다는 것을 실제로 확인했습니다 (아래 3번 참고). 다른 외부 API는 사용하지 않습니다.

1. 예제 영역 스캔

아래 영역에는 대체 텍스트 없는 이미지, 명암비가 낮은 텍스트, 빈 버튼, 라벨 없는 입력창이 일부러 섞여 있습니다. 실제로 몇 개가 잡히는지 스캔해보세요.

위판 시세 공지 (명암비가 낮아 잘 안 보임)

아직 스캔 안 함
코드 보기 
const results = await axe.run('#demoArea');
results.violations.forEach((v) => {
  console.log(v.id, v.impact, v.help);
  console.log(v.nodes[0].target); // 문제 요소의 CSS 선택자
});

2. 위반 요소 하이라이트

1번에서 스캔한 뒤, 목록의 위반사항을 클릭하면 실제 DOM에서 그 요소를 빨간 테두리로 표시합니다.
먼저 1번에서 스캔해주세요
코드 보기 
const selector = violation.nodes[0].target[0];
document.querySelector(selector).style.outline = '3px solid red';
document.querySelector(selector).scrollIntoView({ block: 'center' });

3. WCAG 레벨별 필터링

같은 영역을 WCAG A 레벨만 검사할 때와, A+AA를 함께 검사할 때로 나눠 비교합니다.
아직 비교 안 함
코드 보기 
await axe.run('#demoArea', { runOnly: { type: 'tag', values: ['wcag2a'] } });
await axe.run('#demoArea', { runOnly: { type: 'tag', values: ['wcag2a', 'wcag2aa'] } });
// color-contrast는 AA 레벨 규칙이라 A만 검사하면 결과에서 빠짐

4. 수정 후 재검사 (Before / After)

버튼을 누르면 위 1번 영역이 접근성을 개선한 버전(대체 텍스트 추가, 버튼에 이름 추가, 입력창에 라벨 연결, 명암비 개선)으로 바뀌고 다시 스캔합니다.
아직 적용 안 함
코드 보기 
// 개선 예시
