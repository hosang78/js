Panzoom 대상 영역

이 카드 전체가 Panzoom 대상이다. 휠 줌은 커서 위치를 기준으로 작동한다.

pan()절대 좌표 또는 relative 옵션으로 이동
zoom()원하는 배율로 직접 확대/축소
zoomToPoint()특정 화면 좌표를 기준으로 확대
containinside / outside 경계 제한
setOptions()실행 중 옵션 변경
eventsstart / change / pan / zoom / end / reset

4. 커스텀 transform / 핵심 코드

setTransform

아래 사각형은 Panzoom의 scale/translate에 rotate를 추가한 예시다.

rotate + panzoom
const panzoom = Panzoom(element, {
  maxScale: 5,
  minScale: 0.25,
  step: 0.3,
  contain: 'outside',
  excludeClass: 'panzoom-exclude'
})

// 휠 줌
parent.addEventListener('wheel', panzoom.zoomWithWheel)

// 상태 조회
panzoom.getScale()
panzoom.getPan()

// 동적 옵션 변경
panzoom.setOptions({ disableXAxis: true })

// 이벤트
el.addEventListener('panzoomchange', e => console.log(e.detail))
