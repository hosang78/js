Panzoom 핵심 기능 둘러보기

Panzoom은 CSS transform만으로 어떤 요소든(이미지, SVG, video, canvas, 텍스트...) 손쉽게 패닝·줌 기능을 넣어주는 아주 가벼운(~3.7kb) 라이브러리입니다.
  • Panzoom(element, options) 한 줄로 드래그 패닝 + 핀치 줌이 자동으로 활성화됨
  • zoomIn()/zoomOut()/zoom(scale)/reset()으로 프로그램에서 직접 제어
  • zoomWithWheel을 휠 이벤트에 연결하면 마우스 휠로 확대·축소
  • zoomToPoint(scale, point)로 특정 지점을 기준으로 확대 — 클릭한 자리가 화면 중심을 벗어나지 않고 그대로 확대됨
  • panzoomchange 커스텀 이벤트로 현재 배율·이동값을 실시간 구독
※ 아래 배치도는 실제 수협중앙회 위판장 도면이 아니라, ffmpeg로 생성한 가상의 예시 도면입니다(A/B/C구역, 중앙 통로, 냉동 보관 구역이라는 명칭도 가상). 다른 외부 API는 사용하지 않습니다.

1. 기본 확대/축소/이동

이미지를 드래그해서 이동하고, 버튼으로 확대·축소·초기화해보세요.
코드 보기 
const panzoom = Panzoom(elem, { maxScale: 5, minScale: 0.5 });

zoomInBtn.addEventListener('click', panzoom.zoomIn);
zoomOutBtn.addEventListener('click', panzoom.zoomOut);
resetBtn.addEventListener('click', panzoom.reset);

2. 마우스 휠로 확대/축소

이미지 위에서 마우스 휠을 굴려보세요.
코드 보기 
const panzoom = Panzoom(elem, { maxScale: 5, minScale: 0.5 });
wrapEl.addEventListener('wheel', panzoom.zoomWithWheel);

3. 특정 지점 기준으로 확대

이미지의 원하는 지점을 더블클릭하면 그 지점을 중심으로 확대됩니다. 다시 더블클릭하면 초기화됩니다.
코드 보기 
elem.addEventListener('dblclick', (event) => {
  panzoom.zoomToPoint(2, event); // 클릭 지점을 중심으로 2배 확대
});

4. panzoomchange 이벤트로 상태 추적

아래 이미지를 드래그하거나 휠로 확대/축소하면, 현재 배율과 이동값이 실시간으로 표시됩니다.
배율: 1.00 · 이동: (0, 0)
코드 보기 
elem.addEventListener('panzoomchange', (event) => {
  const { x, y, scale } = event.detail;
  console.log(`배율 ${scale}, 이동 (${x}, ${y})`);
});
