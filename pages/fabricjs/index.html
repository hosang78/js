Fabric.js 핵심 기능 둘러보기

Fabric.js는 HTML <canvas> 위에 도형·텍스트·이미지를 올려놓고, 마우스로 선택·이동·크기조절·회전까지 할 수 있게 해주는 캔버스 조작 라이브러리입니다.
  • new fabric.Canvas(el) 위에 Rect/Circle/Textbox 등을 add()
  • 추가한 객체는 클릭해서 선택하고, 모서리 핸들로 크기·회전, 드래그로 이동 가능
  • isDrawingMode를 켜면 마우스로 자유롭게 선을 그리는 모드로 전환
  • toJSON()/loadFromJSON()으로 캔버스 상태를 저장·복원, toDataURL()로 이미지 추출
※ 아래 위판장 배치도는 Fabric.js 학습용으로 만든 가상의 예시이며, 실제 수협중앙회의 배치 도면이 아닙니다. 이 페이지는 Fabric.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 도형 추가 + 선택 · 이동 · 크기조절

버튼으로 구역(사각형)·매대(원)·라벨(텍스트)을 추가해보세요. 캔버스 위 도형을 클릭하면 선택되고, 모서리 핸들로 크기와 회전을, 드래그로 위치를 바꿀 수 있습니다.
코드 보기 
const canvas = new fabric.Canvas('canvas1');

document.getElementById('addRectBtn').addEventListener('click', () => {
  const rect = new fabric.Rect({ left: 80, top: 80, width: 120, height: 70, fill: '#2a78d6' });
  canvas.add(rect);
  canvas.setActiveObject(rect); // 추가하자마자 선택 상태로
});

2. 자유 그리기 모드

배치도 위에 구역 경계선을 손으로 그어봅니다. 색상과 굵기를 바꿀 수 있습니다.
색상 굵기
코드 보기 
canvas.isDrawingMode = true;
canvas.freeDrawingBrush = new fabric.PencilBrush(canvas);
canvas.freeDrawingBrush.color = '#e34948';
canvas.freeDrawingBrush.width = 4;

3. 선택 객체 속성 편집

도형을 하나 선택한 뒤 색상을 눌러보세요. 선택된 도형의 채우기 색이 바로 바뀝니다.
채우기 색:
도형을 선택해보세요.
코드 보기 
canvas.on('selection:created', (e) => updateStatus(e.selected[0]));
canvas.on('selection:updated', (e) => updateStatus(e.selected[0]));

swatchBtn.addEventListener('click', () => {
  const active = canvas.getActiveObject();
  if (!active) return;
  active.set('fill', swatchBtn.dataset.color);
  canvas.renderAll(); // 색을 바꾼 뒤엔 다시 그려줘야 화면에 반영됨
});

deleteBtn.addEventListener('click', () => {
  const active = canvas.getActiveObject();
  if (active) canvas.remove(active);
});

4. 저장 · 불러오기 + PNG 내보내기

배치도를 자유롭게 편집한 뒤 저장하고, 다시 편집해서 흐트러뜨린 다음 불러와서 복원해보세요. PNG로도 내보낼 수 있습니다.
저장된 배치도 없음
코드 보기 
let saved = null;
saveBtn.addEventListener('click', () => { saved = canvas.toJSON(); });

loadBtn.addEventListener('click', async () => {
  if (saved) await canvas.loadFromJSON(saved); // 비동기로 복원
  canvas.renderAll();
});

exportBtn.addEventListener('click', () => {
  const a = document.createElement('a');
  a.href = canvas.toDataURL({ format: 'png' });
  a.download = 'wipan-layout.png'; // 한글 파일명은 브라우저에서 깨질 수 있어 영문으로 지정
  a.click();
});
