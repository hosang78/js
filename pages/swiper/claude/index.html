Swiper 핵심 기능 둘러보기

Swiper는 모바일/데스크톱에서 터치·드래그로 자연스럽게 넘길 수 있는 슬라이더(캐러셀)를 만들어주는 라이브러리입니다. 이미지 갤러리, 배너, 카드 목록 등에 널리 쓰입니다.
  • 내비게이션 화살표 + 페이지네이션 불릿이 있는 기본 슬라이더
  • effect: "coverflow" 같은 3D 전환 효과
  • 화면 너비에 따라 보이는 슬라이드 개수를 바꾸는 반응형 breakpoints
  • thumbs 모듈로 메인 슬라이더와 썸네일 슬라이더 연동
  • autoplay + loop로 자동재생 무한 배너
※ 아래 카드/썸네일의 위판장·어종 이미지는 이 페이지를 위해 만든 가상의 예시이며 (실제 사진이 아닌 일러스트 스타일 SVG), 실제 수협중앙회의 시설·통계와 무관합니다. Swiper(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 슬라이더 — 내비게이션 + 페이지네이션

가상 위판장 소개 카드입니다. 화살표를 클릭하거나 좌우로 드래그해보세요.
A구역 · 고등어 위판장매일 새벽 5시 개장(가상)
B구역 · 갈치 위판장냉장 직송 라인 운영(가상)
C구역 · 오징어 위판장야간 위판 병행(가상)
D구역 · 냉동 보관동대형 저온 창고(가상)
E구역 · 경매 사무동전자 경매 시스템(가상)
코드 보기 
const swiper1 = new Swiper("#s1", {
  navigation: {
    nextEl: "#s1 .swiper-button-next",
    prevEl: "#s1 .swiper-button-prev"
  },
  pagination: { el: "#s1 .swiper-pagination", clickable: true },
  spaceBetween: 16
});

2. Coverflow 전환 효과

가운데 카드가 도드라져 보이는 3D 커버플로우 효과입니다. 카드를 클릭하면 가운데로 이동합니다.
고등어가상 위판 단가 상승
갈치가상 위판 단가 보합
오징어가상 위판 단가 하락
문어가상 위판 단가 상승
전복가상 위판 단가 보합
코드 보기 
const swiper2 = new Swiper("#s2", {
  effect: "coverflow",
  grabCursor: true,
  centeredSlides: true,
  slideToClickedSlide: true,
  slidesPerView: "auto",
  coverflowEffect: {
    rotate: 40,
    stretch: 0,
    depth: 140,
    modifier: 1,
    slideShadows: true
  },
  pagination: { el: "#s2 .swiper-pagination", clickable: true }
});

3. 반응형 다중 슬라이드 (breakpoints)

브라우저 폭에 따라 한 번에 보이는 카드 수가 바뀝니다(좁으면 1.2장, 넓으면 최대 4장). 창 크기를 조절해보세요.
조합원 소식 #1가상 배당 안내
조합원 소식 #2가상 총회 일정
조합원 소식 #3가상 시설 점검
조합원 소식 #4가상 교육 프로그램
조합원 소식 #5가상 안전 캠페인
조합원 소식 #6가상 신규 조합원 모집
코드 보기 
const swiper3 = new Swiper("#s3", {
  spaceBetween: 14,
  slidesPerView: 1.2,
  breakpoints: {
    640: { slidesPerView: 2.2 },
    900: { slidesPerView: 3.2 },
    1200: { slidesPerView: 4 }
  }
});

4. 썸네일 연동 갤러리 (Thumbs)

아래 썸네일을 클릭하거나 메인 이미지를 드래그하면 서로 연동되어 함께 움직입니다.
코드 보기 
const swiper4Thumbs = new Swiper("#s4thumbs", {
  spaceBetween: 8,
  slidesPerView: "auto",
  freeMode: true,
  watchSlidesProgress: true
});

const swiper4Main = new Swiper("#s4main", {
  spaceBetween: 10,
  thumbs: { swiper: swiper4Thumbs }
});

5. 자동재생 + 무한루프 배너

공지사항이 자동으로 넘어가는 무한루프 배너입니다. 버튼으로 자동재생을 멈추거나 다시 켤 수 있습니다.
📢 가상 공지: 위판장 시설 점검 안내
📢 가상 공지: 조합원 정기총회 일정
📢 가상 공지: 냉동 보관동 이용 안내
📢 가상 공지: 전자 경매 시스템 점검
코드 보기 
const swiper5 = new Swiper("#s5", {
  loop: true,
  autoplay: { delay: 2000, disableOnInteraction: false },
  pagination: { el: "#s5 .swiper-pagination", clickable: true }
});

document.getElementById("s5-toggle").onclick = (e) => {
  if (swiper5.autoplay.running) {
    swiper5.autoplay.stop();
    e.target.textContent = "재생";
  } else {
    swiper5.autoplay.start();
    e.target.textContent = "일시정지";
  }
};
