Ace Editor 핵심 기능 둘러보기

Ace Editor는 클라우드 IDE(예전 Cloud9)에서 출발한 오래되고 가벼운 브라우저용 코드 에디터입니다. Monaco보다 훨씬 작고 빠르게 뜨는 대신, 기능은 필요한 확장(extension)을 골라 붙이는 방식입니다.
  • ace.edit(el) 한 줄로 즉시 편집기 생성, session.setMode()로 언어 문법 강조 전환
  • setTheme()으로 다양한 내장 테마(monokai, twilight, github 등) 전환
  • ext/language_tools 확장을 불러오면 addCompleter()로 커스텀 자동완성 추가 가능
  • setKeyboardHandler()로 vim/emacs/sublime 키바인딩 모드까지 통째로 전환 가능
※ Ace의 자동완성은 Monaco와 달리 마침표 같은 트리거 문자가 아니라, 입력 중인 접두어(prefix)가 완성 항목의 caption과 문자열로 일치해야 팝업이 뜨는 방식임을 실제로 테스트하며 확인했습니다 (예: caption이 "catchReport"인 항목은 "catch"까지 입력해야 뜨고, 전혀 다른 접두어로는 뜨지 않음). 이 페이지의 위판 관련 예시는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 에디터 + 언어 모드 전환

버튼을 누르면 같은 내용을 다른 언어 문법으로 다시 강조합니다.
코드 보기 
const editor = ace.edit('editor1');
editor.setValue("// 가상 위판 기록\nconst records = [{ species: '고등어', weight: 320 }];", -1);
editor.session.setMode('ace/mode/javascript');

// 언어 모드만 나중에 바꾸기
editor.session.setMode('ace/mode/json');

2. 테마 전환

Ace에 내장된 여러 테마 중 하나를 즉시 적용합니다.
코드 보기 
editor.setTheme('ace/theme/monokai');
editor.setTheme('ace/theme/twilight');
editor.setTheme('ace/theme/github');

3. 커스텀 자동완성

아래 에디터에서 suhyup까지 입력해보세요 — 직접 등록한 가상 API 자동완성 목록이 뜹니다(입력한 접두어와 완성 항목 이름이 일치해야 뜨는 방식입니다).
코드 보기 
const langTools = ace.require('ace/ext/language_tools');
langTools.addCompleter({
  getCompletions(editor, session, pos, prefix, callback) {
    callback(null, [
      { caption: 'suhyupCatchReport', value: 'suhyupCatchReport()', meta: '가상 어획 보고 조회' },
      { caption: 'suhyupAuctionPrice', value: 'suhyupAuctionPrice()', meta: '가상 위판 시세 조회' },
    ]);
  },
});
editor.setOptions({ enableBasicAutocompletion: true, enableLiveAutocompletion: true });

4. 키바인딩 모드 전환

에디터 전체의 키 조작 방식을 vim/emacs 모드로 통째로 바꿀 수 있습니다. vim 모드에서는 기본적으로 일반 모드(정규화 모드)로 시작하니, 먼저 i를 눌러 입력 모드로 들어가야 타이핑됩니다.
코드 보기 
editor.setKeyboardHandler('ace/keyboard/vim');
editor.setKeyboardHandler('ace/keyboard/emacs');
editor.setKeyboardHandler(null); // 기본 키바인딩으로 복귀
