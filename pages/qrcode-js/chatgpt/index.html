QRCode.js 기능 실험실

한 페이지에서 QR 콘텐츠 형식, 오류 정정, 색상·여백, 로고 오버레이, PNG·인쇄, 일괄 생성을 확인하는 샘플이다.

원본 API: makeCode() · clear()
UTF-8 0 bytes

1. 콘텐츠 구성

유형을 고른 뒤, 생성 전 최종 페이로드를 직접 편집할 수 있다.

실무 팁. QR 내용이 길수록 점이 촘촘해진다. 인쇄물·중앙 로고를 쓸 때는 오류 정정 수준 H를 권장한다.

2. 미리보기

생성된 QR은 중앙 로고와 캡션을 포함해 PNG로 내보낼 수 있다.

주의. 중앙 로고는 실제 데이터를 가린다. 로고는 QR 폭의 약 20% 이하, 오류 정정 H 사용이 안전하다. 스캔 보장은 기기·인쇄 품질·대비에 따라 달라진다.
원본 QRCode.js API 데모
생성: new QRCode(target, options)
재생성: qrcode.makeCode(text)
초기화: qrcode.clear()

3. 최근 생성

최근 6건을 클릭하면 해당 페이로드를 다시 불러온다.

아직 생성 이력이 없다.

빠른 점검

QRCode.js에서는 생성 전후 예외 처리와 인쇄 테스트가 중요하다.

대비 확인 대기 중
자동 버전 선택. QRCode.js는 입력량에 따라 QR 버전을 자동으로 선택한다. 입력이 너무 길면 오류가 발생할 수 있으므로 짧은 링크 사용을 권장한다.

4. 일괄 생성

한 줄에 표시명 | 페이로드 형식으로 입력한다. 최대 24개 미리보기.

파일 저장 방식. 브라우저 정책상 각 QR을 개별 PNG로 내려받는다. ZIP 묶음은 외부 라이브러리 없이 포함하지 않았다.
일괄 생성 결과가 여기에 표시된다.
