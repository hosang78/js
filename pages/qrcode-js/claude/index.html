QRCode.js 핵심 기능 둘러보기

QRCode.js는 텍스트나 URL을 QR코드 이미지로 만들어주는 초경량 라이브러리입니다. 의존성이 전혀 없고, 서버 없이 브라우저에서 바로 QR코드를 그립니다.
  • new QRCode(요소, 텍스트) 한 줄이면 QR코드가 생성됨
  • 크기·전경색·배경색을 옵션으로 지정 가능
  • 오류 복원 레벨(L/M/Q/H) 선택 — 코드가 일부 가려져도 읽히는 정도를 조절
  • canvas로 그려지므로 PNG 이미지로 바로 저장 가능
※ 아래 위판장/어획물 정보는 QRCode.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 정보/서식이 아닙니다. QR을 스캔하면 가상 데이터가 보일 뿐 실제 페이지로 연결되지 않을 수 있습니다. 이 페이지는 QRCode.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 QR 생성 (실시간)

텍스트나 URL을 입력하면 QR코드가 실시간으로 다시 그려집니다. 휴대폰 카메라로 스캔해보세요.
코드 보기 
const qr = new QRCode(document.getElementById('qr1'), {
  text: 'https://www.suhyup.co.kr',
  width: 160,
  height: 160,
});

// 내용 바꾸기
qr.clear();
qr.makeCode('새로운 텍스트');

2. 색상 · 크기 옵션

전경색(colorDark)/배경색(colorLight)과 크기를 바꿔가며 생성해보세요. 배경과 전경의 명암 차이가 작으면 스캔이 잘 안 되니 주의.
코드 보기 
new QRCode(el, {
  text: '수협 위판장 안내 (예시)',
  width: 160,
  height: 160,
  colorDark: '#1a3fa8',
  colorLight: '#ffffff',
});

3. 오류 복원 레벨 (CorrectLevel)

QR코드는 일부가 가려지거나 훼손돼도 읽을 수 있게 복원 정보를 함께 담습니다. 레벨이 높을수록(H) 더 많이 가려져도 읽히지만, 패턴이 촘촘해집니다. 같은 텍스트로 비교해보세요.
현장에서 QR 스티커가 긁히거나 얼룩질 수 있는 환경(예: 어시장, 야외)일수록 높은 레벨(Q/H)을 쓰는 게 안전합니다.
코드 보기 
new QRCode(el, {
  text: '어획물 이력 예시',
  correctLevel: QRCode.CorrectLevel.H, // L, M, Q, H
});

4. 실용 예시 — 어획물 이력표 QR + PNG 저장

가상의 "어획물 이력표"입니다. 표의 내용을 JSON으로 담은 QR을 생성하고, PNG 파일로 저장합니다. 스캔하면 이력 정보(가상)가 텍스트로 보입니다.

어획물 이력표 (가상 예시)

※ 실제 이력제 데이터가 아닙니다
어종고등어
어획일2026-07-12
위판장부산공동어시장
어선제101호 (가상)
중량320kg
canvas의 toDataURL()로 이미지를 추출해 저장합니다.
코드 보기 
const data = JSON.stringify({ 어종: '고등어', 어획일: '2026-07-12', ... });
new QRCode(el, { text: data, width: 140, height: 140 });

// PNG 저장 (QRCode.js는 canvas로 그림)
const canvas = el.querySelector('canvas');
const link = document.createElement('a');
link.download = 'catch-history-qr.png';
link.href = canvas.toDataURL('image/png');
link.click();
