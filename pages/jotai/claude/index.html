Jotai

Jotai는 상태를 atom(원자)이라는 아주 작은 단위로 쪼개서 관리하는 라이브러리입니다. "하나의 큰 상태 객체"를 만드는 대신, 필요한 만큼 작은 atom을 여러 개 만들고 서로 조합합니다. 특히 다른 atom들로부터 값을 자동으로 계산하는 파생(derived) atom이 1급 개념으로 있는 게 특징입니다. 보통 React 훅과 함께 쓰이지만, 이 페이지는 jotai/vanilla API로 React 없이 순수 JS에서 사용하는 방법을 보여줍니다.

  • atom(초기값)으로 최소 단위 상태를 정의, createStore()로 실행 컨텍스트 생성
  • atom((get) => ...)로 다른 atom에서 값을 읽어 자동 계산되는 파생 atom
  • read와 write를 모두 정의하면 양방향으로 동작하는 "쓰기 가능한 파생 atom"도 가능
  • atom이 Promise를 반환하면 그 자체로 비동기 atom이 됨 (loadable()로 로딩 상태 확인)
⚠️ 이 페이지의 위판·시세 데이터는 Jotai 기능 설명을 위한 가상의 예시이며, 실제 수협중앙회의 통계·조직·절차와 무관합니다. 다른 외부 API는 사용하지 않았습니다 (Jotai 2.20.2를 CDN에서 로드).

1. 기본 atom + store — get/set/sub

atom(초기값)으로 상태 하나를 만들고, store.get(atom)으로 읽고 store.set(atom, 값)으로 씁니다. store.sub(atom, listener)로 변경을 구독합니다.

입찰가 (store.get(countAtom))
0
소스 코드 보기 
import { atom, createStore } from 'jotai/vanilla';

const countAtom = atom(0);
const store = createStore();

store.sub(countAtom, () => {
  console.log('변경됨:', store.get(countAtom));
});

store.set(countAtom, (c) => c + 1000); // 함수형 업데이트

2. 파생 atom (Derived/Computed Atom)

atom((get) => ...)처럼 read 함수만 주면, 그 안에서 참조한 다른 atom이 바뀔 때마다 자동으로 다시 계산되는 읽기 전용 atom이 됩니다. 별도의 수동 재계산 코드가 필요 없습니다.

총 위판 금액 (파생 atom, 자동 계산)
960,000원
소스 코드 보기 
const weightAtom = atom(120);
const priceAtom = atom(8000);

// read 함수 안에서 다른 atom을 get()하면 의존성이 자동으로 추적됨
const totalAtom = atom((get) => get(weightAtom) * get(priceAtom));

store.sub(totalAtom, () => console.log('총액 갱신:', store.get(totalAtom)));
store.set(weightAtom, 150); // totalAtom이 자동으로 재계산됨

3. 쓰기 가능한 파생 atom — 섭씨 ↔ 화씨 양방향 변환

read와 write를 모두 정의하면, "다른 atom에서 값을 계산해서 보여주지만, 이 atom에 직접 값을 쓰면 원본 atom을 역산해서 갱신하는" 양방향 atom을 만들 수 있습니다.

섭씨 (원본 atom)
20℃
화씨 (쓰기 가능한 파생 atom)
68℉
소스 코드 보기 
const celsiusAtom = atom(20);
const fahrenheitAtom = atom(
  (get) => get(celsiusAtom) * 9 / 5 + 32,           // read: 섭씨 -> 화씨
  (get, set, newFahrenheit) => {                     // write: 화씨 -> 섭씨로 역산
    set(celsiusAtom, (newFahrenheit - 32) * 5 / 9);
  }
);

store.set(fahrenheitAtom, 100); // celsiusAtom도 함께 갱신됨 (37.78)

4. 비동기 atom + loadable()

atom의 read 함수가 Promise를 반환하면 그 자체로 비동기 atom이 됩니다. loadable()로 감싸면 {'{ state: "loading" | "hasData" | "hasError" }'} 형태로 로딩 상태까지 함께 알 수 있습니다 (React의 Suspense 없이도 사용 가능).

비동기 시세 조회 상태
-
조회된 시세
-
소스 코드 보기 
const priceQueryAtom = atom(async () => {
  const res = await fetch('/api/price'); // 예시: 실제로는 setTimeout으로 대체
  return res.json();
});

const loadablePriceAtom = loadable(priceQueryAtom);

const result = store.get(loadablePriceAtom);
// result.state === 'loading' | 'hasData' | 'hasError'
// result.state === 'hasData' 일 때 result.data 사용 가능

5. atomWithStorage + selectAtom

atomWithStorage는 atom 값을 자동으로 localStorage에 저장·복원합니다. 즐겨찾기를 토글한 뒤 이 페이지를 새로고침해도 유지되는지 확인해보세요. selectAtom은 객체 atom에서 특정 필드만 선택해 구독하므로, 관계없는 필드가 바뀔 때는 알림을 받지 않습니다.

💡 확인된 동작: atomWithStorage는 기본적으로 구독(mount)이 걸려야 localStorage를 읽어옵니다 — store.get()만으로 새 store를 만들면 저장된 값이 아니라 최초 기본값이 나옵니다. 마운트 없이도 즉시 복원하려면 { getOnInit: true } 옵션을 명시해야 합니다. (아래 예제는 이 옵션을 사용합니다.)
selectAtom 테스트: b값만 바꿔도 "a만 구독"한 리스너는 반응 안 함
a
0
b
0
"a만 구독"한 리스너 호출 횟수
0
소스 코드 보기 
import { atomWithStorage, selectAtom, createJSONStorage } from 'jotai/vanilla/utils';

const favoritesAtom = atomWithStorage(
  'favorites', [], createJSONStorage(() => localStorage), { getOnInit: true }
);
store.set(favoritesAtom, (prev) => [...prev, '고등어']);

const abAtom = atom({ a: 0, b: 0 });
const aSliceAtom = selectAtom(abAtom, (s) => s.a); // a가 바뀔 때만 알림
store.sub(aSliceAtom, () => console.log('a changed'));
