bpmn-js 핵심 기능 둘러보기

bpmn-js는 BPMN 2.0 표준으로 그린 업무 절차 다이어그램을 브라우저에서 보여주고, 직접 편집도 할 수 있게 해주는 라이브러리입니다. 다이어그램은 BPMN XML 형식의 텍스트 파일로 저장·복원됩니다.
  • new BpmnJS({ container }).importXML(xml)로 XML을 불러와 다이어그램으로 렌더링
  • 왼쪽 팔레트에서 태스크·게이트웨이 등을 끌어다 놓고, 요소끼리 화살표로 연결 가능
  • modeling.updateLabel(), modeling.setColor() 같은 API로 코드에서 직접 다이어그램을 수정
  • saveXML()으로 현재 다이어그램을 다시 BPMN XML로 추출
※ 아래 위판 처리 절차는 bpmn-js 학습용으로 만든 가상의 예시이며, 실제 수협중앙회의 업무 절차가 아닙니다. 이 페이지는 bpmn-js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.
ℹ️ 확인된 특이사항: bpmn-js는 원(이벤트)·마름모(게이트웨이)처럼 작은 도형에 붙은 한글 라벨을 한 글자씩 세로로 쌓아서 표시하는 경우가 있습니다(예: "접수" → "접"/"수"). 폭이 넉넉한 사각형(태스크) 라벨은 문제없이 한 줄로 표시되며, 이는 CDN에서 받은 실제 라이브러리로 직접 확인한 동작입니다.

1. 기본 다이어그램 뷰어 + 확대·축소

위판 처리 절차 다이어그램입니다. 버튼으로 확대·축소하거나 전체 화면에 맞출 수 있고, 마우스 휠로도 확대·축소됩니다.
코드 보기 
const viewer = new BpmnJS({ container: '#canvas1' });
await viewer.importXML(xml);
viewer.get('canvas').zoom('fit-viewport');

zoomInBtn.addEventListener('click', () => {
  const canvas = viewer.get('canvas');
  canvas.zoom(canvas.zoom() + 0.1);
});

2. 인터랙티브 모델러

왼쪽 팔레트에서 태스크나 게이트웨이를 캔버스로 끌어다 놓아보세요. 기존 요소에 마우스를 올리면 나오는 화살표 아이콘으로 다른 요소와 연결선을 그릴 수 있고, 더블클릭하면 라벨을 바로 수정할 수 있습니다.
코드 보기 
// BpmnJS(모델러 번들)는 뷰어와 API가 같지만, 팔레트/컨텍스트 패드가 함께 켜져서
// 사용자가 직접 요소를 추가·연결·수정할 수 있습니다.
const modeler = new BpmnJS({ container: '#canvas2' });
await modeler.importXML(xml);
modeler.get('canvas').zoom('fit-viewport');

3. JS API로 요소 편집

화면을 직접 조작하지 않고, 코드에서 modeling 서비스로 라벨과 색상을 바꿔봅니다.
코드 보기 
const elementRegistry = modeler.get('elementRegistry');
const modeling = modeler.get('modeling');

renameBtn.addEventListener('click', () => {
  const task = elementRegistry.get('Task_1');
  modeling.updateLabel(task, '1차 검수');
});

colorBtn.addEventListener('click', () => {
  const task = elementRegistry.get('Task_2');
  modeling.setColor([task], { fill: '#fff6e5', stroke: '#a15c00' });
});

4. XML 저장 · 다운로드

지금 화면의 다이어그램을 BPMN XML 텍스트로 뽑아내거나 .bpmn 파일로 다운로드할 수 있습니다. 캔버스를 자유롭게 편집한 뒤 시도해보세요.
저장된 XML 없음
코드 보기 
const { xml } = await modeler.saveXML({ format: true });
xmlPreview.textContent = xml;

const blob = new Blob([xml], { type: 'application/xml' });
const a = document.createElement('a');
a.href = URL.createObjectURL(blob);
a.download = 'wipan-process.bpmn'; // 한글 파일명은 브라우저에서 깨질 수 있어 영문으로 지정
a.click();
