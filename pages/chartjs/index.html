Chart.js 핵심 기능 둘러보기

Chart.js는 캔버스 기반으로 막대·선·도넛 등 기본 차트 타입을 간단한 설정 객체로 그려주는 라이브러리입니다. 반응형 크기 조절과 애니메이션, 툴팁이 기본 내장돼 있고 플러그인으로 그리기 동작을 직접 확장할 수 있습니다.
  • new Chart(ctx, { type, data, options }) 한 번의 호출로 차트 생성
  • options.plugins.tooltip.callbacks로 툴팁에 표시되는 문구를 직접 커스터마이즈
  • 차트 그리기 전/후에 개입하는 플러그인을 등록해 캔버스에 커스텀 요소를 추가 가능
  • 한 차트 안에 type이 다른 데이터셋(막대+선)을 섞은 혼합 차트 지원
※ 아래 위판 실적 수치는 Chart.js 학습용으로 만든 가상의 샘플 데이터이며, 실제 수협중앙회의 통계가 아닙니다. 이 페이지는 Chart.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 막대 차트

위판장별 위판량(가상)을 비교합니다. 막대 위에 값을 직접 표시했습니다.
코드 보기 
new Chart(document.getElementById('chart1'), {
  type: 'bar',
  data: {
    labels: ['노량진', '통영', '여수', '목포', '포항', '부산'],
    datasets: [{
      data: [130, 150, 190, 210, 260, 480],
      backgroundColor: '#2a78d6',
      borderRadius: 4,
      maxBarThickness: 28,
    }],
  },
  options: {
    indexAxis: 'y',
    scales: { x: { beginAtZero: true } },
    plugins: { legend: { display: false } },
  },
});

2. 다중 계열 선 차트 + 커스텀 툴팁

어종별 월별 위판량(가상) 추이입니다. 마우스를 올리면 tooltip.callbacks로 만든 "kg" 단위가 붙은 문구가 뜹니다.
코드 보기 
new Chart(document.getElementById('chart2'), {
  type: 'line',
  data: {
    labels: ['2월', '3월', '4월', '5월', '6월', '7월'],
    datasets: [
      { label: '고등어', data: [120, 150, 170, 210, 260, 300], borderColor: '#2a78d6' },
      { label: '갈치',   data: [90, 100, 95, 110, 130, 140],  borderColor: '#1baf7a' },
      { label: '오징어', data: [60, 70, 85, 100, 90, 95],    borderColor: '#eda100' },
    ],
  },
  options: {
    interaction: { mode: 'index', intersect: false }, // 점 위가 아니어도 그래프 어디서든 툴팁이 뜨게
    plugins: {
      tooltip: {
        callbacks: {
          // 기본 "라벨: 값" 대신 단위를 붙인 문구로 교체
          label: (ctx) => `${ctx.dataset.label}: ${ctx.parsed.y}kg`,
        },
      },
    },
  },
});

3. 도넛 차트 + 커스텀 플러그인

어종별 위판 비중(가상)입니다. 도넛 가운데 총합을 표시하는 부분은 Chart.js 기본 기능이 아니라, 직접 만든 플러그인이 캔버스에 그려 넣은 것입니다.
코드 보기 
const centerTextPlugin = {
  id: 'centerText',
  afterDraw(chart) {
    const { ctx, chartArea: { left, right, top, bottom } } = chart;
    const total = chart.data.datasets[0].data.reduce((a, b) => a + b, 0);
    ctx.save();
    ctx.textAlign = 'center';
    ctx.textBaseline = 'middle';
    ctx.font = '600 20px sans-serif';
    ctx.fillStyle = '#0b0b0b';
    ctx.fillText(`${total}kg`, (left + right) / 2, (top + bottom) / 2 - 8);
    ctx.font = '12px sans-serif';
    ctx.fillStyle = '#898781';
    ctx.fillText('전체 위판량', (left + right) / 2, (top + bottom) / 2 + 12);
    ctx.restore();
  },
};

new Chart(document.getElementById('chart3'), {
  type: 'doughnut',
  data: {
    labels: ['고등어', '갈치', '오징어', '새우', '기타'],
    datasets: [{ data: [420, 260, 190, 140, 90], backgroundColor: [...] }],
  },
  options: { cutout: '70%' },
  plugins: [centerTextPlugin], // 이 차트에서만 쓰는 플러그인
});

4. 혼합 차트 (막대 + 선)

월별 위판 실적(막대)과 목표치(선)를 같은 축(kg) 위에 겹쳐 그립니다. 한 차트에 서로 다른 type의 데이터셋을 섞을 수 있는 Chart.js의 혼합 차트 기능입니다.
코드 보기 
new Chart(document.getElementById('chart4'), {
  data: {
    labels: ['2월', '3월', '4월', '5월', '6월', '7월'],
    datasets: [
      { type: 'bar',  label: '실적', data: [210, 240, 260, 250, 300, 320], backgroundColor: '#2a78d6' },
      { type: 'line', label: '목표', data: [220, 220, 250, 270, 280, 300], borderColor: '#1baf7a' },
    ],
  },
  options: {
    scales: { y: { beginAtZero: true } }, // 두 데이터셋이 같은 y축을 공유 (축 2개 아님)
  },
});
