시간축 핵심 기능

어댑터가 실제로 개입하는 파싱·포맷·단위·로케일 동작 중심

SAMPLE 01

기본 time 축 + ISO 날짜

ISO 8601 문자열을 자동 파싱하고 시간 간격에 비례해 배치
입력 형식2026-07-01T09:00:00
핵심 옵션type: 'time', tooltipFormat
x: { type: 'time', time: { unit: 'day', tooltipFormat: 'PPP p' } }
SAMPLE 02

사용자 지정 문자열 파서

업무 데이터의 yyyy/MM/dd HH:mm 형식을 time.parser로 해석
time: { parser: 'yyyy/MM/dd HH:mm', displayFormats: { hour: 'M/d HH:mm' } }
SAMPLE 03

time vs timeseries 비교

불규칙 간격을 실제 시간 비율로 표시하거나 동일 간격으로 표시
time · 실제 시간 간격
timeseries · 데이터 동일 간격
type: 'time' ↔ type: 'timeseries'
SAMPLE 04

시간 단위·표시 형식 전환

unit, stepSize, displayFormats, minUnit을 동적으로 변경
time.unit / ticks.stepSize / time.displayFormats[unit]
SAMPLE 05

date-fns 다국어 로케일

adapters.date.locale에 locale 객체를 전달해 월·요일 표기 변경
adapters: { date: { locale: dateFns.locale.ko } }
SAMPLE 06

주 단위·ISO 월요일 시작

unit:'week'와 isoWeekday를 사용해 주간 실적 기준일 제어
time: { unit: 'week', isoWeekday: 1, round: 'week' }

SAMPLE 09

시간 기반 이벤트 산점도
