Vega 핵심 기능 둘러보기

Vega는 시각화를 순수 JSON 명세로 기술하는 그래픽 문법입니다. Observable Plot이 JS 함수 호출로 마크를 나열한다면, Vega는 스케일·축·마크·인터랙션까지 차트 전체를 하나의 JSON 객체로 표현합니다 — 그 JSON 자체가 저장·전송·비교 가능한 데이터입니다.
  • 차트 전체가 JSON 명세 — vega.parse(spec)로 파싱해 실행 가능한 런타임(dataflow)을 만들고 View로 렌더링
  • signal — 슬라이더 같은 HTML 위젯에 바로 연결되는 반응형 변수. 위젯을 조작하면 signal 값이 바뀌고, 그 값을 참조하는 모든 데이터·인코딩이 자동으로 다시 계산됨
  • JSON 안에서 선언하는 데이터 변환(aggregate/filter/bin) 파이프라인
  • 이벤트 스트림 기반 인터랙션 — click/hover 이벤트로 signal을 갱신해 마크 스타일을 동적으로 제어
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Vega(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 순수 JSON 명세로 차트 그리기

아래 막대 차트는 JS 코드가 그린 게 아니라, 스케일·축·마크가 담긴 JSON 객체 하나를 vega.parse()에 넘긴 것입니다. 이 JSON은 그대로 파일로 저장하거나 서버로 전송해도 똑같이 렌더링됩니다.
코드 보기 
const spec = {
  "$schema": "https://vega.github.io/schema/vega/v6.json",
  "width": 400, "height": 220, "padding": 5,
  "data": [{ "name": "table", "values": [
    { "market": "1위판장", "catch": 320 },
    { "market": "2위판장", "catch": 210 },
    { "market": "3위판장", "catch": 450 }
  ]}],
  "scales": [
    { "name": "x", "type": "band", "domain": {"data": "table", "field": "market"}, "range": "width", "padding": 0.2 },
    { "name": "y", "type": "linear", "domain": {"data": "table", "field": "catch"}, "range": "height", "nice": true }
  ],
  "axes": [{ "orient": "bottom", "scale": "x" }, { "orient": "left", "scale": "y" }],
  "marks": [{
    "type": "rect", "from": { "data": "table" },
    "encode": { "enter": {
      "x": {"scale": "x", "field": "market"}, "width": {"scale": "x", "band": 1},
      "y": {"scale": "y", "field": "catch"}, "y2": {"scale": "y", "value": 0},
      "fill": {"value": "#2a78d6"}
    }}
  }]
};

const view = new vega.View(vega.parse(spec), { renderer: 'svg' })
  .initialize(container)
  .run();

2. Signal + HTML 위젯 바인딩

슬라이더를 움직여보세요. signal이 슬라이더에 바로 바인딩되어 있어서, 값이 바뀌면 filter 변환식(datum.price >= threshold)이 다시 평가되고 차트가 즉시 갱신됩니다 — 이 시각화에는 별도의 이벤트 리스너 코드가 없습니다.
코드 보기 
{
  "signals": [
    { "name": "threshold", "value": 0,
      "bind": { "input": "range", "min": 0, "max": 20000, "step": 500 } }
  ],
  "data": [{
    "name": "table", "values": rawPrices,
    "transform": [{ "type": "filter", "expr": "datum.price >= threshold" }]
  }],
  "marks": [{ "type": "rect", "from": { "data": "table" }, "encode": { ... } }]
}
// 슬라이더는 view.initialize(chartEl, bindEl)의 두 번째 인자 위치에 자동 생성됨

3. 데이터 변환 파이프라인 (aggregate)

개별 위판 거래 25건을 원자료 그대로 넣었습니다. 합계를 미리 계산하지 않고, JSON 안의 aggregate 변환이 위판장별로 묶어서 합산합니다.
코드 보기 
// rawRows: [{ market, catch }, ...] 개별 거래 25건 (합계 미계산)
{
  "data": [{
    "name": "table", "values": rawRows,
    "transform": [
      { "type": "aggregate", "groupby": ["market"], "fields": ["catch"], "ops": ["sum"], "as": ["total"] }
    ]
  }],
  "marks": [{ "type": "rect", "from": { "data": "table" },
    "encode": { "enter": { "y": {"scale": "y", "field": "total"}, ... } } }]
}

4. 이벤트 기반 인터랙션 (hover 툴팁 + click 하이라이트)

막대에 마우스를 올리면 값이 뜨고, 클릭하면 빨간색으로 강조됩니다. 강조 상태는 signal의 on 이벤트 스트림으로 정의했고, 막대 색상은 그 signal 값을 참조하는 표현식으로 결정됩니다.
막대를 클릭해보세요.
코드 보기 
{
  "signals": [{
    "name": "selected", "value": null,
    "on": [{ "events": "@bars:click", "update": "datum.market === selected ? null : datum.market" }]
  }],
  "marks": [{
    "name": "bars", "type": "rect", "from": { "data": "table" },
    "encode": {
      "update": {
        "fill": { "signal": "datum.market === selected ? '#e34948' : '#2a78d6'" }
      }
    }
  }]
}

// hover 툴팁은 Vega가 자동으로 만들어주지 않아서 이벤트로 직접 구현:
view.addEventListener('mouseover', (event, item) => {
  if (item?.datum) showTooltip(event, `${item.datum.market}: ${item.datum.catch}kg`);
});
view.addEventListener('mouseout', hideTooltip);
