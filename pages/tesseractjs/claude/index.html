Tesseract.js 핵심 기능 둘러보기

Tesseract.js는 오픈소스 OCR 엔진 Tesseract를 WebAssembly로 포팅해서, 브라우저 안에서 이미지 속 글자를 텍스트로 인식해주는 라이브러리입니다.
  • 이미지에서 영어 텍스트 인식
  • worker.reinitialize()로 하는 한국어 인식
  • logger 콜백으로 보는 엔진·언어 데이터 로딩 진행 상황
  • 인식된 단어 위치(바운딩 박스) 시각화
※ OCR 엔진(WASM)과 언어 데이터는 처음 실행할 때 수 MB를 내려받습니다(영어·한국어 합쳐 약 8MB). 버튼을 누른 뒤 처음 몇 초는 이 다운로드 때문에 걸리는 시간입니다. 아래 위판 안내문 이미지는 이 페이지를 위해 캔버스로 직접 그린 가상의 예시입니다.
🔒 인식은 브라우저 안에서만 이루어집니다. 이미지가 서버로 전송되지 않습니다.

1. 기본 텍스트 인식 (영어)

캔버스로 그린 샘플 이미지에서 텍스트를 인식합니다. worker.recognize(image) 한 번이면 됩니다.
소스 코드 보기 
const worker = await Tesseract.createWorker('eng');
const { data } = await worker.recognize(imageUrlOrFile);
console.log(data.text, data.confidence);
await worker.terminate();

2. 한국어 인식 (언어 전환)

같은 워커를 worker.reinitialize('kor')로 재초기화하면, 워커를 새로 만들지 않고도 다른 언어를 인식할 수 있습니다. (워커를 새로 만들지 못하는 상황이 아니라면 createWorker('kor')로 바로 만드는 편이 더 간단합니다.)
소스 코드 보기 
await worker.reinitialize('kor');
const { data } = await worker.recognize(korImage);
console.log(data.text); // "안녕하세요 위판" 등

3. 로딩 진행 상황 표시 (logger)

createWorker()의 logger 옵션으로 WASM 엔진 로딩, 언어 데이터 다운로드, 인식 진행률 같은 단계별 상태를 실시간으로 받을 수 있습니다. 새 워커를 하나 만들면서 각 단계가 찍히는 것을 확인해 보세요.
소스 코드 보기 
const worker = await Tesseract.createWorker('eng', 1, {
  logger: (m) => console.log(m.status, Math.round(m.progress * 100) + '%'),
  // 예: "loading tesseract core" 0%→100%, "loading language traineddata" 0%→100%,
  //     "initializing tesseract" 0%→100%, "recognizing text" 0%→100% ...
});

4. 인식된 단어 위치 시각화

recognize(image, {}, { blocks: true })로 호출하면 문단·줄·단어 단위의 좌표(bbox)까지 받을 수 있습니다. 각 단어의 위치에 사각형을 그려서 어떤 글자를 어디서 인식했는지 확인합니다.
소스 코드 보기 
const { data } = await worker.recognize(image, {}, { blocks: true });
data.blocks.forEach((block) => {
  block.paragraphs.forEach((para) => {
    para.lines.forEach((line) => {
      line.words.forEach((word) => {
        const { x0, y0, x1, y1 } = word.bbox;
        // 이 좌표에 사각형을 그리면 됨
      });
    });
  });
});
