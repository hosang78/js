WebCola 핵심 기능 둘러보기

WebCola는 force(물리 시뮬레이션) 레이아웃에 제약(constraint)을 함께 걸 수 있는 그래프 레이아웃 라이브러리입니다. "이 두 노드는 같은 줄에 정렬해라", "이 노드는 저 노드보다 최소 100px 오른쪽에 있어라" 같은 규칙을 강제하면서도 나머지는 자연스럽게 힘으로 퍼지게 합니다. 좌표만 계산하고 화면에 그려주지는 않습니다.
  • 겹침 방지(avoidOverlaps)가 있는 기본 force 레이아웃
  • 정렬(alignment)·분리(separation) 제약으로 특정 노드들의 위치 관계를 강제
  • 그룹(groups)으로 관련 노드들을 자동으로 박스에 묶기
  • 방향성 있는 flow 레이아웃 — 힘으로 퍼지면서도 위→아래 순서는 지킴
※ 아래 유통 네트워크는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 유통 구조와 무관합니다. WebCola npm 패키지는 브라우저용 번들 없이 여러 파일로 나뉜 CommonJS로만 배포되어 있어, 필요한 코드를 esbuild로 하나로 묶어 빌드한 번들 파일(webcola-bundle.esm.js)을 페이지와 함께 담아 사용합니다(CodeMirror 페이지와 같은 방식). WebCola는 좌표만 계산하므로 결과는 이 페이지에서 직접 그린 SVG로 표시합니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 force 레이아웃 (겹침 방지)

가상 위판장 유통 네트워크입니다. 노드끼리 서로 밀어내며 자연스럽게 퍼지고, 겹치지 않습니다.
코드 보기 
const layout = new cola.Layout()
  .size([480, 320])
  .nodes(nodes)
  .links(links)
  .linkDistance(80)
  .avoidOverlaps(true)
  .start(10, 15, 20, 0, false); // keepRunning=false → 동기적으로 계산 완료

2. 정렬(alignment) + 분리(separation) 제약

점선은 제약을 시각화한 안내선입니다. 중도매인 A·B는 같은 가로줄(y좌표)에 정렬되고, 1번 위판장과 수출업체는 항상 최소 180px 이상 떨어지도록 강제됩니다.
제약 안내선
코드 보기 
const constraints = [
  // 중도매인 A, B를 같은 y좌표(가로줄)에 정렬
  { type: "alignment", axis: "y", offsets: [{ node: 1, offset: 0 }, { node: 2, offset: 0 }] },
  // 1번 위판장(0)과 수출업체(3)는 x축으로 최소 180px 간격
  { type: "separation", axis: "x", left: 0, right: 3, gap: 180 }
];
new cola.Layout().constraints(constraints)./* ... */.start(10, 15, 20, 0, false);

3. 그룹(groups) — 노드 묶기

가상 조합원들을 소속 위판장별로 그룹 박스에 묶습니다. 그룹의 크기와 위치는 안에 든 노드에 맞춰 자동으로 계산됩니다.
코드 보기 
const groups = [
  { leaves: [0, 1], padding: 12 }, // 1번 위판장 소속 조합원들
  { leaves: [2, 3], padding: 12 }  // 2번 위판장 소속 조합원들
];
new cola.Layout().groups(groups)./* ... */.start(10, 15, 20, 0, false);
// 계산 후 groups[i].bounds 에 그룹 박스의 x, X, y, Y(좌상단/우하단)가 채워짐

4. 방향성 있는 flow 레이아웃

힘으로 자연스럽게 퍼지면서도, 화살표 방향(위→아래)의 순서만은 항상 지켜집니다. Dagre·ELK.js의 딱딱한 단(rank) 배치와 달리 좌우 위치는 유동적입니다.
코드 보기 
new cola.Layout()
  .flowLayout("y", 70) // y축 방향으로 최소 70px씩 순서를 지키며 흐름
  .avoidOverlaps(true)
  ./* ... */
  .start(10, 15, 20, 0, false);
