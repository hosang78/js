13. 활용 시 주의사항

  
표현식 평가 기능은 일반 JavaScript eval보다 제한적이지만, 외부 입력을 무제한 허용하는 서비스에서는 계산량·메모리 사용량 제한과 허용 함수 통제가 별도로 필요합니다.

  
이 파일은 math.js 본체를 CDN에서 불러오므로 최초 실행 시 인터넷 연결이 필요합니다. 내부망에서 사용하려면 math.js 파일을 내려받아 같은 폴더에 두고 script 경로를 로컬 파일로 변경하세요.
