math.js 핵심 기능 둘러보기

math.js는 표현식 파서, 행렬 연산, 단위 변환, 기호 미분까지 아우르는 종합 수학 라이브러리입니다. 숫자뿐 아니라 행렬·복소수·단위가 있는 값까지 하나의 일관된 방식으로 다룰 수 있습니다.
  • math.evaluate()로 문자열 수식을 계산하는 표현식 파서
  • multiply·det·inv·transpose 같은 행렬 연산
  • math.unit()으로 하는 단위가 있는 값 변환
  • math.derivative()로 하는 기호 미분(symbolic differentiation)
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. math.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 표현식 파서

문자열로 된 수식을 변수 스코프와 함께 계산하거나, 수식으로 직접 함수를 정의해서 호출할 수 있습니다.
코드 보기 
math.evaluate('qty * price', { qty: 1200, price: 4200 });   // 위판 금액 계산
math.evaluate('sqrt(16) + 2^3');                              // 12

const f = math.evaluate('f(x) = x^2 + 3x + 2');               // 함수 정의
f(4);                                                          // 30

2. 행렬 연산

3개 위판장의 [수량, 단가]를 행렬로 표현하고, 열 합계·행렬곱·행렬식·역행렬·전치를 계산했습니다.
코드 보기 
const A = math.matrix([
  [1200, 4200],   // A위판장: [수량, 단가]
  [800, 4100],    // B위판장
  [1500, 4300],   // C위판장
]);

math.sum(math.column(A, 0));           // 전체 수량 합계
math.multiply(M, [1, 1]);              // 행렬 × 벡터
math.det(M);                           // 행렬식
math.inv(M);                           // 역행렬
math.transpose(A);                     // 전치행렬

3. 단위 변환

math.unit()은 값에 단위를 붙여서, 서로 다른 단위끼리도 자동으로 환산해 더하거나 변환할 수 있게 해줍니다.
⚠️ math.js의 기본 'ton'은 미국 단톤(약 907kg)입니다. 한국에서 흔히 쓰는 1,000kg 기준 미터톤을 쓰려면 'tonne'(또는 't')을 써야 합니다.
코드 보기 
math.unit('1200 kg').to('tonne').toString();     // "1.2 tonne"
math.add(math.unit('500 kg'), math.unit('0.3 tonne')).toString();   // "800 kg"

math.unit('1200 kg').to('ton').toString();        // "1.32... ton" (미국 단톤! 주의)

4. 기호 미분

3차 함수 2x³ + 3x² − 12x를 미분해서 도함수 식을 얻고, x=2에서의 순간 변화율(기울기)을 계산했습니다. 원함수(파랑)와 도함수(주황)를 함께 그렸습니다.
f(x) = 2x³ + 3x² − 12x f'(x) (도함수)
코드 보기 
const expr = '2x^3 + 3x^2 - 12x';
const derivExpr = math.derivative(expr, 'x').toString();   // "6 * (x ^ 2 + x) - 12"

math.evaluate(derivExpr, { x: 2 });   // x=2에서의 기울기
