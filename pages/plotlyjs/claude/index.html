Plotly.js 핵심 기능 둘러보기

Plotly.js는 차트를 SVG/WebGL로 그려주는 선언적(declarative) 시각화 라이브러리입니다. 데이터와 레이아웃을 객체로 넘기기만 하면, 확대/축소·팬·호버 툴팁·이미지 저장 같은 인터랙션이 모드바(mode bar)와 함께 기본으로 딸려옵니다.
  • Plotly.newPlot(el, data, layout) 하나로 완성되는 선언적 API
  • 확대/축소·팬·박스 선택·리셋을 제공하는 기본 내장 모드바
  • layout.grid로 만드는 서브플롯 그리드
  • 같은 API로 그대로 그려지는 WebGL 기반 3D 차트
  • Plotly.extendTraces()로 데이터만 이어붙이는 실시간 스트리밍 갱신
※ 아래 위판량·시세·수온 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Plotly.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 선언적 API로 그리는 다중 계열 그래프 + 기본 인터랙션

4개 위판장의 최근 12주 평균 시세를 한 차트에 그렸습니다. 그래프 위에 마우스를 올리면 통합 호버 툴팁이, 우측 상단에는 확대/축소·팬·박스 선택·리셋 아이콘이 담긴 모드바가 자동으로 나타납니다. 아래 버튼으로 드래그 동작(확대 ↔ 이동)도 바꿔볼 수 있습니다.
코드 보기 
Plotly.newPlot('chart1', [
  { x: weeks, y: priceA, name: 'A위판장', mode: 'lines+markers', line: { color: '#2a78d6' } },
  { x: weeks, y: priceB, name: 'B위판장', mode: 'lines+markers', line: { color: '#1baf7a' } },
  { x: weeks, y: priceC, name: 'C위판장', mode: 'lines+markers', line: { color: '#eda100' } },
  { x: weeks, y: priceD, name: 'D위판장', mode: 'lines+markers', line: { color: '#008300' } },
], {
  hovermode: 'x unified',
  yaxis: { title: '평균 시세(원/kg)' },
});

// 모드바를 코드로 직접 조작하지 않고, dragmode만 바꿔도 확대/이동 동작이 즉시 전환된다
Plotly.relayout('chart1', { dragmode: 'pan' });

2. 서브플롯(subplot) 그리드

layout.grid에 행/열 수만 지정하면, 위판장별 월간 위판량을 2×2 격자에 나란히 배치할 수 있습니다. 각 차트는 독립적으로 확대/축소됩니다.
코드 보기 
Plotly.newPlot('chart2', [
  { x: months, y: volA, type: 'bar', name: 'A위판장', marker: { color: '#2a78d6' }, xaxis: 'x', yaxis: 'y' },
  { x: months, y: volB, type: 'bar', name: 'B위판장', marker: { color: '#1baf7a' }, xaxis: 'x2', yaxis: 'y2' },
  { x: months, y: volC, type: 'bar', name: 'C위판장', marker: { color: '#eda100' }, xaxis: 'x3', yaxis: 'y3' },
  { x: months, y: volD, type: 'bar', name: 'D위판장', marker: { color: '#008300' }, xaxis: 'x4', yaxis: 'y4' },
], {
  grid: { rows: 2, columns: 2, pattern: 'independent' },
  showlegend: false,
});

3. WebGL 3D 산점도

type: 'scatter3d'만 지정하면 같은 API로 GPU 가속 3D 차트를 그립니다. 가상의 조사 지점별 수온 · 수심 · 어획량 관계를 표시했으며, 점 색은 어획량(연속값)을 밝은 파랑 → 짙은 파랑 순서로 나타냅니다. 마우스로 드래그하면 시점을 회전할 수 있습니다.
코드 보기 
Plotly.newPlot('chart3', [{
  type: 'scatter3d',
  mode: 'markers',
  x: waterTemp, y: depth, z: catchAmount,
  marker: {
    size: 5,
    color: catchAmount,                              // 값 기준 그라데이션(연속형)
    colorscale: [[0, '#eaf2fc'], [0.5, '#5c94dd'], [1, '#154a8f']],
    colorbar: { title: '어획량(kg)' },
  },
}], {
  scene: {
    xaxis: { title: '수온(℃)' },
    yaxis: { title: '수심(m)' },
    zaxis: { title: '어획량(kg)' },
  },
});

4. 실시간 스트리밍 갱신

1초마다 A위판장의 새 시세 한 개를 extendTraces()로 이어붙이고, 가장 오래된 값은 Plotly.relayout의 범위 조정으로 화면에서 밀어냅니다. 차트를 처음부터 다시 그리지 않고 데이터만 추가하므로 가볍습니다.
스트리밍 대기 중...
코드 보기 
const MAX_POINTS = 30;
setInterval(() => {
  const t = new Date();
  const price = lastPrice + (Math.random() - 0.5) * 60;
  Plotly.extendTraces('chart4', { x: [[t]], y: [[price]] }, [0], MAX_POINTS);
  lastPrice = price;
}, 1000);
