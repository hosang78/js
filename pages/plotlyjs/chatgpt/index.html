Plotly.js 기능 종합 샘플

한 파일에서 선·막대·파이·통계·3D·지도·계층·금융·애니메이션·이벤트·API 조작을 확인하는 대시보드형 데모입니다. 각 차트는 확대, 축 이동, 범례 클릭, 박스/라쏘 선택, 이미지 저장 등 Plotly 기본 인터랙션을 포함합니다.

📈 20+ 시각화 예제 🧭 zoom / pan / select ⚙️ restyle · relayout · extendTraces 💾 PNG 저장 🌗 라이트/다크 테마

확인 가능한 핵심 기능

  • 차트 유형scatter, bar, pie, histogram, box, violin, heatmap, contour, surface, scatter3d, choropleth, treemap, sunburst, funnel, waterfall, indicator, table
  • 상호작용hovertemplate, range slider, range selector, legend toggle, lasso/box select, click/hover/relayout event
  • APInewPlot, react, restyle, relayout, update, extendTraces, animate, downloadImage
