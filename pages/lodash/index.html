Lodash 핵심 기능 둘러보기

Lodash는 배열·객체·문자열·함수를 다룰 때 반복적으로 쓰는 로직을 안전하고 짧게 처리해주는 유틸리티 함수 모음입니다.
  • 배열/객체 목록을 그룹핑·집계·정렬하는 함수들 (groupBy, sumBy, orderBy 등)
  • 중복 제거·분할·비교 같은 배열 전용 유틸 (uniq, chunk, difference, intersection)
  • 중첩 객체를 깊은 복사·병합하고, 없는 경로에 접근해도 에러 없이 기본값을 반환 (cloneDeep, merge, get)
  • 연속 호출을 묶어서 마지막 한 번만 실행하게 하는 debounce/throttle
※ 아래 위판 기록/조합원 명부는 Lodash 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 통계·명부가 아닙니다. 이 페이지는 Lodash(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 컬렉션 그룹핑 · 집계 · 정렬

위판 기록을 위판장별로 묶어(groupBy) 물량을 합산(sumBy)하고, 물량이 많은 순으로 정렬(orderBy)합니다.
코드 보기 
const grouped = _.groupBy(records, 'market');

const summary = _.map(grouped, (items, market) => ({
  market,
  total: _.sumBy(items, 'weight'),
  count: items.length,
}));

const sorted = _.orderBy(summary, ['total'], ['desc']);

2. 배열 유틸 (uniq · chunk · difference)

조합원 명부를 다루는 세 가지 자주 쓰는 배열 함수를 각각 버튼으로 실행해봅니다.

중복 제거 — _.uniq

명단에 중복 등록된 조합원 ID가 섞여 있습니다.
원본: A-1042, A-2078, A-1042, A-3155, A-2078, A-4090

일정 크기로 나누기 — _.chunk

전체 조합원 명단을 3명씩 묶어 페이지 단위로 보여줍니다.

명단 비교 — _.difference

전체 조합원 중 이번 주 총회에 참석하지 않은 사람을 찾습니다.
코드 보기 
_.uniq(['A-1042', 'A-2078', 'A-1042', 'A-3155', 'A-2078', 'A-4090']);
// -> ['A-1042', 'A-2078', 'A-3155', 'A-4090']

_.chunk(allMembers, 3);
// -> [[m1, m2, m3], [m4, m5, m6], ...]

_.difference(allMembers, attendedMembers);
// allMembers에는 있지만 attendedMembers에는 없는 값들

3. 깊은 복사 · 병합 · 안전한 경로 접근

중첩된 설정 객체를 깊은 복사(cloneDeep)하면 복사본을 바꿔도 원본이 그대로인지, 기본값과 변경값을 병합(merge)하면 어떻게 합쳐지는지, 없는 경로를 조회(get)해도 에러 없이 기본값이 나오는지 확인합니다.

cloneDeep — 원본 보호

merge — 기본값 + 사용자 설정

get — 안전한 중첩 경로 접근

코드 보기 
const original = { market: { name: '부산공동어시장', hours: { open: 5, close: 20 } } };
const copy = _.cloneDeep(original);
copy.market.hours.open = 6; // 복사본만 바뀌고 original은 그대로

const defaults = { notify: true, hours: { open: 5, close: 20 } };
const userSetting = { hours: { open: 6 } };
_.merge({}, defaults, userSetting);
// -> { notify: true, hours: { open: 6, close: 20 } }  (close는 기본값 유지)

_.get(original, 'market.hours.lunchBreak.start', '설정 없음'); // 에러 없이 '설정 없음' 반환

4. debounce — 연속 호출 묶어서 실행

아래 입력창에 어종 이름을 빠르게 타이핑해도, 실제 검색(필터 실행)은 타이핑이 400ms 멈춘 뒤 한 번만 실행됩니다. 키 입력 횟수와 실제 검색 실행 횟수를 비교해보세요.
검색어를 입력해보세요.
키 입력: 0회 / 실제 검색 실행: 0회
코드 보기 
const debouncedSearch = _.debounce((keyword) => {
  // 실제 필터링은 여기서만 실행됨 (타이핑이 멈춘 뒤 400ms 후)
  runSearchCount++;
  const filtered = species.filter((s) => s.includes(keyword));
  render(filtered);
}, 400);

searchInput.addEventListener('input', (e) => {
  keyPressCount++;
  debouncedSearch(e.target.value);
});
