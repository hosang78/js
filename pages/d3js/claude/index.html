D3.js 핵심 기능 둘러보기

D3.js는 완성된 차트를 그려주는 라이브러리가 아니라, 데이터를 SVG(또는 HTML) 요소에 직접 연결해서 화면을 조립하는 저수준 도구 모음입니다. Chart.js처럼 설정 객체 하나로 차트가 나오는 게 아니라, 좌표·크기·눈금을 직접 계산해서 요소를 만들고 붙이는 방식입니다.
  • d3.select/selectAll로 요소를 고르고 .data().join()으로 배열과 연결
  • d3.scaleLinear/scaleBand로 "데이터 값 → 픽셀 좌표" 변환 함수를 직접 생성
  • 데이터가 바뀌면 새로 생기는 요소(enter)·남는 요소(update)·없어지는 요소(exit)를 각각 다르게 다룰 수 있음
  • d3.pie, d3.arc 같은 "제너레이터"가 좌표 계산을 대신해주고, 그리기는 직접 함
※ 아래 위판 실적 수치는 D3.js 학습용으로 만든 가상의 샘플 데이터이며, 실제 수협중앙회의 통계가 아닙니다. 이 페이지는 D3.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 선택(Selection)과 데이터 바인딩

숫자 배열 하나를 SVG의 <rect> 여러 개에 연결합니다. 막대의 너비는 축이나 스케일 없이, 값을 직접 픽셀로 환산해 계산했습니다.
코드 보기 
const data = [130, 150, 190, 210, 260, 480]; // 위판장별 위판량(가상)
const max = 480;

d3.select('#chart1')
  .selectAll('rect')
  .data(data)
  .join('rect')
  .attr('x', 0)
  .attr('y', (d, i) => i * 34)
  .attr('width', (d) => (d / max) * 560) // 값을 직접 픽셀 너비로 환산
  .attr('height', 24)
  .attr('fill', '#2a78d6');

2. 스케일(Scale)과 축(Axis)

이번엔 값을 직접 계산하지 않고, d3.scaleBand/scaleLinear로 만든 변환 함수를 쓰고, d3.axisBottom/axisLeft로 눈금까지 자동으로 그립니다.
코드 보기 
const data = [
  { market: '노량진', value: 130 }, { market: '통영', value: 150 },
  { market: '여수', value: 190 }, { market: '목포', value: 210 },
  { market: '포항', value: 260 }, { market: '부산', value: 480 },
];

const x = d3.scaleBand().domain(data.map((d) => d.market)).range([0, 560]).padding(0.3);
const y = d3.scaleLinear().domain([0, 480]).range([220, 0]); // 값이 클수록 y는 작아짐(위로)

svg.append('g').call(d3.axisLeft(y));
svg.append('g').attr('transform', 'translate(0,220)').call(d3.axisBottom(x));

svg.selectAll('rect')
  .data(data)
  .join('rect')
  .attr('x', (d) => x(d.market))
  .attr('y', (d) => y(d.value))
  .attr('width', x.bandwidth())
  .attr('height', (d) => 220 - y(d.value))
  .attr('fill', '#2a78d6');

3. enter · update · exit + 트랜지션

버튼을 누를 때마다 어종 목록이 랜덤하게 바뀝니다. 새로 나타나는 막대는 아래에서 스르륵 올라오고(enter), 사라지는 막대는 옅어지며 사라지고(exit), 남아있는 막대는 값이 부드럽게 바뀝니다(update).
코드 보기 
const x = d3.scaleBand().range([0, 560]).padding(0.3);
const y = d3.scaleLinear().domain([0, 400]).range([200, 0]);

function render(data) {
  x.domain(data.map((d) => d.name));

  svg.selectAll('rect')
    .data(data, (d) => d.name) // name을 키로 써서 같은 항목을 추적
    .join(
      (enter) => enter.append('rect')
        .attr('x', (d) => x(d.name))
        .attr('y', 200)      // 처음엔 바닥에서
        .attr('height', 0)   // 높이 0에서 시작
        .call((e) => e.transition().duration(500)
          .attr('y', (d) => y(d.value))
          .attr('height', (d) => 200 - y(d.value))),
      (update) => update.call((u) => u.transition().duration(500)
        .attr('x', (d) => x(d.name))
        .attr('y', (d) => y(d.value))
        .attr('height', (d) => 200 - y(d.value))),
      (exit) => exit.transition().duration(300)
        .attr('height', 0).attr('y', 200).style('opacity', 0).remove(),
    );
}

4. pie / arc 제너레이터 — 도넛 차트

d3.pie()가 값을 각도로 바꿔주고, d3.arc()가 그 각도를 실제 SVG path 좌표로 계산해줍니다. 조각을 그리는 것 자체는 path 요소를 직접 붙이는 일반적인 D3 방식입니다.
코드 보기 
const data = [
  { name: '고등어', value: 420 }, { name: '갈치', value: 260 },
  { name: '오징어', value: 190 }, { name: '새우', value: 140 }, { name: '기타', value: 90 },
];
const color = d3.scaleOrdinal()
  .domain(data.map((d) => d.name))
  .range(['#2a78d6', '#1baf7a', '#eda100', '#008300', '#4a3aa7']);

const pieData = d3.pie().value((d) => d.value)(data); // 각 조각의 시작/끝 각도 계산
const arc = d3.arc().innerRadius(60).outerRadius(100); // 안쪽 반지름을 주면 도넛 모양

svg.selectAll('path')
  .data(pieData)
  .join('path')
  .attr('d', arc)                          // 각도 -> 실제 SVG path 좌표 변환
  .attr('fill', (d) => color(d.data.name))
  .attr('stroke', '#fcfcfb')
  .attr('stroke-width', 2);
