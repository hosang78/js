중요 한계

CryptoJS의 AES-CBC 등은 자체적으로 인증 태그를 제공하지 않는다. 기밀성과 위변조 방지를 함께 보장하려면 검증된 AEAD(AES-GCM 등)를 제공하는 Web Crypto API 사용이 일반적으로 더 적절하다. 이 페이지의 상수 시간 비교 함수도 JavaScript 실행 환경 특성상 엄밀한 하드웨어 수준 보장을 의미하지 않는다.
