crypto-js

crypto-js는 브라우저에서 바로 실행되는 해시·암호화 라이브러리입니다. 비밀번호를 서버로 보내지 않고 클라이언트에서 미리 해시하거나, 저장할 데이터를 암호화하는 등의 작업에 쓰입니다. 이 대시보드도 비밀번호 보호 앱이라 주제가 잘 맞아 함께 다뤄봅니다.

  • SHA-256/MD5/SHA-1 같은 해시 함수 — 같은 입력은 항상 같은 출력, 되돌릴 수 없음
  • HMAC — 비밀키를 섞은 해시로 메시지 위변조·잘못된 키를 감지
  • AES 대칭키 암호화 — 같은 비밀번호로만 원래 내용을 복호화 가능
  • PBKDF2 — 비밀번호에 salt를 섞어 무차별 대입(레인보우 테이블) 공격을 어렵게 만드는 키 유도
⚠️ 이 페이지는 crypto-js 기능을 보여주기 위한 학습용 예제입니다. 실제 로그인 비밀번호 해싱 등 보안이 중요한 용도에는 더 검증된 서버 사이드 라이브러리(bcrypt 등)를 쓰는 것이 안전합니다. 예시 문구는 가상의 데이터이며 실제 수협중앙회 정보와 무관합니다. 다른 외부 API는 사용하지 않았습니다 (crypto-js 4.2.0을 CDN에서 로드).

1. 해시 함수 — SHA-256 / MD5 / SHA-1 + 눈사태 효과

해시 함수는 어떤 길이의 입력이든 고정된 길이의 결과로 바꾸고, 같은 입력이면 항상 같은 결과가 나오며, 결과에서 원래 입력을 역산할 수 없습니다. 입력을 한 글자만 바꿔도 결과가 완전히 달라지는 "눈사태 효과(avalanche effect)"도 확인해보세요.

눈사태 효과: 아래 텍스트에서 숫자 하나만 바꿔서 SHA-256을 비교합니다 (다른 글자는 빨간색)
소스 코드 보기 
CryptoJS.SHA256('고등어 120kg 위판').toString();  // 64자리 16진수
CryptoJS.MD5('고등어 120kg 위판').toString();     // 32자리 16진수
CryptoJS.SHA1('고등어 120kg 위판').toString();    // 40자리 16진수

2. HMAC — 메시지 인증 (위변조 감지)

HMAC은 비밀키와 메시지를 함께 해시합니다. 메시지가 한 글자라도 바뀌거나, 검증하는 쪽이 다른 키를 쓰면 HMAC 값이 완전히 달라져서 위변조나 키 불일치를 감지할 수 있습니다.

소스 코드 보기 
const hmac = CryptoJS.HmacSHA256('메시지', '비밀키').toString();
// 메시지나 키가 조금이라도 다르면 완전히 다른 HMAC이 나옴 -> 검증 실패로 감지

3. AES 대칭키 암호화 / 복호화

같은 비밀번호로 암호화하고 복호화합니다. 비밀번호가 틀리면 원래 내용을 복원할 수 없습니다 — "올바른 비밀번호로 복호화"와 "틀린 비밀번호로 복호화"를 각각 눌러 비교해보세요.

소스 코드 보기 
const ciphertext = CryptoJS.AES.encrypt('평문', '비밀번호').toString();
const bytes = CryptoJS.AES.decrypt(ciphertext, '비밀번호');
const plaintext = bytes.toString(CryptoJS.enc.Utf8); // 원래 평문
// 비밀번호가 틀리면 깨진 바이트가 나와서 toString(Utf8)이 빈 문자열이 되기 쉬움

4. PBKDF2 — Salt 기반 키 유도

같은 비밀번호라도 매번 다른 무작위 salt를 섞어서 키를 유도하면, 같은 비밀번호를 쓰는 두 사용자의 저장된 값이 서로 달라져서 미리 계산해둔 레인보우 테이블 공격이 무력화됩니다.

시도Salt (매번 무작위)유도된 키 (PBKDF2, 1000회 반복)
소스 코드 보기 
const salt = CryptoJS.lib.WordArray.random(128 / 8); // 128비트 무작위 salt
const key = CryptoJS.PBKDF2('비밀번호', salt, {
  keySize: 256 / 32,   // 256비트 키
  iterations: 1000,    // 반복 횟수가 많을수록 무차별 대입이 느려짐
}).toString();

5. 인코딩 변환 — Base64 / Hex / Utf8

crypto-js 내부에서는 데이터를 WordArray라는 형태로 다루고, CryptoJS.enc.*로 여러 텍스트 인코딩과 서로 변환합니다. 암호화하지 않아도 단순 인코딩 변환에도 자주 쓰입니다.

소스 코드 보기 
const wordArray = CryptoJS.enc.Utf8.parse('수협 위판 2026');
const base64 = CryptoJS.enc.Base64.stringify(wordArray);
const hex = CryptoJS.enc.Hex.stringify(wordArray);

CryptoJS.enc.Base64.parse(base64).toString(CryptoJS.enc.Utf8); // 원문으로 복원
CryptoJS.enc.Hex.parse(hex).toString(CryptoJS.enc.Utf8);       // 원문으로 복원
