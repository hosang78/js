Driver.js 핵심 기능 둘러보기

Driver.js는 화면의 특정 요소를 어둡게 처리된 배경 위에 스포트라이트로 강조하면서 설명 팝업을 붙여주는 기능 안내(온보딩 투어) 라이브러리입니다. 신규 사용자에게 "여기를 먼저 누르세요" 식으로 순서대로 안내할 때 씁니다.
  • 여러 요소를 steps 배열로 지정하면 다음/이전 버튼으로 순서대로 안내
  • highlight()로 요소 하나만 즉시 스포트라이트 가능
  • 버튼 문구, 진행률 표시 형식을 자유롭게 커스터마이즈 가능
  • 각 단계 진입/이탈 시점에 콜백을 걸어 원하는 동작을 실행 가능
※ 아래 "위판 등록" 화면은 Driver.js 학습용으로 만든 가상의 목업 화면이며, 실제 수협중앙회의 시스템 화면이 아닙니다. 이 페이지는 Driver.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 다단계 투어

가상의 "위판 등록" 화면입니다. 버튼을 누르면 입력칸을 순서대로 안내합니다.
코드 보기 
const { driver } = window.driver.js;

driver({
  showProgress: true,
  steps: [
    { element: '#tour1-fish', popover: { title: '① 어종 선택', description: '등록할 어종을 고릅니다.' } },
    { element: '#tour1-qty', popover: { title: '② 수량 입력', description: 'kg 단위로 입력합니다.' } },
    { element: '#tour1-market', popover: { title: '③ 위판장 선택', description: '위판이 이루어진 장소를 고릅니다.' } },
    { element: '#tour1-submit', popover: { title: '④ 등록', description: '입력이 끝나면 등록 버튼을 누릅니다.' } },
  ],
}).drive();

2. 단일 요소 하이라이트

투어(여러 단계) 없이, 요소 하나만 바로 스포트라이트로 강조할 수도 있습니다.
알림 아이콘 (가상)
코드 보기 
driver().highlight({
  element: '#tour2-bell',
  popover: { title: '알림', description: '새 위판 알림이 여기 표시됩니다.' },
});

3. 커스텀 버튼 · 진행률 문구

버튼 문구를 한국어로 바꾸고, 진행률 표시 형식도 원하는 대로 지정할 수 있습니다.
코드 보기 
driver({
  showProgress: true,
  progressText: '{{current}} / {{total}} 단계',
  nextBtnText: '다음',
  prevBtnText: '이전',
  doneBtnText: '완료',
  steps: [ /* ... */ ],
}).drive();

4. 단계별 콜백

각 단계에 진입할 때마다 onHighlightStarted 콜백으로 원하는 동작(여기선 로그 기록)을 실행합니다.
단계 진입 로그:
아직 시작하지 않았습니다.
코드 보기 
driver({
  steps: [
    {
      element: '#tour4-fish',
      popover: { title: '어종 선택' },
      onHighlightStarted: (el, step) => {
        console.log('진입:', step.popover.title);
      },
    },
    // ...
  ],
}).drive();
