PhotoSwipe 핵심 기능 둘러보기

PhotoSwipe는 썸네일 그리드를 클릭하면 화면 전체를 덮는 확대 뷰어가 열리는 이미지 갤러리/라이트박스 라이브러리입니다. 터치 제스처(스와이프·핀치줌)도 기본 지원합니다.
  • PhotoSwipeLightbox(그리드의 클릭을 감지하는 역할)와 PhotoSwipe(실제 확대 뷰어 엔진)가 분리되어 있는 v5 구조
  • 각 <a>에 data-pswp-width/data-pswp-height로 원본 이미지 크기를 미리 알려줘야 레이아웃 깜빡임 없이 열림
  • 더블클릭/버튼으로 확대·축소(zoom), 화살표·스와이프로 다음/이전 이동
  • change/close 같은 이벤트로 현재 보고 있는 사진과 열림·닫힘 상태를 실시간 추적 가능
※ 아래 사진은 실제 어획 사진이 아니라, ffmpeg로 생성한 단색 배경에 어종 이름을 넣은 가상의 예시 이미지입니다. 다른 외부 API는 사용하지 않습니다.

갤러리 — 클릭해서 열어보기

아무 사진이나 클릭하면 확대 뷰어가 열립니다. 열린 상태에서 좌우 화살표로 이동, 더블클릭으로 확대, ESC나 닫기 버튼으로 닫아보세요.
코드 보기 
<div id="gallery">
  <a href="photo1-full.jpg" data-pswp-width="1200" data-pswp-height="800">
    <img src="photo1-thumb.jpg" />
  </a>
  ...
</div>

const lightbox = new PhotoSwipeLightbox({
  gallery: '#gallery',
  children: 'a',
  pswpModule: PhotoSwipe, // 전역 스크립트 태그로 불러온 경우 클래스를 직접 전달
});
lightbox.init();

이벤트로 상태 추적 + 프로그램 제어

위 갤러리를 열고 이동하면 아래에 현재 보고 있는 사진 번호가 실시간으로 표시됩니다. 버튼으로 특정 사진을 바로 열 수도 있습니다.

코드 보기 
lightbox.on('change', () => {
  const i = lightbox.pswp.currIndex;
  console.log(`${i + 1}번째 사진 보는 중`);
});
lightbox.on('close', () => console.log('닫힘'));

// 프로그램적으로 특정 인덱스부터 바로 열기
lightbox.loadAndOpen(3); // 0부터 시작하는 인덱스
