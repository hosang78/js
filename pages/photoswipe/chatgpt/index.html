PhotoSwipe v5 종합 기능 샘플

썸네일 갤러리, 라이트박스, 확대·축소, 스와이프, 키보드, 캡션, 커스텀 UI, 이벤트 로그, 동적 이미지 추가, 배열 데이터소스, 업로드 미리보기, 인라인 뷰어까지 한 화면에서 테스트하는 예제.

ES Module CDNResponsive GalleryCustom CaptionDynamic DataSourceProgrammatic APIInline Mode

기능 체크

  • 클릭으로 라이트박스 열기
  • 마우스 휠/핀치 확대
  • 좌우 스와이프·화살표 이동
  • ESC 닫기, 키보드 탐색
  • HTML figcaption 기반 캡션
  • 다운로드·정보 커스텀 버튼
  • 이벤트 hook 로그
  • JS 배열 데이터로 열기
  • 동적 DOM 이미지 추가
  • 로컬 업로드 미리보기

참고: 로컬 파일 업로드 이미지는 브라우저 메모리 URL을 사용하므로 새로고침하면 사라진다.

1. 기본 갤러리 + 캡션 + 썸네일

각 링크의 data-pswp-width, data-pswp-height 값으로 원본 비율을 미리 알려줘서 열릴 때 레이아웃 튐을 줄인다.

2. 프로그램 제어 / 동적 추가 / 업로드

동적 이미지 추가

JS로 새 figure를 만들고 refresh 없이 DOM 갤러리에서 바로 열 수 있다.

3. 배열 DataSource 갤러리

DOM에 썸네일이 없어도 JS 배열만으로 PhotoSwipe를 열 수 있다. 검색 결과, API 응답, DB 조회 결과를 갤러리로 띄울 때 유용하다.

4. 인라인 PhotoSwipe 뷰어

PhotoSwipe는 보통 전체화면 dialog처럼 쓰지만, 특정 컨테이너 안에 붙인 인라인 뷰어 형태도 구성할 수 있다.
