Hotkeys.js 핵심 기능 둘러보기

Hotkeys.js는 의존성 없이 동작하는 아주 가벼운 키보드 단축키 라이브러리입니다. hotkeys('ctrl+s', callback)처럼 한 줄로 단축키를 등록하고, 입력창 안에서는 기본적으로 단축키를 무시하는 등 실전에서 바로 쓸 수 있는 배려가 들어있습니다.
  • 브라우저 기본 동작을 막는 기본 단축키 등록
  • setScope로 화면별로 같은 키를 다르게 동작시키는 스코프 관리
  • 화살표 키 등 여러 단축키 동시 등록 + 눌린 키 실시간 표시
  • 입력창에서는 기본적으로 무시되는 동작과 filter로 하는 예외 허용
※ 아래 데이터·화면은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 단축키 등록

이 섹션에 포커스가 있는 상태(아무 곳이나 클릭)에서 Ctrl+S를 누르면 저장, Ctrl+Z를 누르면 되돌리기가 실행됩니다. 브라우저의 기본 저장 대화상자가 뜨지 않도록 event.preventDefault()로 막았습니다.
Ctrl+S 또는 Ctrl+Z를 눌러보세요.
코드 보기 
hotkeys('ctrl+s', (event) => {
  event.preventDefault(); // 브라우저의 "페이지 저장" 동작을 막는다
  stat.textContent = 'Ctrl+S: 위판 데이터를 저장했습니다.';
});
hotkeys('ctrl+z', (event) => {
  event.preventDefault();
  stat.textContent = 'Ctrl+Z: 마지막 작업을 되돌렸습니다.';
});

2. 스코프(scope)로 화면별 단축키 분리

"목록 화면"과 "상세 화면" 버튼으로 지금 어느 화면에 있는지 바꿔보세요. 같은 Delete 키인데도 hotkeys.setScope()로 지정한 현재 스코프에 따라 서로 다른 동작이 실행됩니다.
현재 화면: 목록 화면 — 여기서 Delete를 누르면 "목록에서 항목 삭제"가 실행됩니다.
코드 보기 
hotkeys('delete', 'list', (event) => {
  event.preventDefault();
  stat.innerHTML = '목록 화면: 선택한 위판장 항목을 삭제했습니다.';
});
hotkeys('delete', 'detail', (event) => {
  event.preventDefault();
  stat.innerHTML = '상세 화면: 상세 메모를 삭제했습니다.';
});

// 기본 활성 스코프는 'list'가 아니라 'all'이므로 시작 화면에 맞춰 직접 지정해야 한다.
hotkeys.setScope('list');

document.getElementById('s2-scope-list').addEventListener('click', () => hotkeys.setScope('list'));
document.getElementById('s2-scope-detail').addEventListener('click', () => hotkeys.setScope('detail'));

3. 여러 단축키 동시 등록 + 눌린 키 실시간 표시

방향키로 카드를 움직여보세요. 콤마로 구분해서 'up,down,left,right' 하나의 등록으로 네 방향을 모두 처리합니다. 지금 눌려있는 키 조합은 hotkeys.getPressedKeyString()로 실시간 표시됩니다.
위판장
눌린 키: 없음
코드 보기 
hotkeys('up,down,left,right', (event, handler) => {
  event.preventDefault();
  move(handler.key); // handler.key: 'up' | 'down' | 'left' | 'right'
});

document.addEventListener('keydown', () => {
  stat.textContent = '눌린 키: ' + hotkeys.getPressedKeyString().join(' + ');
});

4. 입력창 안에서는 기본적으로 무시 + filter로 예외 허용

Hotkeys.js는 INPUT/SELECT/TEXTAREA 안에서는 단축키가 기본적으로 동작하지 않습니다. 아래 첫 번째 입력창에 포커스하고 Ctrl+S를 눌러도 아무 일도 없지만, hotkeys.filter를 재정의해서 두 번째 입력창만 예외로 허용했습니다.
아직 저장한 적이 없습니다.
코드 보기 
hotkeys.filter = (event) => {
  const target = event.target;
  if (target.id === 's4-allowed') return true; // 이 입력창은 예외로 허용
  const tagName = target.tagName;
  return !(target.isContentEditable || tagName === 'INPUT' || tagName === 'SELECT' || tagName === 'TEXTAREA');
};

hotkeys('ctrl+s', (event) => {
  event.preventDefault();
  stat.textContent = 'Ctrl+S: 저장되었습니다.';
});
