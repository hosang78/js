RevoGrid 핵심 기능 둘러보기

RevoGrid는 표준 웹 컴포넌트(<revo-grid>)로 만든 가상 스크롤 데이터 그리드입니다. React/Vue/Angular 없이도 커스텀 엘리먼트 하나만 페이지에 넣고 .columns·.source 속성만 채워주면 바로 동작합니다.
  • 열 헤더를 클릭해 오름차순/내림차순으로 바꾸는 정렬
  • 더블클릭으로 바로 고치는 인라인 셀 편집
  • 마우스로 드래그해 여러 칸을 선택하는 스프레드시트형 범위 선택
  • grouping 속성으로 켜는 행 그룹핑(접기/펼치기)
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. RevoGrid(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 정렬

열 헤더를 클릭하면 정렬 화살표가 나타나고, 화면에 보이는 행 순서가 바로 바뀝니다.
코드 보기 
const grid = document.getElementById('grid1');
grid.columns = [
  { prop: 'market', name: '위판장', sortable: true },
  { prop: 'species', name: '어종', sortable: true },
  { prop: 'qty', name: '수량', sortable: true },
  { prop: 'price', name: '단가', sortable: true },
];
grid.source = records;   // [{ market, species, qty, price }, ...]

2. 인라인 셀 편집

어종·수량 칸을 더블클릭하면 바로 수정할 수 있습니다(위판장 열은 readonly로 잠가뒀습니다). 수정하면 afteredit 이벤트가 발생합니다.
칸을 더블클릭해서 값을 바꿔보세요.
코드 보기 
grid.columns = [
  { prop: 'market', name: '위판장', readonly: true },
  { prop: 'species', name: '어종' },
  { prop: 'qty', name: '수량' },
];
grid.addEventListener('afteredit', (e) => {
  console.log(e.detail.prop, '→', e.detail.val);
});

3. 범위 선택

range: true 하나만 켜면, 엑셀처럼 마우스 드래그로 여러 칸을 한 번에 선택할 수 있습니다.
코드 보기 
grid.range = true;   // 드래그로 셀 범위 선택 활성화

4. 행 그룹핑

위판장별로 묶었습니다. 그룹 줄의 화살표를 클릭하면 접고 펼 수 있습니다.
코드 보기 
grid.grouping = { props: ['market'] };   // market 값 기준으로 행을 그룹핑
