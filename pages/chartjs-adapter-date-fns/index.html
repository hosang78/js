chartjs-adapter-date-fns 핵심 기능 둘러보기

chartjs-adapter-date-fns는 Chart.js가 날짜/시간 축(type: 'time')을 그릴 수 있게 해주는 어댑터입니다. 어댑터 혼자서는 아무것도 그리지 못하고, 내부적으로 date-fns의 날짜 계산 함수를 이용해 "이 구간엔 눈금을 며칠 단위로 찍을지", "툴팁엔 날짜를 어떤 형식으로 보여줄지"를 Chart.js에게 알려주는 역할을 합니다.
  • 데이터 포인트의 x값으로 Date 객체나 날짜 문자열을 그대로 사용 가능
  • 확대/축소 범위에 맞춰 일/주/월/년 눈금 단위를 자동으로 선택
  • time.unit, time.displayFormats로 눈금·툴팁 날짜 포맷을 직접 지정 가능
  • type: 'time'(실제 시간 간격 비례) vs type: 'timeseries'(데이터 간격을 균등 분포)의 두 가지 시간축 모드
※ 아래 위판 실적 수치는 학습용으로 만든 가상의 샘플 데이터이며, 실제 수협중앙회의 통계가 아닙니다. 이 어댑터는 Chart.js(CDN) 없이는 동작하지 않아 Chart.js를 함께 불러왔습니다. 날짜 계산에 쓰는 date-fns는 어댑터의 번들 파일(.bundle.min.js) 안에 이미 포함되어 있어 별도 CDN으로 추가할 필요가 없습니다.

1. 기본 시간축

x값에 실제 Date 객체를 넣으면, type: 'time' 축이 날짜 간격에 맞춰 자동으로 눈금을 찍어줍니다.
코드 보기 
new Chart(ctx, {
  type: 'line',
  data: {
    datasets: [{
      label: '일별 위판 실적',
      data: [
        { x: new Date('2026-06-22'), y: 210 },
        { x: new Date('2026-06-23'), y: 240 },
        // ...
      ],
    }],
  },
  options: {
    scales: {
      x: { type: 'time', time: { unit: 'day' } }, // 어댑터가 없으면 'time' 타입은 에러가 남
    },
  },
});

2. 시간 단위 · 포맷 커스터마이징

같은 4개월치 데이터를 두고, 눈금 단위(day/week/month)를 바꿔봅니다. 툴팁 날짜 형식도 time.tooltipFormat으로 "2026년 7월 3일"처럼 지정했습니다.
눈금 단위:
코드 보기 
scales: {
  x: {
    type: 'time',
    time: {
      unit: 'week',                          // 'day' | 'week' | 'month' 등
      tooltipFormat: 'yyyy년 M월 d일',        // 툴팁에 보이는 날짜 형식
      displayFormats: { week: 'M/d', month: 'yyyy.MM' }, // 눈금 라벨 형식
    },
  },
},

3. time vs timeseries — 빈 구간 처리 차이

위판장은 주말에 쉬어서 데이터에 이틀짜리 공백이 반복됩니다. time 모드는 실제 날짜 간격 그대로 점을 배치해 주말 구간이 넓게 벌어지고, timeseries 모드는 실제 날짜 간격을 무시하고 점을 균등하게 배치해 주말 공백이 눈에 띄지 않습니다.
코드 보기 
// 데이터에 6/27~6/28(토·일)이 없어도 그대로 넣는다
const gappyData = [
  { x: new Date('2026-06-25'), y: 250 },
  { x: new Date('2026-06-26'), y: 300 },
  { x: new Date('2026-06-29'), y: 230 }, // 6/27, 6/28 없이 바로 월요일로 점프
  { x: new Date('2026-06-30'), y: 245 },
];

new Chart(ctx, {
  type: 'line',
  data: { datasets: [{ data: gappyData }] },
  options: {
    scales: { x: { type: 'timeseries' } }, // 'time' 대신 'timeseries'로 바꾸면 간격이 균등해짐
  },
});

4. min / max로 특정 구간만 표시

전체 4개월 데이터 중, scales.x.min/max로 최근 7일 구간만 잘라서 보여줄 수 있습니다.
코드 보기 
chart.options.scales.x.min = '2026-07-06';
chart.options.scales.x.max = '2026-07-12';
chart.update(); // 데이터는 그대로 두고 표시 범위만 좁힘
