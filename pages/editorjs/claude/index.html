Editor.js 핵심 기능 둘러보기

Editor.js는 글을 하나의 큰 HTML 덩어리가 아니라, 제목·문단·목록·인용 같은 블록 단위로 쌓아서 만드는 방식의 리치 텍스트 에디터입니다.
  • 블록마다 + 버튼으로 원하는 타입(제목/목록/인용 등)을 골라 추가
  • save()를 호출하면 HTML이 아니라 { blocks: [...] } 형태의 구조화된 JSON을 반환
  • 저장해둔 JSON을 render()에 그대로 넣으면 동일한 블록 구성으로 복원
  • readOnly.toggle()로 편집 가능 여부를 즉시 전환
※ Editor.js 코어(@editorjs/editorjs)는 문단(Paragraph) 블록만 내장하고 있어, 제목·목록·인용 블록을 쓰려면 @editorjs/header, @editorjs/list, @editorjs/quote 같은 별도 플러그인 패키지를 함께 불러와야 합니다. 실제로 이 셋을 빼고 테스트했더니 해당 블록 타입이 그냥 동작하지 않는 것을 확인했습니다. 이 페이지의 위판 공지 내용은 모두 가상의 예시이며 실제 수협중앙회의 공지·자료가 아닙니다.

1. 블록 스타일 에디터

아래 에디터 빈 줄에서 + 버튼(또는 Tab)을 눌러 제목·목록·인용 블록을 자유롭게 추가해보세요.
코드 보기 
const editor = new EditorJS({
  holder: 'editor1',
  tools: {
    header: Header,
    list: { class: EditorjsList, inlineToolbar: true },
    quote: Quote,
  },
  data: {
    blocks: [
      { type: 'header', data: { text: '위판 공지(가상)', level: 2 } },
      { type: 'paragraph', data: { text: '오늘 위판 일정을 안내합니다.' } },
    ],
  },
});

2. save() — 구조화된 JSON으로 출력

위 에디터의 현재 내용을 save()로 읽어옵니다. HTML 문자열이 아니라 블록 타입별 데이터가 담긴 JSON 배열이 나오는 것을 확인하세요.
아직 저장 안 함
코드 보기 
const data = await editor.save();
console.log(data);
// { time, blocks: [ { type: 'header', data: {...} }, { type: 'list', data: {...} }, ... ], version }

3. render() — 저장된 JSON 다시 불러오기

위에서 저장한 JSON을 새로운 에디터 인스턴스에 render()로 그대로 넣어 복원합니다. 먼저 2번에서 저장을 한 번 해주세요.
코드 보기 
const editor2 = new EditorJS({ holder: 'editor3', tools: { header: Header, list: EditorjsList, quote: Quote } });
await editor2.isReady;
await editor2.render(savedData); // save()로 받은 JSON을 그대로 전달

4. 읽기 전용 모드 토글

readOnly.toggle()로 1번 에디터의 편집 가능 여부를 즉시 전환합니다. 공지가 확정된 뒤 잠그는 용도 등에 씁니다.
현재: 편집 가능
코드 보기 
await editor.readOnly.toggle(true);   // 잠금
await editor.readOnly.toggle(false);  // 잠금 해제
editor.readOnly.isEnabled;            // 현재 상태
