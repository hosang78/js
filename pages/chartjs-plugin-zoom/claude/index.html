chartjs-plugin-zoom 핵심 기능 둘러보기

chartjs-plugin-zoom은 Chart.js 차트를 마우스 휠·드래그· (모바일에서는) 핀치 제스처로 확대·축소·이동할 수 있게 해주는 공식 플러그인입니다. 데이터 포인트가 많아 한 화면에 다 보기 어려운 시계열 차트에 특히 유용합니다.
  • zoom.wheel.enabled로 마우스 휠 줌, pan.enabled로 드래그 이동
  • zoom.drag.enabled로 사각형을 드래그해서 그 구간만 확대
  • limits로 줌/팬이 가능한 범위(min/max)와 최소 확대 폭(minRange)을 제한
  • chart.zoom(), chart.resetZoom(), chart.getZoomLevel() 등 코드로도 직접 제어 가능
※ 이 페이지의 위판량 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. Chart.js와, 핀치 제스처 인식을 위한 Hammer.js를 함께 사용했습니다 (모두 CDN). 검증 중 실제로 확인한 점: limits.minRange를 설정하지 않고 마우스 휠로 계속 확대하면 카테고리 축 범위가 폭 0으로 찌그러지는 현상을 재현했습니다 — 그래서 이 페이지의 모든 차트에 minRange를 기본으로 넣어두었습니다.

1. 마우스 휠 줌 + 드래그 팬

차트 위에서 마우스 휠을 굴려 확대/축소하고, 확대된 상태에서 드래그하면 좌우로 이동합니다.
코드 보기 
plugins: {
  zoom: {
    zoom: { wheel: { enabled: true }, pinch: { enabled: true }, mode: 'x' },
    pan: { enabled: true, mode: 'x' },
    limits: { x: { min: 0, max: 29, minRange: 5 } },
  },
}

2. 드래그로 영역 확대 (drag-to-zoom)

차트 위에서 마우스로 사각형을 드래그하면 그 구간만 확대됩니다. 더블클릭하면 원래대로 돌아갑니다.
코드 보기 
plugins: {
  zoom: {
    zoom: { drag: { enabled: true, backgroundColor: 'rgba(79,125,255,0.2)' }, mode: 'x' },
  },
}
// 더블클릭 시 리셋
canvas.ondblclick = () => chart.resetZoom();

3. 줌/팬 범위 제한 (limits)

아무리 휠을 굴려도 원본 데이터 범위(0~29일) 밖으로는 나갈 수 없고, minRange: 5라 5일 구간보다 더 좁게는 확대되지 않습니다. (검증 중 실제로 확인: minRange가 없으면 계속 확대할 때 축 범위가 폭 0으로 찌그러지는 문제가 있었습니다 — 이 섹션이 바로 그 방지책입니다.)
아직 확대 안 함
코드 보기 
limits: {
  x: { min: 0, max: 29, minRange: 5 }, // 5일 미만으로는 확대 불가, 범위 밖 이동 불가
}

4. 프로그래매틱 API 제어

버튼으로 chart.zoom() / chart.pan() / chart.resetZoom()을 직접 호출합니다.
확대 레벨(getZoomLevel): 1.00
코드 보기 
chart.zoom(1.4);       // 확대
chart.zoom(0.7);       // 축소
chart.pan({ x: -40 }); // 왼쪽으로 이동 (픽셀 단위)
chart.resetZoom();     // 원래대로
chart.getZoomLevel();  // 현재 확대 배율
