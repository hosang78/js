사용 시 주의

        

          팬·핀치 제스처에는 Hammer.js가 필요하다. 스크롤 페이지에서 휠 줌을 항상 활성화하면 페이지 스크롤과 충돌할 수 있으므로 실제 서비스에서는
          Ctrl 같은 modifierKey를 지정하는 편이 안전하다. 이 파일은 CDN을 사용하므로 최초 실행 시 인터넷 연결이 필요하다.
