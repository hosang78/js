vConsole 종합 기능 샘플

오른쪽 아래 vConsole 버튼을 열고 아래 기능 버튼을 눌러 보세요. Log / System / Network / Element / Storage / 커스텀 패널 동작을 한 페이지에서 확인합니다.

실행 팁: 모바일 브라우저에서 더 유용합니다. PC에서도 열리지만 vConsole은 원래 모바일 웹 디버깅용입니다. 외부 API 호출은 네트워크 환경이나 CORS 정책에 따라 실패할 수 있으며, 실패도 Network 패널에서 확인할 수 있습니다.

1. vConsole 초기화 / 제거 / 재생성

인스턴스 생성, 버전 확인, destroy, 라이트/다크 테마 재초기화를 확인합니다.

초기화 대기...

2. 콘솔 로그 타입

log/info/debug/warn/error/table/assert/count/time/group/trace/styled log를 출력합니다.

버튼을 누르면 vConsole Log 패널에 출력됩니다.

3. Network: Fetch / XHR / 실패 요청

성공 GET, POST, XHR, 의도적 실패 요청을 만들어 Network 패널 상세를 확인합니다.

Network 패널을 열고 요청 목록을 확인하세요.

4. Storage: local/session/cookie

LocalStorage, SessionStorage, Cookie 값을 생성·수정·삭제하고 Storage 패널에서 확인합니다.

Storage 패널에서 값 변화를 확인하세요.

5. Element: DOM 동적 변경

DOM 추가, 속성 변경, 스타일 변경을 수행합니다. Element 패널에서 구조가 바뀌는지 확인합니다.

Element 패널에서 이 박스를 검사하세요.

6. 성능 / 타이머 / 메모리 힌트

performance.now, console.time/timeEnd, 반복 작업, 리소스 목록 일부를 출력합니다.

System 패널과 Log 패널을 함께 확인하세요.

7. 에러 캡처 / Promise rejection

try/catch 에러, 전역 error, unhandledrejection을 발생시켜 에러 추적을 확인합니다.

Error 로그와 stack trace를 확인하세요.

8. 커맨드라인 테스트용 상태

vConsole 명령창에서 demoState, document.body.dataset 등을 직접 조회해보세요.

window.demoState를 확인하세요.

9. 커스텀 플러그인 패널

vConsolePlugin API가 사용 가능한 경우 샘플 패널을 추가합니다. 이벤트/버튼/로그를 패널에 표시합니다.

Custom 패널 지원 여부를 확인합니다.

10. 기기 / 브라우저 정보

UserAgent, 화면 크기, 네트워크 타입, 언어, 터치 지원 여부를 로그로 출력합니다.

디버깅 시 복사할 진단 정보를 생성합니다.

11. 이미지 / 리소스 로딩 확인

이미지 로딩 성공과 실패를 발생시켜 Network와 Console에서 확인합니다.

이미지 요청 로그가 출력됩니다.

12. 실전 시나리오: 폼 검증

입력값 검증, 경고 로그, 실패 원인 객체 출력, 성공 이벤트 추적을 확인합니다.

빈 값으로 검증하면 warn/error가 출력됩니다.
개발 완료 후 운영 배포본에서는 vConsole을 반드시 제거하거나 개발 환경에서만 조건부 로드하세요.
