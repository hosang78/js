vConsole 핵심 기능 둘러보기

vConsole는 Tencent가 만든 모바일 브라우저용 경량 개발자도구로, 위챗 미니프로그램의 공식 디버깅 도구이기도 합니다. 페이지에 삽입하면 화면 한쪽에 진입 버튼이 뜨고, 누르면 Log/System/Network/Element/Storage 탭으로 구성된 패널이 열립니다.
  • new VConsole()으로 초기화하면 전역 console 호출을 자동으로 가로챔
  • console.log('[system]', ...)처럼 첫 인자에 [system] 태그를 붙이면 System 탭으로 따로 라우팅됨
  • Network 탭은 fetch/XMLHttpRequest 요청을 별도 설정 없이 자동 캡처
  • Element 탭은 실제 DOM 트리를 보여주며, 노드를 펼쳐두면 이후 변경사항이 실시간으로 반영됨
  • vConsole.addPlugin()으로 커스텀 탭을 직접 추가 가능
※ 이 페이지의 위판장·조합원 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다. 화면 우측 하단의 "vConsole" 버튼이 진입 버튼입니다. (검증 중 발견: vConsole.showPlugin(이름)은 패널이 이미 열려있을 때만 탭을 전환하고, 패널이 닫혀있으면 그 자체로는 열지 않습니다 — 아래 데모는 이를 감안해 항상 인자 없는 show()를 먼저 호출합니다. 또한 패널이 화면 하단 대부분을 덮기 때문에, 다른 섹션 버튼을 가리지 않도록 약 2.5초 뒤 자동으로 닫힙니다.)

1. 콘솔 로그 캡처 & System 탭 라우팅

일반 console.log/warn/error는 Log 탭에 쌓입니다. 첫 인자를 '[system]'로 시작하면 같은 console.log인데도 System 탭으로 따로 분류됩니다.
아직 실행 안 함
코드 보기 
console.log('위판 접수 완료');
console.warn('재고 부족 경고');
console.error('가상 위판 서버 응답 지연');
// 아래는 System 탭으로 라우팅됨
console.log('[system]', '가상 위판장 서버 상태 점검');

2. Network 자동 캡처

버튼을 누르면 가상 위판 데이터 파일(auction-data.json)을 실제로 fetch합니다. vConsole은 별도 설정 없이 이 요청을 자동으로 가로채 Network 탭에 기록합니다.
아직 요청 안 함
코드 보기 
const res = await fetch('./auction-data.json');
const data = await res.json();
// 별도 후킹 코드 없이 Network 탭에 method/status/응답이 자동으로 기록됨

3. Element 탭 — 실시간 DOM 트리

버튼을 누르면 아래 조합원 카드 영역에 새 카드가 실제로 추가됩니다. Element 탭은 트리가 기본적으로 접혀있고 노드를 펼쳐야 그 아래 내용이 보이는데(데모 편의상 자동으로 펼쳐줍니다), 일단 펼쳐진 노드는 이후 추가되는 자식 노드를 클릭 없이도 실시간으로 반영합니다.
가상 조합원 번호
MEM-2026-0101
아직 추가 안 함
코드 보기 
memberArea.appendChild(newCardEl);
// Element 탭에서 해당 노드가 펼쳐진 상태라면 MutationObserver 기반으로
// 별도 새로고침 없이 새 노드가 즉시 트리에 나타남
// (기본은 접힌 트리라서 처음엔 노드를 눌러 펼쳐야 자식이 보임)

4. Storage 탭

버튼을 누르면 가상 위판장 설정값을 localStorage에 저장합니다. Storage 탭 → LocalStorage 서브탭에서 실제로 저장된 값을 확인할 수 있습니다.
아직 저장 안 함
코드 보기 
localStorage.setItem('suhyup_demo_port', 'PORT-B-2026');
// Storage 탭 → LocalStorage 서브탭에서 key/value가 실제로 표시됨

5. 커스텀 플러그인(탭) 추가

VConsole.VConsolePlugin으로 나만의 탭을 만들어 패널에 추가할 수 있습니다. 버튼을 누르면 "위판 요약" 탭이 새로 생기고 그 안에 커스텀 내용이 렌더링됩니다.
아직 추가 안 함
코드 보기 
const plugin = new VConsole.VConsolePlugin('auction_summary', '위판 요약');
plugin.on('renderTab', (callback) => {
  callback('<div>오늘 가상 위판 총액: 1,234,000원</div>');
});
vConsole.addPlugin(plugin);
vConsole.showPlugin('auction_summary');
