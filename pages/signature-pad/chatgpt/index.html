1. 펜 및 캔버스 옵션

빠른 색상

배경색은 초기화·다시 그리기 시 반영됩니다. JPEG는 투명 배경을 지원하지 않으므로 흰색 등 불투명 배경을 권장합니다.

2. 결과 파일 내보내기

PNG · JPEG · SVG 저장 시
이 영역에 출력 미리보기가 나타납니다.
아직 내보낸 결과가 없습니다.

3. 점 데이터(JSON) · 저장 · 복원

점 데이터는 JSON으로 저장하면 이미지보다 편집·재렌더링에 유리합니다.

4. 파일 불러오기 · 이미지 위 필기

이미지를 fromDataURL()로 불러온 경우에는 그 이미지가 점 데이터에 포함되지 않습니다. 따라서 이 페이지는 이미지 URL과 점 데이터를 별도로 관리합니다.

이미지를 불러오면 기존 서명 위에 배경으로 표시한 뒤 추가 필기가 가능합니다.

5. 이벤트 · 입력 제어 · 간단한 제출 시연

단축키 Ctrl + Z 실행취소 · Ctrl + Y 또는 Ctrl + Shift + Z 다시 실행.
본 샘플은 클라이언트에서만 동작합니다. 실제 전자서명 업무에는 본인확인, 서명 시각, 원문 해시, 감사로그, 접근통제, 장기보관 등 별도 보안·법무 요건 검토가 필요합니다.
