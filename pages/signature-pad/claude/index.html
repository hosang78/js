Signature Pad 핵심 기능 둘러보기

Signature Pad는 캔버스 위에 마우스나 손가락(터치)으로 부드러운 손글씨 서명을 그릴 수 있게 해주는 라이브러리입니다. 전자 계약서, 인수확인서, 동의서 같은 화면에서 서명란을 만들 때 씁니다.
  • 베지어 곡선 보간으로 실제 펜처럼 부드러운 선이 그려짐 (마우스/터치/펜 모두 지원)
  • 서명 결과를 PNG/JPEG/SVG 이미지로 바로 추출 가능(toDataURL)
  • 펜 색상·굵기 등을 옵션으로 조절 가능
  • 획 단위 데이터(toData)를 이용해 한 획 되돌리기(undo), 빈 서명 검증(isEmpty) 가능
※ 아래 "위판물 인수확인 서명"은 Signature Pad 학습용으로 만든 가상의 샘플 화면이며, 실제 수협중앙회의 서식/절차가 아닙니다. 이 페이지는 Signature Pad(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 서명 · 지우기 · PNG 저장

아래 서명란에 마우스(또는 손가락)로 서명해보세요. "이미지로 변환"을 누르면 서명이 PNG 이미지로 추출됩니다.
변환된 서명 이미지가 여기 표시됩니다
코드 보기 
const canvas = document.getElementById('pad1');
const pad = new SignaturePad(canvas);

pad.clear();                      // 지우기
const dataUrl = pad.toDataURL();  // PNG data URL로 추출

// 다운로드
const link = document.createElement('a');
link.download = 'signature.png';
link.href = dataUrl;
link.click();

2. 펜 색상 · 굵기 옵션

penColor, minWidth/maxWidth 옵션을 실시간으로 바꿔가며 그려보세요. 굵기는 필압(그리는 속도)에 따라 min~max 사이에서 자동으로 변합니다.
코드 보기 
const pad = new SignaturePad(canvas, {
  penColor: '#1a3fa8',
  minWidth: 0.5,
  maxWidth: 2.5,
});

// 실시간 변경도 가능
pad.penColor = '#c0392b';
pad.minWidth = 2;
pad.maxWidth = 5;

3. 한 획 되돌리기 · 빈 서명 검증

가상의 "위판물 인수확인" 제출 화면입니다. toData()로 획 배열을 얻어 마지막 획만 지우는 되돌리기를 구현하고, 제출 시 isEmpty()로 서명 없이 제출하는 걸 막습니다.
서명 후 제출을 눌러보세요. (가상 예시 — 실제로 제출되지 않습니다)
코드 보기 
// 한 획 되돌리기
const data = pad.toData();   // 획(stroke) 배열
data.pop();                  // 마지막 획 제거
pad.fromData(data);          // 다시 그리기

// 빈 서명 검증
if (pad.isEmpty()) {
  alert('서명을 해주세요.');
}
