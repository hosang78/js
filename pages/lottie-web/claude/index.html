Lottie-web 핵심 기능 둘러보기

Lottie-web은 애니메이션 제작 도구(주로 After Effects)에서 만든 애니메이션을 JSON 파일로 내보낸(Bodymovin 포맷) 뒤, 웹에서 벡터 애니메이션으로 재생해주는 라이브러리입니다. 비디오 파일 없이도 가볍고 선명한 애니메이션을 넣을 수 있습니다.
  • lottie.loadAnimation({ container, renderer, path })로 애니메이션 로드 — renderer를 'svg'/'canvas'/'html' 중 선택 가능
  • play()/pause()/setSpeed()/setDirection()로 재생을 자유롭게 제어
  • goToAndStop(frame)/playSegments()로 특정 프레임·구간만 재생
  • complete/loopComplete/enterFrame 이벤트로 재생 상태를 실시간 구독
※ 아래 애니메이션(pulse.json)은 실제 디자이너가 After Effects로 만든 것이 아니라, Lottie JSON 포맷 사양에 맞춰 직접 작성한 최소 예시(회전하며 커졌다 작아지는 원)입니다. 다른 외부 API는 사용하지 않습니다.

1. 같은 애니메이션, 두 가지 렌더러

동일한 JSON 데이터를 SVG와 Canvas, 서로 다른 렌더러로 각각 그립니다. 화면에는 똑같이 보이지만 내부적으로 SVG는 <svg> 엘리먼트를, Canvas는 <canvas>를 사용합니다.

renderer: 'svg'

renderer: 'canvas'

코드 보기 
lottie.loadAnimation({
  container: document.getElementById('svgContainer'),
  renderer: 'svg',
  loop: true,
  autoplay: true,
  path: 'pulse.json',
});

2. 재생 제어

버튼으로 재생/일시정지하고 배속·역재생을 조절해보세요.
코드 보기 
anim.play();
anim.pause();
anim.setSpeed(2);       // 배속
anim.setDirection(-1);  // 역재생

3. 특정 프레임으로 이동

슬라이더로 애니메이션의 특정 프레임(0~89)을 바로 보여줍니다.
프레임: 0
코드 보기 
anim.goToAndStop(45, true); // true = 프레임 번호 기준 (false면 시간(ms) 기준)

4. 이벤트로 재생 상태 추적

한 번 재생이 끝날 때마다(loopComplete) 횟수가 올라갑니다.
재생 대기 중...
코드 보기 
let loopCount = 0;
anim.addEventListener('loopComplete', () => {
  loopCount++;
  console.log(`${loopCount}번째 반복 완료`);
});
