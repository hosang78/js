interact.js 핵심 기능 둘러보기

interact.js는 드래그·리사이즈·드롭·멀티터치 제스처를 다루는 인터랙션 라이브러리입니다. jQuery UI의 draggable/resizable/droppable과 비슷한 역할을 하지만, 특정 프레임워크에 의존하지 않고 순수 DOM 이벤트로 동작합니다.
  • .draggable() + restrictRect로 하는 영역 제한 드래그
  • .resizable() + restrictSize로 하는 최소 크기가 있는 리사이즈
  • .dropzone()으로 만드는 드래그 앤 드롭
  • modifiers.snap()으로 하는 격자 스냅 이동
※ 아래 카드·구역 이름은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시설·절차와 무관합니다. interact.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 영역 제한 드래그

카드를 자유롭게 드래그할 수 있지만, restrictRect 제약 때문에 점선 영역 밖으로는 나갈 수 없습니다.
A위판장
코드 보기 
interact('#drag1').draggable({
  listeners: {
    move(event) {
      const t = event.target;
      const x = (parseFloat(t.getAttribute('data-x')) || 0) + event.dx;
      const y = (parseFloat(t.getAttribute('data-y')) || 0) + event.dy;
      t.style.transform = `translate(${x}px, ${y}px)`;
      t.setAttribute('data-x', x);
      t.setAttribute('data-y', y);
    },
  },
  modifiers: [
    interact.modifiers.restrictRect({ restriction: 'parent', endOnly: true }),
  ],
});

2. 최소 크기가 있는 리사이즈

상자의 모서리나 변을 드래그하면 크기가 바뀝니다. restrictSize로 너비·높이가 일정 크기 이하로 줄어들지 않게 막았습니다.
보관창고
코드 보기 
interact('#box2').resizable({
  edges: { left: true, right: true, bottom: true, top: true },
  listeners: {
    move(event) {
      const t = event.target;
      let x = (parseFloat(t.getAttribute('data-x')) || 0) + event.deltaRect.left;
      let y = (parseFloat(t.getAttribute('data-y')) || 0) + event.deltaRect.top;
      t.style.width = event.rect.width + 'px';
      t.style.height = event.rect.height + 'px';
      t.style.transform = `translate(${x}px, ${y}px)`;
      t.setAttribute('data-x', x);
      t.setAttribute('data-y', y);
    },
  },
  modifiers: [
    interact.modifiers.restrictSize({ min: { width: 80, height: 60 } }),
  ],
});

3. 드래그 앤 드롭

코드 보기 
interact('.fish-card').draggable({ listeners: { move: /* 위와 동일한 이동 로직 */ } });

interact('#dropzone3').dropzone({
  accept: '.fish-card',
  overlap: 0.5,                 // 카드가 50% 이상 겹쳐야 인식
  ondragenter(event) { event.target.classList.add('drop-active'); },
  ondragleave(event) { event.target.classList.remove('drop-active'); },
  ondrop(event) {
    event.target.classList.remove('drop-active');
    // event.relatedTarget: 놓여진 카드 엘리먼트
  },
});

4. 격자 스냅 이동

카드를 드래그하면 30px 격자 선에 자동으로 달라붙습니다. 창고 슬롯처럼 정렬이 필요한 배치에 유용합니다.
코드 보기 
interact('#drag4').draggable({
  modifiers: [
    interact.modifiers.snap({
      targets: [interact.snappers.grid({ x: 30, y: 30 })],
      range: Infinity,
      relativePoints: [{ x: 0, y: 0 }],   // 커서가 아닌 카드 좌상단 모서리를 격자에 맞춤
    }),
  ],
  listeners: { move: /* 위와 동일한 이동 로직 */ },
});
