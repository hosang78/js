이벤트 로그

dragstart, dragmove, dropactivate, dragenter, drop, gesturemove 등 주요 이벤트를 간단히 기록합니다.

touch-action:noneuser-select:nonedata-x/data-y 상태 저장modifiers 조합listeners 기반 직접 렌더링

핵심 패턴

interact.js는 요소를 자동으로 움직이지 않으므로, 이벤트에서 좌표와 스타일을 직접 갱신합니다.

interact('.draggable').draggable({
  inertia: true,
  modifiers: [interact.modifiers.restrictRect({ restriction: 'parent' })],
  listeners: {
    move (event) {
      const x = (parseFloat(event.target.dataset.x) || 0) + event.dx
      const y = (parseFloat(event.target.dataset.y) || 0) + event.dy
      event.target.style.transform = `translate(${x}px, ${y}px)`
      event.target.dataset.x = x
      event.target.dataset.y = y
    }
  }
})
