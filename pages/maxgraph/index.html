maxGraph 핵심 기능 둘러보기

maxGraph는 노드(Vertex)와 연결선(Edge)으로 이루어진 다이어그램을 브라우저에서 직접 그리고 마우스로 편집할 수 있게 해주는 라이브러리입니다. (draw.io/diagrams.net을 만든 팀 개발)
  • 노드 생성, 드래그 이동, 클릭 선택, 마우스로 새 연결선 그리기 등을 기본 제공
  • 노드/선마다 색상·모양·둥근 정도 등 스타일을 개별 지정 가능
  • 클릭/이동 등 사용자 조작에 이벤트 콜백을 연결할 수 있음
※ 원래 요청하신 mxGraph는 2020년 지원 종료(deprecated)되어, 같은 팀이 만든 후속 라이브러리인 maxGraph(@maxgraph/core)로 대신 만들었습니다. mxGraph의 API 개념을 그대로 이어받아 핵심 기능은 동일하게 파악할 수 있습니다.
※ 아래 예시들은 maxGraph 문법 학습용으로 만든 가상의 샘플 관계도이며, 수협중앙회의 실제 조직/유통 구조와는 무관합니다. 이 페이지는 maxGraph(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 그래프 · 드래그 · 선택

노드를 만들고 화살표로 연결한 기본 다이어그램입니다. 노드를 드래그하면 위치가 바뀌고, 클릭하면 선택되며, 빈 캔버스를 드래그하면 여러 개를 한번에 선택(러버밴드)할 수 있습니다. 예시: 수산물 유통 흐름
노드를 마우스로 끌어서 옮겨보세요. 화면이 좁으면 이 영역을 좌우로 스크롤할 수 있습니다.
코드 보기 
const graph = new Graph(document.getElementById('graph1'));
const parent = graph.getDefaultParent();

graph.batchUpdate(() => {
  const v1 = graph.insertVertex({ parent, value: '어선 조업', position: [20, 20], size: [100, 40],
    style: { fillColor: '#dbe8ff', strokeColor: '#4f7dff', rounded: true } });
  const v2 = graph.insertVertex({ parent, value: '위판장 입고', position: [180, 20], size: [100, 40],
    style: { fillColor: '#dbe8ff', strokeColor: '#4f7dff', rounded: true } });
  // ...
  graph.insertEdge({ parent, source: v1, target: v2 });
});

2. 커스텀 스타일 (색상 · 모양)

노드마다 style 객체로 채우기색/테두리색/글자색/모양(사각형·타원 등)을 다르게 지정할 수 있습니다. 예시: 수협중앙회-지역조합-조합원 관계도
코드 보기 
graph.insertVertex({ parent, value: '수협중앙회 (예시)', position: [180, 20], size: [140, 40],
  style: { fillColor: '#2c3e91', fontColor: '#ffffff', strokeColor: '#1c2666' } });

graph.insertVertex({ parent, value: '지역조합 A', position: [40, 140], size: [120, 40],
  style: { fillColor: '#2ecc71', fontColor: '#ffffff', strokeColor: '#1e8449', rounded: true } });

graph.insertVertex({ parent, value: '조합원', position: [40, 240], size: [120, 40],
  style: { fillColor: '#f5d76e', strokeColor: '#b8912f', shape: 'ellipse' } });

3. 클릭 이벤트 처리

노드를 클릭하면 InternalEvent.CLICK 콜백이 호출되어 상세 정보를 아래에 표시합니다. 예시: 위판장 간 연계 정보
노드를 클릭해보세요.
코드 보기 
graph.addListener(InternalEvent.CLICK, (sender, evt) => {
  const cell = evt.getProperty('cell');
  if (cell && cell.isVertex()) {
    info.textContent = '클릭한 노드: ' + cell.value;
  }
});
