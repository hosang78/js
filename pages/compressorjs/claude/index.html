Compressor.js 핵심 기능 둘러보기

Compressor.js는 브라우저 내장 canvas.toBlob()을 이용해 이미지를 서버 업로드 전에 미리 압축하는 라이브러리입니다. 손실 압축이라 결과가 브라우저마다 조금씩 다를 수 있습니다.
  • quality 옵션으로 하는 용량 압축
  • maxWidth/maxHeight로 하는 리사이즈
  • mimeType으로 하는 포맷 변환(PNG → WebP/JPEG)
  • beforeDraw 훅으로 하는 커스텀 필터
※ 준비된 사진이 없어도 확인할 수 있도록, 그라데이션·도형·텍스트로 구성된 가상의 샘플 이미지를 즉석에서 만드는 기능을 함께 제공합니다. 실제 위판 사진이 아닌 데모용 이미지입니다.
🔒 모든 처리는 브라우저 안에서만 이루어집니다. 업로드한 사진은 서버로 전송되지 않습니다.

이미지 준비

압축 효과를 제대로 보려면 용량이 어느 정도 있는 사진이 좋습니다. 준비된 사진이 없다면 아래 버튼으로 샘플 이미지를 만들어서 확인해 보세요.

1. 기본 압축 (quality)

quality 값이 낮을수록 파일 용량은 줄지만 화질 손실도 커집니다. 슬라이더를 옮기고 압축을 실행해서 크기 변화를 비교해 보세요. quality는 JPEG/WebP에만 적용되고 PNG에는 영향이 없어서, 이 데모는 결과를 항상 image/jpeg로 변환해 효과가 보이도록 했습니다.
소스 코드 보기 
new Compressor(file, {
  quality: 0.6,
  mimeType: 'image/jpeg', // quality는 JPEG/WebP에만 영향을 준다 (PNG는 무손실이라 무시됨)
  success(result) {
    console.log(file.size, '→', result.size, 'bytes');
  },
  error(err) {
    console.log(err.message);
  },
});

2. 리사이즈 (maxWidth / maxHeight)

maxWidth/maxHeight를 주면 원본 비율을 유지하면서 지정한 크기 안으로 줄여줍니다. 리사이즈만으로도 용량이 크게 줄어드는 경우가 많습니다.
소스 코드 보기 
new Compressor(file, {
  quality: 0.8,
  maxWidth: 150,
  maxHeight: 150,   // 비율은 유지한 채 이 안에 들어가도록 축소
  success(result) { /* ... */ },
});

3. 포맷 변환 (mimeType)

같은 이미지를 PNG·JPEG·WebP로 각각 변환해서 크기를 비교해 봅니다. 사진처럼 색이 복잡한 이미지는 보통 WebP/JPEG가 PNG보다 훨씬 작습니다.
포맷크기원본 대비
소스 코드 보기 
for (const mimeType of ['image/png', 'image/jpeg', 'image/webp']) {
  new Compressor(file, {
    quality: 0.8,
    mimeType,
    success(result) { console.log(mimeType, result.size); },
  });
}

4. beforeDraw 훅으로 커스텀 필터

beforeDraw(context, canvas)는 이미지를 캔버스에 그리기 직전에 호출됩니다. 이 시점에 캔버스 컨텍스트에 filter를 지정해두면 압축과 동시에 흑백 변환 같은 효과도 적용할 수 있습니다.
소스 코드 보기 
new Compressor(file, {
  quality: 0.8,
  beforeDraw(context, canvas) {
    context.filter = 'grayscale(100%)';   // 캔버스에 그려지기 전에 필터 지정
  },
  success(result) { /* 흑백으로 압축된 결과 */ },
});
