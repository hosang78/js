MapLibre GL JS 핵심 기능 둘러보기

MapLibre GL JS는 벡터 타일 기반 지도를 웹에서 부드럽게 확대/축소·회전하며 보여주는 오픈소스 지도 라이브러리입니다(Mapbox GL JS의 오픈소스 포크).
  • 지도 확대/축소/회전/기울이기를 GPU(WebGL)로 매끄럽게 렌더링
  • 지도 위에 마커(Marker)와 클릭 시 뜨는 팝업(Popup)을 쉽게 추가 가능
  • GeoJSON 데이터를 지도 레이어로 올리고, 값에 따라 크기·색을 자동으로 다르게 표현(데이터 기반 스타일링) 가능
  • flyTo로 특정 위치까지 부드럽게 카메라 이동 가능
※ 아래 위판장 위치/위판량은 MapLibre 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 통계가 아닙니다(좌표는 대략적인 지역 위치만 참고용으로 사용). 지도 배경은 API 키가 필요 없는 MapLibre 공식 데모 타일(demotiles.maplibre.org)을 사용합니다. 이 페이지는 MapLibre GL JS(CDN) 하나만 사용하고 다른 외부 라이브러리는 사용하지 않습니다.

1. 기본 지도 · 내비게이션 컨트롤

마우스 드래그로 이동, 스크롤로 확대/축소할 수 있습니다. 우측 상단 +/- 버튼과 나침반으로도 조작할 수 있습니다.
코드 보기 
const map = new maplibregl.Map({
  container: 'map1',
  style: 'https://demotiles.maplibre.org/style.json',
  center: [127.8, 36.2], // 대한민국 중심 근처
  zoom: 5.5,
});
map.addControl(new maplibregl.NavigationControl());

2. 마커 · 팝업

가상의 위판장 5곳에 마커를 표시했습니다. 마커를 클릭하면 정보 팝업이 뜹니다.
코드 보기 
new maplibregl.Marker({ color: '#4f7dff' })
  .setLngLat([129.0306, 35.0975])
  .setPopup(new maplibregl.Popup().setHTML('<b>부산공동어시장</b>(가상 예시)'))
  .addTo(map);

3. 데이터 기반 원형 레이어 스타일링

GeoJSON으로 위판장 5곳의 위판량(가상 수치)을 지도에 올리고, 값이 클수록 원이 더 크고 진하게 보이도록 자동 매핑했습니다.
위판량 적음 → 많음
코드 보기 
map.addSource('markets', { type: 'geojson', data: geojson });
map.addLayer({
  id: 'market-circles',
  type: 'circle',
  source: 'markets',
  paint: {
    'circle-radius': ['interpolate', ['linear'], ['get', 'volume'], 0, 6, 500, 24],
    'circle-color': ['interpolate', ['linear'], ['get', 'volume'], 0, '#a8c4ff', 500, '#1c2a5e'],
    'circle-stroke-width': 1,
    'circle-stroke-color': '#fff',
  },
});

4. flyTo로 카메라 이동

위판장을 고르면 그 위치로 지도가 부드럽게 날아가듯 이동하고 팝업이 열립니다.
위판장을 고르고 "이동" 버튼을 눌러보세요.
코드 보기 
map.flyTo({
  center: [129.0306, 35.0975],
  zoom: 10,
  essential: true, // 접근성: 모션 최소화 설정이어도 이동은 보장
});
