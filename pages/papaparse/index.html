Papa Parse 핵심 기능 둘러보기

Papa Parse는 CSV 텍스트/파일을 빠르고 안정적으로 파싱해서 JS 배열로 바꿔주는 라이브러리입니다. 따옴표로 감싼 값, 다양한 구분자, 큰 파일 스트리밍까지 다룰 수 있습니다.
  • CSV 문자열이나 File 객체를 그대로 넣으면 파싱해줌
  • header: true로 첫 줄을 컬럼명으로, dynamicTyping: true로 숫자를 문자열이 아닌 숫자 타입으로 변환
  • 구분자(,/;/tab 등)를 자동으로 감지
  • 행마다 필드 개수가 안 맞는 등 문제가 있으면 errors 배열로 알려줌
  • Papa.unparse()로 JS 배열을 다시 CSV 문자열로 변환 가능
※ 아래 위판 실적 데이터는 Papa Parse 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 통계가 아닙니다. 이 페이지는 Papa Parse(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 파싱 옵션

옵션을 켜고 끄면서 결과가 어떻게 달라지는지 비교해보세요.
코드 보기 
Papa.parse(csvText, {
  header: true,
  dynamicTyping: true,
  skipEmptyLines: true,
  complete: (results) => {
    console.log(results.data);  // [{날짜:'2026-07-02', 수량:320, ...}, ...]
    console.log(results.meta);  // { fields, delimiter, ... }
  },
});

2. 파일 업로드 파싱

.csv 파일을 선택하면 바로 파싱해서 표로 보여주고, 감지된 구분자/컬럼도 함께 표시합니다.
파일을 선택해보세요.
코드 보기 
Papa.parse(file, { // File 객체를 바로 넣을 수 있음
  header: true,
  dynamicTyping: true,
  skipEmptyLines: true,
  complete: (results) => { /* results.data, results.meta.delimiter */ },
});

3. 오류 감지

일부러 행마다 필드 개수가 안 맞는 CSV를 파싱합니다. 파싱은 계속 진행되면서 문제가 있는 행을 errors 배열로 알려줍니다.
코드 보기 
const { data, errors } = Papa.parse(csvText, { header: true, dynamicTyping: true, skipEmptyLines: true });
errors.forEach((e) => console.log(e.row, e.type, e.message));
// 예: 2행 "TooManyFields", 3행 "TooFewFields"

4. JSON → CSV 변환 (unparse)

JS 배열 데이터를 CSV 텍스트로 만들고, 파일로 다운로드합니다.

    

      코드 보기
      
const csv = Papa.unparse(rows); // [{...}, {...}] -> "a,b\n1,2\n..."
const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
const link = document.createElement('a');
link.href = URL.createObjectURL(blob);
link.download = 'wipan-report.csv';
link.click();
