chartjs-plugin-datalabels 핵심 기능 둘러보기

chartjs-plugin-datalabels는 Chart.js 위에 얹어 쓰는 공식 플러그인으로, 차트의 막대·조각·점마다 값을 텍스트 라벨로 자동으로 그려줍니다. 직접 캔버스에 텍스트를 그리는 코드를 작성할 필요가 없습니다.
  • Chart.register(ChartDataLabels)로 전역 등록하면 모든 차트에 적용됨
  • formatter(value, context)로 라벨 텍스트를 원하는 형식으로 가공 가능
  • display: 'auto'로 설정하면 라벨끼리 겹칠 때 우선순위 낮은 라벨을 자동으로 숨김
  • listeners.click/enter/leave로 라벨 자체에 마우스 상호작용 추가 가능
※ 이 페이지의 위판·조합 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 차트 렌더링을 위해 Chart.js를 함께 사용했습니다 (CDN).

1. 막대 차트 + 커스텀 포맷 라벨

formatter로 값에 단위(kg)를 붙이고, anchor: 'end' + align: 'top'로 막대 위쪽에 라벨을 배치합니다.
코드 보기 
new Chart(ctx, {
  type: 'bar',
  data: { labels: ['고등어','갈치','오징어'], datasets: [{ data: [1280, 640, 910] }] },
  options: {
    plugins: {
      datalabels: {
        anchor: 'end',
        align: 'top',
        formatter: (value) => value.toLocaleString('ko-KR') + 'kg',
      },
    },
  },
});

2. 도넛 차트 + 퍼센티지 계산 & 스타일 박스

formatter 안에서 전체 합계 대비 비율을 직접 계산하고, backgroundColor/borderRadius로 라벨에 배경 박스를 입힙니다.
코드 보기 
datalabels: {
  formatter: (value, ctx) => {
    const total = ctx.chart.data.datasets[0].data.reduce((a, b) => a + b, 0);
    return ((value / total) * 100).toFixed(1) + '%';
  },
  backgroundColor: '#fff',
  borderRadius: 4,
}

3. 조밀한 데이터에서 겹침 자동 숨김 (display: 'auto')

데이터 포인트 150개를 촘촘하게 넣은 같은 선 차트를 두 개 비교합니다. 위쪽은 display: true(전부 강제 표시)라 골짜기마다 숫자가 겹쳐 뭉개지고, 아래쪽은 display: 'auto'라 겹치는 라벨을 자동으로 솎아내 더 읽기 편합니다. (검증 중 실제로 확인: 완전히 라벨 개수를 줄이기보다, 겹친 자리의 뭉개짐을 줄여주는 방식으로 동작합니다.)
코드 보기 
// 위: 강제로 전부 표시 → 겹치면 뭉개짐
datalabels: { display: true, formatter: (v) => v }

// 아래: 겹치는 라벨을 자동으로 숨김
datalabels: { display: 'auto', formatter: (v) => v }

4. 라벨 클릭 상호작용

막대 위 라벨을 직접 클릭해보세요. listeners.click으로 클릭된 막대만 강조 색으로 바뀝니다.
아직 클릭 안 함
코드 보기 
datalabels: {
  listeners: {
    click: (context) => {
      selectedIndex = context.dataIndex;
      context.chart.update(); // 강조 색 반영을 위해 재렌더
      return true; // 라벨 갱신 트리거
    },
  },
}
