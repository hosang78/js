chartjs-plugin-datalabels
종합 기능 샘플

차트 위 값 표시를 넘어, 퍼센트 계산·다중 라벨·조건부 렌더링·위치 제어·스크립트형 스타일·겹침 처리·클릭 및 호버 이벤트를 한 페이지에서 직접 실험할 수 있다.

Chart.js 4.5.1Datalabels 2.2.0반응형단일 HTML실시간 옵션 변경
옵션 실험실기본다중 라벨이벤트기능표 8개 샘플 준비됨

1. 막대 차트 — 기본값·단위·조건부 색상

formatter로 단위를 붙이고, context를 이용해 값에 따라 글자색과 배경색을 변경한다.

핵심: formatter, color, backgroundColor, borderRadius, anchor, align, offset

2. 도넛 차트 — 퍼센트·자동 숨김

합계 대비 비율을 계산하고 작은 조각은 숨긴다. display: 'auto'로 겹치는 라벨도 줄인다.

핵심: 퍼센트 formatter, display 함수, textStroke, clamp

3. 선 차트 — 회전·다중행·선택 표시

최댓값·최솟값·마지막 값만 라벨을 표시하며 배열 반환으로 여러 줄 텍스트를 만든다.

핵심: rotation, multiline formatter, 조건부 display, font 함수

4. 가로 누적 막대 — 데이터셋별 재정의

전역 플러그인 설정 위에 각 dataset의 datalabels 설정을 덮어쓴다.

핵심: dataset-level override, textAlign, padding, borderWidth

5. 다중 라벨 — index · name · value

하나의 데이터 요소에 최대 세 개 라벨을 배치한다. labels 객체의 각 라벨은 독립적인 위치와 formatter를 가진다.

핵심: labels: { index, name, value } — 카테고리명, 데이터셋명, 실제 값을 서로 다른 위치에 표현

6. 버블 차트 — 객체 데이터 formatter

{x, y, r, name} 객체에서 원하는 필드를 꺼내 라벨을 만들고 반지름에 따라 글자 크기를 조절한다.

핵심: object data, scriptable font, opacity, clip

7. 겹침·클리핑·클램프 비교

조밀한 산점도에서 display: 'auto', clip, clamp의 차이를 확인한다.

핵심: display: 'auto', clip, clamp

8. 라벨 이벤트 — hover · leave · click

라벨 위에 마우스를 올리거나 터치/클릭하면 context에 상태를 추가하고 즉시 다시 그린다.

이벤트 로그가 여기에 표시된다.
