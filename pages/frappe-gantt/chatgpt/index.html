라이브러리 설명

Frappe Gantt는 프로젝트 작업, 일정, 진행률, 선후행 관계를 타임라인으로 보여주는 오픈소스 JavaScript 간트 차트 라이브러리입니다.

  • 드래그·리사이즈·진행률 핸들 조작
  • Day/Week/Month/Year/Quarter Day 뷰 전환
  • 휴일 표시, 주말 제외, 읽기 전용, 의존 작업 이동
  • 커스텀 팝업, 작업 추가, update_task API

주의 및 외부 자원

수협중앙회/수산업 테마의 가상 예시 데이터입니다. 실제 통계·조직·일정·업무절차가 아닙니다.

외부 라이브러리는 Frappe Gantt CDN만 사용합니다. 별도 외부 API 없음.
