Frappe Gantt 핵심 기능 둘러보기

Frappe Gantt는 프로젝트의 작업(Task)과 일정, 선후 의존관계를 막대(Bar) 형태로 시각화하는 오픈소스 간트차트 라이브러리입니다. (ERPNext 개발팀이 만듦)
  • 작업 배열(id/이름/시작일/종료일/진행률/의존관계)만 넘기면 차트를 자동으로 그려줌
  • 마우스로 막대를 드래그하면 일정이 바뀌고, 진행률 핸들을 끌면 진행률이 바뀜 (readonly 옵션으로 잠글 수도 있음)
  • Day/Week/Month/Year 등 다양한 시간 단위(view mode)로 전환 가능
  • 클릭/일정변경/진행률변경 등 이벤트에 콜백을 연결할 수 있음
※ 아래 예시들은 Frappe Gantt 문법 학습용으로 만든 가상의 샘플 일정이며, 수협중앙회의 실제 사업/공정과는 무관합니다. 이 페이지는 Frappe Gantt(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 차트 · 의존관계 · 진행률 · 클릭 이벤트

작업 간 선후 관계(화살표)와 진행률(막대 안 채워진 부분)을 함께 표현합니다. 막대를 클릭하면 on_click 콜백으로 상세 정보를 아래에 표시합니다. 막대를 드래그하면 on_date_change 콜백이 호출됩니다.
막대를 클릭하거나 드래그해보세요.
코드 보기 
const tasks = [
  { id: 't1', name: '부지 선정 및 인허가', start: '2026-07-13', end: '2026-07-24', progress: 100 },
  { id: 't2', name: '설계 및 도면 작성', start: '2026-07-25', end: '2026-08-07', progress: 70, dependencies: 't1' },
  { id: 't3', name: '착공 및 기초공사', start: '2026-08-08', end: '2026-08-21', progress: 30, dependencies: 't2' },
  { id: 't4', name: '골조 및 마감공사', start: '2026-08-22', end: '2026-09-18', progress: 0,  dependencies: 't3' },
  { id: 't5', name: '설비 반입 및 시운전', start: '2026-09-19', end: '2026-09-30', progress: 0, dependencies: 't4' },
  { id: 't6', name: '준공검사 및 개소식', start: '2026-10-01', end: '2026-10-05', progress: 0, dependencies: 't5' },
];

new Gantt('#gantt1', tasks, {
  view_mode: 'Week',
  on_click: (task) => { /* 상세 정보 표시 */ },
  on_date_change: (task, start, end) => { /* 일정 변경 처리 */ },
});

2. 뷰 모드 전환 (View Mode)

같은 데이터를 Quarter Day / Half Day / Day / Week / Month / Year 단위로 바꿔볼 수 있습니다.
코드 보기 
const gantt2 = new Gantt('#gantt2', tasks, { view_mode: 'Week' });

// 버튼 클릭 시
gantt2.change_view_mode('Month');

3. 커스텀 색상 (custom_class)

작업(task)에 custom_class를 지정하고 CSS 변수(--g-bar-color)를 덮어써서 상태별로 막대 색을 다르게 표시할 수 있습니다. 예시: 위판장별 시설 점검 상태
완료 진행중 지연
코드 보기 
const tasks = [
  { id: 's1', name: '부산공동어시장 점검', start: '2026-07-13', end: '2026-07-17', progress: 100, custom_class: 'status-done' },
  { id: 's2', name: '목포 위판장 점검',   start: '2026-07-15', end: '2026-07-22', progress: 55,  custom_class: 'status-progress' },
  { id: 's3', name: '포항 위판장 점검',   start: '2026-07-13', end: '2026-07-20', progress: 20,  custom_class: 'status-delayed' },
  { id: 's4', name: '여수 위판장 점검',   start: '2026-07-18', end: '2026-07-25', progress: 40,  custom_class: 'status-progress' },
  { id: 's5', name: '통영 위판장 점검',   start: '2026-07-13', end: '2026-07-19', progress: 100, custom_class: 'status-done' },
];

/* CSS */
.bar-wrapper.status-done { --g-bar-color: #2ecc71; }
.bar-wrapper.status-progress { --g-bar-color: #f5a623; }
.bar-wrapper.status-delayed { --g-bar-color: #e74c3c; }
