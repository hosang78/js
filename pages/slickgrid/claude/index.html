SlickGrid 핵심 기능 둘러보기

SlickGrid는 2009년부터 이어져 온 초고성능 데이터 그리드로, 행을 가상 스크롤로 렌더링해 수만 개의 행도 매끄럽게 다룹니다. 이 데모는 jQuery 없이 동작하는 모던(ESM) 버전을 사용합니다. 데이터는 SlickDataView가 관리하고, 그리드는 그 결과를 화면에 그리기만 하는 구조입니다.
  • SlickDataView 기반 정렬
  • Editors로 켜는 셀 인라인 편집
  • setGrouping() + Aggregators로 하는 그룹핑과 합계
  • SlickRowSelectionModel로 하는 행 선택(Shift/Ctrl 다중 선택)
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. SlickGrid는 열 순서 변경(드래그)에 필요한 SortableJS를 의존성으로 요구해 함께 CDN으로 불러왔습니다. 그 외 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. DataView 기반 정렬

열 헤더를 클릭하면 오름차순/내림차순으로 정렬됩니다. 실제 정렬은 그리드가 아니라 SlickDataView가 수행하고, 그리드는 onSort 이벤트를 받아 다시 그리기만 합니다.
코드 보기 
const dataView = new SlickDataView();
const grid = new SlickGrid('#grid1', dataView, columns, options);

grid.onSort.subscribe((e, args) => {
  dataView.sort((a, b) => {
    const v = a[args.sortCol.field] > b[args.sortCol.field] ? 1 : -1;
    return args.sortAsc ? v : -v;
  });
});
dataView.onRowsChanged.subscribe((e, args) => grid.invalidateRows(args.rows));
dataView.onRowsChanged.subscribe(() => grid.render());
dataView.setItems(records);   // 각 행은 고유한 id 필드가 필요

2. 셀 인라인 편집

어종·수량 칸을 더블클릭하면 바로 수정할 수 있습니다. 값을 바꾸고 Enter를 누르면 onCellChange 이벤트로 원본 데이터가 갱신됩니다.
코드 보기 
const columns = [
  { id: 'market', name: '위판장', field: 'market' },
  { id: 'species', name: '어종', field: 'species', editor: Editors.Text },
  { id: 'qty', name: '수량', field: 'qty', editor: Editors.Integer },
];
const grid = new SlickGrid('#grid2', dataView, columns, { editable: true, autoEdit: false });

grid.onCellChange.subscribe((e, args) => {
  dataView.updateItem(args.item.id, args.item);   // 수정된 값을 DataView에 반영
});

3. 그룹핑 + 집계 합계

위판장별로 묶고, 각 그룹 아래에 수량 합계 행을 표시했습니다. 그룹 제목을 클릭하면 접고 펼 수 있습니다.
코드 보기 
dataView.setGrouping({
  getter: 'market',
  formatter: (g) => `${g.value} (${g.count}건)`,
  aggregators: [new Aggregators.Sum('qty')],
  displayTotalsRow: true,
});

// '수량' 열에 그룹 합계 전용 포맷터를 지정해야 합계 행에 값이 표시된다
{ id: 'qty', name: '수량', field: 'qty',
  groupTotalsFormatter: (totals, col) => `합계: ${totals.sum[col.field].toLocaleString()}` }

4. 행 선택 모델

행을 클릭해서 선택하고, Shift/Ctrl(⌘)을 누른 채 클릭하면 여러 행을 함께 선택할 수 있습니다.
선택된 행: 0개
코드 보기 
grid.setSelectionModel(new SlickRowSelectionModel());

grid.onSelectedRowsChanged.subscribe((e, args) => {
  console.log('선택된 행 수:', args.rows.length);
});
