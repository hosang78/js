Tom Select 핵심 기능 둘러보기

Tom Select는 평범한 <select>를 검색·다중 선택·태그 생성·커스텀 렌더링이 가능한 드롭다운으로 바꿔주는 라이브러리입니다. jQuery 없이 동작하고, 옵션 목록을 직접 그리는 방식이라 자유도가 높습니다.
  • 타이핑으로 옵션을 좁혀가는 검색 가능한 단일 선택
  • 목록에 없는 값도 바로 추가하는 태그 생성형 다중 선택
  • load 콜백으로 흉내낸 비동기 검색(서버 조회 시뮬레이션)
  • render로 만드는 카드형 커스텀 드롭다운
※ 아래 위판장·조합원·어종 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 조직·명부와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 검색 가능한 단일 선택

드롭다운을 열고 타이핑하면 일치하는 위판장만 남습니다. 마우스 없이 키보드만으로도 고를 수 있습니다.
아직 선택된 위판장이 없습니다.
코드 보기 
new TomSelect('#ts1', {
  create: false,
  sortField: { field: 'text', direction: 'asc' },
});

2. 태그 생성형 다중 선택

목록에 있는 어종을 여러 개 고르거나, 목록에 없는 어종 이름을 직접 입력하고 Enter를 누르면 새 태그로 즉시 추가됩니다. 각 태그의 ×를 눌러 뺄 수 있습니다.
선택된 어종: 없음
코드 보기 
new TomSelect('#ts2', {
  plugins: ['remove_button'],
  create: true,       // 목록에 없는 값도 새 태그로 추가 허용
  createOnBlur: true,
  persist: false,
  // 기본값은 태그를 추가해도 검색창 텍스트를 지우지 않는다(다시 스크롤해서 이어보라는 의도).
  // 태그를 하나씩 깔끔하게 이어 붙이려면 clearAfterSelect가 필요하다.
  clearAfterSelect: true,
});

3. 비동기 검색 (load 콜백)

두 글자 이상 입력하면 load 콜백이 실행됩니다. 실제 서버 조회를 흉내내기 위해 일부러 400ms 지연을 넣었고, 그동안 "검색 중..." 스피너가 표시됩니다.
검색어를 입력해보세요.
코드 보기 
new TomSelect('#ts3', {
  valueField: 'id',
  labelField: 'name',
  searchField: 'name',
  options: [],
  load: (query, callback) => {
    if (query.length < 2) return callback();
    setTimeout(() => {
      const results = MEMBERS
        .filter((name) => name.includes(query))
        .map((name) => ({ id: name, name }));
      callback(results); // 실제로는 fetch()의 결과를 여기서 넘겨준다
    }, 400);
  },
});

4. 카드형 커스텀 드롭다운

render.option / render.item으로 옵션 마크업을 직접 그려서, 위판장 이름과 함께 지역·오늘 위판량을 카드 형태로 보여줍니다.
코드 보기 
new TomSelect('#ts4', {
  render: {
    option: (data, escape) => `
      <div class="ts-card-option">
        <div class="ts-card-name">${escape(data.text)}</div>
        <div class="ts-card-meta">${escape(data.region)} · 오늘 위판량 ${escape(data.volume)}kg</div>
      </div>`,
    item: (data, escape) => `
      <div>${escape(data.text)} <span class="ts-item-meta">(${escape(data.region)})</span></div>`,
  },
});
