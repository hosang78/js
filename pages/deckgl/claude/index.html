deck.gl 핵심 기능 둘러보기

deck.gl은 Uber가 만든 WebGL 기반 대규모 데이터 시각화 프레임워크입니다. MapLibre·OpenLayers 같은 범용 인터랙티브 지도와 달리, 수만~수백만 건의 데이터를 GPU 가속으로 빠르게 그리는 데 특화되어 있고, "레이어"를 쌓아 올리는 방식으로 동작합니다.
  • ScatterplotLayer로 점 데이터를 값에 비례한 반지름·색상으로 표시
  • ArcLayer로 두 지점을 잇는 곡선 — 유통·이동 경로 시각화에 흔히 사용
  • HeatmapLayer로 데이터 밀도를 색상 그라데이션으로 표현
  • 모든 레이어에 pickable: true와 onClick/onHover를 붙여 인터랙션 추가 가능
※ deck.gl은 배경 지도 없이도 동작하며, 별도 지도 라이브러리(Mapbox/MapLibre/Google Maps)와 결합해 쓰는 경우가 많습니다. 이 페이지는 별도 라이브러리 없이 deck.gl 자체의 TileLayer + BitmapLayer로 OpenStreetMap 래스터 타일을 배경으로 직접 그렸습니다(API 키 불필요). 위판장 위치·물량·경로는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다.

1. ScatterplotLayer — 값에 비례한 점 크기

위판 물량이 많을수록 점이 크게 표시됩니다.
코드 보기 
new deck.ScatterplotLayer({
  data: [{ position: [129.0756, 35.0951], weight: 320 }, ...],
  getPosition: (d) => d.position,
  getRadius: (d) => d.weight,
  radiusScale: 3,
  getFillColor: [79, 125, 255],
});

2. ArcLayer — 유통 경로 표시

위판장에서 각 유통 거점으로 이어지는 경로를 호 모양으로 표시합니다.
코드 보기 
new deck.ArcLayer({
  data: [{ source: [129.0756, 35.0951], target: [129.09, 35.10] }, ...],
  getSourcePosition: (d) => d.source,
  getTargetPosition: (d) => d.target,
  getSourceColor: [79, 125, 255],
  getTargetColor: [27, 175, 122],
});

3. HeatmapLayer — 밀도 히트맵

가상의 어획 지점 데이터를 밀도 기반 히트맵으로 표현합니다.
코드 보기 
new deck.HeatmapLayer({
  data: points, // [{ position: [lon, lat], weight }, ...]
  getPosition: (d) => d.position,
  getWeight: (d) => d.weight,
  radiusPixels: 40,
});

4. 클릭 인터랙션 — 정보 툴팁

점을 클릭하면 해당 위판장의 정보가 툴팁으로 표시됩니다.
아직 클릭 안 함
코드 보기 
new deck.ScatterplotLayer({
  data: points,
  pickable: true,
  onClick: (info) => {
    console.log(info.object); // 클릭한 지점의 데이터
  },
});
