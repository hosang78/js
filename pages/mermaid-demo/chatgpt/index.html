● 준비 중
Mermaid 라이브러리 연결 대기 중CDN에서 Mermaid.js를 불러온 뒤 샘플을 렌더링한다.

렌더링 설정

테마·보안 수준·레이블 처리 방식을 변경하면 선택 샘플이 다시 렌더링된다.

참고: Mermaid 전역 설정은 mermaid.initialize()로 적용한다. 다이어그램 단위 설정은 YAML frontmatter의 config를 사용할 수 있으며, 과거 directives 방식은 v10.5.0부터 deprecated로 안내된다.

이 페이지에서 확인할 수 있는 기능

업무 프로세스, 시스템·데이터 모델링, 프로젝트 관리, 데이터 시각화, 최근 추가된 구조·차트형 문법을 한 번에 살펴볼 수 있도록 구성했다.

구조·프로세스Flowchart, Sequence, State, User Journey, Timeline
설계·모델링Class, ER, Requirement, C4, Architecture, Event Modeling
계획·협업Gantt, Kanban, GitGraph, Mindmap, TreeView
차트·분석Pie, Quadrant, Sankey, XY, Radar, Treemap, Venn

전체 기능 갤러리

선택한 렌더링 설정으로 모든 샘플을 순차적으로 그린다. 일부 신기능은 브라우저·버전별 차이가 있을 수 있다.

● 대기
Mermaid.js는 Markdown 유사 텍스트 정의를 렌더링해 다이어그램과 차트를 생성하는 JavaScript 도구다. 이 샘플은 CDN 연결이 가능한 브라우저에서 동작한다. 사내망 적용 시에는 승인된 내부 정적 자산 경로로 CDN 스크립트를 대체해야 한다.
