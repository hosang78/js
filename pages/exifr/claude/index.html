exifr 핵심 기능 둘러보기

exifr는 JPEG/PNG/HEIC 등 사진 파일 안에 담긴 EXIF 메타데이터(촬영 카메라 정보, 촬영 일시, GPS 위치, 내장 썸네일 등)를 브라우저에서 바로 읽어내는 라이브러리입니다.
  • exifr.parse()로 읽는 기본 메타데이터 (제조사·모델·렌즈·촬영일시)
  • exifr.gps()로 뽑아내는 GPS 좌표 + 지도 링크
  • orientation 값으로 하는 회전 보정 미리보기
  • exifr.thumbnail()로 꺼내는 내장 썸네일
※ 아래 데모는 사진에 실제 EXIF가 없어도 확인할 수 있도록, 다른 라이브러리인 piexifjs로 즉석에서 가상의 EXIF(제조사 "FisheryCam", 부산 인근의 가상 좌표 등)를 심은 샘플 이미지를 만드는 기능을 함께 제공합니다. exifr 자체는 읽기 전용이며 이 가상 EXIF 삽입에는 관여하지 않습니다.
🔒 모든 처리는 브라우저 안에서만 이루어집니다. 업로드한 사진은 서버로 전송되지 않습니다. 다만 본인 사진에는 실제 촬영 위치·시간이 들어있을 수 있으니, 다른 사람과 공유할 사진은 업로드 전에 한 번 더 생각해 보세요.

이미지 준비

직접 찍은 사진(특히 스마트폰 사진)을 올리면 실제 EXIF를 확인할 수 있습니다. 준비된 사진이 없다면 아래 버튼으로 가상 EXIF가 담긴 샘플 이미지를 만들어서 확인해 보세요.

1. 기본 메타데이터 읽기

exifr.parse(file) 하나로 카메라 제조사·모델·렌즈·촬영일시 등 대부분의 태그를 한 번에 객체로 받을 수 있습니다.
소스 코드 보기 
const output = await exifr.parse(file);
// output.Make, output.Model, output.LensModel,
// output.DateTimeOriginal, output.ISO, output.FNumber, ...
console.log(output.Make, output.Model);

2. GPS 좌표 + 지도 링크

exifr.gps(file)는 GPS 관련 태그만 골라 10진수 위도·경도로 바로 변환해줍니다. (원래 GPS 태그는 도/분/초 단위라 직접 계산하려면 번거롭습니다.)
소스 코드 보기 
const { latitude, longitude } = await exifr.gps(file);
const mapUrl = `https://www.openstreetmap.org/?mlat=${latitude}&mlon=${longitude}#map=15/${latitude}/${longitude}`;

3. 방향(orientation) 정보 확인

스마트폰으로 세로/가로를 바꿔 찍은 사진은 실제 픽셀은 눕혀진 채로 저장되고, Orientation 태그로 "이렇게 회전해서 보여줘라"는 정보만 따로 담기는 경우가 많습니다. 그런데 요즘 브라우저는 `<img>`를 표시할 때 이 태그를 이미 자동으로 반영해서 신경 쓰지 않아도 알아서 바르게 보여줍니다. 아래는 그 자동 보정을 image-orientation: none으로 일부러 끈 "저장된 원본 픽셀"과 비교한 화면입니다.
소스 코드 보기 
// orientation 값만 필요하면:
const orientation = await exifr.orientation(file); // 1=정상, 6/8=90도 회전 등

// css/canvas로 직접 돌려야 하는지까지 판단해주는 버전:
const r = await exifr.rotation(file);
// r = { deg, rad, scaleX, scaleY, dimensionSwapped, css, canvas }
// 최신 브라우저는 <img>를 이미 자동으로 바르게 돌려서 보여주기 때문에
// r.css / r.canvas가 false로 나온다 — "따로 돌릴 필요 없음"이라는 뜻.
// (구형/quirky 브라우저에서만 r.css가 true로 나와 수동 보정이 필요해짐)
if (r.css) {
  imgEl.style.transform = `rotate(${r.deg}deg) scale(${r.scaleX}, ${r.scaleY})`;
}

4. 내장 썸네일 추출

많은 카메라·스마트폰은 사진 안에 이미 작은 썸네일 JPEG을 함께 저장해둡니다. exifr.thumbnail()로 원본 사진을 디코딩하지 않고도 이 썸네일만 빠르게 꺼낼 수 있습니다.
소스 코드 보기 
// exifr.thumbnail()은 Blob이 아니라 Uint8Array를 반환한다 (문서에 명시됨).
// 바로 화면에 쓰려면 thumbnailUrl()로 Object URL까지 한 번에 받는 게 더 편하다.
const thumbUrl = await exifr.thumbnailUrl(file); // string 또는 undefined(썸네일 없음)
if (thumbUrl) {
  imgEl.src = thumbUrl;
}
