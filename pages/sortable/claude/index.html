SortableJS 핵심 기능 둘러보기

SortableJS는 목록의 항목을 드래그해서 순서를 바꾸거나 다른 목록으로 옮길 수 있게 해주는 라이브러리입니다. 우선순위 조정, 칸반 보드, 담기/빼기 화면 등에 널리 쓰입니다.
  • 목록 요소 하나에 new Sortable(el)만 하면 드래그 정렬이 바로 동작 (터치 지원)
  • group 옵션으로 여러 목록 사이를 오가며 드래그 가능
  • handle(손잡이로만 드래그), filter(특정 항목 고정) 등 세부 제어 가능
  • 드래그가 끝나면 onEnd 이벤트와 toArray()로 바뀐 순서를 데이터로 받을 수 있음
※ 아래 경매 순서/어선 목록은 SortableJS 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 경매·배정 절차와는 무관합니다. 이 페이지는 SortableJS(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 드래그 정렬 + 순서 데이터 얻기

가상의 "오늘 경매 순서" 목록입니다. 항목을 드래그해서 순서를 바꾸면 onEnd 이벤트로 바뀐 순서를 아래에 표시합니다.
  • 1고등어 (320kg)
  • 2갈치 (180kg)
  • 3오징어 (95kg)
  • 4새우 (60kg)
  • 5전복 (25kg)
항목을 드래그해서 순서를 바꿔보세요.
코드 보기 
const sortable = new Sortable(document.getElementById('list1'), {
  animation: 150,
  onEnd: () => {
    console.log(sortable.toArray()); // data-id 기준 현재 순서 배열
  },
});

3. 손잡이(handle)로만 드래그 + 고정 항목(filter)

실수로 끌리는 걸 막으려면 handle로 지정한 부분(⠿)을 잡았을 때만 드래그되게 할 수 있고, filter로 특정 항목(회색 "고정" 항목)은 아예 움직이지 않게 할 수 있습니다.
  • 📌 오늘 위판 시작 09:00 (고정 항목 — 드래그 불가)
  • ⠿어획물 선별 작업
  • ⠿계량 및 등록
  • ⠿경매장 진열
  • ⠿낙찰 정산 처리
⠿ 부분을 잡아야만 드래그됩니다. 글자 부분을 잡으면 안 끌립니다.
코드 보기 
new Sortable(listEl, {
  animation: 150,
  handle: '.handle',        // 이 선택자 부분을 잡아야만 드래그됨
  filter: '.locked',        // 이 선택자 항목은 드래그 자체가 안 됨
  onMove: (evt) => !evt.related.classList.contains('locked'),
});
