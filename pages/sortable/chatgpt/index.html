옵션 이해 포인트

업무 화면에서 오작동을 줄이는 데 자주 쓰는 설정입니다.

필터 이벤트 로깅
new Sortable(handleList, {
  animation: 180,
  draggable: '.sort-item',
  handle: '.drag-handle',
  filter: '.no-drag, .action-btn',
  preventOnFilter: false,
  ignore: 'a, img, button',
  onFilter: (evt) => log('onFilter', evt)
});
시험 방법
① 텍스트 본문을 끌면 이동하지 않음
② ⠿ 핸들을 끌면 이동
③ 잠김 항목과 우측 버튼은 이동하지 않고 클릭 이벤트만 발생

선택 규칙

선택된 항목에는 .selected 클래스가 적용됩니다.

selectedClass
new Sortable(multiList, {
  animation: 180,
  multiDrag: true,
  selectedClass: 'selected',
  fallbackTolerance: 3,
  multiDragKey: 'CTRL',
  onSelect: (evt) => log('onSelect', evt),
  onDeselect: (evt) => log('onDeselect', evt)
});
참고
MultiDrag와 Swap은 기본 번들이 아닌 Complete ESM build에서 함께 제공되는 플러그인입니다.

Business rule

검토 대기열 — 최대 3건

왼쪽의 후보를 오른쪽으로 끌어보세요. 검토 대기열이 3건이면 추가 이동을 막습니다.

onMove validation
후보 목록
협의안 A후보
협의안 B후보
협의안 C후보
협의안 D후보
검토 대기열 (0/3)

3건을 초과하면 드롭 거부

권한 제어 개념

업무 프로세스에서 상태별 이동을 제한할 때 사용할 수 있습니다.

onMove / group
new Sortable(reviewList, {
  group: { name: 'review', pull: true, put: true },
  animation: 180,
  onMove: (evt) => {
    const count = evt.to.querySelectorAll('.sort-item').length;
    const movingIntoReview = evt.to.id === 'reviewList';
    return !(movingIntoReview && count >= 3);
  }
});
구현 팁
서버 권한 검증은 별도로 수행해야 합니다. onMove는 프론트엔드 화면에서 즉시 피드백을 주는 용도로 적합합니다.

  • Sortable.create() / new Sortable()

  • sortable.toArray() / sortable.sort()

인스턴스 정보가 여기에 표시됩니다.
이 페이지의 SortableJS 로딩 방식과 오프라인 교체 방법
<script type="module">
  import Sortable from 'https://cdn.jsdelivr.net/npm/sortablejs@1.15.7/modular/sortable.complete.esm.js';
  // 사내망 등 오프라인 환경에서는 위 URL을 아래 로컬 경로로 교체
  // import Sortable from './assets/sortable.complete.esm.js';
</script>
실행 유의사항
이 HTML은 SortableJS의 Complete ESM 번들을 CDN에서 불러옵니다. 외부망이 차단된 환경에서는 공식 배포 파일을 assets/sortable.complete.esm.js로 저장하고, 하단 코드에 표시된 import 경로를 로컬 경로로 바꾸면 됩니다. 이 페이지의 UI 및 예제 코드는 외부 프레임워크 없이 동작하도록 작성했습니다.
