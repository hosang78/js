Turf.js 핵심 기능 둘러보기

Turf.js는 위경도 좌표(GeoJSON)를 가지고 거리·면적·포함 여부 같은 지리 공간 계산을 해주는 라이브러리입니다. 지도를 그려주진 않고, 순수하게 좌표 계산만 담당합니다.
  • turf.distance(a, b)로 두 지점 사이의 실제 거리(km) 계산
  • turf.area(polygon)로 다각형의 실제 면적(㎡) 계산
  • turf.buffer(point, radius)로 지점 주변 반경만큼의 원형 다각형 생성
  • turf.booleanPointInPolygon(point, polygon)로 점이 다각형 안에 있는지 판별
※ 이 페이지는 실제 지도 타일(API 키가 필요) 없이, 위경도 좌표를 단순한 SVG 좌표로 직접 투영해서 보여줍니다. 아래 위판장 좌표와 부지 모양은 Turf.js 학습용으로 만든 가상의 좌표이며 실제 수협중앙회의 위치·부지가 아닙니다. Turf.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 지도 API는 사용하지 않습니다.

1. 두 지점 사이 거리 (turf.distance)

본소에서 각 위판장까지의 실제 거리를 계산합니다. 위판장을 선택해보세요.
코드 보기 
const hq = turf.point([129.02, 35.00]);
const target = turf.point([129.08, 35.05]);

const km = turf.distance(hq, target, { units: 'kilometers' });

2. 다각형 면적 (turf.area)

위판장 A 부지(다각형)의 실제 면적을 계산합니다.
코드 보기 
const site = turf.polygon([[
  [129.070, 35.045], [129.092, 35.045],
  [129.092, 35.058], [129.070, 35.058],
  [129.070, 35.045],
]]);

const squareMeters = turf.area(site); // ㎡ 단위로 반환

3. 반경 버퍼 생성 (turf.buffer)

위판장 B를 중심으로 반경을 조절하면서 버퍼(원형 다각형)를 만들어봅니다.
반경: 300m
코드 보기 
const center = turf.point([129.110, 34.990]);
const buffered = turf.buffer(center, 0.3, { units: 'kilometers' }); // 반경 300m

// buffered.geometry.coordinates[0] 가 원을 근사하는 다각형 좌표 배열

4. 점이 다각형 안에 있는지 판별 (turf.booleanPointInPolygon)

지도를 클릭해보세요. 클릭한 지점이 위판장 A 부지(파란 다각형) 안에 있는지 바로 판별합니다.
지도를 클릭해보세요.
코드 보기 
map.addEventListener('click', (e) => {
  const [lng, lat] = unproject(e.offsetX, e.offsetY); // 클릭 좌표 -> 위경도 역변환
  const clicked = turf.point([lng, lat]);
  const isInside = turf.booleanPointInPolygon(clicked, site);
});
