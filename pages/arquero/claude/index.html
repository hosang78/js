Arquero 핵심 기능 둘러보기

Arquero는 워싱턴대 데이터 시각화 연구실(Vega·Observable Plot과 같은 팀)이 만든 데이터 가공 라이브러리입니다. R의 dplyr나 pandas처럼, 테이블 데이터를 필터링·집계·정렬·병합하는 파이프라인을 체이닝 방식으로 작성할 수 있습니다.
  • .filter() + .derive()로 하는 행 필터링과 파생 열 계산
  • .groupby() + .rollup()으로 하는 그룹별 집계
  • .orderby() + .slice()로 하는 정렬 후 상위 N개 추출
  • .join()으로 하는 테이블 병합
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Arquero(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다. 결과 테이블은 Arquero의 table.toHTML()로 그대로 렌더링한 것입니다.

1. 필터링 + 파생 열 계산

원본 위판 기록에서 수량이 400건 이상인 행만 남기고, 수량×단가로 계산한 "위판 금액" 열을 새로 추가했습니다.
코드 보기 
const dt = aq.from(records);   // records: 위판장, 어종, 수량, 단가로 이뤄진 배열

const result = dt
  .filter(d => d.qty >= 400)
  .derive({ amount: d => d.qty * d.price });

document.getElementById('out1').innerHTML = result.toHTML();

2. 그룹별 집계

위판장별로 묶어서 총 위판량·평균 단가·기록 건수를 한 번에 계산했습니다. aq.op가 sum·average· count 같은 집계 함수를 제공합니다.
코드 보기 
const result = dt.groupby('market').rollup({
  totalQty: d => aq.op.sum(d.qty),
  avgPrice: d => Math.round(aq.op.average(d.price)),
  n: d => aq.op.count(),
});

3. 정렬 + 상위 N개 추출

위판 금액(수량×단가)이 가장 큰 순서로 정렬한 뒤, 상위 3건만 잘라냈습니다.
코드 보기 
const result = dt
  .derive({ amount: d => d.qty * d.price })
  .orderby(aq.desc('amount'))   // 내림차순
  .slice(0, 3);                 // 상위 3건

4. 테이블 조인

위판장별 지역 정보가 담긴 별도의 작은 테이블을 market 열 기준으로 합쳤습니다. SQL의 JOIN과 동일한 개념입니다.
코드 보기 
const regions = aq.from([
  { market: 'A위판장', region: '동해' },
  { market: 'B위판장', region: '서해' },
  { market: 'C위판장', region: '남해' },
]);

const result = dt.join(regions, 'market');   // market 열 기준으로 병합
