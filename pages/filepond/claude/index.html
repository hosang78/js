FilePond 핵심 기능 둘러보기

FilePond는 파일 업로드 영역을 드래그앤드롭, 미리보기, 진행률 표시까지 갖춘 완성된 UI로 만들어주는 라이브러리입니다. 평범한 <input type="file"> 하나를 FilePond.create()로 감싸기만 하면 됩니다.
  • 드래그앤드롭 또는 클릭으로 여러 파일을 선택해 목록으로 관리
  • 플러그인을 등록하면 이미지 미리보기, 파일 형식·용량 검증 같은 기능이 추가됨
  • acceptedFileTypes/maxFileSize로 허용하지 않는 파일을 자동으로 걸러냄
  • getFiles()/removeFiles() 같은 API로 코드에서 파일 목록을 직접 제어 가능
※ 이 페이지의 업로드는 실제 서버로 전송되지 않습니다. 브라우저 안에서만 파일을 선택·미리보기하는 학습용 데모이며, 위판 서류/사진 관련 문구도 가상의 예시입니다. FilePond(CDN)와 공식 플러그인 (이미지 미리보기, 파일 형식 검증, 파일 크기 검증)만 사용하고 다른 외부 API는 사용하지 않습니다.

1. 기본 드래그앤드롭 업로드

위판 관련 서류나 사진을 드래그하거나 클릭해서 여러 개 선택해보세요. 목록에서 개별 파일을 삭제할 수도 있습니다.
코드 보기 
FilePond.create(document.getElementById('pond1'), {
  allowMultiple: true,
  instantUpload: false, // 서버로 자동 업로드하지 않음 (이 데모는 서버가 없음)
  labelIdle: '파일을 드래그하거나 <span class="filepond--label-action">찾아보기</span>',
});

2. 이미지 미리보기 플러그인

※ 이 섹션은 FilePond 외에 공식 플러그인 FilePondPluginImagePreview를 함께 사용합니다.
사진 파일을 올리면 업로드 전에 바로 썸네일이 보입니다. 이미지가 아닌 파일은 형식 아이콘으로 표시됩니다.
코드 보기 
FilePond.registerPlugin(FilePondPluginImagePreview);

FilePond.create(document.getElementById('pond2'), {
  allowMultiple: true,
  instantUpload: false,
  acceptedFileTypes: ['image/*'],
  imagePreviewHeight: 140,
});

3. 파일 형식 · 용량 검증

※ 이 섹션은 FilePond 외에 공식 플러그인 FilePondPluginFileValidateType, FilePondPluginFileValidateSize를 함께 사용합니다.
조합원 신청서 첨부를 가정해, PDF·이미지 파일만 허용하고 2MB를 넘는 파일은 거부합니다. 허용되지 않는 파일을 올리면 빨간 오류 표시가 뜹니다.
코드 보기 
FilePond.registerPlugin(FilePondPluginFileValidateType, FilePondPluginFileValidateSize);

FilePond.create(document.getElementById('pond3'), {
  allowMultiple: true,
  instantUpload: false,
  acceptedFileTypes: ['application/pdf', 'image/jpeg', 'image/png'],
  maxFileSize: '2MB',
  labelFileTypeNotAllowed: '지원하지 않는 파일 형식입니다',
  fileValidateTypeLabelExpectedTypes: 'PDF 또는 이미지 파일만 가능합니다',
  labelMaxFileSizeExceeded: '파일 용량이 너무 큽니다',
  labelMaxFileSize: '최대 {filesize}까지 가능합니다',
});

4. API로 파일 목록 제어

파일을 몇 개 올려보고, 버튼으로 코드에서 직접 목록을 확인하거나 한 번에 지워보세요.
아직 확인한 목록 없음
코드 보기 
const pond4 = FilePond.create(document.getElementById('pond4'), { instantUpload: false });

document.getElementById('listFilesBtn').addEventListener('click', () => {
  const names = pond4.getFiles().map((f) => f.filename);
  status4.textContent = names.length ? names.join('\n') : '파일 없음';
});

document.getElementById('clearFilesBtn').addEventListener('click', () => {
  pond4.removeFiles();
});
