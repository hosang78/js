Drawflow 핵심 기능 둘러보기

Drawflow는 노드를 드래그해서 배치하고 케이블로 연결하는 시각적 흐름 편집기(flow editor)를 만들어주는 라이브러리입니다. Node-RED 같은 노드 기반 편집 도구를 만들 때 씁니다.
  • 노드 생성, 드래그 이동, 케이블로 연결
  • 노드 안에 폼 요소(드롭다운, 체크박스 등)를 넣은 커스텀 HTML 노드 + 여러 입출력 포트
  • 마우스로 포트를 직접 드래그해 새 연결 만들기
  • 전체 흐름을 JSON으로 내보내고, 다시 불러와 복원
※ 아래 위판 처리 흐름은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 업무 절차와 무관합니다. Drawflow(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 노드 + 케이블 연결

가상 위판 처리 흐름입니다. 노드를 드래그해서 옮겨보세요. 캔버스 빈 곳을 드래그하면 화면이 이동하고, 휠로 확대/축소됩니다.
코드 보기 
const editor = new Drawflow(container);
editor.start();

const n1 = editor.addNode("market", 0, 1, 60, 100, "node-market",
  {}, "<div class='node-title'>입고</div>");
const n2 = editor.addNode("broker", 1, 1, 320, 100, "node-broker",
  {}, "<div class='node-title'>선별·경매</div>");

editor.addConnection(n1, n2, "output_1", "input_1");

2. 폼 요소가 있는 커스텀 노드 + 다중 포트

노드 안에 실제 동작하는 드롭다운·체크박스를 넣을 수 있습니다. 가운데 노드는 입력 포트 2개, 출력 포트 2개를 가집니다.
노드 안의 드롭다운이나 체크박스를 조작해보세요.
코드 보기 
const html = `
  <div class="node-title">선별 기준</div>
  <div class="node-form">
    <select df-species>
      <option value="mackerel">고등어</option>
      <option value="hairtail">갈치</option>
    </select>
    <label><input type="checkbox" df-frozen> 냉동 여부</label>
  </div>`;
// 입력 2개, 출력 2개짜리 노드
editor.addNode("sort", 2, 2, 340, 40, "node-broker", {}, html);

3. 마우스로 직접 연결하기

아래 두 노드는 아직 연결되어 있지 않습니다. "입고" 노드 오른쪽의 출력 포트(점)를 "포장" 노드 왼쪽의 입력 포트로 드래그해 직접 연결해보세요.
아직 연결되지 않았습니다.
코드 보기 
editor.on("connectionCreated", (info) => {
  console.log(`${info.output_id} → ${info.input_id} 연결됨`);
});

4. 내보내기 / 가져오기

현재 흐름을 JSON으로 내보낸 뒤, 완전히 새로운 편집기에 그대로 불러와 복원합니다.
원본 편집기
가져온(복원된) 편집기

    
내보내기 버튼을 눌러보세요.

    

      코드 보기
      
const data = editor.export();
const json = JSON.stringify(data);

const restored = new Drawflow(otherContainer);
restored.start();
restored.import(JSON.parse(json));
