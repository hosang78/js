JSZip 핵심 기능 둘러보기

JSZip은 브라우저에서 직접 ZIP 파일을 만들고 읽을 수 있게 해주는 라이브러리입니다. file()/folder() 체이닝 API로 폴더 구조가 있는 압축 파일도 쉽게 만듭니다.
  • zip.file(경로, 내용), zip.folder(이름)으로 폴더/파일 추가
  • zip.generateAsync({ type: 'blob' })로 실제 다운로드 가능한 ZIP 생성
  • JSZip.loadAsync(데이터)로 기존 ZIP을 읽고 forEach로 순회
  • 파일마다 { compression: 'STORE' | 'DEFLATE' }로 압축 방식 선택 가능
※ 이 저장소에는 비슷한 목적의 zip.js 데모도 있습니다 — zip.js는 ZipWriter/ZipReader와 비밀번호 암호화·진행률에 초점을 맞췄다면, 이 페이지는 JSZip 특유의 file()/folder() 체이닝과 압축 방식·출력 형식 비교에 집중했습니다. 이 페이지의 위판 서류는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 폴더 구조로 여러 파일 압축

가상 위판 서류를 폴더별로 묶어 ZIP 하나로 만듭니다. 버튼을 누르면 실제로 ZIP 파일이 다운로드됩니다.
아직 만들지 않음
코드 보기 
const zip = new JSZip();
zip.file('README.txt', '가상 위판 서류 모음집입니다.');
const auctionFolder = zip.folder('위판기록');
auctionFolder.file('2026-07-18.csv', 'species,weightKg\n고등어,120');
const blob = await zip.generateAsync({ type: 'blob' });
// blob으로 다운로드 링크 생성

2. ZIP 읽기 + 파일 트리 순회

1번에서 만든 ZIP을 다시 읽어(loadAsync) 폴더 구조를 그대로 나열하고, 특정 파일 내용을 꺼내봅니다.
아직 읽지 않음
코드 보기 
const loaded = await JSZip.loadAsync(blob);
loaded.forEach((relativePath, file) => {
  console.log(relativePath, file.dir ? '(폴더)' : '(파일)');
});
const content = await loaded.file('위판기록/2026-07-18.csv').async('string');

3. 압축 방식 비교 (STORE vs DEFLATE)

반복이 많은 같은 텍스트를 압축 없이(STORE) 담을 때와 DEFLATE로 압축해서 담을 때 실제 파일 크기를 비교합니다.
코드 보기 
zip.file('data.txt', text, { compression: 'STORE' });   // 압축 안 함, 그대로 저장
zip.file('data.txt', text, {
  compression: 'DEFLATE',
  compressionOptions: { level: 9 }, // 1(빠름)~9(고압축)
});

4. 다양한 출력 형식

같은 ZIP을 blob·base64·arraybuffer 세 가지 형식으로 만들어 크기와 타입을 비교하고, base64로 왕복 복원이 되는지 확인합니다.
코드 보기 
await zip.generateAsync({ type: 'blob' });        // 다운로드용
await zip.generateAsync({ type: 'base64' });      // 텍스트 저장/전송용
await zip.generateAsync({ type: 'arraybuffer' }); // 바이너리 처리용
await JSZip.loadAsync(base64String, { base64: true }); // base64에서 복원
