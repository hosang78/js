Grid.js 핵심 기능 둘러보기

Grid.js는 프레임워크에 종속되지 않는 순수 JS 테이블(데이터그리드) 라이브러리입니다. 배열 데이터만 넘기면 정렬·검색·페이지네이션이 자동으로 붙고, 셀 내용을 원하는 대로 커스터마이즈할 수 있습니다.
  • sort + search + pagination이 자동으로 붙는 기본 테이블
  • formatter + html()로 만드는 커스텀 셀 렌더링
  • fixedHeader로 만드는 고정 헤더 스크롤 테이블
  • updateConfig() + forceRender()로 하는 동적 데이터 갱신
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Grid.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 테이블 (정렬 + 검색 + 페이지네이션)

배열 데이터와 열 이름만 넘겼습니다. 검색창·정렬 화살표·페이지 이동 버튼이 모두 기본으로 제공됩니다.
코드 보기 
new gridjs.Grid({
  columns: ['위판장', '어종', '수량', '단가'],
  data: records,             // [['A위판장','고등어',1200,4200], ...]
  sort: true,
  search: true,
  pagination: { limit: 4 },
}).render(document.getElementById('grid1'));

2. 커스텀 셀 포맷터

수량은 천 단위 구분 기호를 넣어 굵게, 수량에 따른 등급은 색이 있는 배지로 직접 렌더링했습니다.
코드 보기 
{
  name: '등급',
  formatter: (cell, row) => {
    const qty = row.cells[2].data;                 // 같은 행의 '수량' 열 값 참조
    const grade = qty >= 1000 ? '상' : qty >= 600 ? '중' : '하';
    return gridjs.html(`<span class="grade-pill" style="background:${color(grade)}">${grade}</span>`);
  },
}

3. 고정 헤더 스크롤 테이블

fixedHeader와 height를 지정하면, 내용이 많아도 헤더가 고정된 채로 본문만 스크롤됩니다.
코드 보기 
new gridjs.Grid({
  columns: ['위판장', '어종', '수량', '단가'],
  data: manyRecords,
  fixedHeader: true,
  height: '220px',
}).render(document.getElementById('grid3'));

4. 동적 데이터 갱신

버튼을 누르면 updateConfig()로 표시할 데이터셋을 통째로 바꾼 뒤 forceRender()로 다시 그립니다.
코드 보기 
const grid = new gridjs.Grid({ columns: [...], data: records }).render(container);

filterBtn.addEventListener('click', () => {
  const filtered = records.filter((row) => row[1] === '고등어');
  grid.updateConfig({ data: filtered }).forceRender();
});
