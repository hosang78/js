Grid.js 구성 제어

상태·조직·진행률 필터는 외부 업무 필터 예시이며, Grid.js의 전역 검색과 함께 사용할 수 있다. 열 표시, 페이지 크기, 고정 헤더 변경은 updateConfig().forceRender() 방식으로 즉시 반영된다.

서버 연동 구성 포인트

실제 백엔드에서는 Grid.js의 server, 그리고 search·sort·pagination 각각의 server.url 함수를 조합해 검색어, 정렬 열, 페이지 오프셋을 API 파라미터로 전달한다. 이 파일의 원격 예시는 공개 API 가용성에 따라 실패할 수 있으며, 통합 그리드는 외부 API 없이 동작한다.

핵심 구성 예시

const grid = new gridjs.Grid({
  columns: [
    { id: "name", name: "담당자", formatter: personFormatter },
    { id: "status", name: "상태", formatter: statusFormatter },
    {
      id: "budget",
      name: "예산",
      sort: { compare: (a, b) => Number(a) - Number(b) },
      formatter: value => `${Number(value).toLocaleString("ko-KR")}만원`
    }
  ],
  data: rows,
  search: true,
  sort: { multiColumn: true },
  pagination: { limit: 10, summary: true, buttonsCount: 5 },
  fixedHeader: true,
  height: "520px",
  resizable: true,
  language: koreanLanguage
}).render(document.getElementById("grid"));

포함된 Grid.js 고유 기능

  • 배열·객체 데이터와 열별 data 접근자
  • 검색, 다중 정렬, 사용자 비교 함수
  • 페이지 크기·요약·이동 버튼 설정
  • 열 formatter, attributes, hidden, width, sort
  • fixedHeader, height, autoWidth, resizable
  • 한국어 language, style, className
  • 비동기 data 함수, server.then 데이터 변환
  • from을 이용한 기존 HTML table 변환
  • updateConfig, forceRender, destroy

샘플에서 추가 구현한 기능

  • 체크박스 행 선택과 선택 행 일괄 작업
  • 추가·수정·삭제 모달과 상태 변경
  • 열 표시 패널과 외부 복합 필터
  • CSV·JSON 다운로드 및 다시 불러오기
  • 클립보드 복사, 인쇄, 다크 모드
