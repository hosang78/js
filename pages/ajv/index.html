Ajv 핵심 기능 둘러보기

Ajv는 JSON 스키마(데이터가 갖춰야 할 형식을 정의한 규칙)를 가지고 실제 데이터가 그 규칙을 만족하는지 검사해주는 라이브러리입니다. 폼 입력값 검증, API 응답 검증 등에 널리 쓰입니다.
  • ajv.compile(schema)로 스키마를 검증 함수로 미리 컴파일(빠른 반복 검증에 유리)
  • required, type, minimum/maximum, pattern, format 등으로 규칙 표현
  • 검증에 실패하면 validate.errors에 어떤 필드가 왜 틀렸는지 배열로 담김
  • $ref로 공통 하위 스키마를 여러 곳에서 재사용 가능
※ 아래 위판 신고서 데이터는 Ajv 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 신고 양식이 아닙니다. Ajv는 npm 패키지 자체에 브라우저용 번들이 없어(CommonJS 전용), jsdelivr의 ESM 변환 주소(/+esm)로 불러옵니다. 이메일·날짜 형식(format) 검증에는 Ajv 공식 애드온인 ajv-formats를 함께 사용합니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 스키마 검증

위판 신고서 스키마를 기준으로, 유효한 데이터와 잘못된 데이터를 각각 검증해봅니다.

    

    

      코드 보기
      
const schema = {
  type: 'object',
  properties: {
    reporterName: { type: 'string', minLength: 2 },
    marketCode: { type: 'string', pattern: '^[A-Z]{2}[0-9]{3}$' },
    quantity: { type: 'number', minimum: 0, maximum: 5000 },
    reportDate: { type: 'string', format: 'date' },
  },
  required: ['reporterName', 'marketCode', 'quantity', 'reportDate'],
  additionalProperties: false,
};

const validate = ajv.compile(schema);
const isValid = validate(data); // true / false
if (!isValid) console.log(validate.errors);

3. 에러 메시지를 한국어로 변환

    
validate.errors는 영어 메시지를 담고 있어서, 필드별 한국어 안내문으로 바꿔서 보여주는 예시입니다.

    

      
    

    
    
    
    
      코드 보기
      
    const KOREAN_MESSAGES = {
  'reporterName/minLength': '신고인 이름은 2글자 이상 입력해주세요.',
  'marketCode/pattern': '위판장 코드는 영문 2자+숫자 3자 형식입니다. (예: BS001)',
  'quantity/maximum': '위판량은 5,000kg을 넘을 수 없습니다.',
  'reportDate/format': '신고일은 날짜 형식(YYYY-MM-DD)이어야 합니다.',
};

validate.errors.forEach((e) => {
  const key = `${e.instancePath.replace('/', '')}/${e.keyword}`;
  console.log(KOREAN_MESSAGES[key] || e.message);
});
    
    
    
  
    

  
    
    
    4. $ref로 하위 스키마 재사용
    
    
    "품목" 스키마 하나를 정의해두고, 위판 품목 목록(배열)의 각 항목에서 $ref로 재사용합니다.
    
    
    
      
    
    
    
    
    
    
      코드 보기
      
    const itemSchema = {
  $id: 'wipanItem',
  type: 'object',
  properties: {
    species: { type: 'string', minLength: 1 },
    weight: { type: 'number', exclusiveMinimum: 0 },
  },
  required: ['species', 'weight'],
};

const listSchema = {
  type: 'array',
  items: { $ref: 'wipanItem' }, // 위에서 정의한 품목 스키마를 그대로 참조
};

ajv.addSchema(itemSchema);
const validateList = ajv.compile(listSchema);
validateList(items); // 배열의 각 원소가 itemSchema를 만족해야 함
