ELK.js 핵심 기능 둘러보기

ELK.js(Eclipse Layout Kernel)는 노드와 엣지의 좌표를 계산해주는 그래프 레이아웃 엔진입니다. 화면에 그려주지는 않고, "이 노드는 여기, 이 엣지는 이렇게 꺾여서 지나가라"는 좌표만 알려줍니다. 계산이 무거울 수 있어 내부적으로 Web Worker에서 비동기로 동작합니다.
  • 레이어드(layered) 알고리즘으로 방향성 있는 흐름을 단(layer)별로 배치
  • 직교(orthogonal) 엣지 라우팅 — 다른 노드를 피해 꺾어서 지나가는 선의 꺾임점(bend point)까지 계산
  • 노드 안에 노드가 들어가는 중첩(컴파운드) 그래프 배치
  • layered/mrtree/radial/force 등 여러 레이아웃 알고리즘 중 선택
※ 아래 유통 흐름도는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 유통 구조와 무관합니다. ELK.js는 좌표만 계산하므로 결과는 이 페이지에서 직접 그린 간단한 SVG로 표시합니다. ELK.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 레이어드 레이아웃

가상 위판장 유통 흐름입니다. ELK가 계산한 x, y 좌표를 그대로 SVG 사각형 위치에 사용합니다.
코드 보기 
const elk = new ELK();
const graph = {
  id: "root",
  layoutOptions: { "elk.algorithm": "layered", "elk.direction": "RIGHT" },
  children: [
    { id: "market1", width: 90, height: 34, labels: [{ text: "1번 위판장" }] },
    { id: "broker1", width: 90, height: 34, labels: [{ text: "중도매인 A" }] },
    // ...
  ],
  edges: [{ id: "e1", sources: ["market1"], targets: ["broker1"] }]
};

const result = await elk.layout(graph);
// result.children[i].x / .y 가 계산된 위치

2. 엣지 라우팅 (직교 라우팅 + 꺾임점)

같은 그래프를 직선 라우팅과 직교(orthogonal) 라우팅으로 각각 계산해봅니다. 빨간 선은 다른 노드를 피해 bendPoints(꺾임점)를 거쳐 돌아가는 경로입니다.
직선(POLYLINE) 라우팅 직교(ORTHOGONAL) 라우팅
코드 보기 
layoutOptions: { "elk.algorithm": "layered", "elk.edgeRouting": "ORTHOGONAL" }
// result.edges[i].sections[0].bendPoints 배열에 꺾임점 좌표가 담김

3. 중첩(컴파운드) 그래프

점선 박스가 하위 그래프를 담은 컴파운드 노드입니다. ELK가 그룹 크기까지 자동으로 계산합니다.
코드 보기 
{
  id: "group1",
  layoutOptions: { "elk.padding": "[top=34,left=12,bottom=12,right=12]" },
  labels: [{ text: "1번 위판장 소속" }],
  children: [
    { id: "member1", width: 70, height: 28, labels: [{ text: "조합원 A" }] },
    { id: "member2", width: 70, height: 28, labels: [{ text: "조합원 B" }] }
  ],
  edges: [{ id: "eg1", sources: ["member1"], targets: ["member2"] }]
}
// group1의 width/height는 자식 배치 결과에 맞춰 ELK가 자동으로 정함
//
// 주의: member2 → market2처럼 그룹 "안" 노드에서 그룹 "밖" 노드로
// 가는 엣지는 루트의 elk.hierarchyHandling: "INCLUDE_CHILDREN" 옵션을
// 켜야 sections(경로 좌표)가 계산됩니다. 꺼두면 sections이 비어있어
// 좌표를 읽으려다 에러가 납니다.

4. 레이아웃 알고리즘 비교

같은 그래프를 여러 내장 알고리즘으로 다시 계산해봅니다.
코드 보기 
graph.layoutOptions["elk.algorithm"] = "mrtree";
const result = await elk.layout(graph);
