Transformers.js

Transformers.js는 Hugging Face의 트랜스포머 모델을 서버 없이 브라우저 안에서 직접 실행하는 라이브러리입니다. 감정 분석, 문장 임베딩, 제로샷 분류, 질의응답 같은 실제 AI 모델 추론이 사용자의 기기(CPU, WebAssembly)에서 돌아가며, 입력한 텍스트는 어디로도 전송되지 않습니다.

  • pipeline(task, model) 한 줄로 사전학습 모델을 불러와 바로 추론
  • 모델 가중치는 최초 1회 Hugging Face Hub에서 내려받아 브라우저에 캐시됨 (이후 즉시 로딩)
  • 감정 분석·임베딩·제로샷 분류·질의응답 등 다양한 NLP 태스크를 동일한 API로 처리
  • 텍스트가 서버로 전송되지 않아 프라이버시에 유리 (완전히 클라이언트 사이드)
⚠️ 각 섹션의 버튼을 누르면 실제 사전학습 모델(섹션당 약 30~90MB)을 Hugging Face Hub에서 다운로드합니다. 최초 실행은 네트워크 속도에 따라 수 초~수십 초 걸릴 수 있고, 이후에는 브라우저 캐시(Cache API)로 즉시 로딩됩니다. 사용한 모델은 모두 영어 전용이라 예시 문장은 영어로 되어 있습니다 (다국어 모델도 존재하지만 크기가 더 큽니다). 이 페이지의 예시 문장·문맥은 Transformers.js 기능 설명을 위한 가상의 내용이며, 실제 수협중앙회의 통계·조직·절차와 무관합니다. 다른 외부 API는 사용하지 않았습니다 (Transformers.js 4.2.0을 CDN에서 로드, 모델 가중치만 Hugging Face Hub에서 받아옵니다).

1. 감정 분석 (Sentiment Analysis)

pipeline('sentiment-analysis')로 문장의 긍정/부정을 분류합니다. 위판 후기를 영어로 입력해보세요.

소스 코드 보기 
import { pipeline } from '@huggingface/transformers';

const classifier = await pipeline(
  'sentiment-analysis',
  'Xenova/distilbert-base-uncased-finetuned-sst-2-english'
);
const output = await classifier('I love transformers!');
// [{ label: 'POSITIVE', score: 0.999788761138916 }]

2. 문장 임베딩 + 의미 유사도

pipeline('feature-extraction')으로 문장을 숫자 벡터(임베딩)로 바꾸고, cos_sim()으로 두 문장이 의미적으로 얼마나 비슷한지 계산합니다. 단어가 달라도 의미가 비슷하면 유사도가 높게 나옵니다.

소스 코드 보기 
import { pipeline, cos_sim } from '@huggingface/transformers';

const extractor = await pipeline('feature-extraction', 'onnx-community/all-MiniLM-L6-v2-ONNX');
const a = await extractor('sentence A', { pooling: 'mean', normalize: true });
const b = await extractor('sentence B', { pooling: 'mean', normalize: true });
const similarity = cos_sim(a.tolist()[0], b.tolist()[0]); // -1 ~ 1

3. 제로샷 분류 (Zero-Shot Classification)

pipeline('zero-shot-classification')은 미리 정해진 카테고리로 학습되지 않은 모델도 "이 라벨들 중 어디에 가장 가까운가?"를 즉석에서 판단합니다. 라벨을 자유롭게 바꿔서 실험해보세요.

소스 코드 보기 
import { pipeline } from '@huggingface/transformers';

const classifier = await pipeline('zero-shot-classification', 'Xenova/mobilebert-uncased-mnli');
const text = 'My phone overheats every time I use the app.';
const labels = ['mobile app', 'billing', 'shipping', 'customer service'];
const output = await classifier(text, labels);
// { sequence: '...', labels: [...정렬됨], scores: [...] }

4. 질의응답 (Question Answering)

pipeline('question-answering')은 긴 지문(context) 안에서 질문에 대한 답을 직접 찾아냅니다. 별도의 정답 목록 없이, 지문 자체에서 답이 되는 구간을 추출합니다.

소스 코드 보기 
import { pipeline } from '@huggingface/transformers';

const answerer = await pipeline('question-answering', 'Xenova/distilbert-base-uncased-distilled-squad');
const question = 'Who was Jim Henson?';
const context = 'Jim Henson was a nice puppet.';
const output = await answerer(question, context);
// { answer: 'a nice puppet', score: 0.5768911502526741 }
