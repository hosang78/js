geotiff.js 핵심 기능 둘러보기

geotiff.js는 GeoTIFF 파일 — 각 픽셀이 값(고도·수온·수심 등)과 지리적 위치 정보를 함께 담고 있는 위성·항공 관측용 래스터 파일 포맷 — 을 브라우저에서 직접 읽는 라이브러리입니다.
  • GeoTIFF.fromArrayBuffer()로 파일을 열고, getWidth()/getBoundingBox()로 크기·좌표 범위 확인
  • readRasters()로 실제 픽셀 값 배열을 통째로 읽어옴
  • 읽어온 값을 색상으로 매핑해 <canvas>에 직접 시각화
  • 이미지의 좌표 범위(bbox)를 이용해 위경도 ↔ 픽셀 좌표를 서로 변환
※ 아래 예시에 쓰인 depth-sample.tif는 실제 해양 관측 자료가 아니라, 같은 geotiff.js의 writeArrayBuffer()로 직접 생성한 가상의 합성 수심 데이터입니다 (64×64 픽셀, 연안에서 먼바다로 갈수록 깊어지는 패턴 + 약간의 기복을 섞어 만듦). 좌표(부산 인근)도 가상의 예시이며 실제 위판장·해역 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. GeoTIFF 파일 열기 + 메타데이터 읽기

파일을 열어 이미지 크기, 좌표 범위(bbox), 해상도 등 메타데이터를 확인합니다.
아직 열지 않음
코드 보기 
const response = await fetch('depth-sample.tif');
const tiff = await GeoTIFF.fromArrayBuffer(await response.arrayBuffer());
const image = await tiff.getImage();

image.getWidth();         // 64
image.getBoundingBox();   // [minLon, minLat, maxLon, maxLat]
image.getResolution();    // [픽셀당 경도, 픽셀당 위도]

2. 픽셀(래스터) 값 읽기

readRasters()로 이미지 전체의 실제 값(이 예시에서는 가상의 수심, m)을 배열로 읽어옵니다.
아직 읽지 않음
코드 보기 
const rasters = await image.readRasters();
const band = rasters[0]; // 단일 밴드 (수심 값 배열)
Math.min(...band); // 최솟값
Math.max(...band); // 최댓값

3. Canvas에 시각화

읽어온 값을 색상 그라데이션으로 매핑해 canvas에 그립니다(진할수록 깊은 수심).
코드 보기 
const imgData = ctx.createImageData(width, height);
for (let i = 0; i < band.length; i++) {
  const t = (band[i] - min) / (max - min); // 0~1로 정규화
  imgData.data[i * 4 + 2] = Math.round(150 + t * 100); // 값이 클수록 더 진한 파랑
  imgData.data[i * 4 + 3] = 255;
}
ctx.putImageData(imgData, 0, 0);

4. 좌표 ↔ 픽셀 변환

위 3번 이미지를 클릭하면, 클릭한 지점의 위경도와 그 지점의 수심 값을 계산해서 보여줍니다.
이미지를 클릭해보세요
코드 보기 
const [minX, minY, maxX, maxY] = image.getBoundingBox();
const px = Math.floor(((lon - minX) / (maxX - minX)) * width);
const py = Math.floor(((maxY - lat) / (maxY - minY)) * height);
const depth = band[py * width + px];
