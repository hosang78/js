FlexSearch 핵심 기능 둘러보기

FlexSearch는 매우 빠른 전문(full-text) 검색 라이브러리입니다. 한글을 포함한 여러 문자셋을 지원하고, 완전 일치가 아니어도 결과를 찾아주는 기능이 특징입니다.
  • Index로 하는 부분 일치 실시간 검색
  • Document로 하는 여러 필드 검색 + 하이라이트
  • tag 옵션으로 하는 카테고리 필터
  • suggest 옵션으로 하는 제안 검색
※ 아래 위판 물품 목록은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 물품·통계와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 부분 일치 실시간 검색

tokenize: 'forward'로 만든 인덱스는 단어 앞부분만 입력해도 찾아줍니다. 타이핑할 때마다 바로 검색됩니다.
    소스 코드 보기 
    const index = new FlexSearch.Index({ tokenize: 'forward' });
index.add(0, '고등어 위판 안내');
index.add(1, '가상 수협중앙회 위판장');

index.search('위판'); // → [0, 1] ('forward' 토크나이저라 일부만 입력해도 매칭)

    2. 여러 필드를 가진 문서 검색 + 하이라이트

    Document는 이름·설명처럼 여러 필드를 한 번에 색인하고 검색할 수 있습니다. highlight 옵션으로 일치한 부분을 표시합니다.
      소스 코드 보기 
      const doc = new FlexSearch.Document({
  document: {
    id: 'id',
    index: ['name', 'description'], // 검색 대상 필드
    tag: 'category',
    store: true, // 원본 문서를 결과에 포함
  },
  tokenize: 'forward',
});
doc.add({ id: 1, name: '고등어', description: '가상 위판장에서 오늘 낙찰된 고등어', category: '어류' });

await doc.search('위판장', {
  enrich: true,
  highlight: '<mark>$1</mark>',
});

      3. 태그(카테고리)로 걸러보기

      tag 옵션에 { 필드명: 태그값 } 형태로 넘기면 검색어 없이도 해당 카테고리만 걸러볼 수 있습니다.
        소스 코드 보기 
        // 주의: tag 값은 문자열이 아니라 { 필드명: 태그값 } 객체로 줘야 한다.
// 문자열을 그대로 주면 글자 단위로 쪼개져서 잘못 매칭된다 (실제로 겪은 실수).
await doc.search('', {
  tag: { category: '어류' },
  enrich: true,
});

        4. 제안 검색 (suggest)

        기본 검색은 입력한 단어가 전부 포함돼야 결과가 나옵니다. suggest: true를 켜면 일부만 일치해도 가까운 결과를 보여줍니다.
          소스 코드 보기 
          const index = new FlexSearch.Index({ tokenize: 'forward' });
index.add(0, '고등어 갈치 오징어');

index.search('고등어 상어');                    // → [] ('상어'가 없어서 실패)
index.search('고등어 상어', { suggest: true });  // → [0] ('고등어'만 일치해도 제안)
