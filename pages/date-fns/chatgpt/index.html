핵심 주의사항

불변성대부분 원본 Date를 수정하지 않고 새 Date를 반환
시간대일반 Date는 실행 환경의 로컬 시간대 영향을 받음
날짜 전용 문자열2026-07-12 파싱 방식은 함수와 브라우저 해석 차이를 확인
월 인덱스네이티브 Date 생성자의 월은 0부터 시작하지만 date-fns 포맷 월은 1~12 표현
공휴일addBusinessDays는 법정공휴일 데이터까지 자동 반영하지 않음
대용량 인터벌매초·매분 배열 생성 시 범위를 제한해 메모리 사용량 관리
npm / ESM 사용 예
npm install date-fns @date-fns/tz

import { format, addDays, isSameDay } from "date-fns";
import { ko } from "date-fns/locale";
import { TZDate, tz } from "@date-fns/tz";

const tomorrow = addDays(new Date(), 1);
console.log(format(tomorrow, "PPP", { locale: ko }));

const seoul = new TZDate("2026-07-12T09:00:00Z", "Asia/Seoul");
const sameInSeoul = isSameDay(dateA, dateB, { in: tz("Asia/Seoul") });
