date-fns 핵심 기능 둘러보기

date-fns는 날짜를 다루는 함수들을 각각 독립된 순수 함수로 제공하는 라이브러리입니다. Day.js처럼 객체를 만들어 메서드를 체이닝하는 대신, 평범한 자바스크립트 Date 객체를 함수에 직접 넣고 꺼내 쓰는 방식입니다.
  • format(date, 'yyyy-MM-dd')처럼 함수에 Date를 직접 넘겨서 사용
  • 모든 함수는 원본 Date를 바꾸지 않고 항상 새 값을 반환(불변성)
  • 날짜 구간(interval)을 다루는 eachDayOfInterval, isWithinInterval 같은 함수 내장
  • 로케일은 Day.js처럼 전역 설정이 아니라, 함수를 호출할 때마다 옵션으로 넘김
※ 아래 위판 일정/이력 데이터는 date-fns 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 일정이 아닙니다. 이 페이지는 date-fns(CDN, 공식 @date-fns/cdn 배포판) 하나만 사용하고(한국어 로케일 파일도 같은 배포판의 일부입니다) 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 포맷팅 · 파싱

지금 이 순간을 여러 형식으로 표현하고, 문자열을 날짜로 파싱해봅니다.
코드 보기 
dateFns.format(new Date(), 'yyyy-MM-dd');                     // 2026-07-12
dateFns.format(new Date(), 'yyyy년 MM월 dd일 EEEE', { locale: dateFns.locale.ko });
dateFns.isValid(dateFns.parseISO('2026-07-15'));               // true
dateFns.isValid(dateFns.parseISO('이상한문자열'));               // false

2. 순수 함수 날짜 연산 (add · sub · differenceInCalendarDays)

모든 계산 함수는 원본을 바꾸지 않고 새 Date를 반환합니다. 원본 위판 예정일을 그대로 둔 채 연산 결과만 확인해보세요.
기준일부터 일 후는?
시작일 종료일
두 날짜를 고르고 버튼을 눌러보세요.
코드 보기 
const base = new Date('2026-07-12');
const later = dateFns.add(base, { days: 7 });

base.getDate();  // 12 — base는 그대로
later.getDate(); // 19 — later는 새 객체

dateFns.differenceInCalendarDays(
  new Date('2026-08-01'),
  new Date('2026-07-12'),
); // 달력 기준 날짜 차이

3. 구간(Interval) 다루기

이번 위판 주간(월~금)의 날짜를 eachDayOfInterval로 나열하고, 특정 날짜가 그 구간에 포함되는지 isWithinInterval로 확인합니다.
확인할 날짜
날짜를 고르고 버튼을 눌러보세요.
코드 보기 
const week = { start: new Date('2026-07-13'), end: new Date('2026-07-17') };

dateFns.eachDayOfInterval(week); // 구간에 속한 모든 날짜 배열

dateFns.isWithinInterval(new Date('2026-07-15'), week); // true
dateFns.isWithinInterval(new Date('2026-07-19'), week); // false

4. 상대 시간 · 로케일 옵션

Day.js는 dayjs.locale('ko')로 로케일을 전역으로 바꾸지만, date-fns는 함수를 호출할 때마다 { locale: dateFns.locale.ko } 옵션을 넘깁니다. 같은 시각을 로케일만 바꿔 나란히 비교해봅니다.

기본(영어) 로케일

한국어 로케일 옵션

코드 보기 
dateFns.formatDistanceToNow(target, { addSuffix: true });                              // "3 hours ago"
dateFns.formatDistanceToNow(target, { addSuffix: true, locale: dateFns.locale.ko });    // "3시간 전"
