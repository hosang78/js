EditorState
문서, 선택 영역, Facet, StateField를 보관하는 불변 상태 객체

          
Transaction
문서 변경, 선택 변경, 효과를 하나의 상태 전이로 전달하는 단위

          
Compartment
편집기를 다시 만들지 않고 언어·테마·옵션을 재구성하는 확장 구획

          
ViewPlugin
DOM 장식, 이벤트 반응, 툴팁 등 화면 동작을 추가하는 확장 방식

기능단축키설명

            
              
검색 / 치환Ctrl + F / Ctrl + H검색 패널 열기 및 치환 모드

              
다음 검색 결과F3다음 일치 항목으로 이동

              
줄 이동Alt + G지정한 줄 번호로 이동

              
자동완성Ctrl + Space현재 위치의 완성 목록 표시

              
실행 취소 / 다시 실행Ctrl + Z / Ctrl + Y편집 이력 이동

              
줄 주석Ctrl + /언어별 주석 토큰 사용

              
들여쓰기Tab / Shift + Tab선택 영역 들여쓰기·내어쓰기

              
코드 접기Ctrl + Shift + [현재 구문 블록 접기

              
다중 선택Ctrl + 클릭여러 커서 또는 선택 영역 생성

              
사각 선택Alt + 드래그열 기준 직사각형 선택
