CodeMirror 핵심 기능 둘러보기

CodeMirror(6버전)는 웹페이지 안에 문법 강조·자동 들여쓰기·괄호 매칭 같은 기능을 갖춘 코드 에디터를 넣을 수 있게 해주는 라이브러리입니다. VSCode의 웹 버전 등에서도 비슷한 기술이 쓰입니다.
  • new EditorView({ doc, extensions, parent })로 에디터 생성
  • javascript(), html(), sql() 같은 언어별 확장을 넣으면 그 언어에 맞는 문법 강조
  • Compartment로 언어·테마 같은 설정을 나중에 동적으로 교체 가능
  • EditorView.updateListener로 에디터 내용이 바뀔 때마다 실시간으로 감지
※ CodeMirror 6는 npm 패키지 자체에 브라우저용 번들이 없습니다(ESM 전용, codemirror + @codemirror/lang-* + @codemirror/theme-one-dark 등 여러 패키지로 나뉘어 있음). CDN의 ESM 변환 주소(/+esm)로 이 패키지들을 각각 따로 불러와보면 "multiple instances of @codemirror/state are loaded" 에러로 실제로 깨지는 것을 확인했습니다 (여러 패키지가 내부적으로 공유해야 하는 @codemirror/state를 패키지별로 따로 번들링해서 벌어지는 문제입니다). 그래서 이 페이지는 필요한 패키지들을 한 번에 올바르게 묶어 만든 번들 파일 (codemirror-bundle.esm.js, 같은 CDN 배포 버전으로 직접 빌드)을 함께 담아 사용합니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 에디터 + 상태 읽기

줄 번호, 괄호 자동 매칭, 실행 취소(Ctrl/Cmd+Z) 같은 기본 기능이 포함된 basicSetup으로 만든 에디터입니다. 코드를 수정한 뒤 버튼을 눌러 현재 내용을 읽어와 보세요.
아직 읽지 않음
코드 보기 
import { EditorView, basicSetup } from 'codemirror';
import { javascript } from '@codemirror/lang-javascript';

const view = new EditorView({
  doc: "const total = records.reduce((sum, r) => sum + r.weight, 0);",
  extensions: [basicSetup, javascript()],
  parent: document.getElementById('editor1'),
});

readBtn.addEventListener('click', () => {
  output.textContent = view.state.doc.toString();
});

2. 언어 모드 전환

버튼을 누르면 에디터의 언어 모드와 예시 코드가 함께 바뀝니다. Compartment를 이용해 이미 만들어진 에디터의 설정을 나중에 바꾸는 방식입니다.
코드 보기 
const langCompartment = new Compartment();
const view = new EditorView({
  extensions: [basicSetup, langCompartment.of(javascript())],
  parent: el,
});

langBtn.addEventListener('click', () => {
  view.dispatch({ effects: langCompartment.reconfigure(html()) });
});

3. 다크 테마

버튼으로 @codemirror/theme-one-dark 테마를 켜고 끕니다.
코드 보기 
import { oneDark } from '@codemirror/theme-one-dark';

const themeCompartment = new Compartment();
// 처음엔 빈 확장([])으로 시작
extensions: [basicSetup, themeCompartment.of([])]

themeBtn.addEventListener('click', () => {
  darkOn = !darkOn;
  view.dispatch({ effects: themeCompartment.reconfigure(darkOn ? oneDark : []) });
});

4. 실시간 글자수 감시 + 읽기 전용 토글

타이핑할 때마다 글자수·줄 수가 실시간으로 갱신됩니다. "읽기 전용" 버튼을 누르면 더 이상 편집할 수 없습니다.
글자수: 0 · 줄 수: 1
코드 보기 
const view = new EditorView({
  extensions: [
    basicSetup,
    javascript(),
    EditorView.updateListener.of((update) => {
      if (update.docChanged) {
        const doc = update.state.doc;
        stats.textContent = `글자수: ${doc.length} · 줄 수: ${doc.lines}`;
      }
    }),
    readOnlyCompartment.of(EditorView.editable.of(true)),
  ],
});

readOnlyBtn.addEventListener('click', () => {
  isReadOnly = !isReadOnly;
  view.dispatch({ effects: readOnlyCompartment.reconfigure(EditorView.editable.of(!isReadOnly)) });
});
