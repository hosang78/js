Immer

Immer는 "직접 값을 바꾸는 것처럼" 코드를 쓰면, 실제로는 원본을 건드리지 않고 새로운 불변 객체를 만들어주는 라이브러리입니다. {...state, a: {...state.a, x: 1}}처럼 번거로운 스프레드 중첩 없이, draft.a.x = 1이라고 그냥 쓰면 됩니다.

  • produce(state, recipe) — recipe 안에서 draft를 자유롭게 mutate
  • 바뀌지 않은 하위 트리는 참조가 그대로 유지되는 구조적 공유(structural sharing)
  • 커링된 produce(recipe)로 재사용 가능한 업데이트 함수 생성
  • produceWithPatches로 변경 내역을 JSON Patch 형태로 추출 (실행 취소 등에 활용)
💡 확인된 동작: jsdelivr의 dist/immer.mjs(개발용 ESM 빌드)를 번들러 없이 브라우저에 그냥 <script type="module">로 로드하면 ReferenceError: process is not defined로 즉시 깨집니다 — 코드 안에 process.env.NODE_ENV 체크가 그대로 남아있기 때문입니다(브라우저엔 process가 없음). 번들러 없이 CDN에서 직접 쓸 때는 반드시 dist/immer.production.mjs를 명시해서 불러와야 합니다. 이 페이지도 그렇게 로드합니다.
⚠️ 이 페이지의 위판 데이터는 Immer 기능 설명을 위한 가상의 예시이며, 실제 수협중앙회의 통계·조직·절차와 무관합니다. 다른 외부 API는 사용하지 않았습니다 (Immer 11.1.15를 CDN에서 로드).

1. 기본 produce() — mutate처럼 쓰고 불변 업데이트 받기

recipe 함수의 매개변수 draft는 실제 프록시 객체입니다. 여기에 값을 직접 대입해도 원본(baseState)은 전혀 바뀌지 않고, produce()가 새 객체를 반환합니다.

원본 baseState.kg
120
produce() 결과 nextState.kg
120
baseState === nextState ?
-
소스 코드 보기 
import { produce } from 'immer';

const baseState = { kg: 120, name: '고등어' };
const nextState = produce(baseState, (draft) => {
  draft.kg = 150; // 직접 대입하는 것처럼 쓴다
});

baseState.kg;              // 120 (그대로)
nextState.kg;               // 150
baseState === nextState;    // false (완전히 다른 객체)

2. 구조적 공유 (Structural Sharing)

깊이 중첩된 상태에서 실제로 바뀐 경로의 객체만 새로 만들어지고, 건드리지 않은 형제 브랜치는 이전 참조 그대로 재사용됩니다. 이 덕분에 React 같은 프레임워크의 얕은 비교(===) 최적화가 잘 작동합니다.

state.auction (바뀐 브랜치)
-
state.weather (안 건드린 브랜치)
-
소스 코드 보기 
const state = {
  auction: { items: [{ name: '고등어', kg: 120 }] },
  weather: { temp: 24, condition: 'sunny' }, // 이번엔 건드리지 않음
};

const next = produce(state, (draft) => {
  draft.auction.items[0].kg = 150;
});

next.auction !== state.auction;   // true  — 바뀐 경로는 새 객체
next.weather === state.weather;   // true  — 안 바뀐 브랜치는 참조 그대로!

3. 커링된 produce(recipe) — 재사용 가능한 업데이트 함수

produce(recipe)처럼 state 없이 recipe만 주면, 나중에 (state, ...args)로 호출할 수 있는 재사용 가능한 업데이트 함수가 만들어집니다. Redux reducer 패턴과 잘 어울립니다.

품목중량(kg)
소스 코드 보기 
// state 없이 recipe만 넘기면 재사용 가능한 함수가 반환됨
const addWeight = produce((draft, amount) => {
  draft.kg += amount;
});

const item1 = { name: '갈치', kg: 85 };
const item2 = { name: '오징어', kg: 60 };
addWeight(item1, 10); // { name: '갈치', kg: 95 } — 새 객체
addWeight(item2, 10); // { name: '오징어', kg: 70 } — 같은 함수를 재사용

4. produceWithPatches + applyPatches — 실행 취소(Undo)

produceWithPatches는 새 상태와 함께 "무엇이 바뀌었는지"를 JSON Patch 배열로, 그리고 되돌리기용 역패치(inverse patches)도 함께 돌려줍니다. 이걸로 실행 취소 기능을 간단히 구현할 수 있습니다.

현재 kg당 단가
8,000원
소스 코드 보기 
import { produceWithPatches, applyPatches, enablePatches } from 'immer';
enablePatches(); // 패치 기능은 명시적으로 켜야 함 (Map/Set과 마찬가지 패턴)

const [next, patches, inversePatches] = produceWithPatches(state, (draft) => {
  draft.price += 1000;
});
// patches:        [{ op: 'replace', path: ['price'], value: 9000 }]
// inversePatches: [{ op: 'replace', path: ['price'], value: 8000 }]

const undone = applyPatches(next, inversePatches); // 되돌리기

5. Map 지원 — enableMapSet()

기본적으로 Immer는 일반 객체·배열만 지원합니다. enableMapSet()을 호출하면 Map/Set에도 draft.set()/draft.delete() 같은 네이티브 메서드를 그대로 쓰면서 불변 업데이트를 받을 수 있습니다.

품목중량(kg)
소스 코드 보기 
import { produce, enableMapSet } from 'immer';
enableMapSet();

const state = new Map([['고등어', 120], ['갈치', 85]]);
const next = produce(state, (draft) => {
  draft.set('오징어', 60);   // Map의 네이티브 메서드를 그대로 사용
  draft.delete('갈치');
});

state.has('갈치');   // true (원본은 그대로)
next.has('갈치');    // false
state !== next;      // true
