Cropper.js 핵심 기능 둘러보기

Cropper.js는 이미지 위에 크롭(잘라내기) 영역을 올려두고, 마우스로 옮기거나 크기를 조절해서 원하는 부분만 잘라낼 수 있게 해주는 라이브러리입니다. v2부터는 <cropper-canvas>, <cropper-image>, <cropper-selection> 같은 커스텀 엘리먼트(태그) 조합으로 동작합니다.
  • 크롭 영역을 마우스로 드래그해서 옮기거나, 모서리를 끌어 크기 조절
  • aspect-ratio 속성으로 정사각형·4:3 같은 비율을 고정
  • 이미지 자체를 회전·확대축소·좌우반전 (크롭 영역과는 별개로 동작)
  • selection.$toCanvas()로 크롭된 부분만 새 캔버스로 뽑아내기
※ 아래 크롭 대상 이미지는 실제 사진이 아니라 이 페이지에서 직접 그린 가상의 위판장 일러스트(SVG)입니다. 이 페이지는 Cropper.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 자유 영역 크롭 + 결과 내보내기

파란 영역을 드래그해서 옮기거나 모서리를 끌어 크기를 바꾼 뒤, "잘라내기" 버튼을 눌러보세요.

잘라낸 결과

아직 없음
코드 보기 
// HTML: cropper-canvas 안에 cropper-image + cropper-selection을 배치

const selection = document.getElementById('sel1');
document.getElementById('cropBtn1').addEventListener('click', async () => {
  const canvas = await selection.$toCanvas(); // 선택 영역만 새 캔버스로 추출
  resultEl.innerHTML = '';
  resultEl.appendChild(canvas);
});

2. 비율 고정 크롭

비율을 고르면 크롭 영역이 그 비율로 고정된 채로만 크기가 바뀝니다.

비율

코드 보기 
document.getElementById('ratioSelect').addEventListener('change', (e) => {
  selection.setAttribute('aspect-ratio', e.target.value); // 'NaN'이면 자유 비율
});

3. 회전 · 확대축소 · 좌우반전

이미지 자체를 돌리거나 뒤집어봅니다. 크롭 영역의 위치는 그대로 두고 이미지만 움직입니다.

이미지 조작

코드 보기 
const image = document.getElementById('img3');
rotateBtn.addEventListener('click', () => image.$rotate('90deg'));
flipBtn.addEventListener('click', () => { flipped = !flipped; image.$scale(flipped ? -1 : 1, 1); });
zoomInBtn.addEventListener('click', () => image.$zoom(0.1));
zoomOutBtn.addEventListener('click', () => image.$zoom(-0.1));
resetBtn.addEventListener('click', () => image.$resetTransform());

4. 실시간 미리보기 + 다운로드

크롭 영역을 움직이는 즉시 오른쪽 미리보기가 갱신됩니다. "다운로드"를 누르면 잘라낸 이미지를 PNG 파일로 저장합니다.

코드 보기 
let pending = false;
selection.addEventListener('change', () => {
  if (pending) return;
  pending = true;
  requestAnimationFrame(async () => {
    const canvas = await selection.$toCanvas({ width: 160 });
    preview.innerHTML = '';
    preview.appendChild(canvas);
    pending = false;
  });
});

downloadBtn.addEventListener('click', async () => {
  const canvas = await selection.$toCanvas();
  const a = document.createElement('a');
  a.href = canvas.toDataURL('image/png');
  a.download = 'wipan-crop.png'; // 한글 파일명은 브라우저에서 깨질 수 있어 영문으로 지정
  a.click();
});
