Shepherd.js 핵심 기능 둘러보기

Shepherd.js는 화면 요소를 하나씩 짚어가며 사용법을 안내하는 "가이드 투어"를 만들어주는 라이브러리입니다. 특정 요소 옆에 말풍선을 붙이고, 다음/이전 버튼으로 단계를 넘기며, 필요하면 나머지 화면을 어둡게 가려 지금 볼 곳에 집중시킬 수 있습니다.
  • next/back 버튼이 있는 기본 가이드 투어
  • attachTo로 요소 위·아래·좌·우에 화살표 붙이기
  • useModalOverlay로 나머지 화면을 어둡게 막는 모달 오버레이
  • 이벤트로 만드는 진행 상황 표시(N / 전체 단계)
※ 아래 대시보드 화면은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 가이드 투어

버튼을 누르면 모의 대시보드의 메뉴 → 시세 차트 → 새로고침 버튼 순서로 안내하는 4단계 투어가 시작됩니다. 각 단계에서 "다음"·"이전"·"건너뛰기"로 이동할 수 있습니다.
위판 현황
정산 내역
조합원 명부
오늘 시세 차트
코드 보기 
const tour = new Shepherd.Tour({
  defaultStepOptions: {
    cancelIcon: { enabled: true },
    classes: 'shepherd-theme-custom',
  },
});

tour.addStep({
  title: '1. 메뉴',
  text: '왼쪽 메뉴에서 지금 보고 있는 화면을 확인할 수 있습니다.',
  attachTo: { element: '#s1-menu', on: 'right' },
  buttons: [{ text: '다음', action: tour.next }],
});
// ...나머지 단계도 attachTo + buttons로 이어붙인다
tour.start();

2. attachTo로 화살표 위치 지정

가운데 카드를 기준으로 위·아래·좌·우 카드에 각각 다른 방향으로 화살표가 붙는 투어입니다. attachTo.on 값만 바꾸면 화살표 방향이 자동으로 바뀝니다.
위
왼쪽
중심
오른쪽
아래
코드 보기 
tour.addStep({ text: '위쪽 카드', attachTo: { element: '#s2-top', on: 'bottom' } });
tour.addStep({ text: '오른쪽 카드', attachTo: { element: '#s2-right', on: 'left' } });
tour.addStep({ text: '아래쪽 카드', attachTo: { element: '#s2-bottom', on: 'top' } });
tour.addStep({ text: '왼쪽 카드', attachTo: { element: '#s2-left', on: 'right' } });

3. 모달 오버레이

useModalOverlay: true를 켜면 지금 안내 중인 요소만 밝게 뚫려 보이고 나머지 화면은 어둡게 가려져서 클릭이 막힙니다.
코드 보기 
const tour = new Shepherd.Tour({
  useModalOverlay: true,
  defaultStepOptions: { cancelIcon: { enabled: true } },
});
tour.addStep({
  text: '이 버튼만 밝게 뚫려 보이고, 나머지 화면은 어둡게 가려집니다.',
  attachTo: { element: '#s3-save', on: 'bottom' },
});

4. 이벤트로 만드는 진행 상황 표시

tour.on('show', ...)로 지금 몇 번째 단계인지 계산해서 진행률 박스에 표시하고, complete/cancel 이벤트로 종료 상태를 구분해서 보여줍니다.
투어를 시작하면 진행 상황이 여기에 표시됩니다.
코드 보기 
let stepIndex = 0;
tour.on('show', () => {
  stepIndex = tour.steps.indexOf(tour.getCurrentStep());
  stat.innerHTML = `진행 상황: ${stepIndex + 1} / ${tour.steps.length}`;
});
tour.on('complete', () => { stat.textContent = '투어를 모두 완료했습니다.'; });
tour.on('cancel', () => { stat.textContent = '투어를 중간에 닫았습니다.'; });
