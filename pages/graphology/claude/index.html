Graphology 핵심 기능 둘러보기

Graphology는 그래프(노드+엣지) 데이터를 다루기 위한 자료구조·API 라이브러리입니다. 그림을 그려주진 않고, 노드·엣지를 만들고 탐색하고 계산하는 "데이터 레이어"를 담당합니다.
  • 노드·엣지 생성/수정/삭제, 속성(attribute) 관리
  • neighbors(), degree() 등으로 그래프 순회·질의
  • 그래프 API 위에서 직접 구현한 너비 우선 탐색(BFS) 최단 경로
  • export() / import()로 그래프를 JSON으로 저장·복원
※ 아래 유통 네트워크는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 유통 구조와 무관합니다. 그래프는 별도 렌더링 라이브러리 없이 이 페이지에서 직접 그린 간단한 SVG로 표시합니다(WebGL 렌더링이 궁금하다면 같은 개발팀의 Sigma.js 페이지를 참고하세요). Graphology(CDN) 하나만 사용하고 다른 외부 API는 사용하지 않습니다.

1. 그래프 생성/조작

노드·엣지를 추가/삭제하고 이름(속성)을 바꿔봅니다.
—
코드 보기 
const graph = new graphology.Graph();
graph.addNode("market1", { label: "1번 위판장" });
graph.addNode("market2", { label: "2번 위판장" });

graph.setNodeAttribute("market1", "label", "새 이름");

3. 최단 경로 탐색 (BFS)

출발/도착 노드를 고르면 neighbors()만으로 직접 구현한 너비 우선 탐색으로 최단 경로를 찾아 강조합니다.
→
출발/도착 노드를 고르고 버튼을 눌러보세요.
코드 보기 
function shortestPath(graph, start, end) {
  const queue = [start];
  const visited = new Set([start]);
  const parent = new Map();

  while (queue.length) {
    const current = queue.shift();
    if (current === end) break;
    graph.forEachNeighbor(current, (neighbor) => {
      if (!visited.has(neighbor)) {
        visited.add(neighbor);
        parent.set(neighbor, current);
        queue.push(neighbor);
      }
    });
  }

  if (!visited.has(end)) return null; // 경로 없음
  const path = [end];
  while (path[path.length - 1] !== start) path.push(parent.get(path[path.length - 1]));
  return path.reverse();
}
