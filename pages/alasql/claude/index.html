AlaSQL 핵심 기능 둘러보기

AlaSQL은 자바스크립트 배열이나 객체를 대상으로 진짜 SQL 문을 실행할 수 있게 해주는 인메모리 SQL 엔진입니다. 서버나 별도 DB 없이, 브라우저 안에서 SELECT· JOIN·GROUP BY는 물론 CREATE TABLE 같은 DDL 문까지 쓸 수 있습니다.
  • SELECT ... WHERE ... ORDER BY로 배열 조회·필터링·정렬
  • GROUP BY + SUM/AVG/COUNT로 하는 그룹별 집계
  • JOIN으로 하는 테이블 병합
  • CREATE TABLE + INSERT + UPDATE로 만드는 실제 인메모리 테이블
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. AlaSQL(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. SELECT + WHERE + ORDER BY

자바스크립트 배열을 ? 파라미터로 그대로 SQL에 넘겨서, 수량이 500건 이상인 기록만 수량 내림차순으로 조회했습니다.
코드 보기 
const records = [ /* 위판장, 어종, 수량, 단가로 이뤄진 배열 */ ];

const rows = alasql(
  'SELECT market, species, qty, price FROM ? WHERE qty >= 500 ORDER BY qty DESC',
  [records]
);

2. GROUP BY + 집계 함수

위판장별로 묶어서 총 위판량·평균 단가·기록 건수를 SQL의 GROUP BY로 계산했습니다.
코드 보기 
const rows = alasql(`
  SELECT market, SUM(qty) AS totalQty, AVG(price) AS avgPrice, COUNT(*) AS n
  FROM ?
  GROUP BY market
`, [records]);

3. JOIN

위판 기록 테이블과 위판장-지역 매핑 테이블을 market 열 기준으로 조인했습니다. 두 배열 모두 파라미터(?)로 넘길 수 있습니다.
코드 보기 
const regions = [
  { market: 'A위판장', region: '동해' },
  { market: 'B위판장', region: '서해' },
  { market: 'C위판장', region: '남해' },
];

const rows = alasql(`
  SELECT r.market, r.species, r.qty, g.region
  FROM ? r JOIN ? g ON r.market = g.market
`, [records, regions]);

4. CREATE TABLE + INSERT + UPDATE

배열을 즉석에서 조회하는 것을 넘어, CREATE TABLE로 진짜 인메모리 테이블을 만들고 INSERT·UPDATE까지 실행했습니다. 고등어 기록은 재조사로 수량이 100건씩 늘어난 것으로 갱신했습니다.
코드 보기 
alasql('CREATE TABLE catch (market STRING, species STRING, qty NUMBER)');
alasql('INSERT INTO catch VALUES (?,?,?)', ['D위판장', '전어', 400]);
alasql('INSERT INTO catch SELECT market, species, qty FROM ?', [records]);
alasql('UPDATE catch SET qty = qty + 100 WHERE species = ?', ['고등어']);

const rows = alasql('SELECT * FROM catch ORDER BY qty DESC');
