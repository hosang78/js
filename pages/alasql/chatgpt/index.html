AlaSQL Feature Lab

브라우저에서 SQL로 JavaScript 배열·JSON·메모리 테이블을 조회하고, 조인·집계·서브쿼리·집합 연산·데이터 변경·CSV/JSON/XLSX 입출력·사용자 정의 함수·쿼리 성능을 직접 시험하는 단일 HTML 샘플.

라이브러리 확인 중

1. 자유 SQL 콘솔

현재 메모리 DB의 employees, departments, sales 테이블을 대상으로 직접 SQL 실행

2. 현재 DB 상태

테이블 행 수와 라이브러리 버전

3. JavaScript 배열 직접 조회

FROM ? 매개변수로 별도 테이블 생성 없이 객체 배열 질의

4. JOIN

INNER, LEFT, 다중 테이블 조인

5. 집계·그룹

COUNT, SUM, AVG, MIN, MAX, HAVING, CASE

6. ROLLUP·CUBE

다차원 소계 및 총계 생성

7. 서브쿼리·CTE

스칼라/IN 서브쿼리 및 WITH 공통 테이블 식

8. 집합 연산

UNION, UNION ALL, EXCEPT, INTERSECT 지원 확인

9. 윈도 함수

ROW_NUMBER, RANK, DENSE_RANK 및 누적 합계

10. DDL·DML 데이터 편집

CREATE TABLE, INSERT, UPDATE, DELETE, 트랜잭션 유사 흐름 테스트

11. 함수·문자열·날짜

문자열, 숫자, 날짜 함수 및 사용자 정의 함수

12. CSV 가져오기

CSV 파일을 선택하거나 내장 샘플 CSV 파싱

13. JSON 가져오기

JSON 배열 파일을 읽어 SQL로 분석

14. XLSX 가져오기

SheetJS와 연계하여 첫 시트 데이터를 객체 배열로 변환 후 조회

15. 파일 내보내기

조회 결과를 CSV, JSON, XLSX로 다운로드
브라우저 보안 정책상 다운로드는 사용자 버튼 클릭으로 실행됨. XLSX는 SheetJS 로드 필요.

16. 데이터 피벗

조건부 집계로 부서·분기별 매출 피벗 테이블 구성

17. 데이터 품질 점검

NULL, 중복, 범위 이상치 탐지 SQL

18. 쿼리 컴파일·재사용

alasql.compile()로 반복 실행 함수 생성

19. 대용량 성능 테스트

가상 데이터 생성 후 필터·그룹 집계 시간 측정

20. 오류 처리

잘못된 SQL을 안전하게 포착하고 메시지 표시

포함 기능 요약

이 페이지에서 즉시 시험 가능한 범위
