1. 추진 개요

docx.js는 JavaScript 또는 TypeScript로 OOXML 기반 Word 문서를 생성하는 오픈소스 라이브러리다.

2. 기능별 적용 예시

기능적용 예시상태
문단·텍스트굵게, 색상, 강조, 정렬포함
표·셀 병합업무현황 및 일정표포함
머리말·꼬리말문서번호, 페이지 번호포함
docx.js 기능 시연 문서1 / N
화면 미리보기는 구조 확인용이며 실제 Word의 줄바꿈·목차·페이지 수와 차이가 있을 수 있음
OUTPUT

생성 결과

아직 생성된 문서가 없음
Word 필드 업데이트
목차·페이지 참조가 비어 보이면 Word에서 전체 선택(Ctrl+A) 후 F9를 눌러 필드를 업데이트해야 함.
PRIVACY

처리 방식

입력한 텍스트와 이미지는 현재 브라우저 메모리에서 DOCX 압축 파일로 만들어지며 별도 서버로 업로드하지 않음. 단, 라이브러리 파일은 최초 실행 시 jsDelivr CDN에서 불러옴.
COMPATIBILITY

권장 환경

Chrome·Edge 최신 버전, Microsoft Word 또는 LibreOffice에서 확인 권장. 웹뷰나 일부 모바일 브라우저에서는 파일 저장 동작이 제한될 수 있음.
