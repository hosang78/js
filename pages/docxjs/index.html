docx.js 핵심 기능 둘러보기

docx.js(npm 패키지 이름은 docx)는 Microsoft Word(.docx) 파일을 브라우저나 Node.js에서 코드로 직접 만들 수 있게 해주는 라이브러리입니다. 서버 없이, 지금 이 페이지의 자바스크립트만으로 진짜 .docx 파일을 생성해서 다운로드합니다.
  • Paragraph, TextRun으로 문단과 굵게·기울임 같은 글자 서식 표현
  • Table/TableRow/TableCell로 표 삽입
  • bullet: { level: 0 }로 글머리 기호 목록, alignment로 정렬 지정
  • Packer.toBlob(doc)로 완성된 문서를 브라우저에서 바로 파일로 내보내기
※ 아래에서 만들어지는 위판 보고서는 docx.js 학습용 가상의 샘플이며, 실제 수협중앙회의 보고서 양식이 아닙니다. 이 페이지는 docx.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 제목 · 문단 · 텍스트 서식

제목과, 굵게·기울임·밑줄이 섞인 문단이 있는 문서를 만들어 다운로드합니다.
코드 보기 
const { Document, Paragraph, TextRun, HeadingLevel, Packer } = docx;

const doc = new Document({
  sections: [{
    children: [
      new Paragraph({ text: '위판 실적 보고서', heading: HeadingLevel.HEADING_1 }),
      new Paragraph({
        children: [
          new TextRun('작성일: 2026-07-13, 작성자: '),
          new TextRun({ text: '김수협', bold: true }),
          new TextRun({ text: ' (검수 담당)', italics: true }),
        ],
      }),
    ],
  }],
});

const blob = await Packer.toBlob(doc);

2. 표 삽입

위판 실적을 표로 정리한 문서를 만들어 다운로드합니다.
코드 보기 
const { Table, TableRow, TableCell, Paragraph, WidthType } = docx;

function cell(text) {
  return new TableCell({ children: [new Paragraph(text)] });
}

const table = new Table({
  width: { size: 100, type: WidthType.PERCENTAGE },
  rows: [
    new TableRow({ children: [cell('어종'), cell('중량(kg)'), cell('단가(원/kg)')] }),
    new TableRow({ children: [cell('고등어'), cell('320'), cell('3,200')] }),
    new TableRow({ children: [cell('갈치'), cell('180'), cell('8,500')] }),
  ],
});

3. 글머리 기호 목록 · 정렬

주의사항을 글머리 기호 목록으로, 안내 문구는 가운데 정렬로 넣은 문서를 만듭니다.
코드 보기 
const { Paragraph, AlignmentType } = docx;

new Paragraph({ text: '위판 등록 전 중량을 반드시 확인하세요.', bullet: { level: 0 } });
new Paragraph({ text: '어종 표기는 표준 명칭을 사용하세요.', bullet: { level: 0 } });
new Paragraph({ text: '— 이하 여백 —', alignment: AlignmentType.CENTER });

4. 전체 보고서 다운로드

제목·서식 문단·표·목록을 한 문서에 모두 담아서, 완성된 보고서 형태로 다운로드합니다.
코드 보기 
const doc = new Document({
  sections: [{
    children: [
      new Paragraph({ text: '위판 실적 보고서', heading: HeadingLevel.HEADING_1 }),
      new Paragraph({ children: [new TextRun('작성일: 2026-07-13')] }),
      table, // 위에서 만든 표
      new Paragraph({ text: '주의사항', heading: HeadingLevel.HEADING_2 }),
      new Paragraph({ text: '위판 등록 전 중량을 반드시 확인하세요.', bullet: { level: 0 } }),
    ],
  }],
});

const blob = await Packer.toBlob(doc);
const a = document.createElement('a');
a.href = URL.createObjectURL(blob);
a.download = 'wipan-report.docx'; // 한글 파일명은 브라우저에서 깨질 수 있어 영문으로 지정
a.click();
