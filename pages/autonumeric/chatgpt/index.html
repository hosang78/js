autoNumeric 종합 기능 실험실

숫자·통화 입력을 입력 즉시 포맷하고, 원시값 추출·옵션 변경·범위 제한·수식 계산·이벤트 감시·다중 인스턴스 제어까지 한 페이지에서 확인하는 샘플이다.

v4.10.10단일 HTML반응형외부 의존성 없음(autoNumeric 제외)
autoNumeric 라이브러리를 불러오지 못했다. 인터넷 연결 또는 CDN 접근 상태를 확인해 줘.
라이브러리 확인 중

1. 국가별 숫자·통화 포맷

통화 기호 위치, 천 단위 구분자, 소수점 문자, 인도식 구분, 음수 표기 차이를 비교한다.

2. 입력 규칙과 특수 동작

최솟값·최댓값, 소수 정밀도, 퍼센트 환산, 접두·접미 기호, leading zero, 빈 값 처리 등을 확인한다.

set, getNumericString, getNumber, update, clear, remove, reformat 등 주요 메서드를 버튼으로 호출한다.

4. 증감·휠·화살표 키

step 값 기반 증감과 mouse wheel, 위·아래 방향키 처리 옵션을 실험한다.

5. 다중 필드·폼 데이터 처리

여러 autoNumeric 필드의 원시값을 한 번에 수집하고 JSON 또는 쿼리 문자열 형태로 확인한다.
