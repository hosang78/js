autoNumeric 핵심 기능 둘러보기

autoNumeric은 입력창에 숫자를 타이핑하는 즉시 천 단위 구분 기호·통화 기호·소수 자리수를 자동으로 맞춰주는 라이브러리입니다. 내부적으로는 항상 정확한 숫자 값을 별도로 들고 있어서, 화면 표시 형식과 실제 계산용 숫자를 분리해서 다룰 수 있습니다.
  • digitGroupSeparator + suffixText로 하는 원화 통화 포맷
  • decimalPlaces + 범위 제한으로 하는 백분율 입력
  • minimumValue / maximumValue와 초과 이벤트로 하는 입력 범위 제한
  • AutoNumeric.multiple()로 여러 입력에 한 번에 적용하고 getNumber()로 합계 계산
※ 아래 금액·수량 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 정산 절차·통계와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 원화 통화 포맷

숫자를 입력하면 천 단위마다 콤마가 자동으로 붙고, 뒤에 "원"이 항상 따라붙습니다. 소수점은 입력할 수 없도록 decimalPlaces: 0으로 막았습니다.
아직 입력된 금액이 없습니다.
코드 보기 
new AutoNumeric('#an1', {
  digitGroupSeparator: ',',
  decimalPlaces: 0,
  suffixText: '원',
});

2. 백분율 입력

소수 첫째 자리까지만 입력받고, 0~100 범위를 벗어나는 값은 입력 자체가 막힙니다.
아직 입력된 수수료율이 없습니다.
코드 보기 
new AutoNumeric('#an2', {
  decimalPlaces: 1,
  suffixText: '%',
  minimumValue: '0',
  maximumValue: '100',
});

3. 최소·최대값 제한과 초과 이벤트

조업량은 0 ~ 5,000kg 범위만 허용됩니다. 직접 타이핑하면 범위를 벗어나는 키 입력 자체가 막힙니다. 버튼으로 범위를 벗어나는 값을 set()으로 한 번에 넣어보면 autoNumeric:minExceeded / maxExceeded 이벤트가 먼저 발생하고, 이어서 예외가 발생해 이전 값이 그대로 유지됩니다 — 이때 catch에서 범위 끝 값으로 다시 set()해서 보정합니다.
범위 안의 값을 입력하거나, 버튼으로 범위 밖 값을 시도해보세요.
코드 보기 
const an3 = new AutoNumeric('#an3', {
  digitGroupSeparator: ',',
  decimalPlaces: 0,
  suffixText: ' kg',
  minimumValue: '0',
  maximumValue: '5000',
});
// set()이 범위를 벗어나면 minExceeded/maxExceeded 이벤트가 먼저 발생한 뒤 예외를 던진다.
// (참고: 입력창 전체를 선택한 뒤 붙여넣기를 하면 onInvalidPaste 옵션과 무관하게
//  이 예외 경로를 그대로 타므로, 프로그램에서 값을 넣을 때는 항상 try/catch가 필요하다.)
document.getElementById('an3').addEventListener('autoNumeric:maxExceeded', () => {
  stat.textContent = '최대 5,000kg를 초과할 수 없습니다.';
});
document.getElementById('an3').addEventListener('autoNumeric:minExceeded', () => {
  stat.textContent = '0 미만으로 입력할 수 없습니다.';
});

s3Over.addEventListener('click', () => {
  try { an3.set(6000); } catch (e) { an3.set(5000); } // 범위 끝 값으로 보정
});
s3Under.addEventListener('click', () => {
  try { an3.set(-100); } catch (e) { an3.set(0); }
});

4. 여러 입력에 한 번에 적용 + 합계 계산

AutoNumeric.multiple()로 위판장 3곳의 정산 금액 입력창에 같은 설정을 한 번에 적용합니다. 각 입력이 바뀔 때마다 getNumber()로 실제 숫자 값을 읽어와 합계를 다시 계산합니다.
합계: 0원
코드 보기 
const inputs = [an4a, an4b, an4c];
const list = AutoNumeric.multiple(inputs, {
  digitGroupSeparator: ',',
  decimalPlaces: 0,
  suffixText: '원',
});

function updateSum() {
  const sum = list.reduce((acc, an) => acc + an.getNumber(), 0);
  stat.textContent = `합계: ${sum.toLocaleString()}원`;
}
inputs.forEach((el) => el.addEventListener('autoNumeric:formatted', updateSum));
