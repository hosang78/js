Eruda 핵심 기능 둘러보기

Eruda는 PC 개발자도구를 열 수 없는 모바일 브라우저에서도 콘솔·엘리먼트·네트워크 등을 확인할 수 있게 해주는 라이브러리입니다. 페이지에 삽입하면 화면 한쪽에 작은 진입 버튼이 뜨고, 누르면 크롬 개발자도구와 비슷한 패널이 그 위에 펼쳐집니다.
  • eruda.init()으로 초기화하면 console/elements/network/resources/info/snippets 등의 탭이 자동 구성됨
  • 초기화 이후에는 console.log 등 전역 콘솔 호출을 가로채 Eruda 콘솔 탭에 그대로 표시
  • eruda.get('도구이름')으로 각 탭의 API(예: elements.select(), info.add())를 직접 호출 가능
  • eruda.show('탭이름')으로 특정 탭으로 전환 가능 (단, 패널이 닫혀있을 땐 먼저 인자 없는 eruda.show()로 열어야 함 — 아래에서 실제로 확인)
※ 이 페이지의 위판장·어획량 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다. 화면 우측 하단의 파란 원형 버튼이 Eruda 진입 버튼입니다 — 언제든 눌러서 패널을 열고 닫을 수 있습니다. 아래 데모 버튼을 눌러 자동으로 패널이 열리면 다른 섹션 버튼을 가리지 않도록 약 2.5초 뒤 자동으로 닫힙니다.

1. 콘솔 로그 캡처

버튼을 누르면 이 페이지에서 console.log/warn/error를 실제로 호출합니다. Eruda는 이를 가로채 자신의 콘솔 탭에 그대로 쌓아둡니다 — 아래 결과는 Eruda 패널 내부 DOM을 직접 읽어 실제로 몇 건이 잡혔는지 보여줍니다. (검증 중 발견: Eruda 콘솔은 가상 스크롤 목록이라 패널을 한 번도 열지 않으면 로그 자체는 캡처돼도 화면에는 렌더링되지 않습니다 — 그래서 로그를 발생시키면 자동으로 Console 탭이 함께 열립니다.)
아직 실행 안 함
코드 보기 
eruda.init({ tool: ['console', 'elements', 'network', 'info', 'snippets'] });
console.log('테스트 로그', { a: 1 }); // Eruda 콘솔 탭에 그대로 캡처됨
eruda.show('console'); // 가상 스크롤 목록이라 한 번은 열어야 화면에 렌더링됨

2. 네트워크 요청 캡처

버튼을 누르면 가상 위판 데이터 파일(catch-data.json)을 실제로 fetch합니다. Eruda의 Network 탭은 페이지가 보내는 요청을 실시간으로 가로채 기록합니다.
아직 요청 안 함
코드 보기 
const res = await fetch('./catch-data.json');
const data = await res.json();
// Eruda Network 탭에 이 요청이 method/status/응답과 함께 기록됨
eruda.show(); eruda.show('network'); // 패널이 닫혀있으면 인자 없는 show()로 먼저 열어야 함

3. Elements 탭에서 DOM 요소 선택

아래 가상 위판장 카드를 Eruda의 Elements 탭에서 직접 선택해 DOM 트리를 확인합니다.
가상 위판장 코드
PORT-A-2026
아직 선택 안 함
코드 보기 
eruda.get('elements').select(document.getElementById('portCard1'));
eruda.show(); eruda.show('elements'); // 선택한 요소의 DOM 트리가 강조되어 표시됨

4. Info 탭에 커스텀 정보 추가

Info 탭은 기본으로 페이지 URL·User Agent 등을 보여주는데, add()로 커스텀 항목(가상 조합원 정보)을 추가할 수 있습니다.
아직 추가 안 함
코드 보기 
eruda.get('info').add('가상 조합원 번호', 'MEM-2026-0731');
eruda.get('info').add('소속 위판장', 'PORT-A-2026');
eruda.show(); eruda.show('info');
console.log(eruda.get('info').get()); // 등록된 전체 info 항목 목록

5. Snippets 등록 및 실행

Snippets 탭은 반복 실행할 함수를 등록해두고 버튼 한 번으로 실행하는 기능입니다. 등록한 스니펫을 실제로 실행해서 아래 카운터가 올라가는지 확인해보세요.
아직 등록 안 함
코드 보기 
eruda.get('snippets').add(
  '위판 카운터 증가',
  () => { runCount++; render(); },
  '가상 위판 건수 카운터를 1 증가시킴'
);
eruda.get('snippets').run('위판 카운터 증가');
