내부망·오프라인 사용

현재 파일은 jsDelivr에서 Eruda 3.4.3을 불러온다. 외부망이 차단된 환경에서는 eruda.min.js를 HTML과 같은 폴더에 두고 상단 script 경로를 ./eruda.min.js로 바꾸면 된다. Network 실험 중 외부 URL 요청도 내부망에서는 실패하는 것이 정상이다.
