포함 기능 요약

옵션·API·이벤트

domain / subDomain

year-month, year-day, month-day, week-day, day-hour 조합 예시.

scale.color / scale.opacity

threshold, quantize, linear, diverging, opacity 스케일 전환.

data.groupY

sum, average, max, min, count 집계 방식 비교.

플러그인

Tooltip, Legend, LegendLite, CalendarLabel 적용.

이벤트

click, mouseover, mouseout, fill, resize, destroy, min/max 도달 이벤트 로그.

API

next(), previous(), jumpTo(), fill(), dimensions(), destroy() 직접 호출.

레이아웃

gutter, padding, radius, dynamicDimension, verticalOrientation 조정.

날짜 옵션

start, min, max, highlight, locale, timezone 적용.

실무형 확장

샘플 데이터 교체, CSV 저장, 현재 옵션 코드 복사 기반 제공.
