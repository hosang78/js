Cal-Heatmap 핵심 기능 둘러보기

Cal-Heatmap은 GitHub의 커밋 잔디밭처럼, 날짜별 값을 색 농도가 다른 사각형으로 캘린더 위에 표시하는 시계열 히트맵 라이브러리입니다. d3.js 위에서 동작하며 날짜 탐색과 툴팁·범례 같은 부가 기능을 플러그인으로 붙일 수 있습니다.
  • 월/주/일 단위로 구성되는 캘린더형 히트맵, 색상은 값의 크기(단계)를 나타냄
  • previous() / next() / jumpTo()로 표시 기간을 이동하는 탐색 기능
  • Tooltip · Legend 같은 플러그인 시스템(필요한 것만 골라 추가)
  • on('click', ...) 이벤트와 date.highlight로 만드는 날짜 클릭·강조 표시
※ 아래 위판 실적 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Cal-Heatmap은 내부적으로 d3.js를 필요로 하며, 툴팁 플러그인은 위치 계산에 Popper.js를 사용합니다(둘 다 CDN). 그 외 다른 외부 API는 사용하지 않습니다.

1. 연간 캘린더 히트맵 + 범례

최근 1년간 일별 위판 건수를 GitHub 잔디밭과 같은 형태(subDomain: 'ghDay')로 표시했습니다. 색이 짙을수록 그날 위판 건수가 많았다는 뜻이며, 아래 범례가 색상 단계와 값의 대응 관계를 보여줍니다.
코드 보기 
const cal = new CalHeatmap();
await cal.paint({
  itemSelector: '#cal1',
  domain: { type: 'month', label: { text: 'MMM' } },
  subDomain: { type: 'ghDay', radius: 2, width: 11, height: 11 },
  range: 12,                                     // 12개월치 표시
  data: { source: dailyRecords, x: 'date', y: 'value' },
  scale: {
    color: {
      type: 'threshold',
      domain: [1, 5, 10, 15],                    // 값 구간 경계
      range: ['#eaf2fc', '#b9d4f5', '#7aa9e8', '#3f7dd0', '#154a8f'],
    },
  },
}, [
  [Legend, { itemSelector: '#legend1', width: 300, label: '위판량(건)' }],
]);

2. 기간 이동 탐색

기본으로 최근 3개월을 표시하며, 버튼으로 previous() / next()를 호출해 한 달씩 이동하거나 jumpTo()로 오늘로 즉시 복귀할 수 있습니다.
코드 보기 
cal.paint({ itemSelector: '#cal2', domain: { type: 'month' }, range: 3, /* ... */ });

prevBtn.addEventListener('click', () => cal.previous());
nextBtn.addEventListener('click', () => cal.next());
todayBtn.addEventListener('click', () => cal.jumpTo(new Date(), true));

3. Tooltip 플러그인

최근 4주를 일 단위로 표시했습니다. 각 칸에 마우스를 올리면 Tooltip 플러그인이 날짜와 값을 말풍선으로 보여줍니다. 텍스트 형식은 함수로 직접 지정할 수 있습니다.
코드 보기 
cal.paint({ itemSelector: '#cal3', domain: { type: 'week' }, range: 4, /* ... */ }, [
  [Tooltip, {
    text: (timestamp, value) =>
      `${new Date(timestamp).toISOString().slice(0, 10)}: ${value == null ? '데이터 없음' : value + '건'}`,
  }],
]);

4. 클릭 이벤트 + 날짜 하이라이트

칸을 클릭하면 on('click', ...) 이벤트로 해당 날짜의 값을 읽어와 아래 정보 박스에 표시합니다. 성수기가 시작된 날짜는 date.highlight로 테두리를 둘러 강조했습니다(아래 캘린더에서 네모 테두리가 있는 칸을 찾아보세요).
칸을 클릭해보세요.
코드 보기 
cal.paint({
  itemSelector: '#cal4',
  domain: { type: 'week' },
  range: 4,
  date: { highlight: [peakSeasonStartDate] },     // 강조할 날짜
  /* ... */
});

cal.on('click', (event, timestamp, value) => {
  const dateStr = new Date(timestamp).toISOString().slice(0, 10);
  infoBox.textContent = `${dateStr} 위판 건수: ${value == null ? '데이터 없음' : value + '건'}`;
});
