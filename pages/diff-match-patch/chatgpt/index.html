Diffdiff_main(text1, text2, checklines)두 텍스트의 삽입·삭제·동일 구간 배열 계산[[op, text], ...]

Metricdiff_levenshtein(diffs)삽입·삭제·치환 기반 최소 편집 거리 산출정수
Displaydiff_prettyHtml(diffs)예시용 HTML 표현 생성HTML 문자열

Patchpatch_make(...)텍스트 또는 diff 배열에서 패치 객체 생성패치 배열

Patchpatch_apply(patches, text)원문이 일부 달라도 최선 방식으로 패치 적용[result, boolean[]]
Deltadiff_toDelta / diff_fromDelta원본 기반 압축형 변경 문자열 생성·복원델타 문자열 ↔ diff
