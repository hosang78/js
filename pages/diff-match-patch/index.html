diff-match-patch 핵심 기능 둘러보기

diff-match-patch는 Google이 만든 텍스트 비교(diff)·근사 검색(match)·패치 생성/적용(patch) 라이브러리입니다. 문서 버전 비교, 협업 편집 병합, 오타를 허용하는 검색 등에 쓰입니다.
  • diff_main()으로 두 텍스트의 차이를 삽입/삭제 조각으로 계산
  • diff_cleanupSemantic()으로 잘게 쪼개진 diff를 사람이 읽기 좋게 정리
  • patch_make() / patch_apply()로 변경 내용을 다른 텍스트에 병합
  • match_main()으로 오타가 있어도 비슷한 위치를 근사 검색
※ 아래 공지사항 문구는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 공지·통계와 무관합니다. diff-match-patch npm 패키지는 브라우저용 번들 없이 CommonJS (module.exports)로만 배포되어 있어, jsdelivr의 ESM 변환 엔드포인트 (/+esm)로 불러옵니다(Ajv 페이지와 같은 방식). 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 텍스트 diff + 하이라이트

가상 위판 공지사항의 개정 전/후 문구를 비교합니다. 초록색은 추가된 부분, 빨간색은 삭제된 부분입니다.
코드 보기 
const dmp = new DiffMatchPatch();
const diffs = dmp.diff_main(textA, textB);
dmp.diff_cleanupSemantic(diffs); // 잘게 쪼개진 조각을 사람이 읽기 좋게 정리

// diffs: [[0, "공통부분"], [-1, "삭제됨"], [1, "추가됨"], ...]
// 0 = DIFF_EQUAL, -1 = DIFF_DELETE, 1 = DIFF_INSERT

2. diff_cleanupSemantic — 정리 전/후 비교

diff_main() 결과를 그대로 쓰면 자잘하게 쪼개진 diff가 나올 수 있습니다. diff_cleanupSemantic()을 거치면 의미 단위로 뭉쳐져 훨씬 읽기 편해집니다.
코드 보기 
const rawDiffs = dmp.diff_main(textA, textB);       // 정리 전
const cleanDiffs = dmp.diff_main(textA, textB);
dmp.diff_cleanupSemantic(cleanDiffs);                // 정리 후

3. Patch 생성 및 적용

"원본"과 "수정본"의 차이로 패치를 만든 뒤, 그 패치를 조금 다르게 편집된 "다른 사본"에도 적용해봅니다. 오프라인에서 각자 편집한 문서를 나중에 병합하는 상황을 흉내낸 것입니다.
코드 보기 
const patches = dmp.patch_make(original, edited);
const patchText = dmp.patch_toText(patches); // 사람이 읽을 수 있는 패치 포맷

const [mergedText, appliedResults] = dmp.patch_apply(patches, otherCopy);
// appliedResults: 각 패치 조각이 성공적으로 적용됐는지 [true, true, ...]

4. 근사 문자열 검색 (오타 허용)

아래 공지문 안에서 검색어를 찾습니다. 철자가 정확하지 않아도(오타가 있어도) 비슷한 위치를 찾아줍니다.
코드 보기 
const dmp = new DiffMatchPatch();
dmp.Match_Threshold = 0.5; // 0에 가까울수록 정확히 일치해야 함
const loc = dmp.match_main(doc, query, approxLocationGuess);
// loc === -1 이면 못 찾은 것, 아니면 가장 비슷한 위치의 인덱스
