OpenSeadragon 핵심 기능 둘러보기

OpenSeadragon은 아주 커다란 고해상도 이미지(기가픽셀 스캔본, 지도, 위성사진 등)를 부드럽게 확대·축소하며 볼 수 있게 해주는 딥줌(deep zoom) 이미지 뷰어 라이브러리입니다. 실제로는 이미지를 여러 배율의 타일로 미리 잘라둔 "DZI(Deep Zoom Image)" 형식과 함께 쓰는 경우가 많지만, 이 페이지는 학습 목적상 단일 이미지를 그대로 불러오는 가장 단순한 방식(type: "image")을 사용합니다.
  • 휠/드래그로 자유로운 확대·축소·이동(pan & zoom), 회전
  • sequenceMode로 여러 이미지를 갤러리처럼 순서대로 전환
  • viewer.addOverlay()로 이미지 위 특정 좌표에 HTML 오버레이(라벨/마커) 배치
  • 내장 네비게이터(미니맵)와 API로 특정 위치로 즉시 이동
※ 아래 배치도와 위판 현황판 이미지는 이 페이지를 위해 직접 그린 가상의 예시 이미지이며, 실제 수협중앙회의 시설·조직·위판 실적과 무관합니다. OpenSeadragon(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다. 기본값인 WebGL 렌더러는 환경에 따라(예: GPU 가속이 막힌 브라우저·가상 디스플레이) 텍스처 생성에 실패해 화면이 비어 보이는 경우가 있어, 이 페이지는 drawer: "canvas"로 지정해 더 널리 호환되는 2D 캔버스 렌더러를 사용합니다.

1. 기본 뷰어 — 확대·축소·이동·회전

가상 위판장 전체 배치도입니다. 각 구역 안에는 일부러 아주 작은 글씨로 세부사항을 적어두었으니, 휠로 확대해서 읽어보세요. 딥줌 뷰어는 이렇게 "멀리서는 전체 구조, 가까이서는 세부 정보"를 한 이미지 안에서 모두 보여줄 때 유용합니다.
코드 보기 
const viewer1 = window.viewer1 = OpenSeadragon({
  id: "viewer1",
  prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@6.0.2/build/openseadragon/images/",
  drawer: "canvas",
  tileSources: { type: "image", url: "sample-layout.svg" },
  showNavigator: false
});

document.getElementById("v1-zoomin").onclick = () => viewer1.viewport.zoomBy(1.4);
document.getElementById("v1-zoomout").onclick = () => viewer1.viewport.zoomBy(0.7);
document.getElementById("v1-rotate").onclick = () => viewer1.viewport.setRotation((viewer1.viewport.getRotation() + 90) % 360);
document.getElementById("v1-home").onclick = () => viewer1.viewport.goHome();

2. 다중 이미지 전환 (시퀀스 모드)

어종별 위판 현황판 3장을 갤러리처럼 넘겨볼 수 있습니다. sequenceMode: true로 설정하면 내장 이전/다음 버튼이 자동으로 나타나고, 이미지가 바뀔 때마다 확대 상태는 초기화됩니다.
1 / 3 · 고등어 위판 현황판
코드 보기 
const viewer2 = window.viewer2 = OpenSeadragon({
  id: "viewer2",
  prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@6.0.2/build/openseadragon/images/",
  drawer: "canvas",
  sequenceMode: true,
  tileSources: [
    { type: "image", url: "sample-catch-mackerel.svg" },
    { type: "image", url: "sample-catch-hairtail.svg" },
    { type: "image", url: "sample-catch-squid.svg" }
  ]
});

viewer2.addHandler("page", (e) => {
  const names = ["고등어", "갈치", "오징어"];
  seqIndicator.textContent = `${e.page + 1} / 3 · ${names[e.page]} 위판 현황판`;
});

3. 이미지 위 오버레이 (HTML 마커)

배치도 이미지의 특정 픽셀 좌표에 HTML 라벨을 고정해서 붙입니다. 오버레이는 이미지 좌표계에 묶여 있으므로 확대·이동해도 항상 같은 위치에 따라다닙니다. 라벨을 클릭하면 해당 구역으로 이동합니다.
코드 보기 
const viewer3 = window.viewer3 = OpenSeadragon({
  id: "viewer3",
  prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@6.0.2/build/openseadragon/images/",
  drawer: "canvas",
  tileSources: { type: "image", url: "sample-layout.svg" }
});

const spots = [
  { name: "고등어 위판장", x: 390, y: 310 },
  { name: "갈치 위판장", x: 1070, y: 310 },
  { name: "경매 사무동", x: 1290, y: 810 }
];

viewer3.addHandler("open", () => {
  spots.forEach((spot) => {
    const el = document.createElement("div");
    el.className = "overlay-pin";
    el.textContent = spot.name;
    el.onclick = () => {
      const rect = viewer3.viewport.imageToViewportRectangle(spot.x - 260, spot.y - 260, 520, 520);
      viewer3.viewport.fitBounds(rect);
    };
    const point = viewer3.viewport.imageToViewportCoordinates(spot.x, spot.y);
    viewer3.addOverlay({ element: el, location: point, placement: OpenSeadragon.Placement.BOTTOM });
  });
});

4. 네비게이터(미니맵) + 특정 위치로 이동

우측 상단 미니맵으로 전체 이미지에서 현재 보고 있는 영역을 확인할 수 있습니다. 아래 버튼으로 특정 구역까지 자동으로 확대·이동해보세요.
코드 보기 
const viewer4 = window.viewer4 = OpenSeadragon({
  id: "viewer4",
  prefixUrl: "https://cdn.jsdelivr.net/npm/openseadragon@6.0.2/build/openseadragon/images/",
  drawer: "canvas",
  tileSources: { type: "image", url: "sample-layout.svg" },
  showNavigator: true,
  navigatorPosition: "TOP_RIGHT"
});

document.querySelectorAll(".goto-btn").forEach((btn) => {
  btn.onclick = () => {
    const x = Number(btn.dataset.x), y = Number(btn.dataset.y);
    const rect = viewer4.viewport.imageToViewportRectangle(x - 350, y - 350, 700, 700);
    viewer4.viewport.fitBounds(rect);
  };
});
document.getElementById("v4-home").onclick = () => viewer4.viewport.goHome();
