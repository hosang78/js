Dagre 핵심 기능 둘러보기

Dagre는 방향성 있는 그래프(DAG)를 단(rank)별로 배치해주는 레이아웃 엔진입니다. ELK.js처럼 좌표만 계산하고 화면에 그려주지는 않습니다. Mermaid.js 같은 다이어그램 도구의 흐름도(flowchart) 레이아웃에도 실제로 쓰입니다.
  • 레이어드 그래프 배치 + 랭크 방향(위→아래, 왼→오 등) 전환
  • 엣지에 라벨을 달면 그 라벨이 놓일 공간까지 레이아웃에 반영
  • 같은 두 노드를 잇는 다중 엣지, 자기 자신으로 돌아오는 셀프 루프 처리
  • 노드 간격·랭크 간격을 조절해 레이아웃 밀도 제어
※ 아래 유통 흐름도는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 유통 구조와 무관합니다. Dagre는 좌표만 계산하므로 결과는 이 페이지에서 직접 그린 SVG로 표시합니다. Dagre(CDN, @dagrejs/dagre — 활발히 관리되는 포크판) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 레이어드 그래프 + 랭크 방향

가상 위판장 유통 흐름입니다. 방향 버튼으로 같은 그래프를 다시 배치해보세요.
코드 보기 
const g = new dagre.graphlib.Graph();
g.setGraph({ rankdir: "LR" }); // TB / BT / LR / RL
g.setDefaultEdgeLabel(() => ({}));

g.setNode("market1", { width: 90, height: 34 });
g.setNode("broker1", { width: 90, height: 34 });
g.setEdge("market1", "broker1");

dagre.layout(g);
g.nodes().forEach((id) => console.log(g.node(id).x, g.node(id).y));

2. 엣지 라벨이 차지하는 레이아웃 공간

왼쪽은 라벨이 없는 엣지, 오른쪽은 같은 구조에 label만 추가한 엣지입니다. 라벨이 들어갈 자리만큼 랭크(단) 사이 간격이 자동으로 벌어집니다.
라벨 없음
라벨 있음
코드 보기 
g.setEdge("market1", "broker1", { label: "고등어 위주" });
// 라벨 텍스트 크기만큼 width/height를 지정해두면
// 레이아웃 계산 시 그 자리를 실제로 비워둔다

3. 다중 엣지 + 셀프 루프

같은 두 노드를 잇는 여러 엣지(수산물 종류별)와, 자기 자신에게 돌아오는 셀프 루프(재작업)를 함께 배치합니다.
코드 보기 
const g = new dagre.graphlib.Graph({ multigraph: true });
g.setEdge("market1", "broker1", { label: "고등어" }, "e1");
g.setEdge("market1", "broker1", { label: "갈치" }, "e2");   // 같은 두 노드를 잇는 두 번째 엣지
g.setEdge("broker1", "broker1", { label: "재작업" }, "loop"); // 셀프 루프

4. 노드/랭크 간격 조정

슬라이더로 같은 랭크 안 노드 사이 간격(nodesep)과 랭크 사이 간격(ranksep)을 바꿔보세요.
코드 보기 
g.setGraph({ rankdir: "TB", nodesep: 40, ranksep: 50 });
