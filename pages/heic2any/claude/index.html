heic2any 핵심 기능 둘러보기

heic2any는 아이폰이 기본으로 저장하는 HEIC/HEIF 사진을 브라우저에서 바로 볼 수 있는 JPEG/PNG/GIF로 변환하는 라이브러리입니다. HEIC는 대부분의 브라우저가 직접 표시하지 못하기 때문에, 업로드 폼 등에서 미리보기를 보여주려면 이런 변환이 필요합니다.
  • toType: 'image/jpeg'로 하는 기본 변환
  • toType: 'image/png'로 하는 무손실 변환
  • quality 옵션별 용량 비교
  • 연속 촬영(버스트) HEIC를 GIF로 합치거나 개별 이미지로 분리
※ HEIC 샘플 사진이 없어도 확인할 수 있도록, 실제 HEIC 인코더(libheif + x265)로 직접 만든 진짜 HEIC 파일(가상의 위판 사진, 3장짜리 가상 연속 촬영)을 페이지에 함께 담아뒀습니다. 물론 아이폰으로 찍은 실제 HEIC 사진을 업로드해도 됩니다.
🔒 모든 처리는 브라우저 안에서만 이루어집니다. 업로드한 사진은 서버로 전송되지 않습니다.

1~3. HEIC 사진 준비

아이폰에서 찍은 HEIC 사진이 있다면 업로드해 보세요. 없다면 아래 버튼으로 준비된 샘플 HEIC를 사용할 수 있습니다.

1. 기본 변환 (HEIC → JPEG)

heic2any({ blob, toType: 'image/jpeg', quality }) 한 번 호출로 HEIC를 JPEG Blob으로 바꿔줍니다.
소스 코드 보기 
const jpegBlob = await heic2any({
  blob: heicFile,
  toType: 'image/jpeg',
  quality: 0.8,
});
imgEl.src = URL.createObjectURL(jpegBlob);

2. PNG로 변환 (무손실)

toType: 'image/png'로 바꾸면 화질 손실 없이 변환됩니다. 대신 파일 크기는 JPEG보다 훨씬 큽니다.
소스 코드 보기 
const pngBlob = await heic2any({ blob: heicFile, toType: 'image/png' });

3. quality 옵션별 용량 비교

같은 HEIC를 quality 값만 바꿔가며 여러 번 변환해서 용량 차이를 비교합니다.
quality크기
소스 코드 보기 
for (const quality of [0.2, 0.5, 0.8, 1.0]) {
  const blob = await heic2any({ blob: heicFile, toType: 'image/jpeg', quality });
  console.log(quality, blob.size);
}

4. 연속 촬영(버스트) HEIC → GIF / 개별 이미지

아이폰의 "라이브 포토"나 연속 촬영처럼 하나의 HEIC 안에 여러 장의 이미지가 들어있는 경우, multiple 옵션 없이 호출하면 자동으로 애니메이션 GIF 하나로 합쳐주고, multiple: true를 주면 각 프레임을 개별 이미지 배열로 따로 받을 수 있습니다.
소스 코드 보기 
// 여러 장을 하나의 움직이는 GIF로
const gifBlob = await heic2any({ blob: burstHeicFile, toType: 'image/gif' });

// 여러 장을 각각 따로 (배열로 반환됨)
const frames = await heic2any({ blob: burstHeicFile, toType: 'image/jpeg', multiple: true });
frames.forEach((frameBlob, i) => console.log('frame', i, frameBlob.size));
