Lit

Lit은 브라우저 표준 기능인 웹 컴포넌트(Custom Elements + Shadow DOM)를 가볍게 만들 수 있게 도와주는 라이브러리입니다. React처럼 상태가 바뀌면 화면이 자동으로 다시 그려지지만, 프레임워크 없이도 어느 사이트에나 그대로 갖다 붙일 수 있는 순수 브라우저 표준 커스텀 태그를 만든다는 게 특징입니다.

  • static properties로 반응형 속성을 정의하면 값이 바뀔 때 자동으로 재렌더링
  • html 태그드 템플릿 + repeat/classMap/styleMap 등 디렉티브
  • Shadow DOM으로 스타일이 컴포넌트 안에 캡슐화되어 외부와 충돌하지 않음
  • 표준 CustomEvent로 컴포넌트 간 통신, <slot>으로 콘텐츠 재사용
⚠️ 이 페이지의 위판·입찰 데이터는 Lit 기능 설명을 위한 가상의 예시이며, 실제 수협중앙회의 통계·조직·절차와 무관합니다. 다른 외부 API는 사용하지 않았습니다 (Lit 3.3.3을 CDN에서 로드).

1. 반응형 속성 (Reactive Properties)

static properties로 선언한 속성이 바뀌면 Lit이 자동으로 render()를 다시 호출합니다. 직접 DOM을 조작할 필요가 없습니다.

소스 코드 보기 
class BidCounter extends LitElement {
  static properties = { amount: { type: Number } };
  constructor() { super(); this.amount = 0; }
  render() {
    return html`
      <span>현재 입찰가: ${this.amount.toLocaleString()}원</span>
      <button @click=${() => this.amount += 1000}>+1,000원</button>
    `;
  }
}
customElements.define('bid-counter', BidCounter);

2. 리스트 렌더링 — repeat + classMap/styleMap

repeat(items, keyFn, template)은 각 항목을 고유 키로 추적해서, 순서가 바뀌거나 항목이 추가/삭제돼도 기존 DOM 노드를 최대한 재사용합니다. classMap/styleMap은 객체로 클래스·인라인 스타일을 동적으로 적용합니다.

소스 코드 보기 
class CatchList extends LitElement {
  static properties = { items: { type: Array } };
  render() {
    return html`${repeat(this.items, (i) => i.id, (i) => html`
      <li class=${classMap({ active: i.active })}
          style=${styleMap({ fontWeight: i.active ? 'bold' : 'normal' })}
          @click=${() => this._toggle(i.id)}>
        ${i.name} — ${i.weight}kg
      </li>
    `)}`;
  }
}

3. 커스텀 이벤트 — 자식 컴포넌트 → 부모

자식 컴포넌트는 표준 CustomEvent를 dispatchEvent()로 쏘아 올리고, 부모(또는 페이지 전체)는 일반 addEventListener로 받습니다. 프레임워크에 얽매이지 않는 표준 DOM 이벤트라, Lit 컴포넌트를 어떤 환경(React, Vue, 순수 HTML)에 넣어도 똑같이 동작합니다.

소스 코드 보기 
class BidButton extends LitElement {
  render() {
    return html`<button @click=${this._onClick}>입찰하기</button>`;
  }
  _onClick() {
    this.dispatchEvent(new CustomEvent('bid-placed', {
      detail: { amount: Math.floor(Math.random() * 5000) + 1000 },
      bubbles: true, composed: true, // Shadow DOM 경계를 넘어 밖으로 전파
    }));
  }
}

// 부모(일반 페이지 스크립트)에서 수신
document.getElementById('s3-mount').addEventListener('bid-placed', (e) => {
  console.log('받은 입찰가:', e.detail.amount);
});

4. <slot> — 라이트 DOM 콘텐츠 투영

<slot>을 쓰면 컴포넌트 바깥(라이트 DOM)에 작성한 콘텐츠를 컴포넌트 내부의 지정된 위치에 그대로 꽂아 넣을 수 있습니다. name 속성으로 여러 슬롯을 구분할 수 있어, 재사용 가능한 카드/패널 컴포넌트를 만들 때 유용합니다.

소스 코드 보기 
class InfoCard extends LitElement {
  render() {
    return html`
      <div class="card">
        <h3><slot name="title"></slot></h3>
        <div><slot></slot></div> <!-- 기본 슬롯 -->
      </div>
    `;
  }
}
customElements.define('info-card', InfoCard);
<!-- 사용하는 쪽: 컴포넌트 내부 구조를 몰라도 콘텐츠만 채우면 됨 -->
<info-card>
  <span slot="title">오늘의 위판 요약</span>
  <p>고등어 120kg, 갈치 85kg이 위판되었습니다.</p>
</info-card>

5. 라이프사이클 — updated() + attribute reflection

속성이 바뀔 때마다 Lit은 updated(changedProperties)를 호출해서 "무엇이 어떻게 바뀌었는지" 알려줍니다. reflect: true를 주면 속성값이 실제 HTML attribute에도 동기화되어, CSS 선택자([status="done"])나 개발자 도구에서 바로 확인할 수 있습니다.

소스 코드 보기 
class AuctionStatus extends LitElement {
  static properties = {
    status: { type: String, reflect: true }, // attribute와 동기화됨
  };
  constructor() { super(); this.status = 'waiting'; }
  updated(changedProps) {
    if (changedProps.has('status')) {
      console.log(`상태 변경: ${changedProps.get('status')} → ${this.status}`);
    }
  }
  render() { return html`<span>${this.status}</span>`; }
}
// reflect:true 덕분에 실제 DOM에는 <auction-status status="done">처럼 attribute가 붙는다
