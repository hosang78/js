Three.js 핵심 기능 둘러보기

Three.js는 브라우저의 WebGL API를 직접 다루지 않고도 3D 장면을 만들 수 있게 감싸주는 라이브러리입니다. Scene(장면)·Camera(카메라)·Renderer(렌더러) 세 가지가 기본 뼈대입니다.
  • new THREE.Mesh(지오메트리, 머티리얼)로 3D 물체를 만들고 scene.add()
  • 조명 없이는 MeshStandardMaterial 같은 재질이 검게만 보임 — 조명 종류별로 결과가 다름
  • OrbitControls로 마우스 드래그(회전)·휠(확대)·오른쪽 드래그(이동) 카메라 조작
  • Raycaster로 화면의 마우스 좌표를 3D 광선으로 바꿔 어떤 물체와 부딪히는지 판별
※ 최신 Three.js는 window.THREE 같은 전역 변수로 배포되지 않고 ES 모듈로만 제공됩니다. 그래서 이 페이지는 <script type="importmap">로 CDN 주소를 매핑한 뒤 <script type="module">에서 import * as THREE from 'three'로 불러옵니다. 이 페이지의 위판장 텍스처 문구는 가상의 예시입니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 씬 — 지오메트리 + 회전 애니메이션

큐브·구·원통 세 가지 기본 지오메트리를 만들어 각자 회전시킵니다.
코드 보기 
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshStandardMaterial({ color: 0x4f7dff })
);
scene.add(cube);
function animate() {
  requestAnimationFrame(animate);
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}

2. 조명 종류 비교

버튼으로 조명을 하나씩 꺼보세요. Ambient(전체 은은한 빛)를 끄면 그림자 진 면이 완전히 까매지고, Directional(태양광 같은 평행광)을 끄면 입체감이 사라집니다.
코드 보기 
scene.add(new THREE.AmbientLight(0xffffff, 0.3));       // 전체를 은은하게
scene.add(new THREE.DirectionalLight(0xffffff, 1.0));   // 태양광처럼 한 방향에서
scene.add(new THREE.PointLight(0xff6666, 1.5, 10));     // 전구처럼 한 점에서 사방으로

3. OrbitControls — 마우스로 카메라 조작

캔버스 위에서 왼쪽 드래그로 회전, 휠로 확대/축소, 오른쪽 드래그로 이동해보세요.
카메라 거리: -
코드 보기 
import { OrbitControls } from 'three/addons/controls/OrbitControls.js';
const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true; // 관성 효과
function animate() {
  requestAnimationFrame(animate);
  controls.update();
  renderer.render(scene, camera);
}

4. 텍스처 매핑

2D 캔버스로 직접 그린 "위판" 로고 이미지를 3D 큐브 표면 텍스처로 입힙니다.
코드 보기 
const texCanvas = document.createElement('canvas');
// ...캔버스에 로고 그리기...
const texture = new THREE.CanvasTexture(texCanvas);
const box = new THREE.Mesh(
  new THREE.BoxGeometry(1.4, 1.4, 1.4),
  new THREE.MeshStandardMaterial({ map: texture })
);

5. Raycasting — 클릭한 물체 판별

도형을 클릭해보세요. 마우스 좌표를 3D 광선으로 변환해 실제로 어떤 물체에 부딪혔는지 판별합니다.
아직 클릭 안 함
코드 보기 
const raycaster = new THREE.Raycaster();
const mouse = new THREE.Vector2();
canvas.addEventListener('click', (e) => {
  const rect = canvas.getBoundingClientRect();
  mouse.x = ((e.clientX - rect.left) / rect.width) * 2 - 1;
  mouse.y = -((e.clientY - rect.top) / rect.height) * 2 + 1;
  raycaster.setFromCamera(mouse, camera);
  const hits = raycaster.intersectObjects([cube, sphere, cylinder]);
  if (hits.length) console.log(hits[0].object.name, '클릭됨');
});
