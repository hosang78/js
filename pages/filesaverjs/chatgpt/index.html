01. 텍스트 · MIME · Unicode BOM

가장 기본적인 new Blob() + saveAs() 패턴을 직접 확인합니다.

Core API

사용자 입력 텍스트 저장

파일명, MIME 타입, UTF-8 BOM 자동 추가 옵션을 조합하여 저장합니다.

BOM 자동 추가는 MIME 타입에 charset=utf-8이 포함된 텍스트/XML 계열에서 작동합니다. Excel 등 일부 환경에서 한글 CSV 깨짐을 줄일 때 유용합니다.

짧은 코드 예제

이 샘플의 모든 Blob 저장 기능은 아래의 원리를 확장한 것입니다.

// 1) 저장할 데이터를 Blob으로 구성
const blob = new Blob(
  ["Hello, FileSaver.js!"],
  { type: "text/plain;charset=utf-8" }
);

// 2) 파일명과 함께 저장 호출
saveAs(blob, "hello.txt", {
  autoBom: true
});
저장 대화상자 또는 브라우저 기본 다운로드 동작은 브라우저 설정에 따라 달라질 수 있습니다.

04. Binary 데이터 · File 객체

ArrayBuffer/DataView 바이너리와 브라우저의 File 생성자를 저장 대상으로 사용합니다.

Blob variants

ArrayBuffer / DataView

헤더, 버전, 타임스탬프, 부동소수 값을 32바이트 바이너리 레코드로 구성합니다.

생성 레이아웃: MAGIC(4) + version(2) + flags(2) + timestamp(8) + score(8) + random(8)

new File() 저장

File 객체 안의 이름을 유지한 저장과 별도 파일명 덮어쓰기를 비교합니다.

문서상 File 생성자는 일부 구형 IE/Edge에서 지원되지 않아, 호환성을 높이려면 Blob + 파일명 방식이 안전합니다.

05. URL 저장 · 로컬 업로드 파일 재저장

URL 문자열을 직접 전달하는 방식과 사용자가 선택한 File 객체를 다시 저장하는 방식을 확인합니다.

URL & File input

URL 문자열 저장

FileSaver.js는 외부 URL의 CORS 가능 여부를 확인한 뒤 Blob 다운로드 또는 링크 방식으로 동작합니다.

외부 서버가 CORS 또는 HEAD 요청을 허용하지 않으면 동작이 제한될 수 있습니다. 보안 정책상 URL 입력은 신뢰할 수 있는 출처만 사용하세요.

선택한 파일 재저장

로컬에서 선택한 File 객체를 그대로 저장하거나 새 이름을 적용합니다.

파일을 선택하세요선택한 파일은 서버에 전송되지 않습니다.
입력 파일은 이 페이지의 메모리에서만 참조합니다. 업로드 서버 기능은 포함하지 않습니다.

06. 대용량 Blob 테스트

메모리에서 생성한 큰 파일을 저장합니다. 실제 운영 환경의 제한을 가늠하는 용도입니다.

Memory test
주의대용량 Blob은 브라우저 메모리를 사용합니다. 모바일·저사양 환경에서는 작은 크기부터 점검하세요. 파일을 서버가 제공하는 경우에는 일반적으로 응답 헤더 Content-Disposition: attachment 방식이 더 적합할 수 있습니다.

07. 실행 로그와 보관

이 페이지에서 시도한 저장 요청을 기록합니다. 다운로드 완료 여부는 브라우저 보안 모델상 JavaScript가 확정적으로 알 수 없습니다.

적용 시 참고 사항
이 샘플은 FileSaver.js가 담당하는 범위와 그 외 기능의 경계를 분명히 보여 줍니다.

        

          
FileSaver.js가 담당하는 것Blob, File, URL 등 이미 준비된 데이터를 브라우저 다운로드 동작으로 연결하고 파일명·BOM 처리 옵션을 적용합니다.

          
별도 도구가 필요한 것압축(ZIP), XLSX, PDF, 대용량 스트리밍 진행률·취소·완료 확인은 FileSaver.js 단독 범위가 아닙니다. 대용량 스트리밍은 StreamSaver.js와 같은 별도 도구를 검토해야 합니다.
