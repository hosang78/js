FileSaver.js 핵심 기능 둘러보기

FileSaver.js는 브라우저에서 만든 데이터(Blob)를 파일로 저장(다운로드)할 때 브라우저마다 다른 방식 차이를 신경 쓰지 않아도 되게 해주는 아주 작은 라이브러리입니다.
  • saveAs(blob, 파일명) 한 줄로 어떤 데이터든 파일로 저장 가능
  • 텍스트, JSON, 이미지(canvas) 등 Blob으로 만들 수 있는 건 뭐든 저장 가능
  • Blob의 MIME 타입에 따라 확장자만 바꿔주면 됨 (txt/json/csv/html 등)
  • 직접 <a download> 태그를 만드는 것보다 브라우저 차이를 덜 신경 써도 됨
※ 아래 메모 예시는 FileSaver.js 학습용 샘플이며, 실제 수협중앙회의 자료가 아닙니다. 이 페이지는 FileSaver.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 텍스트 파일 저장

아래 내용을 .txt 파일로 저장합니다.
코드 보기 
const blob = new Blob([text], { type: 'text/plain;charset=utf-8' });
saveAs(blob, '위판메모.txt');

2. JSON 파일 저장

아래 표를 JS 객체로 만들어 JSON 파일로 저장합니다.
코드 보기 
const data = [
  { 어종: '고등어', 수량: 320, 위판장: '부산공동어시장' },
  { 어종: '갈치', 수량: 180, 위판장: '목포수산시장' },
];
const blob = new Blob([JSON.stringify(data, null, 2)], { type: 'application/json' });
saveAs(blob, 'wipan-data.json');

3. 캔버스 이미지 저장

아래 캔버스에 간단히 그려진 그림을 PNG 파일로 저장합니다.
코드 보기 
canvas.toBlob((blob) => {
  saveAs(blob, 'wipan-canvas.png');
});

4. 여러 MIME 타입으로 저장

같은 데이터를 형식만 바꿔서(txt/csv/json/html) 각각 저장해봅니다.
코드 보기 
saveAs(new Blob([csvText], { type: 'text/csv;charset=utf-8' }), 'wipan.csv');
saveAs(new Blob([htmlText], { type: 'text/html;charset=utf-8' }), 'wipan.html');
// MIME 타입은 브라우저가 파일을 어떻게 다룰지 힌트를 줄 뿐, 실제 형식은 파일명 확장자로 결정됨
