Fuse.js 핵심 기능 둘러보기

Fuse.js는 오타나 일부 글자가 달라도 원하는 항목을 찾아주는 퍼지 검색(fuzzy search) 라이브러리입니다. 서버나 DB 없이 브라우저에서 목록을 바로 검색할 때 씁니다.
  • 정확히 일치하지 않아도(오타·일부 글자 누락) 비슷한 항목을 점수(score)와 함께 찾아줌
  • 검색 대상 필드를 여러 개 지정하고, 필드별 중요도(가중치)를 다르게 줄 수 있음
  • threshold 값으로 얼마나 느슨하게/엄격하게 매칭할지 조절 가능
  • 어느 글자가 매칭됐는지 위치 정보(includeMatches)를 받아 하이라이트 가능
※ 아래 예시의 위판장/어종 목록은 Fuse.js 학습용으로 만든 샘플 데이터이며, 수협중앙회의 실제 위판장 현황과는 무관합니다. 이 페이지는 Fuse.js(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 퍼지 검색 (오타 허용)

어종 이름 목록에서 검색합니다. 예를 들어 고등오처럼 한 글자를 틀리게 입력해도 고등어가 결과에 나옵니다.
코드 보기 
const fish = ['고등어', '갈치', '오징어', '멸치', '참치', '광어', '우럭', '전어', '삼치', '도미'];
const fuse = new Fuse(fish, { threshold: 0.4 });

fuse.search('고등오');
// -> [{ item: '고등어', refIndex: 0, score: 0.1x }]

2. 다중 필드 + 가중치 검색

위판장 이름과 지역, 두 필드를 동시에 검색하되 이름에 더 높은 가중치를 줍니다. 지역명(예: 부산)으로 검색해도 결과가 나옵니다.
코드 보기 
const markets = [
  { name: '부산공동어시장', region: '부산' },
  { name: '노량진수산시장', region: '서울' },
  { name: '목포수산시장', region: '전남' },
  { name: '포항죽도시장', region: '경북' },
];

const fuse = new Fuse(markets, {
  keys: [
    { name: 'name', weight: 0.7 },
    { name: 'region', weight: 0.3 },
  ],
});

3. threshold 조절 (매칭 엄격도)

threshold가 0에 가까울수록 엄격(정확히 일치), 1에 가까울수록 느슨(대충 비슷해도 매칭)합니다. 고정된 검색어 고등얼로 threshold를 바꿔가며 결과 개수 변화를 확인해보세요.
엄격 느슨 0.4
코드 보기 
const fuse = new Fuse(fish, { threshold: 0.4 }); // 0(엄격) ~ 1(느슨)
fuse.search('고등얼');

4. 매치 하이라이트

includeMatches: true 옵션을 주면 어느 글자가 매칭됐는지 위치 정보를 받아 이렇게 강조 표시할 수 있습니다.
코드 보기 
const fuse = new Fuse(fish, { includeMatches: true, threshold: 0.4 });
const [result] = fuse.search('삼치');
// result.matches[0].indices -> [[0, 1]] 같은 매칭 구간 배열
