Monaco Editor 핵심 기능 둘러보기

Monaco Editor는 VS Code(비주얼 스튜디오 코드)에 실제로 쓰이는 것과 동일한 편집기 엔진을 웹페이지에 그대로 가져다 쓸 수 있게 만든 라이브러리입니다.
  • 문법 강조, 괄호 자동 매칭, 여러 줄 편집 등 VS Code 수준의 편집 기능을 그대로 제공
  • monaco.editor.createDiffEditor()로 두 텍스트를 나란히 비교하는 diff 뷰 지원
  • registerCompletionItemProvider()로 원하는 언어에 커스텀 자동완성(IntelliSense) 추가 가능
  • TypeScript/JavaScript는 타입 추론 기반 자동완성까지 기본 내장
※ Monaco Editor는 번들 크기가 커서(min/vs 폴더만 약 16MB) 이 페이지 안에 직접 담지 않고, CDN (jsDelivr, 버전 고정 0.55.1)에서 AMD 로더(loader.js) 방식으로 필요한 부분만 그때그때 불러옵니다. README에 "AMD 방식은 향후 제거 예정"이라는 안내가 있지만, 번들러 없이 <script> 태그만으로 붙이는 방법은 현재로선 이 방식뿐이라 그대로 사용했습니다. 아래 예시에 쓰인 물품·가격·거래처 등은 모두 가상의 예시이며 실제 수협중앙회의 통계·자료가 아닙니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.
Monaco Editor 로딩 중...

1. 기본 에디터 + 언어 모드 전환

VS Code와 동일한 문법 강조·자동 들여쓰기가 적용된 기본 에디터입니다. 버튼을 누르면 같은 내용을 다른 언어 문법으로 다시 강조합니다.
아직 읽지 않음
코드 보기 
const editor = monaco.editor.create(document.getElementById('editor1'), {
  value: "// 가상 위판 기록\nconst records = [{ species: '고등어', weight: 320 }];",
  language: 'javascript',
  automaticLayout: true,
});

// 언어 모드만 나중에 바꾸기 (내용은 그대로)
monaco.editor.setModelLanguage(editor.getModel(), 'json');

// 현재 내용 읽기
const code = editor.getValue();

2. 테마 전환

monaco.editor.setTheme()는 페이지 안의 모든 Monaco 에디터 테마를 한 번에 바꿉니다(에디터별 설정이 아님). 아래 버튼으로 확인해보세요 — 이 섹션뿐 아니라 다른 섹션의 에디터들도 함께 바뀝니다.
코드 보기 
// 전역으로 적용됨 (특정 에디터 인스턴스가 아님)
monaco.editor.setTheme('vs-dark');   // 어둡게
monaco.editor.setTheme('hc-black');  // 고대비
monaco.editor.setTheme('vs');        // 기본(밝게)

3. Diff 에디터 (두 내용 비교)

위판 시세표가 수정되기 전/후를 나란히 비교합니다. 변경된 줄은 자동으로 색이 칠해지고, getLineChanges()로 몇 줄이 바뀌었는지 코드에서도 읽어올 수 있습니다.
아직 확인 안 함
코드 보기 
const diffEditor = monaco.editor.createDiffEditor(container);
const original = monaco.editor.createModel('가격: 4200\n품목: 고등어', 'text/plain');
const modified = monaco.editor.createModel('가격: 4500\n품목: 고등어\n비고: 인상', 'text/plain');
diffEditor.setModel({ original, modified });

const changes = diffEditor.getLineChanges();
console.log(changes.length); // 바뀐 구간 개수

4. 커스텀 자동완성(IntelliSense) 제공자

아래 에디터에서 suhyup.까지 입력해보세요(마침표 입력 시 자동으로, 또는 Ctrl/Cmd+Space로) — 직접 등록한 가상 API 자동완성 목록이 뜹니다. VS Code의 자동완성창과 동일한 UI가 그대로 동작합니다.
코드 보기 
monaco.languages.registerCompletionItemProvider('javascript', {
  triggerCharacters: ['.'],
  provideCompletionItems(model, position) {
    return {
      suggestions: [
        {
          label: 'catchReport',
          kind: monaco.languages.CompletionItemKind.Function,
          insertText: 'catchReport()',
          detail: '가상 어획 보고 조회',
          range: new monaco.Range(position.lineNumber, position.column, position.lineNumber, position.column),
        },
        {
          label: 'auctionPrice',
          kind: monaco.languages.CompletionItemKind.Function,
          insertText: 'auctionPrice(species)',
          detail: '가상 위판 시세 조회',
          range: new monaco.Range(position.lineNumber, position.column, position.lineNumber, position.column),
        },
      ],
    };
  },
});
