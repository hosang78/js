기능별 활용 포인트
데모에서 바로 확인 가능한 API

          

            
허용·차단 정책
USE_PROFILES, ALLOWED_*, ADD_*, FORBID_*로 적용 범위를 최소 권한으로 설계합니다.

            
렌더링 전 처리
SAFE_FOR_TEMPLATES, SANITIZE_NAMED_PROPS, WHOLE_DOCUMENT로 템플릿·DOM 이름·문서 단위 맥락을 실험합니다.

            
확장과 관찰
addHook으로 감사·정책 보강을 구현하고, removed로 제거 결과를 관찰합니다.

            
사용자 정의 요소
CUSTOM_ELEMENT_HANDLING에서 태그·속성 패턴을 좁게 정의하여 컴포넌트 기반 UI와 병행합니다.

            
반환 방식
RETURN_DOM, RETURN_DOM_FRAGMENT, RETURN_TRUSTED_TYPE를 비교해 후속 DOM 처리 방식을 선택합니다.

            
직접 DOM 정화
IN_PLACE 모드로 노드를 정화해 복사 비용을 줄이는 사용 사례를 확인합니다.
