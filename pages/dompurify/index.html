DOMPurify 핵심 기능 둘러보기

DOMPurify는 사용자가 입력한 HTML에서 <script>, onerror 같은 위험한 코드(XSS 공격)를 걸러내고 안전한 부분만 남겨주는 보안(정화) 라이브러리입니다. 댓글, 게시판, 에디터처럼 사용자가 HTML/서식이 있는 글을 올리는 화면에서 필수적으로 씁니다.
  • DOMPurify.sanitize(html) 한 줄로 위험한 태그/속성을 제거
  • ALLOWED_TAGS/ALLOWED_ATTR로 허용할 태그·속성을 직접 제한 가능
  • addHook으로 정화 과정에 커스텀 규칙(예: 모든 링크에 안전 속성 추가)을 끼워넣기 가능
  • 정화된 결과만 화면에 그리면 사용자가 입력한 악성 코드가 실행되지 않음
※ 아래 예시의 "공격 코드"는 DOMPurify가 실제로 무엇을 막아주는지 보여주기 위한 교육용 안전한 예시입니다. 이 페이지는 정화되지 않은 원본 코드를 절대 직접 실행(렌더링)하지 않고, 텍스트로만 보여줍니다. 위판장 게시판 예시는 가상이며 실제 수협중앙회 시스템과 무관합니다. DOMPurify(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 정화 (sanitize)

아래에는 일부러 위험한 코드(스크립트, 이미지 오류 핸들러, javascript: 링크)가 섞여 있습니다. "정화하기"를 누르면 위험한 부분만 제거된 결과를 보여줍니다. 원본은 절대 그대로 실행하지 않고 텍스트로만 표시합니다.
정화 전 원본 (텍스트로만 표시 · 실행 안 됨)
정화 후 결과 코드
정화 후 실제 렌더링 (안전하게 화면에 표시)
코드 보기 
const clean = DOMPurify.sanitize(rawHtml);
// <script>, onerror, javascript: 링크 등은 전부 제거되고
// <p>, <b> 같은 안전한 서식 태그는 남음
safeBox.innerHTML = clean; // 정화된 결과만 렌더링

2. 허용 태그 제한 (ALLOWED_TAGS)

기본값은 안전한 서식 태그(굵게, 링크, 이미지 등)를 폭넓게 허용합니다. 더 엄격하게 "굵게/기울임만 허용"으로 제한하면 링크나 이미지까지 전부 제거됩니다.
정화 후 실제 렌더링
코드 보기 
// 엄격 모드: b, i 태그만 남기고 나머지(a, img 등)는 전부 제거
DOMPurify.sanitize(html, { ALLOWED_TAGS: ['b', 'i'] });

3. 커스텀 훅 (addHook)

정화 과정에 규칙을 끼워넣을 수 있습니다. 예: 게시글의 모든 외부 링크에 target="_blank" rel="noopener noreferrer"를 자동으로 붙여서, 새 탭으로 안전하게 열리게 합니다.
정화 후 결과 코드 (속성이 추가된 것을 확인하세요)
실제 렌더링
코드 보기 
DOMPurify.addHook('afterSanitizeAttributes', (node) => {
  if (node.tagName === 'A' && node.hasAttribute('href')) {
    node.setAttribute('target', '_blank');
    node.setAttribute('rel', 'noopener noreferrer');
  }
});

4. 실용 예시 — 게시판 댓글 안전하게 표시

가상의 위판장 게시판 댓글창입니다. 등록 버튼을 누르면 항상 정화를 거친 뒤에만 목록에 추가됩니다.
코드 보기 
function addComment(rawHtml) {
  const clean = DOMPurify.sanitize(rawHtml);
  const li = document.createElement('div');
  li.innerHTML = clean; // 항상 정화된 값만 렌더링
  commentList.appendChild(li);
}
