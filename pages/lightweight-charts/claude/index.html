Lightweight Charts 핵심 기능 둘러보기

Lightweight Charts는 TradingView가 만든 초경량(약 45KB) 금융 차트 라이브러리입니다. Canvas에 직접 그려서 캔들스틱 같은 OHLC 차트를 빠르게 렌더링하고, 마커·가격 라인·크로스헤어 이벤트 같은 트레이딩 차트 특유의 기능을 기본 API로 제공합니다.
  • candlestickSeries + histogramSeries로 만드는 캔들스틱 · 거래량 차트
  • subscribeCrosshairMove()로 만드는 커스텀 호버 범례
  • createSeriesMarkers() · createPriceLine()로 표시하는 이벤트 마커와 기준선
  • series.update()로 마지막 캔들을 갱신하는 실시간 스트리밍
※ 아래 "고등어 일별 시세"는 실제 위판 데이터에는 없는 시가·고가·저가·종가(OHLC) 개념을 이 라이브러리 데모를 위해 임의로 구성한 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Lightweight Charts(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 캔들스틱 + 거래량 차트

고등어의 가상 일별 시세를 캔들스틱으로, 그날 위판량을 하단의 막대(히스토그램)로 함께 표시했습니다. 거래량은 별도 가격축 없이 캔들 차트 아래 20% 영역에 겹쳐 그려집니다.
코드 보기 
const chart = createChart(container, { autoSize: true });

const candleSeries = chart.addSeries(CandlestickSeries, {
  upColor: '#1baf7a', downColor: '#e34948',
  borderVisible: false, wickUpColor: '#1baf7a', wickDownColor: '#e34948',
});
candleSeries.setData(ohlcData);   // [{ time, open, high, low, close }, ...]

const volumeSeries = chart.addSeries(HistogramSeries, {
  priceFormat: { type: 'volume' },
  priceScaleId: '',                                  // 별도 가격축을 만들지 않고 겹쳐 그림
});
volumeSeries.priceScale().applyOptions({ scaleMargins: { top: 0.8, bottom: 0 } });
volumeSeries.setData(volumeData);  // [{ time, value, color }, ...]

chart.timeScale().fitContent();

2. 크로스헤어 이벤트로 만드는 커스텀 범례

차트 위에서 마우스를 움직이면 subscribeCrosshairMove 이벤트로 그 날짜의 OHLC 값과 거래량을 읽어와 좌측 상단 범례에 표시합니다.
차트 위에 마우스를 올려보세요
코드 보기 
chart.subscribeCrosshairMove((param) => {
  if (!param.time) { legendEl.textContent = '차트 위에 마우스를 올려보세요'; return; }
  const bar = param.seriesData.get(candleSeries);   // { open, high, low, close }
  const vol = param.seriesData.get(volumeSeries);   // { value }
  legendEl.innerHTML = `${param.time} · 종가 ${bar.close}원 · 거래량 ${vol.value}건`;
});

3. 시리즈 마커 + 가격 라인

성수기가 시작된 날짜에 화살표 마커를, 최근 30일 평균 시세 위치에 수평 기준선(가격 라인)을 그렸습니다.
코드 보기 
createSeriesMarkers(candleSeries, [
  { time: peakSeasonStart, position: 'aboveBar', color: '#eda100', shape: 'arrowDown', text: '성수기 시작' },
]);

candleSeries.createPriceLine({
  price: averagePrice,
  color: '#4a3aa7',
  lineWidth: 1,
  lineStyle: LineStyle.Dashed,
  title: '30일 평균',
});

4. 실시간 스트리밍 갱신

1초마다 진행 중인 오늘 캔들의 값을 바꾸다가, 일정 확률로 다음날 캔들을 새로 추가합니다. series.update()는 마지막 항목과 시간이 같으면 값만 바꾸고, 시간이 더 미래면 새 항목을 이어붙입니다.
스트리밍 대기 중...
코드 보기 
let last = ohlcData[ohlcData.length - 1];
setInterval(() => {
  const move = (Math.random() - 0.5) * 60;
  last = { ...last, close: last.close + move, high: Math.max(last.high, last.close + move), low: Math.min(last.low, last.close + move) };
  candleSeries.update(last);       // 시간이 같으므로 마지막 캔들 값만 갱신
}, 1000);
