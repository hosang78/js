GSAP 핵심 기능 둘러보기

GSAP(GreenSock Animation Platform)은 웹에서 부드럽고 정교한 애니메이션을 만드는 자바스크립트 라이브러리입니다. CSS 애니메이션보다 세밀한 제어와 시퀀스 구성이 쉽습니다.
  • 요소의 위치·크기·투명도 등을 to/from/fromTo로 애니메이션
  • Timeline으로 여러 애니메이션을 순서대로/겹쳐서 재생 가능
  • stagger로 여러 요소를 살짝씩 시간차를 두고 순차적으로 재생
  • 다양한 이징(ease) 함수로 "가속/감속/튕김" 같은 움직임의 느낌을 조절
※ 아래 "위판 진행 상황" 카드는 GSAP 학습용으로 만든 가상의 샘플 화면이며, 실제 수협중앙회의 절차/데이터가 아닙니다. 이 페이지는 GSAP(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 트윈 (fromTo)

버튼을 누르면 박스가 왼쪽 밖에서 나타나 제자리로 이동하며 서서히 나타납니다(fade in).
입고
코드 보기 
gsap.fromTo('#box1',
  { x: -120, opacity: 0 },
  { x: 0, opacity: 1, duration: 0.8, ease: 'power2.out' }
);

2. 타임라인 (Timeline) — 순서대로 재생

가상의 "위판 진행 상황" 4단계 카드가 타임라인으로 순서대로 나타납니다.
1
입고
2
경매
3
낙찰
4
정산
코드 보기 
const tl = gsap.timeline({ paused: true });
tl.to('#flow1', { opacity: 1, y: 0, duration: 0.4 })
  .to('#flow2', { opacity: 1, y: 0, duration: 0.4 }, '+=0.1') // 0.1초 텀
  .to('#flow3', { opacity: 1, y: 0, duration: 0.4 }, '+=0.1')
  .to('#flow4', { opacity: 1, y: 0, duration: 0.4 }, '+=0.1');

playBtn.addEventListener('click', () => tl.restart());

3. stagger — 여러 요소 순차 등장

가상의 위판장 6곳 카드가 0.08초씩 시간차를 두고 차례로 나타납니다.
부산공동어시장
목포수산시장
통영수산시장
여수수산시장
포항죽도시장
노량진수산시장
코드 보기 
gsap.to('.stagger-item', {
  opacity: 1,
  scale: 1,
  duration: 0.4,
  stagger: 0.08, // 요소마다 0.08초씩 지연
  ease: 'back.out(1.7)',
});

4. 이징(ease) 비교

같은 거리·시간이어도 이징에 따라 움직임의 느낌이 다릅니다. "출발"을 눌러 4개를 동시에 비교해보세요.
linear
power2.out
bounce.out
elastic.out
코드 보기 
gsap.to(dotEl, { x: trackWidth - 18, duration: 1.2, ease: 'bounce.out' });
// ease: 'none' | 'power2.out' | 'bounce.out' | 'elastic.out(1,0.4)' 등
