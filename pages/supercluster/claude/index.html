Supercluster 핵심 기능 둘러보기

Supercluster는 지도를 그리지 않는 순수 알고리즘 라이브러리로, 수만 개의 지점을 빠르게 클러스터(뭉치)로 묶어주는 데 특화되어 있습니다. 지도를 확대할수록 클러스터가 점점 개별 지점으로 흩어지는, 지도 앱에서 흔히 보는 마커 뭉침 효과의 계산 엔진입니다.
  • index.load(points)로 GeoJSON 포인트들을 한 번에 인덱싱
  • index.getClusters(bbox, zoom)으로 특정 영역·줌 레벨에서의 클러스터 결과 조회
  • getClusterExpansionZoom(clusterId)로 그 클러스터가 펼쳐지기 시작하는 줌 레벨 계산
  • getLeaves(clusterId)로 클러스터 안에 실제로 포함된 개별 지점의 원본 데이터 조회
※ Supercluster는 결과(클러스터 좌표·개수)만 계산해줄 뿐 화면에 그리지는 않습니다. 이 페이지는 결과를 눈으로 확인하기 위해 위경도를 canvas 좌표로 단순 매핑해 직접 그렸습니다(실제 서비스에서는 MapLibre·Leaflet 같은 지도 라이브러리 위에 얹어 씁니다). 위판 물량 지점은 모두 가상의 예시이며 실제 수협중앙회의 조업 데이터가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 기본 클러스터링

가상 위판 물량 60개 지점을 낮은 줌 레벨(넓은 범위)로 조회하면, 대부분 큰 클러스터 하나로 뭉칩니다. 원 안의 숫자는 그 클러스터에 포함된 지점 수입니다.
코드 보기 
const index = new Supercluster({ radius: 60, maxZoom: 16 });
index.load(points); // GeoJSON Feature 배열

const clusters = index.getClusters([west, south, east, north], zoom);
// cluster.properties.cluster === true 면 클러스터, 아니면 개별 지점
// cluster.properties.point_count 로 포함된 지점 수 확인

2. Zoom 레벨에 따른 클러스터링 변화

슬라이더로 줌 레벨을 올려보세요. 줌이 높아질수록(지도를 확대할수록) 클러스터가 점점 개별 지점으로 흩어집니다.
코드 보기 
// 같은 index, 같은 bbox라도 zoom 값에 따라 결과가 달라짐
index.getClusters(bbox, 3);  // 클러스터 1~2개로 뭉침
index.getClusters(bbox, 16); // 거의 모든 지점이 개별로 분리

3. 클러스터 상세 정보 — 확장 줌 & 포함된 지점

위 2번 캔버스에서 숫자가 적힌 원(클러스터)을 클릭해보세요. 그 클러스터가 몇 번째 줌부터 펼쳐지기 시작하는지, 그리고 안에 어떤 지점들이 포함되어 있는지 확인합니다.
클러스터를 클릭해보세요
