MicroModal 핵심 기능 둘러보기

MicroModal은 의존성 없이 동작하는 아주 가벼운(약 2KB) 모달(팝업) 라이브러리입니다. HTML 속성만으로 모달을 열고 닫을 수 있고, 포커스 트랩·ESC 닫기 같은 접근성 기능이 기본으로 들어있습니다.
  • data-micromodal-trigger로 여는 기본 모달
  • Tab 키가 모달 밖으로 나가지 않는 포커스 트랩 + ESC/배경 클릭 닫기
  • onShow/onClose 콜백과 CSS 애니메이션을 기다리는 열기·닫기 연출
  • MicroModal.show() / close() / closeAll()로 하는 프로그래밍 방식 제어
※ 아래 위판장·정산 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 시스템 화면과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 모달

버튼에 data-micromodal-trigger 속성만 넣으면 MicroModal.init()이 자동으로 클릭 이벤트를 연결합니다. 배경을 클릭하거나 우측 상단 ×, ESC 키로 닫을 수 있습니다.
코드 보기 
<button data-micromodal-trigger="modal-basic">상세 정보 보기</button>

<div class="modal" id="modal-basic" aria-hidden="true">
  <div class="modal__overlay" tabindex="-1" data-micromodal-close>
    <div class="modal__container" role="dialog" aria-modal="true">
      ...
    </div>
  </div>
</div>

MicroModal.init();

2. 포커스 트랩 + ESC / 배경 클릭 닫기

모달을 열고 Tab을 계속 눌러보면 포커스가 모달 안의 입력창·버튼 사이에서만 순환하고 뒤쪽 페이지로 빠져나가지 않습니다. 스크린리더 사용자를 포함해 키보드만으로도 안전하게 모달을 사용할 수 있게 해주는 기본 접근성 기능입니다.
코드 보기 
MicroModal.init({
  disableScroll: true,   // 모달이 열려 있는 동안 배경 스크롤 방지
});
// 포커스 트랩·ESC 닫기는 별도 설정 없이 기본으로 동작한다

3. onShow / onClose 콜백 + 열기·닫기 애니메이션

모달이 열리고 닫힐 때마다 콜백이 실행되어 아래 상태 박스를 갱신합니다. awaitCloseAnimation: true를 켜면 CSS 애니메이션이 끝나는 animationend 이벤트를 기다렸다가 모달을 실제로 숨기는데, 애니메이션을 정의해두지 않은 채 이 옵션만 켜면 그 이벤트가 영영 오지 않아 모달이 화면에 계속 남아있게 됩니다 — 실제로 겪어본 함정이라 아래 코드에 CSS 애니메이션을 꼭 같이 넣어뒀습니다.
아직 모달을 연 적이 없습니다.
코드 보기 
MicroModal.show('modal-anim', {
  awaitOpenAnimation: true,
  awaitCloseAnimation: true,
  onShow: () => { stat.textContent = '모달이 열렸습니다.'; },
  onClose: () => { stat.textContent = '모달이 닫혔습니다.'; },
});

/* 이 애니메이션이 없으면 awaitCloseAnimation:true일 때 모달이 안 닫힌다 */
.modal--anim.is-open .modal__overlay { animation: mmfadeIn .2s ease-out; }
.modal--anim[aria-hidden="true"] .modal__overlay { animation: mmfadeOut .2s ease-in; }

4. 프로그래밍 방식 제어

버튼 클릭이 아니라 코드에서 직접 MicroModal.show() / close()를 호출해서 두 개의 모달을 순서대로 열고, closeAll()로 한 번에 모두 닫아봅니다.
아직 열린 모달이 없습니다.
코드 보기 
document.getElementById('s4-open-a').addEventListener('click', () => {
  MicroModal.show('modal-a');
});
// 모달 A가 열려 있는 동안은 오버레이가 화면 전체를 덮어 뒤쪽 페이지를 클릭할 수 없으므로,
// "B 열기" 버튼은 모달 A의 푸터 안에 넣어야 실제로 누를 수 있다.
document.getElementById('s4-open-b').addEventListener('click', () => {
  MicroModal.close('modal-a');
  MicroModal.show('modal-b');
});
document.getElementById('s4-close-all').addEventListener('click', () => {
  MicroModal.closeAll();
});
