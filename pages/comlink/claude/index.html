Comlink 핵심 기능 둘러보기

Comlink는 Web Worker와의 통신(postMessage 기반이라 원래는 번거로움)을 ES6 Proxy로 감싸서, 워커 안의 함수·객체를 마치 로컬에 있는 것처럼 await로 호출할 수 있게 해주는 라이브러리입니다.
  • Comlink.expose(Class)(워커 쪽) + Comlink.wrap(worker)(메인 쪽)로 원격 호출 연결
  • 워커 안에서 new로 만든 클래스 인스턴스는 여러 번 호출해도 상태가 유지됨
  • Comlink.proxy(fn)으로 메인 스레드 콜백을 워커에 넘겨 진행 상황을 실시간으로 전달받음
  • Comlink.transfer(buffer, [buffer])로 ArrayBuffer를 복사 없이 워커로 이전(원본은 비워짐)
※ 이 페이지의 위판 물량·시세 계산은 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. 워커에서 무거운 계산 실행 (메인 스레드가 멈추지 않음)

버튼을 누르면 워커 안에서 2백만 번 반복 계산을 수행합니다. 계산 중에도 옆의 스피너가 끊김 없이 계속 도는 것을 확인하세요 — 메인 스레드(화면)가 전혀 막히지 않았다는 뜻입니다.
← 계속 돌고 있어야 정상
아직 실행 안 함
코드 보기 
// worker.js
class MarketCalculator {
  async heavyCompute(n) {
    let sum = 0;
    for (let i = 0; i < n; i++) sum += Math.sqrt(i);
    return sum;
  }
}
Comlink.expose(MarketCalculator);

// 메인 스레드
const WorkerAPI = Comlink.wrap(new Worker('worker.js'));
const instance = await new WorkerAPI();
const result = await instance.heavyCompute(2000000); // await해도 화면은 안 멈춤

2. 워커 안의 클래스 인스턴스 — 상태 유지

버튼을 여러 번 누르면 워커 안의 같은 인스턴스에 값이 계속 누적됩니다(요청마다 새로 만들어지는 게 아님).
누적 물량: 0kg
코드 보기 
const instance = await new WorkerAPI(); // 워커 안에 인스턴스 하나 생성
await instance.addToTotal(10); // 10
await instance.addToTotal(10); // 20 — 이전 호출의 상태가 유지됨

3. 콜백 프록시로 진행률 받기

워커가 처리 중간중간 진행 상황을 메인 스레드의 콜백 함수로 직접 호출해 알려줍니다.
대기 중
코드 보기 
await instance.processWithProgress(5, Comlink.proxy((step, total) => {
  console.log(`${step}/${total} 완료`); // 워커에서 메인 스레드 함수를 직접 호출
}));

4. Transferable 객체 전송

버퍼를 복사하지 않고 워커로 이전(transfer)합니다. 전송 후 메인 스레드에 남은 원본 버퍼의 크기가 0이 되는 것을 확인하세요 — 소유권 자체가 넘어갔다는 증거입니다.
아직 전송 안 함
코드 보기 
const buffer = new Float64Array([10, 20, 30, 40, 50]).buffer;
buffer.byteLength; // 40

const result = await instance.sumBuffer(Comlink.transfer(buffer, [buffer]));
buffer.byteLength; // 0 — 복사가 아니라 소유권이 워커로 이전됨(더 빠름)
