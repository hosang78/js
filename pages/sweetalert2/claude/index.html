SweetAlert2 핵심 기능 둘러보기

SweetAlert2는 브라우저 기본 alert()/confirm()보다 훨씬 꾸며진 팝업 알림·확인창·입력폼을 손쉽게 띄워주는 라이브러리입니다.
  • Swal.fire({ title, text, icon }) 한 번으로 완성된 알림창 표시
  • showCancelButton과 결과 객체의 isConfirmed로 확인/취소 분기 처리
  • input 옵션으로 텍스트·선택·textarea 등 입력 폼을 팝업 안에 바로 넣을 수 있음
  • toast: true로 화면 구석에 잠깐 떴다 사라지는 알림도 지원
※ 아래 위판 업무 상황(등록·오류·입력 등)은 SweetAlert2 학습용으로 만든 가상의 예시이며, 실제 수협중앙회의 시스템 메시지가 아닙니다. 이 페이지는 SweetAlert2(CDN, 올인원 번들) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 알림

상황별로 아이콘이 다른 알림창을 띄워봅니다.
코드 보기 
Swal.fire({
  title: '등록 완료',
  text: '고등어 320kg 위판이 등록되었습니다.',
  icon: 'success',
  confirmButtonText: '확인',
});

2. 확인 · 취소 다이얼로그

위판 등록을 취소하기 전에 한 번 더 확인을 받습니다.
아직 선택 없음
코드 보기 
const result = await Swal.fire({
  title: '정말 취소하시겠습니까?',
  text: '고등어 320kg 위판 등록이 취소됩니다.',
  icon: 'warning',
  showCancelButton: true,
  confirmButtonText: '취소하기',
  cancelButtonText: '유지하기',
  confirmButtonColor: '#e34948',
});

if (result.isConfirmed) {
  // 사용자가 "취소하기"를 눌렀을 때
} else {
  // "유지하기"를 눌렀거나 팝업을 닫았을 때
}

3. 입력 폼 다이얼로그

팝업 안에서 바로 위판 신고 정보를 입력받고, 값이 비어있으면 검증 메시지를 보여줍니다.
아직 입력 없음
코드 보기 
const { value } = await Swal.fire({
  title: '위판 신고',
  html:
    '<select id="swal-species" class="swal2-select">' +
    '<option>고등어</option><option>갈치</option><option>오징어</option>' +
    '</select>' +
    '<input id="swal-qty" type="number" class="swal2-input" placeholder="수량(kg)">',
  focusConfirm: false,
  preConfirm: () => {
    const species = document.getElementById('swal-species').value;
    const qty = document.getElementById('swal-qty').value;
    if (!qty) {
      Swal.showValidationMessage('수량을 입력해주세요.');
      return false;
    }
    return { species, qty };
  },
});

4. 토스트 알림

화면 구석에 잠깐 떴다가 자동으로 사라지는 알림입니다. 진행 표시줄로 남은 시간을 보여줍니다.
코드 보기 
Swal.fire({
  toast: true,
  position: 'top-end',
  icon: 'success',
  title: '변경사항이 저장되었습니다.',
  showConfirmButton: false,
  timer: 2500,
  timerProgressBar: true,
});
