uPlot 핵심 기능 둘러보기

uPlot은 속도와 크기에 극단적으로 최적화된 시계열 차트 라이브러리입니다(번들 약 50KB, 의존성 없음). SVG가 아니라 Canvas 하나에 직접 그려서, 수만~수십만 개의 점도 지연 없이 렌더링합니다.
  • Canvas 기반 초고속 렌더링 — 대용량 시계열 데이터에 특화
  • 배열의 배열로 값을 넘기는 컬럼형(columnar) 데이터 포맷 — Plot/Vega의 "객체 배열"과 다른 방식
  • 여러 차트를 같은 sync 키로 묶으면 커서 위치와 확대/축소(zoom) 상태가 함께 동기화
  • setData()로 데이터를 빠르게 교체하는 실시간 스트리밍 갱신
※ 아래 위판 시세 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. uPlot(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 대용량 데이터 즉시 렌더링

1분 간격으로 기록된 가상의 위판 시세 20,000개 포인트를 그렸습니다. Canvas에 직접 그리기 때문에 SVG처럼 DOM 노드가 늘어나지 않고, 이 정도 데이터도 렌더링이 즉시 끝납니다.
렌더링 중...
코드 보기 
const t0 = performance.now();
const u = new uPlot({
  width: 700, height: 300,
  series: [{}, { label: '시세', stroke: '#2a78d6', width: 1.5 }],
}, [xs, ys], container);   // xs, ys: 각각 20,000개짜리 숫자 배열
const renderMs = performance.now() - t0;   // 수 ms 안에 끝남

2. 컬럼형(columnar) 데이터 포맷

Observable Plot이나 Vega는 [{market, price}, ...] 같은 "객체 배열"을 쓰지만, uPlot은 [xs, ys1, ys2, ...] 형태의 "배열의 배열"만 받습니다. 같은 x축(시간)을 공유하는 여러 계열을 다룰 때 메모리와 처리 속도 면에서 유리한 구조입니다.
코드 보기 
// 객체 배열이 아니라, 값들을 열(column) 단위로 미리 뽑아 배열로 준비한다
const xs  = [t0, t1, t2, ...];        // 공통 시간축
const ys1 = [p0, p1, p2, ...];        // 1위판장 시세
const ys2 = [p0, p1, p2, ...];        // 2위판장 시세
const ys3 = [p0, p1, p2, ...];        // 3위판장 시세

new uPlot({
  series: [
    {},
    { label: '1위판장', stroke: '#2a78d6' },
    { label: '2위판장', stroke: '#1baf7a' },
    { label: '3위판장', stroke: '#eda100' },
  ],
}, [xs, ys1, ys2, ys3], container);

3. 여러 차트의 커서 · 확대(zoom) 동기화

아래 두 차트는 같은 sync 키를 공유합니다. 한쪽 차트 위에 마우스를 올리면 다른 차트의 커서도 같은 시점으로 움직이고, 한쪽을 드래그해서 확대하면 다른 차트도 같은 구간으로 함께 확대됩니다. 더블클릭하면 원래대로 돌아옵니다.

코드 보기 
const cursorOpts = { sync: { key: 'market-sync' } };   // 두 차트가 같은 키를 공유

new uPlot({ cursor: cursorOpts, series: [{}, { label: 'A위판장', stroke: '#2a78d6' }] }, dataA, elA);
new uPlot({ cursor: cursorOpts, series: [{}, { label: 'B위판장', stroke: '#1baf7a' }] }, dataB, elB);
// 커서 이동과 드래그 확대(zoom) 상태가 sync 키를 공유하는 모든 차트에 자동 전파됨

4. 실시간 스트리밍 갱신

1초마다 새 값 하나를 추가하고 가장 오래된 값을 버린 뒤 setData()를 호출합니다. 차트 인스턴스를 새로 만들지 않고 데이터만 교체합니다.
코드 보기 
setInterval(() => {
  xs.push(xs[xs.length - 1] + 1);
  xs.shift();                          // 가장 오래된 시간 제거
  ys.push(nextPrice());
  ys.shift();                          // 가장 오래된 값 제거
  u.setData([xs, ys]);                 // 차트를 새로 만들지 않고 데이터만 교체
}, 1000);
