인라인 텍스트의 정확한 기준점

문장 중간의 여러 줄로 감싸질 수 있는 인라인 대상은 일반 요소와 다른 사각형 계산이 필요할 수 있다. narrow viewport에서 줄바꿈이 일어나면 특히 차이를 보기 쉽다.

07가상 기준점과 컨텍스트 메뉴

DOM 요소가 아닌 포인터 좌표를 기준점으로 사용한다. getReferenceClientRect가 필요한 대표 사례다.

virtual positioning

오른쪽 클릭 또는 모바일 환경에서는 길게 눌러 보자.
클릭한 위치 옆에 Tippy 기반 컨텍스트 메뉴가 열린다.

08Delegate·Singleton·사용자 플러그인

많은 동적 항목은 이벤트 위임으로 지연 생성하고, 가까운 툴팁 그룹은 singleton으로 부드럽게 이동시킬 수 있다.

addons · custom plugin

Event delegation

추가된 버튼도 별도 초기화 없이 처음 트리거될 때 Tippy가 만들어진다.

Singleton + custom plugin

각 대상은 하나의 팝오버를 공유한다. 하단 버튼으로 순서를 제어한다.

custom plugin은 생성·표시 시점 같은 라이프사이클 훅을 공통화할 때 유용하다. 이 페이지에서는 singleton 항목이 열릴 때 상단 상태 문구를 갱신하는 간단한 플러그인을 사용한다.

실행 방법: 인터넷 연결 상태에서 HTML 파일을 브라우저로 열면 된다. 내부망에서 활용하려면 CDN 주소의 JS/CSS 파일을 내려받아 로컬 assets/tippy/ 경로로 교체하면 된다.
