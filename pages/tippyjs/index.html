Tippy.js 핵심 기능 둘러보기

Tippy.js는 툴팁·팝오버를 쉽게 만들어주는 라이브러리입니다. CSS 선택자 하나로 요소에 붙일 수 있고, 위치 계산은 내부적으로 Popper 엔진을 사용합니다.
  • tippy(selector, options) 한 줄로 요소에 툴팁을 붙임
  • placement로 툴팁이 뜨는 방향을 지정
  • trigger로 hover/click/focus 등 언제 뜰지 지정
  • interactive: true면 툴팁 안의 버튼·링크를 클릭할 수 있음
  • content를 함수로 주면 툴팁이 열리는 시점에 내용을 늦게(지연) 채울 수 있음
※ 아래 위판장/조합원/시세 정보는 Tippy.js 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 통계·조직·시세 자료가 아닙니다. 이 페이지는 Tippy.js(CDN) 외에 Tippy.js가 위치 계산을 위해 반드시 필요로 하는 Popper(@popperjs/core, CDN)를 함께 사용합니다. (다른 외부 API는 사용하지 않습니다.)

1. 기본 툴팁 · 배치(placement)

위판장 카드에 마우스를 올리면 툴팁이 뜹니다. 아래 select로 툴팁이 뜨는 방향을 바꿔볼 수 있습니다.
배치 방향:
부산공동어시장
목포수산시장
코드 보기 
const tips1 = tippy('#card1, #card1b', {
  placement: 'bottom',
  animation: 'shift-away',
});

// 방향 바꾸기
document.getElementById('placementSelect').addEventListener('change', (e) => {
  tips1.forEach((t) => t.setProps({ placement: e.target.value }));
});

2. trigger 옵션 (hover · click · focus)

조합원 카드 3개에 각각 다른 trigger를 지정했습니다. 첫 번째는 마우스를 올리면, 두 번째는 클릭하면, 세 번째는 Tab으로 포커스가 가면 뜹니다.
마우스 올리기 (hover)
클릭 (click)
Tab으로 포커스 (focus)
코드 보기 
tippy('#member1', { trigger: 'mouseenter' }); // 기본값
tippy('#member2', { trigger: 'click' });
tippy('#member3', { trigger: 'focus' });

3. interactive 툴팁 (버튼 클릭 가능)

위판 정보 카드를 클릭하면, 툴팁 안에 있는 버튼을 직접 클릭할 수 있는 상호작용 툴팁이 뜹니다. (interactive: true + allowHTML: true)
1번 위판 물량 (고등어 320kg)
아직 아무 동작 없음
코드 보기 
tippy('#lot1', {
  trigger: 'click',
  interactive: true,
  allowHTML: true,
  theme: 'light-border',
  content: `
    <div style="font-size:13px;">
      고등어 320kg · 시작가 3,200원/kg<br/>
      <button id="bidBtn">즉시 입찰</button>
    </div>`,
  onShown(instance) {
    // 툴팁이 렌더링된 뒤에 안쪽 버튼에 이벤트를 건다
    document.getElementById('bidBtn').onclick = () => {
      document.getElementById('lotStatus').textContent = '입찰 접수됨: 고등어 320kg';
      instance.hide();
    };
  },
});

4. 지연 로딩 콘텐츠 (content 함수 + onShow)

어종 카드에 마우스를 올리면 "시세 조회 중..."이 먼저 뜨고, 잠시 후 실제 시세로 내용이 바뀝니다. 실시간 API 호출을 흉내 낸 것으로, 실제 시세 데이터는 아닙니다.
고등어 시세 보기
갈치 시세 보기
코드 보기 
const priceData = { price1: '고등어 3,200원/kg', price2: '갈치 8,500원/kg' };

tippy('#price1, #price2', {
  allowHTML: true,
  onShow(instance) {
    instance.setContent('시세 조회 중...');
    // 실제로는 fetch()로 API를 호출하는 자리 (여기서는 setTimeout으로 흉내)
    setTimeout(() => {
      instance.setContent(priceData[instance.reference.id]);
    }, 600);
  },
});
