Observable Plot 핵심 기능 둘러보기

Observable Plot은 D3.js 위에 만들어진 선언형(grammar-of-graphics) 차트 라이브러리입니다. D3.js처럼 축·스케일·DOM을 직접 조립하는 대신, "어떤 마크를 어떤 데이터에 올릴지"만 선언하면 축·스케일·범례를 자동으로 계산해줍니다.
  • 여러 마크(bar, rule, text, line 등)를 배열에 나열하는 것만으로 겹쳐 그리기
  • groupX/stackY 같은 내장 변환(transform) — 원본 데이터를 직접 집계하지 않고 선언만으로 합산·누적 계산
  • facet으로 하나의 스펙에서 소단위(small multiples) 그래프 자동 분할
  • 다중 계열 색상 자동 범례, Plot.tip으로 마우스 오버 툴팁 내장
※ 아래 위판 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Observable Plot은 D3.js 위에서 동작하므로 D3.js(CDN)도 함께 로드합니다. 다른 외부 API는 사용하지 않습니다.

1. 레이어 마크 조합

막대(barY) + 기준선(ruleY) + 라벨(text), 세 가지 마크를 배열에 나열하기만 하면 한 좌표계 위에 겹쳐 그려집니다. 축과 스케일은 Plot이 데이터 범위를 보고 자동으로 계산합니다.
코드 보기 
const avg = d3.mean(data, (d) => d.catch);

Plot.plot({
  marks: [
    Plot.barY(data, { x: 'market', y: 'catch', fill: '#2a78d6' }),
    Plot.ruleY([avg], { stroke: '#e34948', strokeWidth: 2 }),      // 평균 기준선
    Plot.text([{ market: lastMarket, catch: avg }], {
      x: 'market', y: avg, text: () => `평균 ${avg.toFixed(0)}`, dy: -8, fill: '#e34948',
    }),
  ],
});

2. 자동 집계 변환 (groupX / stackY)

왼쪽은 위판장별 개별 거래 원자료를 그대로 넣고 Plot.groupX가 합계를 자동 계산한 막대입니다. 오른쪽은 같은 원자료를 어종별로 Plot.stackY로 누적해 구성비를 보여줍니다 — 두 경우 모두 사전에 합계를 직접 계산하지 않았습니다.
groupX(sum) — 위판장별 합계
stackY — 어종별 누적
코드 보기 
// rawRows: [{ market, catch }, ...] 형태의 개별 거래 원자료 (합계 미리 계산 안 함)
Plot.plot({
  marks: [Plot.barY(rawRows, Plot.groupX({ y: 'sum' }, { x: 'market', y: 'catch', fill: '#1baf7a' }))],
});

// stackRows: [{ market, species, amount }, ...]
Plot.plot({
  color: { legend: true, domain: ['고등어', '갈치', '오징어'], range: ['#2a78d6', '#1baf7a', '#eda100'] },
  marks: [Plot.barY(stackRows, Plot.stackY({ x: 'market', y: 'amount', fill: 'species' }))],
});

3. facet — 소단위 분할

facet 옵션 하나로 어종별 소단위(small multiples) 그래프를 자동으로 나눠 그립니다. 반복문 없이 하나의 스펙만 작성했습니다.
코드 보기 
Plot.plot({
  facet: { data, x: 'species' },              // species 값마다 소단위 패널을 자동 생성
  fx: { domain: ['고등어', '갈치', '오징어'] },  // 패널 순서 고정
  marks: [Plot.lineY(data, { x: 'day', y: 'price', stroke: '#2a78d6' })],
});

4. 다중 계열 + 자동 범례 + 인터랙티브 tip

위판장별 일별 시세 추이입니다. 색상은 stroke: 'market' 채널 하나로 지정했을 뿐인데 범례가 자동으로 만들어졌고, Plot.tip이 마우스를 가까이 가져가면 해당 지점의 값을 보여줍니다. 그래프 위에 마우스를 올려보세요.
코드 보기 
Plot.plot({
  color: { legend: true, domain: ['1위판장', '2위판장'], range: ['#2a78d6', '#1baf7a'] },
  marks: [
    Plot.lineY(data, { x: 'day', y: 'catch', stroke: 'market' }),
    Plot.tip(data, Plot.pointerX({ x: 'day', y: 'catch', stroke: 'market' })),  // 마우스 오버 툴팁
  ],
});
