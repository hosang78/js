Observable Plot
종합 기능 샘플

Plot의 그래픽 문법을 중심으로 mark, transform, scale, facet, projection, interaction을 한 페이지에 모았습니다. 모든 데이터는 페이지 내부에서 생성되며, 각 차트의 코드 확인과 SVG·PNG 저장이 가능합니다.

01. 정렬 막대 + 직접 라벨

barX, sort, text, rule을 이용한 순위형 막대 차트

barXsorttext
Plot.plot({
  x: {grid: true},
  y: {domain: d3.sort(data, d => -d.value).map(d => d.name)},
  marks: [
    Plot.barX(data, {x: "value", y: "name", fill: "name", tip: true}),
    Plot.text(data, {x: "value", y: "name", text: d => d.value, dx: 5, textAnchor: "start"}),
    Plot.ruleX([0])
  ]
})

02. 그룹 집계 + 누적 막대

groupX의 sum reducer와 암시적 stackY 결합

groupXstackYlegend
Plot.barY(rows,
  Plot.groupX({y: "sum"}, {x: "quarter", y: "amount", fill: "channel", tip: true})
)

03. 다중 시계열 + 영역 + 끝점 라벨

curve 선택, marker, selectLast, tip을 조합한 시계열

lineYareaYselectLasttip
Plot.plot({
  marks: [
    Plot.areaY(total, {x: "date", y: "value", fillOpacity: .12, curve}),
    Plot.lineY(series, {x: "date", y: "value", stroke: "product", curve, marker: "circle", tip: true}),
    Plot.text(series, Plot.selectLast({x: "date", y: "value", text: "product", fill: "product", dx: 7}))
  ]
})

]})
