DuckDB-Wasm

DuckDB-Wasm은 분석용 데이터베이스 DuckDB 전체를 WebAssembly로 컴파일해 브라우저 안에서 그대로 돌리는 라이브러리입니다. 서버로 데이터를 보내지 않고, 페이지를 연 브라우저 탭 안(Web Worker)에서 진짜 SQL 엔진이 CSV/JSON을 읽고, JOIN·GROUP BY·윈도우 함수 같은 본격적인 분석 쿼리를 실행합니다.

  • 표준 SQL 그대로 사용 (CREATE TABLE, JOIN, GROUP BY, 윈도우 함수, CTE 등)
  • read_csv_auto() 등으로 CSV/JSON 텍스트를 파일처럼 등록해서 바로 쿼리
  • 쿼리 결과는 Apache Arrow 컬럼형 포맷으로 반환 — 대용량도 빠르게 JS로 변환
  • 컬럼형 OLAP 엔진이라 대량 데이터 집계가 일반 JS 반복문보다 훨씬 빠름
⚠️ 이 페이지의 위판·조업 데이터는 DuckDB-Wasm 기능 설명을 위한 가상의 예시이며, 실제 수협중앙회의 통계·조직·절차와 무관합니다. Apache Arrow(결과 포맷 변환)를 함께 사용하며, 다른 외부 API는 사용하지 않았습니다 (DuckDB-Wasm 1.32.0, apache-arrow 17.0.0 — CDN에서 로드).
첫 로딩 시 WASM 엔진 파일을(약 30MB) 내려받기 때문에 초기화에 몇 초 걸릴 수 있습니다 (이후에는 브라우저 캐시로 빨라집니다).

1. 기본 SQL 실행 — 브라우저 안 인메모리 DB

CREATE TABLE / INSERT / SELECT를 그대로 실행합니다. 아래 SQL을 자유롭게 수정하고 "실행"을 눌러보세요. 세미콜론(;)으로 여러 문장을 이어서 실행할 수 있습니다.

소스 코드 보기 
const conn = await db.connect();
for (const statement of sql.split(';').filter((s) => s.trim())) {
  const result = await conn.query(statement);
  // result.toArray().map(row => row.toJSON()) 로 일반 JS 객체 배열로 변환
}

2. CSV 텍스트를 파일처럼 등록 — registerFileText + read_csv_auto

실제 파일 업로드 없이도 문자열을 가상 파일로 등록하면 read_csv_auto('파일명')으로 바로 쿼리할 수 있습니다. 아래 CSV를 수정하고 다시 실행해보세요.

소스 코드 보기 
await db.registerFileText('catch.csv', csvText);
await conn.query(`CREATE OR REPLACE TABLE catch_log AS SELECT * FROM read_csv_auto('catch.csv')`);
const summary = await conn.query(`SELECT COUNT(*) AS cnt, SUM(weight_kg) AS total FROM catch_log`);

3. Prepared Statement — 매개변수화된 쿼리

conn.prepare(sql)로 ? 자리표시자가 있는 쿼리를 준비해두고, 값만 바꿔가며 안전하게(SQL 인젝션 없이) 재실행할 수 있습니다. 슬라이더로 최소 중량을 바꿔보세요.

최소 중량: 80kg 이상
SELECT * FROM auction WHERE weight_kg >= ?
소스 코드 보기 
const stmt = await conn.prepare('SELECT * FROM auction WHERE weight_kg >= ?');
const result = await stmt.query(threshold);
await stmt.close();

4. 집계 + 윈도우 함수 — GROUP BY / RANK() OVER

지역별 총 위판량을 집계하고, RANK() OVER (ORDER BY ... DESC)로 순위를 함께 매깁니다. JOIN·서브쿼리·CTE 등 표준 분석 SQL을 그대로 쓸 수 있다는 게 DuckDB-Wasm의 핵심입니다.

소스 코드 보기 
const result = await conn.query(`
  SELECT region, SUM(weight_kg) AS total_weight,
         RANK() OVER (ORDER BY SUM(weight_kg) DESC) AS rnk
  FROM catch_log
  GROUP BY region
  ORDER BY rnk
`);

5. 대량 데이터 집계 성능 — generate_series

generate_series()로 가상의 조업 데이터를 대량 생성한 뒤 바로 집계해서, 컬럼형 OLAP 엔진이 브라우저 안에서 얼마나 빠른지 체감해봅니다. (실제 소요 시간은 기기 성능에 따라 달라집니다.)
