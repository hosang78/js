simple-statistics 핵심 기능 둘러보기

simple-statistics는 평균·표준편차 같은 기초 통계부터 선형회귀·클러스터링· 가설검정까지 순수 JS로 제공하는 통계 라이브러리입니다. 그래프를 그려주지는 않으므로, 아래 산점도와 막대는 이 페이지에서 직접 그린 최소한의 SVG입니다.
  • mean·median·standardDeviation 같은 기초 기술통계
  • linearRegression + sampleCorrelation + rSquared로 하는 선형회귀·상관관계 분석
  • jenks로 값을 자연스러운 그룹으로 나누는 구간 분류
  • tTest + zScore로 하는 가설검정과 이상치 탐지
※ 아래 위판 시세·수온 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. simple-statistics(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기초 기술통계

최근 20일간 A위판장의 고등어 시세 표본에 대한 기초 통계량입니다.
코드 보기 
ss.mean(prices);                          // 평균
ss.median(prices);                        // 중앙값
ss.standardDeviation(prices);             // 표준편차
ss.min(prices); ss.max(prices);           // 최솟값·최댓값
ss.quantile(prices, 0.25);                // 1사분위수(Q1)
ss.quantile(prices, 0.75);                // 3사분위수(Q3)

2. 선형회귀 + 상관계수 + R²

가상의 조사 지점별 수온과 어획량 데이터에 회귀선을 그렸습니다. 상관계수(r)와 결정계수(R²)로 두 값의 관계가 얼마나 뚜렷한지 함께 나타냅니다.
코드 보기 
const points = temps.map((t, i) => [t, catches[i]]);   // [[수온, 어획량], ...]

const { m, b } = ss.linearRegression(points);           // 기울기, 절편
const line = ss.linearRegressionLine({ m, b });          // x => y 함수
const r2 = ss.rSquared(points, line);                     // 결정계수
const r = ss.sampleCorrelation(temps, catches);           // 상관계수

3. Jenks 자연 구간분류

6개 위판장의 평균 시세를 jenks로 하/중/상 3단계로 자동 분류했습니다. 값들이 뭉쳐있는 지점을 기준으로 경계를 찾기 때문에, 동일 간격으로 나누는 것보다 실제 분포를 더 잘 반영합니다.
하위 등급 중위 등급 상위 등급
코드 보기 
const breaks = ss.jenks(marketPrices, 3);   // 3개 구간의 경계값 배열
// breaks 예: [4100, 5400, 6800, 7900] → [4100~5400), [5400~6800), [6800~7900]
function classify(v) {
  for (let i = 1; i < breaks.length; i++) if (v <= breaks[i]) return i - 1;
  return breaks.length - 2;
}

4. t-검정 + z-score 이상치 탐지

이번 달 표본 평균 시세가 예년 평균(가정값)과 통계적으로 다른지 t-검정으로 확인하고, 개별 관측값의 z-score로 평균에서 크게 벗어난 이상치를 찾았습니다.
코드 보기 
const t = ss.tTest(thisMonthPrices, historicalAverage);   // t값 (표본평균이 가정값과 얼마나 떨어져 있는지)

const mean = ss.mean(thisMonthPrices);
const sd = ss.standardDeviation(thisMonthPrices);
const z = (value) => (value - mean) / sd;                  // 개별 값의 z-score
// 관례상 |z| > 2 정도면 이상치로 본다
