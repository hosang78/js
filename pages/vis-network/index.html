vis-network 핵심 기능 둘러보기

vis-network는 노드(점)와 엣지(선)로 이루어진 네트워크·관계도를 그려주는 라이브러리입니다. 물리 시뮬레이션으로 노드들이 자연스럽게 퍼지도록 배치하거나, 조직도처럼 계층 구조로 정렬할 수 있습니다.
  • 물리 시뮬레이션 기반 자동 배치 네트워크 그래프
  • layout.hierarchical로 위→아래 계층형(조직도) 배치
  • 그룹별 색상 구분 + 클릭 시 연결된 노드만 강조
  • 체크박스로 특정 그룹의 노드·엣지를 표시/숨김
※ 아래 유통 흐름도·조직도는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 조직·유통 구조와 무관합니다. vis-network(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 네트워크 그래프 (물리 시뮬레이션)

가상 수산물 유통 흐름입니다. 노드를 드래그하거나 빈 곳을 드래그해 확대·이동해보세요.
위판장
중도매인
소매상
수출업체
코드 보기 
const nodes = new vis.DataSet([
  { id: 1, label: "1번 위판장", group: "market" },
  { id: 2, label: "2번 위판장", group: "market" },
  { id: 3, label: "중도매인 A", group: "broker" },
  // ...
]);
const edges = new vis.DataSet([
  { from: 1, to: 3 }, { from: 2, to: 3 }, /* ... */
]);

new vis.Network(container, { nodes, edges }, {
  groups: {
    market: { color: { background: "#2a78d6" } },
    broker: { color: { background: "#1baf7a" } },
    retail: { color: { background: "#eda100" } },
    export:  { color: { background: "#008300" } }
  },
  physics: { stabilization: true }
});

2. 계층형 레이아웃 (조직도)

가상 수협 조직도입니다. layout.hierarchical로 위에서 아래로 단계별 정렬됩니다. 단계(깊이)는 파란색 하나를 진하기로 구분해 표현했습니다.
코드 보기 
new vis.Network(container, { nodes, edges }, {
  layout: {
    hierarchical: {
      direction: "UD",       // Up to Down
      sortMethod: "directed",
      levelSeparation: 80,
      nodeSpacing: 130
    }
  },
  physics: false,
  edges: { arrows: "to" }
});

3. 그룹별 색상 + 클릭 시 연결 노드 강조

가상 조합원 네트워크입니다. 노드를 클릭하면 그 노드와 직접 연결된 노드·엣지만 진하게 남고 나머지는 흐려집니다.
조합원
위판장
가공업체
노드를 클릭해보세요.
코드 보기 
network.on("click", (params) => {
  if (params.nodes.length === 0) {
    // 빈 곳 클릭 → 원상태로 복귀
    nodes.forEach((n) => nodes.update({ id: n.id, opacity: 1 }));
    return;
  }
  const clickedId = params.nodes[0];
  const connected = new Set([clickedId, ...network.getConnectedNodes(clickedId)]);
  nodes.forEach((n) => {
    nodes.update({ id: n.id, opacity: connected.has(n.id) ? 1 : 0.15 });
  });
});

4. 그룹 필터링

체크박스를 끄면 해당 그룹의 노드와 그 노드에 연결된 엣지가 그래프에서 사라집니다.
코드 보기 
const allNodes = new vis.DataSet([ /* ... */ ]);
const view = new vis.DataView(allNodes, {
  filter: (node) => activeGroups.has(node.group)
});
new vis.Network(container, { nodes: view, edges }, options);

checkbox.addEventListener("change", () => {
  activeGroups[checkbox.checked ? "add" : "delete"](checkbox.value);
  view.refresh(); // 필터를 다시 적용
});
