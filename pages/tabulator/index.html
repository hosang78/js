Tabulator 핵심 기능 둘러보기

Tabulator는 정렬·검색·편집·페이지네이션이 되는 인터랙티브 데이터 테이블을 JSON 배열만 주면 바로 만들어주는 라이브러리입니다. 엑셀처럼 대량의 표 데이터를 다루는 화면에 적합합니다.
  • 컬럼 헤더를 클릭하면 자동으로 정렬됨
  • 컬럼별로 헤더 필터(검색창)를 붙여 실시간으로 좁혀볼 수 있음
  • 셀을 더블클릭하면 그 자리에서 값을 수정(inline editing) 가능
  • 대량 데이터를 페이지 단위로 나누거나(pagination), 특정 컬럼 값으로 그룹핑 가능
※ 아래 위판 거래 내역은 Tabulator 학습용으로 만든 가상의 샘플 데이터이며, 실제 수협중앙회의 거래 기록이 아닙니다. 이 페이지는 Tabulator(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 테이블 · 정렬

컬럼 헤더를 클릭해보세요. 오름차순/내림차순으로 정렬됩니다.
코드 보기 
new Tabulator('#table1', {
  data: rows,
  layout: 'fitColumns',
  columns: [
    { title: '날짜', field: 'date', sorter: 'date' },
    { title: '위판장', field: 'market' },
    { title: '어종', field: 'fish' },
    { title: '수량(kg)', field: 'qty', sorter: 'number', hozAlign: 'right' },
    { title: '금액', field: 'amount', sorter: 'number', hozAlign: 'right',
      formatter: 'money', formatterParams: { symbol: '', precision: 0 } },
  ],
});

2. 헤더 필터 (컬럼별 검색)

각 컬럼 제목 아래 입력칸에 검색어를 입력하면 실시간으로 표가 좁혀집니다.
코드 보기 
{ title: '위판장', field: 'market', headerFilter: 'input' },
{ title: '어종', field: 'fish', headerFilter: 'list',
  headerFilterParams: { valuesLookup: true, clearable: true } },

3. 셀 편집

"상태" 컬럼을 클릭하면 드롭다운으로 값을 바꿀 수 있고, "비고" 컬럼은 더블클릭해서 텍스트를 직접 입력할 수 있습니다.
셀을 편집해보세요.
코드 보기 
{ title: '상태', field: 'status', editor: 'list',
  editorParams: { values: ['대기', '정산완료'] } },
{ title: '비고', field: 'memo', editor: 'input' },

table.on('cellEdited', (cell) => {
  console.log(cell.getField(), '->', cell.getValue());
});

4. 그룹핑 · 페이지네이션

위판장별로 그룹지어 보여주고, 한 페이지에 8건씩 나눠서 표시합니다.
코드 보기 
new Tabulator('#table4', {
  data: rows,
  groupBy: 'market',
  pagination: true,
  paginationSize: 8,
  columns: [ /* ... */ ],
});
