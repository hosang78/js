이 페이지에서 확인할 기능

  • 데이터 편집
    텍스트·숫자·날짜·목록·체크박스·텍스트영역
  • 조회/탐색
    다중 정렬, 헤더 필터, 전체 검색, 로컬 페이지
  • 표 구조
    열 이동·너비 조절·고정 열·반응형 접기·열 메뉴
  • 행 제어
    체크 선택, 컨텍스트 메뉴, 행 추가/삭제, 클릭 이벤트
  • 분석 표현
    상태 배지·진행바·별점·태그·하단 합계/평균/건수
  • 데이터 형태
    부서 그룹, 계층형 데이터 트리, 접기/펼치기
  • 작업 이력
    편집·삭제 후 실행 취소/다시 실행, 열 배치 LocalStorage 저장
  • 입출력
    CSV·JSON·XLSX·PDF·HTML 내보내기 및 JSON/CSV/XLSX 파일 읽기
팁: 헤더 우클릭으로 열 숨김/고정/정렬 해제, 행 우클릭으로 행 단위 동작을 확인할 수 있다. 모바일에서는 일부 열이 반응형 상세 영역으로 이동한다.
