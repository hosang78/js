html2canvas 핵심 기능 둘러보기

html2canvas는 화면에 그려진 HTML 요소를 그대로 이미지(canvas)로 캡처해주는 라이브러리입니다. 서버에서 이미지를 만들지 않고, 브라우저에서 바로 "스크린샷"처럼 저장할 수 있습니다.
  • 특정 DOM 요소를 지정하면 그 모양 그대로 canvas에 그려줌
  • 결과 canvas를 PNG 등 이미지 파일로 바로 다운로드 가능
  • scale 옵션으로 캡처 해상도를 높이거나 낮출 수 있음
  • ignoreElements 옵션으로 특정 요소만 캡처에서 제외 가능(예: 화면에는 보이지만 이미지에는 빼고 싶은 메모/버튼)
※ 아래 "위판 정산서"는 html2canvas 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 정산 서식/수치가 아닙니다. 이 페이지는 html2canvas(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 캡처 · PNG 다운로드

아래 "위판 정산서" 카드를 캡처해서 이미지를 만들고, PNG로 다운로드합니다.

위판 정산서 (예시)

2026-07-13 · 부산공동어시장
어종수량(kg)단가금액
고등어3204,5001,440,000
갈치1808,2001,476,000
오징어9512,0001,140,000
합계4,056,000
※ 가상 예시 데이터입니다
캡처 결과가 여기 표시됩니다
코드 보기 
const canvas = await html2canvas(document.getElementById('card1'));
resultBox.appendChild(canvas);

// PNG 다운로드
const link = document.createElement('a');
link.download = 'wipan-settlement.png'; // 일부 브라우저는 data URL 다운로드에서 한글 파일명을 깨뜨려서 영문으로 지정
link.href = canvas.toDataURL('image/png');
link.click();

2. 해상도 배율(scale) 조절

같은 카드를 1배/2배/3배로 캡처해서 실제 픽셀 크기가 어떻게 달라지는지 비교합니다.

위판 정산서 (예시)

2026-07-13 · 목포수산시장
어종수량(kg)단가금액
새우6018,0001,080,000
꽃게11015,5001,705,000
합계2,785,000
배율을 선택해보세요
코드 보기 
const canvas = await html2canvas(card, { scale: 2 });
console.log(canvas.width, canvas.height); // 원본의 2배 픽셀

3. 특정 요소 캡처 제외 (ignoreElements)

카드 안의 "내부 검토용" 메모는 화면에는 보이지만, 캡처 이미지에는 빠지도록 처리합니다.

위판 정산서 (예시)

2026-07-13 · 통영수산시장
어종수량(kg)단가금액
전복2542,0001,050,000
합계1,050,000
내부 검토용 메모 (캡처 제외 대상)
캡처 결과가 여기 표시됩니다
코드 보기 
const canvas = await html2canvas(card, {
  ignoreElements: (el) => el.classList.contains('no-capture'),
});
