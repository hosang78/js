상태

라이브러리 로딩 확인 중…
TEXT

텍스트·스타일

폰트 크기, 굵기, 색상, 배경색, 장식, 문자 간격, 정렬, 링크, 스타일 상속

LAYOUT

열·스택

columns, 자동/고정/별표 너비, columnGap, stack

LIST

목록

글머리표, 번호 목록, 중첩 목록, 시작 번호, 사용자 마커 색상

TABLE

고급 표

헤더 반복, colSpan, rowSpan, 사용자 레이아웃, 셀 색상, 정렬, 페이지 분할

MEDIA

이미지·SVG

Data URI 이미지, 비율 유지, fit/cover, SVG 문자열, 사용자 업로드 이미지

VECTOR

Canvas 벡터

선, 사각형, 원, 타원, 폴리라인, 채우기, 선 스타일, 대시 패턴

QR

QR 코드

QR 데이터, 크기, 전경·배경색, 오류 교정 수준

PAGE

페이지 제어

용지 크기·방향, 여백, 강제 페이지 나눔, pageBreakBefore, keepWithHeaderRows

REPEAT

머리글·바닥글

페이지별 동적 함수, 현재 페이지·전체 페이지, 홀짝 페이지 분기

DECOR

배경·워터마크

페이지 배경 함수, 투명 워터마크, 각도·색상·불투명도

META

문서 메타데이터

title, author, subject, keywords, creator, producer, creationDate

SECURITY

암호화·권한

사용자/소유자 암호와 인쇄·복사·수정 권한 지정

HTML

HTML 변환

html-to-pdfmake로 기본 HTML을 Document Definition 노드로 변환

OUTPUT

출력 API

open, download, print, getBlob, getBase64, getDataUrl 등 브라우저 출력

FONT

동적 TTF 등록

FileReader로 TTF를 VFS에 추가하고 사용자 폰트 패밀리 적용
