pdfmake 핵심 기능 둘러보기

pdfmake는 JSON과 비슷한 "문서 정의(document definition)" 객체를 JS 코드만으로 작성하면 그대로 PDF 파일을 만들어주는 라이브러리입니다. 서버 없이 브라우저에서 바로 PDF를 생성·다운로드·미리보기할 수 있습니다.
  • 제목·본문·스타일이 있는 기본 문서 생성 + 다운로드
  • 커스텀 테두리·줄무늬 배경이 있는 표(table) 생성
  • 캔버스로 그린 차트를 그대로 넣는 이미지 삽입
  • getDataUrl()로 다운로드 없이 바로 보는 미리보기
※ 아래 위판 실적 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·보고서와 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 문서 생성 + 다운로드

제목·부제·목록이 있는 간단한 보고서를 만들어 PDF로 내려받습니다. download()은 비동기(Promise)로 동작하므로 await로 완료를 기다려야 합니다.
아직 생성한 적이 없습니다.
코드 보기 
const docDefinition = {
  content: [
    { text: '위판 실적 보고서', style: 'header' },
    { text: '작성일: 2026-07-17', style: 'subheader' },
    '이 보고서는 가상의 위판 실적 데이터를 기반으로 작성되었습니다.',
    { text: '주요 요약', style: 'sectionHeader' },
    { ul: ['총 위판량: 4,820kg', '참여 위판장: 8곳', '평균 단가: 4,200원/kg'] },
  ],
  styles: {
    header: { fontSize: 20, bold: true, margin: [0, 0, 0, 10] },
    subheader: { fontSize: 11, color: '#666', margin: [0, 0, 0, 10] },
    sectionHeader: { fontSize: 14, bold: true, margin: [0, 10, 0, 6] },
  },
};

// download()/open()/getBlob() 등은 모두 Promise를 반환한다 (await 필요)
await pdfMake.createPdf(docDefinition).download('위판_실적_보고서.pdf');

2. 표(table) 생성

위판장별 실적을 표로 정리합니다. layout 옵션으로 헤더 배경색과 줄무늬 배경을 직접 지정했습니다.
아직 생성한 적이 없습니다.
코드 보기 
const tableDoc = {
  content: [
    { text: '위판장별 실적', style: 'header' },
    {
      table: {
        headerRows: 1,
        widths: ['*', 'auto', 'auto', 'auto'],
        body: [
          [
            { text: '위판장', color: 'white', bold: true },
            { text: '지역', color: 'white', bold: true },
            { text: '위판량(kg)', color: 'white', bold: true },
            { text: '평균가(원)', color: 'white', bold: true },
          ],
          ['A위판장', '부산', '820', '4,200'],
          ['B위판장', '포항', '340', '3,900'],
          ['C위판장', '여수', '560', '4,450'],
          ['D위판장', '속초', '610', '4,100'],
        ],
      },
      layout: {
        fillColor: (rowIndex) => (rowIndex === 0 ? '#4f7dff' : rowIndex % 2 === 0 ? '#f5f6f8' : null),
      },
    },
  ],
  styles: { header: { fontSize: 18, bold: true, margin: [0, 0, 0, 10] } },
};

3. 이미지 삽입

캔버스에 직접 그린 막대그래프를 canvas.toDataURL()로 이미지 데이터 URL로 바꾼 뒤, image 항목으로 그대로 PDF에 삽입합니다.
아직 생성한 적이 없습니다.
코드 보기 
const chartDataUrl = canvas.toDataURL('image/png');

const imageDoc = {
  content: [
    { text: '월별 위판량 추이', style: 'header' },
    { image: chartDataUrl, width: 300 },
  ],
  styles: { header: { fontSize: 18, bold: true, margin: [0, 0, 0, 10] } },
};

4. getDataUrl()로 즉시 미리보기

다운로드하지 않고도 getDataUrl()로 PDF의 data URL을 바로 받아와 아래 iframe에 렌더링합니다.
아직 생성한 적이 없습니다.
코드 보기 
const dataUrl = await pdfMake.createPdf(previewDoc).getDataUrl();
document.getElementById('s4-frame').src = dataUrl;
