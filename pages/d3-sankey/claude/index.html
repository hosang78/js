d3-sankey 핵심 기능 둘러보기

d3-sankey는 노드와 링크의 좌표만 계산해주는 산키 다이어그램 레이아웃 엔진입니다. 실제 그리기는 D3.js의 SVG 조작과 sankeyLinkHorizontal() path 생성기를 함께 써야 합니다 — 완성된 차트 라이브러리가 아니라 "배치 계산기"에 가깝습니다.
  • d3.sankey().nodeId().nodeWidth().nodePadding().extent()로 레이아웃 설정
  • 계산 결과 각 노드에 x0,x1,y0,y1,depth,layer, 각 링크에 y0,y1,width 부여
  • 링크의 width는 value에 정확히 비례
  • sankey.update(graph)로 노드를 옮긴 뒤 링크 경로를 다시 계산 가능
※ 이 페이지의 위판·유통 흐름은 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. D3.js를 함께 사용했습니다 (CDN).

1. 기본 산키 다이어그램 + 값 비례 두께

어선 → 위판장 → 도매상 → 소매/수출/산지직판으로 이어지는 가상 유통 흐름입니다. 링크 굵기는 value에 정확히 비례합니다 (500kg 링크가 300kg 링크보다 정확히 5/3배 굵음).
코드 보기 
const sankeyGen = d3.sankey()
  .nodeId(d => d.id)
  .nodeWidth(16)
  .nodePadding(10)
  .extent([[1, 1], [width - 1, height - 1]]);
const graph = sankeyGen({ nodes, links });

svg.selectAll('path').data(graph.links).join('path')
  .attr('d', d3.sankeyLinkHorizontal())
  .attr('stroke-width', d => Math.max(1, d.width)); // value에 비례

2. 노드 정렬 방식 비교 (nodeAlign)

'산지직판' 노드는 위판장에서 바로 갈라져 나가는 출고 링크가 없는 노드입니다. sankeyLeft는 원래 깊이(위판장 바로 다음 열)에 그대로 두지만, sankeyJustify는 다른 leaf 노드(소매·수출)처럼 맨 오른쪽 열로 강제로 밀어냅니다.

sankeyLeft

sankeyJustify

코드 보기 
d3.sankey().nodeAlign(d3.sankeyLeft)    // 산지직판이 자기 깊이(1열)에 남음
d3.sankey().nodeAlign(d3.sankeyJustify) // 산지직판이 맨 오른쪽 열로 밀려남

3. 노드 드래그로 위치 조정

아무 노드나 위아래로 드래그해보세요. sankey.update()로 연결된 링크 경로가 실시간으로 다시 그려집니다.
코드 보기 
d3.drag().on('drag', (event, d) => {
  const h = d.y1 - d.y0;
  d.y0 = event.y - h / 2;
  d.y1 = d.y0 + h;
  sankeyGen.update(graph);           // 링크 y0/y1/width 재계산
  linkSelection.attr('d', d3.sankeyLinkHorizontal());
})

4. 마우스오버 링크 강조

노드 위에 마우스를 올리면 그 노드와 연결된 링크만 진하게, 나머지는 흐리게 표시됩니다.
코드 보기 
nodeSelection.on('mouseover', (event, d) => {
  const related = new Set([...d.sourceLinks, ...d.targetLinks]);
  linkSelection.attr('stroke-opacity', l => related.has(l) ? 0.8 : 0.08);
});
