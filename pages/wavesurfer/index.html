WaveSurfer.js 핵심 기능 둘러보기

WaveSurfer.js는 오디오 파일을 파형(waveform)으로 그려주고, 재생·구간 선택·확대 같은 상호작용을 붙일 수 있는 오디오 플레이어 라이브러리입니다.
  • WaveSurfer.create({ container, url }) 한 번으로 파형이 그려지고 재생 가능
  • Regions 플러그인으로 파형 위에 구간을 드래그로 만들고, 그 구간만 반복 재생 가능
  • ws.zoom(pxPerSec)로 파형을 확대·축소
  • 재생 속도 조절, 특정 시간으로 이동 같은 세밀한 재생 제어 API 제공
※ 실제 음원 파일을 구할 수 없어, 이 페이지 전용으로 만든 4초짜리 가상의 알림음 (sample-chime.wav, 사인파로 합성한 소리)을 사용합니다. 실제 수협중앙회의 위판 개장 알림음이 아닙니다. WaveSurfer.js 핵심 라이브러리(CDN)와 공식 플러그인 Regions(CDN)를 함께 사용하고, 다른 외부 API는 사용하지 않습니다.

1. 기본 파형 표시 + 재생 컨트롤

파형이 그려지면 재생/일시정지할 수 있고, 파형을 클릭하면 그 위치로 바로 이동합니다.
0:00 / 0:00 볼륨
코드 보기 
const ws = WaveSurfer.create({
  container: '#waveform1',
  waveColor: '#4f7dff',
  progressColor: '#2a4fb8',
  url: 'sample-chime.wav',
});

playBtn.addEventListener('click', () => ws.playPause());
ws.on('audioprocess', () => { timeLabel.textContent = formatTime(ws.getCurrentTime()); });
volumeSlider.addEventListener('input', (e) => ws.setVolume(Number(e.target.value)));

2. 구간(리전) 선택 + 반복 재생

파형 위를 마우스로 드래그해서 구간을 만들어보세요. "반복 재생"을 켜면 그 구간만 계속 반복됩니다.
파형 위를 드래그해서 구간을 만들어보세요.
코드 보기 
const regions = WaveSurfer.Regions.create();
const ws = WaveSurfer.create({ container: '#waveform2', url: 'sample-chime.wav', plugins: [regions] });

regions.enableDragSelection({ color: 'rgba(79,125,255,0.25)' });

let activeRegion = null;
regions.on('region-created', (region) => { activeRegion = region; });

let looping = false;
regions.on('region-out', (region) => {
  if (looping && region === activeRegion) region.play(); // 구간이 끝나면 다시 그 구간부터 재생
});

3. 파형 확대 · 축소

슬라이더로 파형을 확대·축소합니다. 확대하면 짧은 소리의 세부 모양을 더 자세히 볼 수 있습니다.
확대 배율 20px/s
코드 보기 
const ws = WaveSurfer.create({ container: '#waveform3', url: 'sample-chime.wav' });

zoomSlider.addEventListener('input', (e) => {
  ws.zoom(Number(e.target.value)); // 1초를 몇 픽셀로 그릴지 지정
});

4. 재생 속도 조절 + 특정 시간으로 이동

배속 버튼과, 초 단위로 원하는 지점으로 바로 이동하는 입력창입니다.
이동할 시간(초):
코드 보기 
rateBtn.addEventListener('click', () => ws.setPlaybackRate(Number(rateBtn.dataset.rate)));

seekBtn.addEventListener('click', () => {
  ws.setTime(Number(seekInput.value)); // 초 단위로 절대 이동
  // 주의: ws.seekTo(x)는 초가 아니라 0~1 사이의 "재생 비율"을 받는 별개의 메서드
});
