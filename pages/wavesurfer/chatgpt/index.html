실행 유의사항

WaveSurfer.js 모듈은 CDN에서 불러오므로 최초 실행 시 인터넷 연결이 필요하다. 원격 URL 음원은 서버가 CORS를 허용해야 한다. 대용량 파일은 브라우저 메모리를 많이 사용할 수 있으므로 사전 생성 Peaks 사용을 고려한다. 마이크 녹음은 보안 정책상 HTTPS 또는 localhost 환경이 가장 안정적이다.

로컬 서버 실행 예시

# Python이 설치된 폴더에서
python -m http.server 8000

# 브라우저
http://localhost:8000/WaveSurferJS_종합_기능_샘플.html
WaveSurfer.js는 오디오 파형 시각화·재생 라이브러리다. 이 샘플의 구간, 엔벌로프, 녹음, 스펙트로그램 기능은 학습·검증 목적이며, 원본 오디오를 실제로 절단·합성·효과 처리하는 편집기는 아니다.
