PptxGenJS 핵심 기능 둘러보기

PptxGenJS는 브라우저에서 서버 없이 진짜 PowerPoint(.pptx) 파일을 만들어주는 라이브러리입니다. 만들어진 파일은 실제 파워포인트/한컴오피스/키노트 등에서 그대로 열립니다.
  • 슬라이드를 추가하고 제목·본문 텍스트를 배치 가능
  • 표(table)를 슬라이드에 바로 삽입 가능
  • 막대/파이 등 파워포인트 네이티브 차트를 데이터만 주면 생성 (이미지가 아니라 PPT 안에서 편집 가능한 진짜 차트)
  • 도형(사각형·화살표 등)으로 간단한 다이어그램 구성 가능
※ 아래 위판 실적 데이터는 PptxGenJS 학습용으로 만든 가상의 샘플이며, 실제 수협중앙회의 통계/보고서가 아닙니다. 이 페이지는 PptxGenJS(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 슬라이드 생성

제목 슬라이드 + 요약 텍스트 슬라이드, 총 2장짜리 PPTX를 만들어 다운로드합니다.
버튼을 누르면 파일이 다운로드됩니다.
코드 보기 
const pptx = new PptxGenJS();

const title = pptx.addSlide();
title.addText('2026년 7월 위판 실적 보고 (예시)', { x: 0.5, y: 2, w: 9, h: 1, fontSize: 32, bold: true, align: 'center' });
title.addText('수협 위판장 5곳 · 가상 샘플 데이터', { x: 0.5, y: 3, w: 9, h: 0.5, fontSize: 16, color: '666666', align: 'center' });

const body = pptx.addSlide();
body.addText('이번 달 요약', { x: 0.5, y: 0.4, fontSize: 24, bold: true });
body.addText(
  [
    { text: '위판량 전체 1,050kg 처리 (가상)' },
    { text: '최다 취급 어종: 고등어' },
    { text: '전월 대비 위판량 소폭 증가 (가상)' },
  ],
  { x: 0.5, y: 1.2, w: 9, h: 3, fontSize: 18, bullet: true, lineSpacing: 32 });

await pptx.writeFile({ fileName: 'wipan-report.pptx' });

2. 표 삽입

아래 표를 그대로 슬라이드 안의 표로 넣어 PPTX를 만듭니다.
날짜위판장어종수량(kg)금액
2026-07-02부산공동어시장고등어3201,440,000
2026-07-03목포수산시장갈치1801,476,000
2026-07-04통영수산시장오징어951,140,000
코드 보기 
const rows = [
  [{ text: '날짜', options: { bold: true } }, { text: '위판장', options: { bold: true } }, /* ... */],
  ['2026-07-02', '부산공동어시장', '고등어', '320', '1,440,000'],
  // ...
];
slide.addTable(rows, { x: 0.5, y: 0.6, w: 9, colW: [1.4, 2.4, 1.2, 1.5, 2.5], fontSize: 12, border: { type: 'solid', color: 'DDDDDD' } });

3. 네이티브 차트 삽입

어종별 위판 비중(가상)을 이미지가 아닌 진짜 파워포인트 차트로 넣습니다. 파워포인트에서 열면 색상·데이터를 직접 편집할 수 있습니다.
코드 보기 
slide.addChart(pptx.ChartType.pie, [{
  name: '어종별 위판 비중',
  labels: ['고등어', '갈치', '오징어', '새우', '기타'],
  values: [420, 260, 190, 140, 90],
}], { x: 1.5, y: 1, w: 7, h: 5, showLegend: true, showValue: true });

4. 도형으로 다이어그램 구성

사각형과 화살표 도형을 이어붙여 간단한 유통 흐름도를 만듭니다.
코드 보기 
const steps = ['어선 조업', '위판장 입고', '경매', '정산'];
steps.forEach((label, i) => {
  slide.addShape(pptx.ShapeType.roundRect, { x: 0.5 + i * 2.3, y: 2, w: 1.8, h: 1, fill: { color: '4F7DFF' }, line: { color: '2C3E91' } });
  slide.addText(label, { x: 0.5 + i * 2.3, y: 2, w: 1.8, h: 1, align: 'center', valign: 'middle', color: 'FFFFFF', fontSize: 14, bold: true });
  if (i < steps.length - 1) {
    slide.addShape(pptx.ShapeType.rightArrow, { x: 2.35 + i * 2.3, y: 2.3, w: 0.45, h: 0.4, fill: { color: '898781' } });
  }
});
