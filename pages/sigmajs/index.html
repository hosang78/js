Sigma.js 핵심 기능 둘러보기

Sigma.js는 WebGL로 그래프(노드+엣지)를 그려주는 라이브러리로, 수천 개 단위의 노드도 부드럽게 렌더링할 수 있는 게 특징입니다. 그래프 데이터 구조 자체는 같은 개발팀이 만든 graphology 라이브러리가 담당하고, Sigma.js는 그걸 화면에 그리는 역할만 합니다.
  • WebGL 기반 렌더링 + 휠 확대/축소, 드래그로 캔버스 이동
  • 연결 수(degree)에 비례한 노드 크기, 그룹별 색상 인코딩
  • 마우스오버 시 nodeReducer/edgeReducer로 이웃만 강조하고 나머지는 흐리게
  • 클릭으로 특정 노드와 그 연결망만 남기는 포커스 모드
※ 아래 유통 네트워크는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 유통 구조와 무관합니다. 노드 위치는 별도 레이아웃 알고리즘 패키지 없이 이 페이지에서 직접 계산한 원형 배치입니다. Sigma.js + graphology(둘 다 CDN) 조합만 사용하고 다른 외부 API는 사용하지 않습니다.

1. 기본 그래프 렌더링

가상 위판장 ↔ 중도매인 네트워크입니다. 마우스 휠로 확대/축소, 드래그로 캔버스를 이동해보세요.
코드 보기 
const graph = new graphology.Graph();
graph.addNode("market1", { x: 0, y: 0, size: 10, label: "1번 위판장", color: "#2a78d6" });
graph.addNode("broker1", { x: 1, y: 0.4, size: 8, label: "중도매인 A", color: "#1baf7a" });
// ...
graph.addEdge("market1", "broker1");

const renderer = new Sigma(graph, container);

2. 노드 크기(연결 수) + 그룹별 색상

연결이 많은 노드일수록 크게 표시됩니다. 그룹(역할)에 따라 색이 다릅니다.
위판장
중도매인
소매상
수출업체
코드 보기 
graph.forEachNode((node) => {
  const degree = graph.degree(node);
  graph.setNodeAttribute(node, "size", 6 + degree * 2.5); // 연결 수에 비례한 크기
});

3. 호버 시 이웃 노드 강조

노드 위에 마우스를 올리면 직접 연결된 이웃만 선명하게 남고 나머지는 흐려집니다.
코드 보기 
let hoveredNode = null;

const renderer = new Sigma(graph, container, {
  nodeReducer: (node, data) => {
    if (hoveredNode && node !== hoveredNode && !graph.areNeighbors(node, hoveredNode)) {
      return { ...data, color: "#e1e0d9", label: "" };
    }
    return data;
  },
  edgeReducer: (edge, data) => {
    if (hoveredNode && !graph.extremities(edge).includes(hoveredNode)) {
      return { ...data, hidden: true };
    }
    return data;
  }
});

renderer.on("enterNode", ({ node }) => { hoveredNode = node; renderer.refresh(); });
renderer.on("leaveNode", () => { hoveredNode = null; renderer.refresh(); });

4. 클릭으로 포커스 모드

노드를 클릭하면 그 노드와 직접 연결된 노드만 남고 나머지는 숨겨집니다. 다시 클릭하거나 버튼을 누르면 전체 보기로 돌아갑니다.
노드를 클릭해보세요.
코드 보기 
let focusNode = null;

renderer.on("clickNode", ({ node }) => {
  focusNode = focusNode === node ? null : node;
  renderer.refresh();
});

nodeReducer: (node, data) => {
  if (focusNode && node !== focusNode && !graph.areNeighbors(node, focusNode)) {
    return { ...data, hidden: true };
  }
  return data;
}
