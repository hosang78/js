Packery 핵심 기능 둘러보기

Packery는 카드 크기가 제각각이어도 빈틈없이 채워주는 빈패킹(bin-packing) 그리드 레이아웃 라이브러리입니다(Isotope·Masonry와 같은 Metafizzy 계열). Muuri와 비슷한 목적이지만, 특정 영역을 "고정"해두고 그 주변으로 카드를 자동 배치하는 stamp() 기능이 특징입니다.
  • 카드 크기가 달라도 빈틈없이 채우는 빈패킹 그리드 + 드래그 재배치(Draggabilly 연동)
  • stamp()로 고정 영역을 피해서 배치
  • appended() / remove()로 하는 카드 동적 추가·삭제
  • DOM 순서를 바꾼 뒤 reloadItems() + layout()으로 하는 재정렬
※ 아래 위판장 이름과 위판량 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·조직과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 빈패킹 그리드 + 드래그 재배치

카드마다 크기가 다르지만 Packery가 빈 공간 없이 자동으로 채워 배치합니다. 카드를 드래그하면 Draggabilly가 이동을 처리하고, 손을 떼면 Packery가 빈 자리에 딱 맞춰 스냅시킵니다.
코드 보기 
const pckry = new Packery('#grid1', {
  itemSelector: '.packery-item',
  columnWidth: 100,
  gutter: 8,
  rowHeight: 90,
});

pckry.getItemElements().forEach((el) => {
  const draggie = new Draggabilly(el);
  pckry.bindDraggabillyEvents(draggie);
});

2. stamp()로 고정 영역 피해서 배치

점선 무늬 영역은 stamp()로 고정해둔 자리입니다(예: 공지 배너). 나머지 카드들은 이 영역을 침범하지 않고 자동으로 피해서 배치됩니다.
코드 보기 
const pckry = new Packery('#grid2', {
  itemSelector: '.packery-item',
  columnWidth: 100,
  gutter: 8,
  rowHeight: 90,
});

// 고정 배너 영역을 stamp로 등록 — 이 영역은 레이아웃 계산에서 항상 비워둔다
pckry.stamp(document.getElementById('banner2'));
pckry.layout();

3. 카드 동적 추가 · 삭제

버튼을 누르면 appended()로 새 카드가 즉시 그리드에 들어오고, remove() + shiftLayout()으로 마지막 카드가 빠지면서 나머지가 다시 배치됩니다.
카드 6개
코드 보기 
const el = document.createElement('div');
el.className = 'packery-item';
el.innerHTML = '<div class="item-content c-blue">...</div>';
grid3.appendChild(el);
pckry.appended(el);
pckry.layout();

const items = pckry.getItemElements();
const last = items[items.length - 1];
pckry.remove(last);
pckry.shiftLayout();
last.remove();

4. 기준별 재정렬

Packery에는 Muuri 같은 내장 정렬 함수가 없어서, 카드의 DOM 순서를 원하는 기준으로 바꾼 뒤 reloadItems()로 새 순서를 알려주고 layout()을 다시 호출하는 방식으로 재정렬합니다.
코드 보기 
const items = [...grid4.querySelectorAll('.packery-item')];
items.sort((a, b) => Number(b.dataset.volume) - Number(a.dataset.volume));
items.forEach((el) => grid4.appendChild(el)); // DOM 순서를 바꾼다

pckry.reloadItems(); // 바뀐 DOM 순서를 Packery에 알려줌
pckry.layout();
