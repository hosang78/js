이 샘플에 포함된 MiniSearch 기능

            
new MiniSearch({
  fields: ['title', 'body', 'category', 'tags', 'meta.author'],
  storeFields: ['title', 'body', 'category', 'tags', 'year', 'importance', 'meta'],
  extractField, tokenize, processTerm,
  searchOptions: { prefix, fuzzy, boost, combineWith }
})

            

              색인 설정: fields, storeFields, idField, extractField, tokenize, processTerm

              검색: exact, prefix, fuzzy, 고급 prefix/fuzzy 함수, combineWith OR/AND/AND_NOT, fields 제한

              랭킹: boost, boostDocument, boostTerm

              후처리: filter, highlight, raw result, elapsed time

              자동완성: autoSuggest

              동적 관리: add, addAll, replace, remove, discard, vacuum

              저장/복원: toJSON, loadJSON
            

            

              참고: 이 파일은 CDN으로 MiniSearch UMD 번들을 불러옵니다. 내부망에서는 해당 JS 파일을 내려받아 같은 폴더에 두고 script src만 로컬 경로로 바꾸면 됩니다.
