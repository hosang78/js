검색 결과

autoSuggest

autoSuggest는 검색 옵션과 유사한 옵션을 받으며, 기본적으로 마지막 단어 prefix 검색과 AND 결합을 사용한다.



동적 문서 관리
문서를 추가하거나 교체해 보자. discard는 ID만으로 제외하고, remove는 원본 문서 객체가 필요하다.
현재 문서 목록


toJSON / loadJSON
색인을 JSON으로 직렬화한 뒤 같은 옵션으로 다시 로드한다. 대량 데이터에서는 loadJSONAsync도 사용할 수 있다.


Query Expression Tree
문자열 대신 객체 쿼리를 넘겨 OR / AND / AND_NOT 하위 쿼리를 조합한다.
