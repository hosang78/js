MiniSearch 핵심 기능 둘러보기

MiniSearch는 작고 가벼운 인메모리 전문(full-text) 검색 라이브러리입니다. 같은 검색 라이브러리인 FlexSearch와 달리, 필드 가중치·오타 허용·자동완성 제안 쪽에 좀 더 특화되어 있습니다.
  • boost 옵션으로 하는 필드별 가중치 검색
  • prefix: true로 하는 접두어 검색
  • fuzzy 옵션으로 하는 오타 허용 검색
  • autoSuggest()로 하는 자동완성 제안
※ 아래 위판 물품 목록은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 물품·통계와 무관합니다. 한글은 조사(은/는/이/가 등)가 단어에 그대로 붙기 때문에, 이 데모는 간단한 공백 기준 토크나이저를 씁니다 — 형태소 분석 없이 "위판장"과 "위판장에서"는 서로 다른 단어로 취급됩니다(자동완성 결과에서 확인할 수 있습니다). 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 필드별 가중치 검색 (boost)

boost: { name: 3 }처럼 특정 필드에 가중치를 주면, 그 필드에서 찾은 결과의 점수가 더 높아져 검색 결과 순위가 바뀝니다.
    소스 코드 보기 
    const mini = new MiniSearch({
  fields: ['name', 'description'],
  storeFields: ['name', 'description', 'category'],
});
mini.addAll(products);

mini.search('위판장');                          // 기본 검색
mini.search('위판장', { boost: { name: 3 } });   // name 필드에서 찾으면 점수 3배

    2. 접두어 검색 (prefix)

    prefix: true를 주면 단어 앞부분만 입력해도 찾아줍니다. 기본값은 정확히 일치하는 단어만 찾습니다.
      소스 코드 보기 
      mini.search('고등');                    // → [] (완전 일치하는 단어가 없음)
mini.search('고등', { prefix: true });   // → [고등어] ('고등'으로 시작하는 단어를 찾음)

      3. 오타 허용 검색 (fuzzy)

      fuzzy: 0.2는 단어 길이의 20%까지 오타(편집 거리)를 허용합니다. 아래 기본값은 일부러 오타가 섞인 검색어입니다.
        소스 코드 보기 
        mini.search('고둥어');                  // → [] ('고둥어'라는 단어는 없음, 정확히는 '고등어')
mini.search('고둥어', { fuzzy: 0.2 });   // → [고등어] (편집 거리 1까지 허용해서 찾음)

        4. 자동완성 제안 (autoSuggest)

        입력 중인 검색어를 바탕으로, 실제로 인덱스에 있는 단어들로 이어질 만한 완성된 검색어를 제안합니다. 관련 문서의 점수를 기준으로 순위가 매겨집니다.
          소스 코드 보기 
          mini.autoSuggest('위판');
// => [
//   { suggestion: '위판장의', terms: ['위판장의'], score: 0.73 },
//   { suggestion: '위판장에서', terms: ['위판장에서'], score: 0.65 },
//   { suggestion: '위판장', terms: ['위판장'], score: 0.27 },
// ]
// 조사가 붙은 형태가 각각 다른 제안으로 나오는 것에 유의
