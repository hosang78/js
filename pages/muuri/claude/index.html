Muuri 핵심 기능 둘러보기

Muuri는 카드 크기가 제각각이어도 빈틈없이 채워주는 빈패킹(bin-packing) 그리드 레이아웃 라이브러리입니다. 드래그로 순서를 바꾸거나, 필터링·정렬하거나, 항목을 동적으로 더하고 뺄 때도 부드러운 애니메이션으로 재배치해줍니다.
  • 카드 크기가 달라도 빈틈없이 배치하는 빈패킹 그리드 + 드래그 정렬
  • filter()로 하는 조건별 카드 필터링
  • sort()로 하는 기준별 정렬(위판량 · 이름)
  • add() / remove()로 하는 카드 동적 추가·삭제
※ 아래 위판장 이름과 위판량 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·조직과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 빈패킹 그리드 + 드래그 정렬

카드마다 크기가 다르지만 Muuri가 빈 공간 없이 자동으로 채워 배치합니다. 카드를 마우스로 눌러 드래그하면 순서가 바뀌고 나머지 카드들이 애니메이션과 함께 다시 정렬됩니다.
코드 보기 
const grid1 = new Muuri('#grid1', {
  dragEnabled: true,
  layout: { fillGaps: true },
});

2. 조건별 필터링

버튼을 눌러 어종별로 카드를 필터링합니다. 조건에 맞지 않는 카드는 숨겨지고, 남은 카드들이 빈 공간을 채우며 다시 배치됩니다.
코드 보기 
grid2.filter((item) => {
  if (type === 'all') return true;
  return item.getElement().dataset.species === type;
});

3. 기준별 정렬

위판량이 많은 순, 이름 가나다순으로 정렬해봅니다. 정렬된 순서대로 카드가 애니메이션과 함께 이동합니다.
코드 보기 
grid3.sort((a, b) => {
  const va = Number(a.getElement().dataset.volume);
  const vb = Number(b.getElement().dataset.volume);
  return vb - va; // 위판량 많은 순
});

4. 카드 동적 추가 · 삭제

버튼을 누르면 add()로 새 카드가 즉시 그리드에 들어오고, remove()로 마지막 카드가 빠지면서 나머지가 다시 배치됩니다.
카드 6개
코드 보기 
const el = document.createElement('div');
el.className = 'muuri-item size-m';
el.innerHTML = '<div class="item-content c-blue">...</div>';
grid4.getElement().appendChild(el);
grid4.add(el);

const items = grid4.getItems();
const last = items[items.length - 1];
grid4.remove([last], { removeElements: true });
