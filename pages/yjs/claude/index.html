Yjs 핵심 기능 둘러보기

Yjs는 완성된 에디터가 아니라, 여러 사람이 같은 문서를 동시에 편집해도 충돌 없이 자동으로 합쳐지는 데이터 구조를 제공하는 CRDT (Conflict-free Replicated Data Type) 라이브러리입니다. Google Docs류 실시간 공동 편집 기능의 "하부 엔진" 역할을 합니다.
  • Y.Text, Y.Array, Y.Map 같은 공유 데이터 타입에 변경을 가하면 observe()로 실시간 감지
  • 서버 없이도 Y.encodeStateAsUpdate() / Y.applyUpdate()로 두 문서의 상태를 교환·병합 가능
  • 같은 문서를 두 곳에서 동시에, 서로 다른 위치를 수정해도 병합 시 둘 다 자동으로 반영됨 (충돌 해결 로직을 직접 짤 필요 없음)
  • Y.UndoManager로 트랜잭션 단위 실행 취소/다시 실행 지원
※ 실제 서비스에서는 y-websocket·y-webrtc 같은 provider 패키지가 네트워크로 이 업데이트를 자동 교환해주지만, 이 페이지는 Yjs 자체의 동작만 보여주기 위해 provider 없이 버튼을 눌러 수동으로 상태를 교환합니다. 이 페이지의 위판 공지 내용은 모두 가상의 예시이며 실제 수협중앙회의 공지·자료가 아닙니다. 다른 외부 API는 사용하지 않습니다.

1. Y.Text 공유 텍스트 + 실시간 변경 감지

아래에 자유롭게 입력해보세요. observe()로 등록한 콜백이 변경될 때마다 호출되어 감지 횟수가 올라갑니다.
변경 감지: 0회
코드 보기 
const doc = new Y.Doc();
const ytext = doc.getText('notice');
ytext.insert(0, '금일 위판 공지: ...');

ytext.observe(() => {
  console.log(ytext.toString()); // 현재 값
});

2. 두 문서의 독립 수정 → 충돌 없는 자동 병합

문서 A, B는 각자 따로 떨어진(오프라인) 상태라고 가정합니다. 양쪽에서 서로 다른 부분을 수정한 뒤 "동기화" 버튼을 눌러, 둘 다 하나로 자동 합쳐지는 것을 확인하세요.

문서 A

문서 B

아직 동기화 안 함 — 두 문서가 다른 상태입니다
코드 보기 
// A, B가 서로 다르게 수정한 뒤
const updateFromA = Y.encodeStateAsUpdate(docA, Y.encodeStateVector(docB));
const updateFromB = Y.encodeStateAsUpdate(docB, Y.encodeStateVector(docA));
Y.applyUpdate(docB, updateFromA);
Y.applyUpdate(docA, updateFromB);
// 이제 docA와 docB의 텍스트가 완전히 동일해짐

3. Y.Array / Y.Map 공유 데이터 구조

텍스트뿐 아니라 배열·맵 형태의 데이터도 같은 방식으로 다룰 수 있습니다.

    

    

    

      코드 보기
      
const yarray = doc.getArray('species');
yarray.push(['고등어', '갈치']);

const ymap = doc.getMap('priceInfo');
ymap.set('species', '고등어');
ymap.set('price', 4200);

    

  


  

    
4. Y.UndoManager — 실행 취소/다시 실행

    
아래에 문장을 이어서 입력해보고 버튼으로 실행 취소/다시 실행을 확인하세요. 짧은 시간 안에 이어친 입력은 한 번에 묶여서 취소됩니다.

    
    

      
      
    

    

      코드 보기
      
const ytext = doc.getText('notice');
const undoManager = new Y.UndoManager(ytext);

undoManager.undo();
undoManager.redo();
