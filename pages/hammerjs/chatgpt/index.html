Hammer.js 종합 기능 샘플

터치·마우스·포인터 입력을 Hammer.js Recognizer로 해석하는 샘플이다. 가운데 블록을 탭, 더블탭, 길게 누르기, 드래그, 빠르게 스와이프, 두 손가락 확대/축소, 회전해 볼 수 있다.

tap / doubletap press / pressup pan start/move/end swipe 방향 감지 pinch 확대·축소 rotate 회전 recognizeWith / requireFailure touchAction / Manager option

4. Touch Action 비교

Hammer는 Recognizer 설정에 맞춰 브라우저 기본 스크롤/줌 동작과 제스처 인식 충돌을 줄이기 위해 touch-action 값을 계산하거나 직접 지정할 수 있다.

none: 스크롤/줌 방지 경향 pan-x: 세로 제스처 허용 조정 pan-y: 가로 제스처 허용 조정 auto: 브라우저 기본 동작 우선
