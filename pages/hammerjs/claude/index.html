Hammer.js 핵심 기능 둘러보기

Hammer.js는 탭·팬(드래그)·스와이프·핀치·회전·길게 누르기 같은 터치 제스처를 인식하는 라이브러리입니다. 터치스크린뿐 아니라 마우스로도 동작하도록 설계되어 있어, 아래 데모는 PC에서 마우스로 드래그·클릭해도 그대로 동작합니다.
  • new Hammer(el)로 매니저를 만들면 tap/doubletap/pan/swipe/press가 기본 활성화됨
  • pinch/rotate는 오작동 방지를 위해 기본적으로 비활성화되어 있어 직접 켜야 함
  • pan/swipe는 기본 인식 방향이 가로(HORIZONTAL)뿐이라 세로 드래그는 기본 설정으로는 안 잡힘
  • mc.get('이름').set({ 옵션 })으로 개별 인식기의 옵션을 변경
※ 이 페이지의 위판·조합원 카드는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 다른 외부 API는 사용하지 않습니다. 핀치·회전은 실제 손가락 두 개가 필요한 제스처라 터치 기기가 아니면 시연이 어려워, 데스크톱에서도 확인할 수 있도록 별도 시뮬레이션 버튼을 두었습니다(검증 중 확인: 마우스 이벤트로는 핀치를 만들 수 없음).

1. 탭 / 더블탭

카드를 한 번 클릭(탭)하거나 빠르게 두 번 클릭(더블탭)해보세요. (검증 중 발견: 기본 설정에서는 더블탭을 해도 tap 이벤트가 함께 발생해 카운트가 한 번에 여러 번 올라갑니다 — 실제 횟수로 확인해보세요.)
탭 / 더블탭
여기를 클릭
탭 0회 / 더블탭 0회
코드 보기 
const mc = new Hammer(tapBox);
mc.on('tap', () => tapCount++);
mc.on('doubletap', () => doubletapCount++);
// 기본 설정: 더블탭 한 번 하면 tap이 2번(각 클릭마다), doubletap이 1번 함께 발생함
// 공식 문서가 권장하는 recognizeWith + requireFailure 조합으로 분리를 시도해봤지만,
// 이 조합은 양방향 requireFailure 관계가 되어버려 오히려 doubletap이 전혀 발생하지
// 않게 되는 것을 실제로 확인했다(재현 검증 완료) — 그래서 이 페이지에서는 "고치는
// 버튼" 대신 기본 동작을 있는 그대로 보여준다.

2. 팬(드래그) — 방향 제한

카드를 마우스로 눌러서 끌어보세요. 기본값은 가로 방향만 인식하므로 세로로 끌어도 카드가 안 움직입니다. 버튼을 눌러 방향을 전체로 바꾸면 세로로도 끌립니다.
가상 위판 카드
드래그해보세요
현재 허용 방향: 가로만 (DIRECTION_HORIZONTAL)
코드 보기 
const mc = new Hammer(panBox); // 기본: direction = DIRECTION_HORIZONTAL
mc.on('panmove', (e) => {
  panBox.style.left = startLeft + e.deltaX + 'px';
  panBox.style.top = startTop + e.deltaY + 'px'; // 세로값은 기본 설정에선 무시됨
});
mc.get('pan').set({ direction: Hammer.DIRECTION_ALL }); // 이후 세로도 인식

3. 스와이프

카드를 빠르게 좌우로 튕기듯 드래그해보세요. 방향과 속도(velocity)가 실제 이벤트 값으로 표시됩니다.
가상 조합원 카드
빠르게 튕겨보세요
아직 스와이프 안 함
코드 보기 
mc.on('swipe', (e) => {
  console.log(e.direction, e.velocity);
  // direction: 2=LEFT, 4=RIGHT, 8=UP, 16=DOWN
});

4. 길게 누르기 (Press)

카드를 짧게 클릭하면 press로 인식되지 않고, 약 0.25초 이상 움직이지 않고 누르고 있어야 press로 인식됩니다.
눌러서
버텨보세요
아직 시도 안 함
코드 보기 
mc.on('press', () => { /* 0.25초 이상 눌렀을 때만 발생 */ });
mc.on('pressup', () => { /* 누르고 있다가 뗐을 때 */ });

5. 핀치 & 회전 (기본 비활성화)

pinch/rotate는 기본적으로 꺼져 있습니다. 먼저 켠 뒤, 터치 기기라면 카드 위에서 두 손가락으로 오므리기/돌리기를 해보세요. 데스크톱이라면 시뮬레이션 버튼으로 동일한 동작을 코드로 재현해 확인할 수 있습니다.
가상 위판장
로고 카드
핀치/회전 비활성화 상태
코드 보기 
const mc = new Hammer(pinchBox);
mc.get('pinch').set({ enable: true });
mc.get('rotate').set({ enable: true });
mc.on('pinchmove', (e) => { box.style.transform = `scale(${e.scale}) rotate(${rotation}deg)`; });
mc.on('rotatemove', (e) => { rotation = e.rotation; });
