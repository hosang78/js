Print.js 핵심 기능 둘러보기

Print.js는 화면 뒤에 숨겨진 <iframe>을 만들어 인쇄할 내용을 채운 뒤, 브라우저의 인쇄 대화상자를 바로 띄우는 라이브러리입니다. 새 탭을 열거나 팝업을 띄우지 않습니다.
  • type: 'html'로 하는 HTML 요소 인쇄
  • type: 'json'로 하는 데이터 표 인쇄
  • type: 'image'로 하는 이미지 인쇄
  • type: 'pdf'로 하는 PDF 파일 인쇄
※ 아래 버튼을 누르면 실제로 브라우저 인쇄 대화상자가 뜹니다. 그냥 취소를 눌러도 됩니다. 예시 데이터는 이 페이지를 위한 가상의 위판 실적이며 실제 통계가 아닙니다.

1. HTML 요소 인쇄

화면에 이미 있는 요소를 id로 지정해서 그대로 인쇄합니다. 화면에는 안 보이지만 인쇄될 때만 쓰는 요소도 만들 수 있습니다.

위판 실적 요약 (2026년 3월, 가상 예시)

총 어획량 680kg, 참여 조합원 12명. 이 문서는 Print.js 데모를 위한 가상의 자료입니다.

소스 코드 보기 
printJS({
  printable: 'html-printable', // 요소의 id
  type: 'html',
  targetStyles: ['*'], // 대상 요소의 스타일을 그대로 유지
  documentTitle: '위판 실적 요약',
});

2. JSON 데이터 표 인쇄

배열 형태의 데이터를 properties로 지정한 컬럼만 골라 표로 변환해서 인쇄합니다. 화면에 표를 미리 그려둘 필요가 없습니다.
소스 코드 보기 
const data = [
  { item: '고등어', catch_kg: 320, price: 4200 },
  { item: '갈치', catch_kg: 150, price: 8900 },
  { item: '오징어', catch_kg: 210, price: 6500 },
];

printJS({
  printable: data,
  type: 'json',
  properties: [
    { field: 'item', displayName: '품목' },
    { field: 'catch_kg', displayName: '어획량(kg)' },
    { field: 'price', displayName: '단가(원)' },
  ],
  documentTitle: '위판 품목별 실적',
});

3. 이미지 인쇄

이미지 URL(또는 data URI)을 type: 'image'로 바로 인쇄할 수 있습니다.
소스 코드 보기 
printJS({
  printable: canvas.toDataURL('image/png'), // 이미지 URL도 가능
  type: 'image',
  documentTitle: '위판 안내 이미지',
});

4. PDF 파일 인쇄

PDF 파일 URL을 주면 내부적으로 내려받아 Blob으로 만든 뒤 인쇄 대화상자를 띄웁니다. (base64: true를 주면 base64로 인코딩된 PDF 데이터를 직접 전달할 수도 있습니다.)
소스 코드 보기 
printJS({
  printable: '/sample.pdf',
  type: 'pdf',
  onError: (error) => console.log('인쇄 실패:', error),
});
