ApexTree 핵심 기능 둘러보기

ApexTree는 SVG 기반으로 조직도·계층 구조를 그리는 차트 라이브러리입니다 (ApexCharts 팀 제작). 노드마다 확장/축소 버튼이 자동으로 붙고, 카드형 노드 템플릿·검색· 브레드크럼(경로 표시)·레이아웃 방향 전환 같은 조직도 특화 기능을 기본 옵션만으로 켤 수 있습니다.
  • 계층형 데이터를 넣으면 자동 배치되는 조직도 트리 + 확장/축소 버튼
  • 아바타·직함·배지가 들어간 내장 카드 템플릿(contentKey: 'data')
  • enableSearch + enableBreadcrumb로 켜는 검색과 경로 추적
  • changeLayout()로 바꾸는 트리 방향과 다중 선택(enableSelection)
※ 아래 조직도는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 조직·직제와 무관합니다. ApexTree는 상업용 라이선스가 필요한 유료 라이브러리이며, 라이선스 키 없이 쓰면 배경에 "APEXCHARTS" 워터마크가 표시됩니다(아래 예시도 라이선스 키 없이 무료 상태 그대로 표시). ApexTree(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 조직도 + 확장/축소

계층형 JSON을 넣기만 하면 트리가 자동으로 배치됩니다. 자식이 있는 노드에는 －/＋ 버튼이 자동으로 붙어 눌러서 접고 펼 수 있습니다.
코드 보기 
const tree = new ApexTree(document.getElementById('tree1'), {
  width: 700, height: 380,
  nodeWidth: 110, nodeHeight: 44,
  direction: 'top',
  edgeColorMode: 'node',              // 가지마다 자식 노드 테두리색을 따라감
});
tree.render({
  id: 'root', name: '수협중앙회',
  children: [
    { id: 'a', name: '경제사업부문', children: [
      { id: 'a1', name: '위판사업팀', children: [] },
      { id: 'a2', name: '유통사업팀', children: [] },
    ]},
    { id: 'b', name: '신용사업부문', children: [ /* ... */ ] },
  ],
});

2. 내장 카드 템플릿

contentKey: 'data'로 바꾸고 각 노드에 title· subtitle·badge·accentColor· meta를 채우면, 커스텀 템플릿 없이도 직함·부서·상태 배지가 담긴 카드가 자동으로 그려집니다.
코드 보기 
const options = {
  contentKey: 'data',
  nodeWidth: 190, nodeHeight: 84,
};
const data = {
  id: 'ceo', name: '회장',
  data: {
    name: '김OO 회장', title: '수협중앙회', subtitle: '임원진',
    accentColor: '#2a78d6',
    badge: { text: '재임중', color: '#e6f0fb' },
    meta: [{ label: '가상 인물' }],
  },
  children: [ /* ... */ ],
};

3. 검색 + Breadcrumb + 툴바

좀 더 큰 조직도입니다. 상단 툴바 검색창에 부서명을 입력하면 일치하는 노드가 강조되고, 뿌리까지의 경로도 함께 표시됩니다. 노드를 클릭하면 그 아래의 브레드크럼(경로)이 갱신됩니다.
코드 보기 
new ApexTree(document.getElementById('tree3'), {
  width: 700, height: 440,
  nodeWidth: 110, nodeHeight: 40,
  enableToolbar: true,
  enableSearch: true,
  enableBreadcrumb: true,
});

4. 레이아웃 방향 전환 + 다중 선택

버튼으로 graph.changeLayout()을 호출해 트리가 자라는 방향을 바꿔볼 수 있습니다. 노드를 클릭하면 enableSelection: 'multi'에 의해 여러 개를 동시에 선택할 수 있고, 선택된 노드 수가 아래에 표시됩니다.
선택된 노드: 0개
코드 보기 
const graph = tree.render(data);
graph.changeLayout('left');    // 'top' | 'bottom' | 'left' | 'right'

// enableSelection: 'multi' 옵션과 함께 사용
graph.onSelectionChange((ids) => {
  console.log('선택된 노드:', ids);
});
