fflate 핵심 기능 둘러보기

fflate(fast + inflate)는 순수 JavaScript로 만든 초경량·고성능 압축 라이브러리입니다. DEFLATE/GZIP/Zlib 압축과 ZIP 아카이브 생성·해제를 브라우저에서 별도 서버 없이 바로 처리할 수 있습니다.
  • gzipSync / gunzipSync로 하는 텍스트 압축 · 해제 (압축률 확인)
  • zipSync로 여러 파일을 묶는 ZIP 아카이브 생성 + 다운로드
  • unzipSync로 ZIP 안의 파일 목록·내용 다시 꺼내보기
  • Deflate 스트림 클래스로 하는 청크 단위 점진적 압축
※ 아래 위판 일지·서류 내용은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계·기록과 무관합니다. 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 텍스트 압축 · 해제

strToU8()로 문자열을 바이트로 바꾼 뒤 gzipSync()로 압축하고, gunzipSync() + strFromU8()로 다시 문자열로 되돌립니다. 반복되는 내용이 많을수록 압축률이 좋아집니다.
소스 코드 보기 
const u8 = fflate.strToU8(text);
const compressed = fflate.gzipSync(u8, { level: 9 });
const ratio = (100 * (1 - compressed.length / u8.length)).toFixed(1) + '%';

const restored = fflate.strFromU8(fflate.gunzipSync(compressed));
console.log(restored === text); // true

2. 여러 파일 ZIP 아카이브 생성 + 다운로드

zipSync()에 중첩된 객체를 넘기면 그대로 폴더 구조가 되는 ZIP 파일을 한 번에 만들 수 있습니다. 결과는 Blob으로 감싸서 바로 다운로드 링크를 만들 수 있습니다.
소스 코드 보기 
const zipped = fflate.zipSync({
  '위판일지': {
    '1월.txt': fflate.strToU8('1월 위판 기록...'),
    '2월.txt': fflate.strToU8('2월 위판 기록...'),
  },
  '조합원명단.txt': fflate.strToU8('홍길동, 김철수, 이영희'),
}, { level: 6 });

const blob = new Blob([zipped], { type: 'application/zip' });
const url = URL.createObjectURL(blob);
// 다운로드

3. ZIP 내용물 다시 풀어보기

바로 위에서 만든 ZIP을 unzipSync()로 다시 풀어서 파일 목록을 확인하고, 클릭하면 내용을 미리 봅니다. 디렉터리 자체도 빈 항목(끝이 /인 키)으로 함께 나오므로 파일 목록에 표시할 때는 걸러내야 합니다.
    소스 코드 보기 
    const unzipped = fflate.unzipSync(zipped);
// unzipped = { '위판일지/': Uint8Array(0), '위판일지/1월.txt': Uint8Array(...), ... }

Object.keys(unzipped)
  .filter((name) => !name.endsWith('/'))   // 디렉터리 항목 제외
  .forEach((name) => {
    console.log(name, fflate.strFromU8(unzipped[name]));
  });

    4. 스트림으로 청크 단위 압축

    큰 데이터를 한 번에 메모리에 올리지 않고 조각(청크) 단위로 순차 압축하고 싶을 때는 Deflate 클래스를 씁니다. push()를 호출할 때마다 압축된 조각이 ondata 콜백으로 나오고, 마지막 조각에는 true를 넘겨 스트림을 마무리합니다.
    소스 코드 보기 
    const chunks = [];
const deflateStream = new fflate.Deflate({ level: 6 }, (chunk, isLast) => {
  chunks.push(chunk);   // 압축된 조각이 준비될 때마다 호출됨
});

deflateStream.push(fflate.strToU8('1번째 위판 기록 조각...'), false);
deflateStream.push(fflate.strToU8('2번째 위판 기록 조각...'), false);
deflateStream.push(fflate.strToU8('3번째(마지막) 조각...'), true); // 마지막은 true

// 조각들을 이어 붙이면 fflate.inflateSync()로 원본 복원 가능
