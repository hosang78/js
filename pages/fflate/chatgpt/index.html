8. API 맵과 실행 로그
  • fflate는 데이터를 주로 Uint8Array로 주고받는다.
  • 작은 데이터는 동기 API가 간단하지만, 큰 데이터는 비동기 또는 스트리밍 API가 UI 멈춤을 줄인다.
  • ZIP 암호화, RAR, 7z, Brotli 기능은 이 라이브러리 범위가 아니다.
  • 이미 압축된 JPEG, PNG, MP4 등은 다시 압축해도 크기 감소가 거의 없으므로 ZIP STORE가 유리할 수 있다.
  • 이 파일은 CDN에서 fflate를 불러오므로 최초 실행 시 인터넷 연결이 필요하다.
