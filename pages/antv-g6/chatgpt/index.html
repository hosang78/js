관계형 데이터 시각화, 레이아웃 전환, 노드·엣지·콤보, 선택/드래그/줌, 플러그인, 데이터 조작, 검색·필터·분석 기능을 한 화면에서 확인하는 데모입니다.

그래프 제어

레이아웃 선택
레이아웃 전환 시 그래프를 안전하게 재생성합니다. CDN 또는 브라우저 환경에 따라 일부 레이아웃은 기본 레이아웃으로 대체될 수 있습니다.
표시 옵션
데이터 조작
G6 데이터 API의 add/update/remove 개념을 샘플 데이터 재생성 방식으로 체험할 수 있게 구성했습니다.
검색·필터
분석 기능
알고리즘은 샘플 내부 JS로 계산하고, 결과를 G6 스타일에 반영합니다.
내보내기
마우스 휠: 줌 드래그: 캔버스/노드 이동 클릭: 선택/로그
준비 중
G6 로딩 또는 렌더링 실패
외부망 차단 환경에서는 CDN 스크립트를 불러올 수 없어 실제 그래프가 보이지 않을 수 있습니다.
사내망에서 사용하려면 @antv/g6의 g6.min.js 파일을 내려받아 로컬 경로로 바꾸면 됩니다.
