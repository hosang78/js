AntV G6 핵심 기능 둘러보기

AntV G6는 앤트그룹(Ant Group)이 만든 그래프 시각화 라이브러리로, 다양한 내장 레이아웃 알고리즘과 노드를 묶어 보여주는 Combo, 선언적인 상태(state) 스타일 시스템이 특징입니다.
  • 드래그로 캔버스 이동, 휠 확대/축소, 노드 드래그 같은 기본 동작(behaviors)
  • force·circular·grid·dagre 등 여러 내장 레이아웃 알고리즘을 코드 몇 줄로 전환
  • combo로 관련 노드들을 하나의 그룹 도형으로 묶어서 표시
  • 호버·클릭 시 state 설정에 따라 스타일이 자동으로 바뀌는 상태 시스템
※ 아래 유통 네트워크는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 유통 구조와 무관합니다. AntV G6(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 그래프 + 기본 동작

가상 위판장 유통 네트워크입니다. 빈 곳을 드래그해 캔버스를 이동하고, 휠로 확대/축소하고, 노드를 직접 드래그해보세요.
위판장
중도매인
소매상
코드 보기 
const graph = new G6.Graph({
  container: "g6-1",
  data: { nodes, edges },
  node: { style: { labelText: (d) => d.data.label, fill: (d) => d.data.color } },
  layout: { type: "force" },
  behaviors: ["drag-canvas", "zoom-canvas", "drag-node"]
});
await graph.render();

2. 내장 레이아웃 알고리즘 전환

같은 그래프를 여러 레이아웃 알고리즘으로 다시 배치해봅니다.
코드 보기 
await graph.setLayout({ type: "circular" });
await graph.layout(); // setLayout만으로는 재배치되지 않고 layout()을 호출해야 적용됨

3. Combo — 노드 그룹핑

가상 조합원들을 소속 위판장별로 묶어서 보여줍니다. Combo 자체도 드래그로 통째로 옮길 수 있습니다.
코드 보기 
const data = {
  nodes: [
    { id: "m1", combo: "c1", data: { label: "1번 위판장" } },
    { id: "member1", combo: "c1", data: { label: "조합원 A" } },
    // ...
  ],
  combos: [
    { id: "c1", data: { label: "1번 위판장 소속" } },
    { id: "c2", data: { label: "2번 위판장 소속" } }
  ]
};

4. 상태(state) 스타일 — 호버/클릭

노드 위에 마우스를 올리면 강조되고, 클릭하면 선택 상태로 고정됩니다. 상태별 스타일은 설정만 해두면 G6가 자동으로 적용합니다. 단, hover-activate 동작이 실제로 켜는 상태 이름은 "hover"가 아니라 "active"이니 state 설정의 키도 그에 맞춰야 실제로 스타일이 바뀝니다.
노드를 클릭하거나 마우스를 올려보세요.
코드 보기 
node: {
  style: { fill: "#2a78d6" },
  state: {
    active: { fill: "#eda100" },
    selected: { fill: "#e34948", lineWidth: 2, stroke: "#a13c3b" }
  }
},
behaviors: ["drag-canvas", "zoom-canvas", "hover-activate", "click-select"]
