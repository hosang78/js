Dygraphs 핵심 기능 둘러보기

Dygraphs는 2011년부터 이어져 온 순수 JS 시계열 차트 라이브러리로, 수만 개의 점도 매끄럽게 그리는 렌더링 성능과 마우스 드래그로 바로 확대되는 인터랙션, 세밀하게 커스터마이즈 가능한 범례로 잘 알려져 있습니다.
  • 다중 계열 라인차트 + legendFormatter로 만드는 커스텀 인터랙티브 범례
  • showRangeSelector로 켜는 내장 미니맵 확대/축소
  • customBars로 그리는 변동폭(최저~최고) 음영 밴드
  • setVisibility()로 하는 시리즈 표시/숨기기 토글
※ 아래 위판 시세 데이터는 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 통계와 무관합니다. Dygraphs(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 다중 계열 라인차트 + 커스텀 범례

3개 위판장의 90일간 일별 시세입니다. 차트 위에서 마우스를 움직이면 legendFormatter로 만든 범례가 그 날짜의 값을 보여주고, 해당 계열의 선은 굵게 강조됩니다.
차트 위에 마우스를 올려보세요
코드 보기 
new Dygraph(document.getElementById('chart1'), data, {
  labels: ['날짜', 'A위판장', 'B위판장', 'C위판장'],
  colors: ['#2a78d6', '#1baf7a', '#eda100'],
  highlightSeriesOpacity: 0.25,          // 강조되지 않은 선은 흐리게
  legend: 'always',
  labelsDiv: document.getElementById('legend1'),
  legendFormatter: (data) => {
    if (data.x == null) return '차트 위에 마우스를 올려보세요';
    return data.xHTML + '   ' + data.series.map(
      (s) => `${s.dashHTML} ${s.labelHTML}: ${s.yHTML}`
    ).join('   ');
  },
});

2. 내장 Range Selector로 확대/축소

showRangeSelector: true 하나만 켜면 차트 아래 미니맵이 생깁니다. 미니맵의 양 끝 손잡이를 드래그하면 위쪽 메인 차트가 해당 구간으로 확대됩니다.
코드 보기 
new Dygraph(document.getElementById('chart2'), data, {
  labels: ['날짜', 'A위판장', 'B위판장', 'C위판장'],
  colors: ['#2a78d6', '#1baf7a', '#eda100'],
  showRangeSelector: true,
  rangeSelectorHeight: 40,
  rangeSelectorPlotStrokeColor: '#4f7dff',
  rangeSelectorPlotFillColor: '#dbe4ff',
});

3. Custom Bars — 변동폭 음영 밴드

각 값을 [최저, 평균, 최고] 세 숫자로 넘기면, 평균선 주변에 그날의 변동폭(최저~최고)을 옅은 음영으로 함께 그려줍니다. 시세가 하루 중 얼마나 출렁였는지 한눈에 보입니다.
코드 보기 
// 각 셀이 숫자 하나가 아니라 [최저, 평균, 최고] 배열
const data = days.map((date, i) => [date, [low[i], mid[i], high[i]]]);

new Dygraph(document.getElementById('chart3'), data, {
  labels: ['날짜', '고등어 평균 시세'],
  customBars: true,                      // [low, mid, high] 형식으로 해석
  color: '#2a78d6',
});

4. 시리즈 표시/숨기기 토글

체크박스를 해제하면 setVisibility()로 해당 위판장의 선을 차트에서 숨깁니다. 축 범위는 남아있는 계열에 맞춰 다시 계산됩니다.
코드 보기 
checkbox.addEventListener('change', (e) => {
  g.setVisibility(seriesIndex, e.target.checked);
});
