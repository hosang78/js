Dygraphs 기능 종합 샘플

시계열 데이터 탐색에 특화된 Dygraphs의 핵심 기능을 한 페이지에 모았다. 드래그 확대, 더블클릭 초기화, Range Selector, Roller 평균, 주석, 콜백, 다중 축, 로그축, 결측치, 에러밴드, 동기화, 실시간 업데이트, CSV 편집을 모두 직접 눌러볼 수 있다.

Time Series Range Selector Annotations Dual Axis Custom Bars Synchronized Zoom Callbacks CSV Import
Dygraphs 라이브러리를 불러오지 못했다. 인터넷 연결 또는 CDN 접근 가능 여부를 확인해야 한다.

1. 메인 시계열: 확대·이동·범위 선택·Roller·주석

마우스로 구간을 드래그하면 확대되고, 더블클릭하면 초기화된다. Range Selector 하단 미니 차트로 빠르게 기간을 선택할 수 있으며, Roller는 이동평균 기간을 조정한다.

-데이터 행
-현재 표시 범위
-선택 포인트
0줌 이벤트

2. 다중 Y축·배경 음영·이벤트 라인

수온은 좌측 축, 기압은 우측 축에 배치했다. underlayCallback으로 특정 기간 음영과 기준선을 직접 그린다.

3. 에러밴드·예측구간 Custom Bars

customBars 옵션으로 [하한, 중심값, 상한] 형태의 데이터를 표현한다. 관측치 주변의 예측구간이나 신뢰구간 시연에 적합하다.

4. 결측치·계단형 그래프·점 표시

null 값이 들어간 시계열을 연결하거나 끊어 표시할 수 있다. stepPlot, drawPoints를 통해 상태값·등급값 같은 데이터를 표현한다.

5. 실시간 데이터 추가·업데이트

setInterval로 새 포인트를 추가하고 updateOptions({file: data})로 차트를 갱신한다. 운영 모니터링 화면의 기본 구조와 비슷하다.

6. 동기화 차트: 하나를 확대하면 같이 움직임

extras/synchronizer.js를 사용해 여러 Dygraph 인스턴스의 줌, 선택, 범위를 연결한다. 위 차트나 아래 차트 중 하나를 드래그해 확인한다.

7. CSV 직접 편집·불러오기

Dygraphs는 CSV 문자열도 바로 입력받을 수 있다. 아래 CSV를 수정한 뒤 다시 그리기를 눌러보면 된다.

8. 콜백·이벤트 로그

highlightCallback, pointClickCallback, zoomCallback, annotationClickHandler 등에서 발생한 이벤트를 실시간으로 기록한다.

highlightCallback unhighlightCallback pointClickCallback zoomCallback drawCallback annotationClickHandler underlayCallback

사용 팁: PC에서는 드래그로 확대, 더블클릭으로 초기화, Shift+드래그로 이동을 시도해볼 수 있다. 모바일에서는 브라우저·기기별 터치 이벤트 처리 방식이 달라 일부 세밀한 조작이 제한될 수 있다. CDN 방식이므로 오프라인 또는 폐쇄망에서는 dygraph.min.js, dygraph.min.css, extras/synchronizer.js를 내부 경로로 바꿔야 한다.
