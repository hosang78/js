직접 확인할 수 있는 기능

항목 유형(box·point·range·background), 그룹·중첩 그룹·서브그룹, 드래그 이동·그룹 변경·범위 조절, 다중 선택, 그룹 순서 변경, 클러스터, 숨김 날짜, 커스텀 시간선, 툴팁·템플릿, 검색 강조, 이벤트 로그, JSON 입출력, localStorage 저장 기능을 포함한다.

추천 실험 순서

  1. 전체 맞춤 후 확대·축소와 화면 이동을 시험한다.
  2. 항목을 선택해 오른쪽 편집기에서 제목·기간·그룹·상태를 바꾼다.
  3. 클러스터를 켜고 ‘클러스터 실험’ 그룹의 밀집 항목이 묶이는지 확인한다.
  4. 주말 숨김, 축 위치, 쌓기, 롤링 모드 등 옵션을 바꾼다.
  5. 외부 항목 카드를 원하는 날짜·그룹으로 끌어 놓는다.
  6. JSON 입출력에서 현재 데이터를 백업하거나 수정된 JSON을 다시 적용한다.

키보드: F 전체 맞춤, T 오늘, + 확대, - 축소, N 새 항목, Delete 선택 삭제
