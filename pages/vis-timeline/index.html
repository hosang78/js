vis-timeline 핵심 기능 둘러보기

vis-timeline은 일정·이벤트를 가로 시간축 위에 막대나 점으로 표시해주는 라이브러리입니다. 확대/축소, 드래그 이동, 그룹별 행 구분, 아이템 편집(추가·이동·삭제)까지 지원합니다.
  • 마우스 휠로 확대/축소, 드래그로 시간축 이동
  • 그룹(행)별로 아이템을 나눠서 표시
  • 기간이 있는 range, 특정 시점만 표시하는 point, 배경으로 깔리는 background 세 가지 아이템 종류
  • 드래그로 일정 이동·기간 조절, 버튼/더블클릭으로 추가, 선택 후 × 버튼으로 삭제하는 편집 모드
※ 아래 위판 일정은 이 페이지를 위해 만든 가상의 예시이며, 실제 수협중앙회의 위판 일정과 무관합니다. vis-timeline(CDN) 하나만 사용하고 다른 외부 라이브러리나 API는 사용하지 않습니다.

1. 기본 타임라인

가상 조합 행사 일정입니다. 마우스 휠로 확대/축소, 드래그로 좌우 이동해보세요.
코드 보기 
const items = new vis.DataSet([
  { id: 1, content: "정기총회", start: "2026-07-03" },
  { id: 2, content: "위판장 시설 점검", start: "2026-07-08", end: "2026-07-10" },
  // ...
]);

new vis.Timeline(container, items, {
  start: "2026-06-28",
  end: "2026-07-20"
});

2. 그룹별 타임라인

위판장별로 행을 나눠서 일정을 비교합니다.
1번 위판장
2번 위판장
3번 위판장
코드 보기 
const groups = new vis.DataSet([
  { id: 1, content: "1번 위판장" },
  { id: 2, content: "2번 위판장" },
  { id: 3, content: "3번 위판장" }
]);
const items = new vis.DataSet([
  { id: 1, group: 1, content: "고등어 위판", start: "2026-07-01", end: "2026-07-05" },
  { id: 2, group: 2, content: "갈치 위판", start: "2026-07-03", end: "2026-07-08" },
  // ...
]);

new vis.Timeline(container, items, groups, { start: "2026-06-28", end: "2026-07-20" });

3. 아이템 종류 — point / range / background

■ range는 기간이 있는 일정(위판 기간), ● point는 특정 시점(서류 마감일), ▭ background는 기간 전체를 배경으로 표시(휴무 기간)합니다.
코드 보기 
const items = new vis.DataSet([
  { id: 1, content: "고등어 위판 기간", start: "2026-07-01", end: "2026-07-06", type: "range", className: "item-range" },
  { id: 2, content: "서류 마감일", start: "2026-07-09", type: "point", className: "item-point" },
  { id: 3, content: "휴무 기간", start: "2026-07-12", end: "2026-07-14", type: "background", className: "item-bg" }
]);

4. 아이템 편집

아이템을 드래그해 옮기거나 가장자리를 끌어 기간을 조절할 수 있습니다. 아이템을 클릭해 선택하면 나타나는 × 버튼으로 삭제하고, 버튼으로 새 일정을 추가해보세요(빈 곳을 더블클릭해도 추가됩니다).
아이템을 옮기거나 클릭해서 선택해보세요.
코드 보기 
const timeline = new vis.Timeline(container, items, {
  editable: {
    add: true,             // 빈 곳 더블클릭으로 추가
    updateTime: true,       // 드래그로 이동
    updateGroup: false,
    remove: true            // 선택 후 나타나는 × 버튼으로 삭제
  },
  onAdd: (item, callback) => {
    item.content = "새 일정";
    callback(item); // callback(null)이면 추가 취소
  }
});

items.on("update", (event, props) => {
  console.log("이동/수정된 아이템:", props.items);
});
