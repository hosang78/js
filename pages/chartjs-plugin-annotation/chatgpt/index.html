1. 선 주석 종합

수평/수직/대각선, 곡선, 화살표, 다중 라벨, 점선 및 런타임 임계값
LINE
구현 포인트 보기
scaleID + value / xMin·xMax·yMin·yMax
curve, controlPoint, arrowHeads
label.display, label.position, borderDash

2. 박스 주석 종합

목표 구간, 경고 구간, 둥근 테두리, 회전 라벨, drawTime과 z 순서
BOX
구현 포인트 보기
xMin, xMax, yMin, yMax
backgroundColor, borderRadius, borderDash
drawTime, z, label.rotation

3. 라벨·포인트·타원·다각형

독립 라벨, 콜아웃, 포인트 스타일, 타원, 삼각형·육각형 강조
SHAPES
구현 포인트 보기
type: label / point / ellipse / polygon
pointStyle, radius, sides, rotation
label.callout, content 배열(여러 줄)

4. 클릭·호버·드래그 상호작용

주석 이벤트 콜백, 커서 변경, 직접 드래그, 이벤트 로그
INTERACTION
주석 위로 마우스를 이동하거나, 박스를 드래그해 봐.

5. 스크립터블 옵션·컨텍스트

데이터 상태에 따라 색상·표시 여부·텍스트를 함수로 동적 결정
SCRIPTABLE
구현 포인트 보기
borderColor: (ctx) => ...
display: (ctx) => ...
label.content: (ctx) => ...
옵션 resolver를 통한 다른 옵션 참조

6. 동적 생성·삭제·수정

런타임에 주석 객체 추가, 선택 삭제, 전체 삭제, JSON 상태 확인
RUNTIME

7. 카테고리 축·로그 축

카테고리 값 지정과 로그 스케일 구간 표시 예시
SCALES

8. 기능 체크리스트

이 페이지에 포함된 주요 기능 확인
SUMMARY
분류포함 기능상태
기본 타입선, 박스, 라벨, 포인트, 타원, 다각형포함
선 확장곡선, 제어점, 화살표, 점선, 대각선포함
라벨위치, 회전, 다중 줄, 콜아웃, 스타일포함
렌더링drawTime, z-order, animation포함
상호작용enter, leave, click, drag포함
고급 옵션scriptable, context, dynamic CRUD포함
축linear, category, logarithmic포함
주의: 플러그인은 정확히 2개의 축을 갖는 차트에 적합하며, pie/radar/polarArea 같은 차트에는 일반 주석이 적용되지 않는다.
CDN 연결이 필요해. 내부망에서 사용할 경우 Chart.js UMD 파일과 chartjs-plugin-annotation 배포 파일을 내려받아 script 경로만 로컬 파일로 바꾸면 된다.
