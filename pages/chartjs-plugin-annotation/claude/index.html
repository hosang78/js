chartjs-plugin-annotation 핵심 기능 둘러보기

chartjs-plugin-annotation은 Chart.js 위에 선·박스·점·텍스트· 도형 등을 겹쳐 그려주는 공식 주석(annotation) 플러그인입니다. 목표선, 임계 구간, 특이 지점 설명 같은 것을 차트 데이터와 별개로 얹을 수 있습니다.
  • Chart.register(window['chartjs-plugin-annotation'])로 등록 (반드시 등록해야 동작)
  • type: 'line' | 'box' | 'point' | 'label' | 'polygon' | 'ellipse' | 'doughnutLabel'로 종류 지정
  • 각 주석에 click/enter/leave 콜백을 걸어 마우스 상호작용 가능
  • 좌표는 xMin/xMax/yMin/yMax(선/박스) 또는 xValue/yValue(점/라벨)로 지정
※ 이 페이지의 위판 실적 데이터는 모두 가상의 예시이며 실제 수협중앙회의 자료가 아닙니다. 차트 렌더링을 위해 Chart.js를 함께 사용했습니다 (CDN).

1. 기준선(line) + 구간 강조(box)

목표 위판량 100kg 지점에 빨간 점선 기준선을 긋고, 4~5월 성수기 구간을 초록 배경 박스로 강조합니다.
코드 보기 
annotation: {
  annotations: {
    targetLine: {
      type: 'line',
      yMin: 100, yMax: 100,
      borderColor: '#e0524a',
      borderDash: [6, 6],
      label: { display: true, content: '목표 100kg', position: 'end' },
    },
    peakSeason: {
      type: 'box',
      xMin: 2.5, xMax: 4.5, // 4월~5월 구간
      backgroundColor: 'rgba(34,192,122,0.15)',
    },
  },
}

2. 특정 지점 강조 + 클릭 상호작용

주간 위판량 중 최고치 지점에 point 주석을 찍었습니다. 빨간 점을 클릭해보세요.
아직 클릭 안 함
코드 보기 
annotation: {
  annotations: {
    peakPoint: {
      type: 'point',
      xValue: '3주', yValue: 80,
      backgroundColor: '#e0524a',
      radius: 8,
      click(ctx) { showPeakInfo(); },
    },
  },
}

3. 화살표 콜아웃 텍스트 (label)

이상치로 보이는 지점을 화살표가 달린 텍스트 박스로 설명합니다. (검증 중 발견: label 주석은 기본적으로 차트 영역 밖으로 나가면 잘려 보이지 않아, y축에 여유 공간을 미리 확보해야 했습니다.)
코드 보기 
annotation: {
  annotations: {
    callout: {
      type: 'label',
      xValue: '수요일', yValue: 40,
      content: ['평소 대비 급증'],
      callout: { display: true, side: 10 },
      yAdjust: -30, // 차트 영역 밖으로 나가지 않도록 y축에 여유(suggestedMax) 확보 필요
    },
  },
}

4. 도넛 차트 중앙 라벨 (doughnutLabel)

도넛 차트 가운데 빈 공간에 합계 텍스트를 표시합니다. 일반 도넛 차트로는 캔버스에 직접 텍스트를 그리는 코드가 필요하지만, 이 주석 타입 하나로 해결됩니다.
코드 보기 
annotation: {
  annotations: {
    centerLabel: {
      type: 'doughnutLabel',
      content: ['2,830kg', '이번 달 총 위판량'],
      font: [{ size: 22, weight: 'bold' }, { size: 12 }],
    },
  },
}
